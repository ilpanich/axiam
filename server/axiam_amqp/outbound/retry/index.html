The bounded exponential retry policy, generic over kind.

The policy is the one webhooks already had (D-08/D-20), now parameterised by the env-var prefix: AXIAM__<SLUG>__MAX_ATTEMPTS, AXIAM__<SLUG>__BACKOFF_BASE_MS, AXIAM__<SLUG>__BACKOFF_CEILING_MS. For [OutboundKind::Webhook] those are exactly the three AXIAM__WEBHOOK__* variables operators already set.

Structs§

OutboundRetryConfig
Retry policy for one outbound kind. Every field has a safe default and is fully overridable; nothing is mandatory for the server to boot.

Functions§

backoff_ttl_ms
Bounded exponential backoff (D-08): base_ms * 2^(attempt-1), clamped to [0, ceiling_ms]. The result becomes the retry queue’s per-message TTL, not an in-process sleep, so no consumer slot is held for its duration.
env_var_name
The environment variable suffix (MAX_ATTEMPTS, BACKOFF_BASE_MS, BACKOFF_CEILING_MS) is read from for kind: AXIAM__<SLUG>__<suffix>.
