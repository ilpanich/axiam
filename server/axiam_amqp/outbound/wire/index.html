The bytes on the queue.

SA-14 (N3): every message travels inside the server-only signed envelope of crate::internal_envelope, with purpose outbound.<slug>. seal and the consumer’s gate own the envelope; this module owns its body.

The webhook kind’s body keeps its pre-extraction format: the JSON of WebhookMessage (webhook_id, delivery_id, tenant_id, event_type, payload, attempt), which is also what an old replica wrote un-enveloped and what AXIAM__AMQP__INTERNAL_QUEUES__REQUIRE_SIGNATURE=false still admits during a rolling upgrade.

Every other kind’s body is the plain JSON of OutboundMessage, which carries its own kind. A new kind needs no code here; it takes the generic path by default.
