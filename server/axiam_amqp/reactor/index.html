Reactors (X1) — AMQP-native extension actors.

See [axiam_core::models::reactor] for the event registry and the domain model; this module is the wire protocol, the dispatch chain, and the gate that joins them to a routing table, a concurrency bound, the audit trail and a set of counters.

The split across the two crates is the design: axiam-auth, axiam-oauth2 and the REST handlers call reactors through ReactorGate, which lives in axiam-core, so the crates that issue tokens and sessions never learn that a message broker is involved.
