Module tenant_admission 

Source
Expand description

Per-request tenant lifecycle enforcement for the gRPC listener (SA-13, N16, D-3).

A suspended tenant’s principals are refused at every authentication door, and this listener is one: a token a suspended tenant’s user or service account obtained before the suspension stays cryptographically valid until it expires, and the verifying interceptor (middleware::auth) checks nothing else. Unlike the session check (middleware::strict_revocation, opt-in for latency), this one is always on — D-3 makes suspension refuse API requests, with no transport excepted.

§Why a tower::Layer and not the interceptor

For the reason strict_revocation gives: Interceptor::call is synchronous, and the tenant’s status is a datastore read.

§Why deciding on unverified claims is sound

Also strict_revocation’s argument: this layer can only deny. A request it lets through still meets the verifying interceptor, so a forged token can at most be passed on here and refused there. It denies when the claims name a tenant whose stored status does not admit principals (axiam_core::models::tenant::tenant_accepts_principals).

An undecodable token, and a tenant that is not stored, fall through: the interceptor refuses the first, and the second is a tombstoned or unknown tenant, whose sessions and clients are revoked elsewhere.

§A datastore error refuses

Unlike strict_revocation, this layer fails closed: when the tenant cannot be read the call is answered UNAVAILABLE with a generic message (the error itself is logged). No service behind the listener re-checks the tenant’s status, so passing the call on would admit a possibly suspended tenant’s token whenever the read failed. This matches the REST extractor and the AMQP consumer, which also refuse on “could not tell”.

§Cost

One tenant read per authenticated call. There is no tenant-status cache to reuse (tenant_org_cache caches the organization mapping, which never changes; status does), and none is added: a suspension takes effect at the next call, on every replica.
