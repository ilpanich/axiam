Expand description

The authorization decision UserServiceImpl needs: may subject_id of tenant_id perform action, globally (resource nil — REST’s RequirePermission::new(action, Uuid::nil())).

A trait object rather than five more type parameters, for the reason lockout_policy is one: this service is generic over U alone, and the engine’s five repository parameters would reach every call site and every test double. Production passes an [AuthorizationEngine], which implements it.
