Expand description

What the route guard needs to know about an authenticated caller: who it is, which tenant it acts on, and where its grants live.

Implemented by both extractors, so that RequirePermission::check reads the same three facts from a user and from a service account and a handler that switches extractor (S-9) changes its signature and nothing else.
