Resolve a URL-shaped client_id into a shadow client row, if this tenant admits one.

Returns nothing on purpose: see the module header. The caller’s next step is the client lookup it was always going to make.

§Cost on the path that is not CIMD

Two starts_with calls. Every client_id AXIAM has ever issued is oa_ followed by hex, so the overwhelming majority of requests leave this function having read no setting, taken no lock and touched no socket. The settings read happens only for a client_id that is literally an http/https URL — which, on a deployment that has not enabled CIMD, is a request that was going to be refused anyway.
