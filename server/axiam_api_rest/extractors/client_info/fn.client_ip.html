pub fn client_ip(req: &HttpRequest) -> Option<String>
Expand description

Extract the client IP by the rate limiters’ rule, capped to MAX_IP_LEN.

The rightmost untrusted X-Forwarded-For hop under AXIAM__RATE_LIMIT__TRUSTED_HOPS, read only from a peer inside AXIAM__RATE_LIMIT__TRUSTED_PROXIES (every peer with the list empty); otherwise the transport peer ([axiam_core::forwarded_for::select_client_ip]). The audit rows and the http.client_ip log field follow the same rule (#752, T-212), so a row, a log line and a rate-limit bucket name one address.

§What this still is not

With TRUSTED_PROXIES empty (the default) every peer’s header is read, so behind no appending proxy the value is whatever the caller typed. List the proxies in front of the server to close that; on an unauthenticated path peer_ip is still the stricter choice (SEC-087, §22.3).
