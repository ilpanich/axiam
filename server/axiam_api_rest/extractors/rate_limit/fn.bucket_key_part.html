The identity part of a bucket key — {endpoint}:{this} in the shared counter, the whole key in the in-memory governor — for every key mode.

One function for both layers, so the shared counter (crate::middleware::rate_limit_shared::RateLimitShared) and the in-process governor (ClientAwareKeyExtractor) can never disagree about which bucket a request belongs to: with AXIAM__RATE_LIMIT__SHARED on or off, a route keys the same way.

None only when the key needs the address and there is none; the caller then fails open (shared layer) or refuses the key (governor), as before.
