The client_id a request names itself by: the form body’s when present, otherwise the Authorization: Basic header’s.

The body wins because that is the order the handlers resolve it in (resolve_client_id), and a request naming two different ids is refused there before any secret is checked, so a caller cannot use the disagreement to guess a secret under a bucket other than the one it is charged to.
