Reactor management endpoints (X1).

A registration decides whether third-party code can veto a login or add a claim to a token, so every write goes through axiam_core::models::reactor::validate_registration against the same EVENT_REGISTRY the dispatcher reads. Restating the valid event set here would create a second source of truth, and the one that drifted would be whichever nobody was looking at.
