Expand description

Admin endpoints for SCIM provisioning tokens.

See claude_dev/scim-provisioning-token-design.md. These mint, list and revoke the long-lived credential an IdP pastes into its SCIM connector; the credential itself is consumed in axiam_scim, never here.

Gated on scim_tokens:*, deliberately separate from scim:provision: minting a credential for a provisioner is an administrative act, and the provisioner should not be able to mint more of itself.
