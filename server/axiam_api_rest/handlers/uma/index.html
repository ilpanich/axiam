X2 — the UMA 2.0 HTTP surface: the permission endpoint and discovery.

The uma-ticket grant itself lives in crate::handlers::oauth2, because actix deserializes the token endpoint’s body once and the grant is not knowable until grant_type has been read out of it — the same reason the device and token-exchange grants are dispatched there rather than routed.
