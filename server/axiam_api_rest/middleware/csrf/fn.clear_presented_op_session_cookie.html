pub fn clear_presented_op_session_cookie(
    tenant_path: Option<Uuid>,
) -> Cookie<'static>
Expand description

The removal for the one OP-session cookie the request in hand could have carried: the per-tenant one on a /t/{tenant_id}/… request, the bare one otherwise (T23.1.8).

For a handler that has just found the presented cookie stale. It clears the copy that proved stale and nothing else: the other paths may carry a value minted by a later sign-in into another tenant, which is still good there.
