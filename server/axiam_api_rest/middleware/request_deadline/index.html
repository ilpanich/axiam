F4 P23W3-03 — the request tracer’s root span, query values redacted (T-325). A bound on how long a REST request may take, used with the WebSocket database engine (AXIAM__DB__ENGINE=ws).

The WebSocket engine does not fail a query while it reconnects to the database: the query waits for the connection to come back. The SDK offers no per-query timeout on its remote engines, so the bound is applied here, to the whole request: one that has not answered within the deadline is answered 503 Service Unavailable with Retry-After, and the work behind it is dropped. With the HTTP engine (the default) the server is built with no deadline and this middleware passes every request straight through.

The deadline (AXIAM__DB__WS_REQUEST_DEADLINE_SECS, 60 s by default) sits above the longest legitimate request — an SSF long poll waits up to 30 s — so a healthy request never meets it.
