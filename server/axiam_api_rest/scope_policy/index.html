§What is cached, and what is not

The tenant_id → organization_id mapping comes from crate::tenant_org_cache, which is immutable for a tenant’s lifetime and therefore safe to remember (see that module). The policy is read fresh on every call: caching it would reintroduce exactly the delay #613 removes, a withdrawn scope still being served after the tenant withdrew it. The cost is paid only for an externally registered client — axiam_oauth2’s scope_ceiling::applies_to is answered from the client row before this is reached — and it is the read crate::cimd::materialise_if_cimd already makes for every URL-shaped client_id.
