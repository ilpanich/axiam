Expand description

The management API’s way to start a reconciliation. A port, because the deliverer that makes the run lives in axiam-scim, which sits above this crate (layer 7) and so cannot be named here; axiam-scim implements it (ReconcileLauncher) and the composition root binds it.

fn start<'a>( &'a self, tenant_id: Uuid, target_id: Uuid, ) -> Pin<Box<dyn Future<Output = Result<ScimReconcileStart, AxiamError>> + Send + 'a>>

Take the target’s reconciliation claim and, when it is taken, make the run in the background. Answers as soon as the claim is decided.

§Errors

NotFound when the target does not exist in the tenant; any other failure of the datastore while claiming.
