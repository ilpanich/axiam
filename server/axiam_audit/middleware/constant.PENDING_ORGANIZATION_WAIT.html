pub const PENDING_ORGANIZATION_WAIT: Duration;
Expand description

How long after a row is queued the audit worker may still wait for its PendingAuditOrganization; past that it appends the row without one. One point read; a datastore that does not answer within this would not take the append either, and the worker must not stall behind it indefinitely.

The bound runs from when the row was queued, not from when the worker reaches it (QR5-2): rows whose lookups stall together expire together, so N of them hold the worker about one wait in total, not N waits one after another while every row behind them backs up into the dead-letter file.
