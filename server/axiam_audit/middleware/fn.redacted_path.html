pub fn redacted_path(path: &str, pattern: Option<&str>) -> String
Expand description

path with every segment that pattern (the matched route) marks with a BEARER_ROUTE_PATTERNS placeholder replaced by REDACTED_PATH_SEGMENT.

Fails closed for the routes in BEARER_ROUTE_PATTERNS. A request shaped wrongly for its route (a trailing /, a doubled //) matches no pattern, so the router answers 404 without ever consuming the single-use handle in it; the handle is still valid, and copying it verbatim into an append-only audit row would hand it to every reader of the log. With no usable pattern, the segment that follows a pattern’s literal prefix (ignoring empty segments) is redacted instead. This covers only the routes listed there: a bearer value in a route that is not listed is recorded as-is, matched or not.
