Expand description

Something that reacts to an audit event after it has been recorded.

Exactly one implementation today — the notification-rule dispatcher, which turns “a certificate was revoked” into email to the addresses an administrator listed. It is a trait rather than a direct call because the dispatcher is generic over its rule repository and its mail publisher, and AuditMiddleware is deliberately not generic over anything: it wraps every route in the application, so a type parameter here would spread through the whole server builder.

Runs after the append and never blocks the response — the worker is already off the request path. An implementation must not propagate errors; audit recording is the guarantee here, and notification is best-effort on top of it.
