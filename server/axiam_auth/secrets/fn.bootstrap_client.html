pub fn bootstrap_client() -> AxiamResult<Client>
Expand description

The short-lived HTTP client the composition root hands to SecretProviderKind::build before the shared client exists.

It never follows a redirect (T-476, #620): a 3xx from Vault arrives as an ordinary response, which VaultSecretProvider::fetch turns into an error naming the host that answered. It trusts the built-in roots only; a Vault behind a private CA is handled by build, which makes a second client.

§Errors

[AxiamError::Internal] if the TLS backend cannot be initialised.
