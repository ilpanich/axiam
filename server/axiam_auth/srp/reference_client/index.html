Expand description

A minimal SRP-6a client, used by this crate’s tests and by the integration tests in axiam-api-rest.

It is deliberately compiled into the library rather than living in a test module: the eleven SDKs each implement this same computation, and this is the executable definition they are checked against. It performs no KDF — callers pass x directly — because the KDF is the one part that differs by language and is specified in sdks/CONTRACT.md rather than here.
