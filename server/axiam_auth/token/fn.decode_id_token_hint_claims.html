Verify an id_token_hint with validation and return its claims, or None when it is not an ID token this key signed.

Two rules beyond the signature, applied by both hint decoders (end-session and /oauth2/authorize, CIBA):

  1. Header. The typ is an ID token’s own JWT, or absent. An access token (at+jwt), a purpose token or a logout token is refused, however well its claims fit IdTokenClaims (Q-8 / S-10).
  2. Claims. None of [NEVER_IN_AN_ID_TOKEN] is present. Rule 1 cannot tell an access token minted before SA-03 (typ: JWT) from an ID token, and the hint decoders skip exp, so without this rule every such token would stay a valid hint for good (SR2-2). It needs no relax flag: it refuses nothing an ID token has ever contained.
