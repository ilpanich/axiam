Expand description

Decide one network-relevant write, at write time (design note §5.1).

See the module documentation for what each NetworkWrite is checked against. A write that touches nothing in the network: namespace is cleared with GateClearance::is_network_sensitive false and costs the reads needed to know that (the role’s grants, the permission’s action, the resource’s type).

§Errors

Only what the reads return: NotFound for a segment that is not the tenant’s, and datastore failures. A role or permission that is not the tenant’s is cleared, not refused: the write cannot confer anything, and the repository answers it as it did before this function existed. A refusal is not an error.
