pub fn canonical(ip: IpAddr) -> IpAddr
Expand description

ip, with an IPv4-mapped IPv6 address (::ffff:a.b.c.d) folded to the IPv4 address it denotes.

On a dual-stack host, connecting to ::ffff:a.b.c.d reaches a.b.c.d, so a guard must reason about — and compare, and pin — the IPv4 form (SEC-094). The deprecated IPv4-compatible form (::a.b.c.d) is not folded: nothing legitimate resolves to it, and classify calls it IpClass::SpecialPurpose outright.
