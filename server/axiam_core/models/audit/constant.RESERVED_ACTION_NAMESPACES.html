The action namespaces the server reserves for its own control records (R101W3-03, #637).

Rows in these namespaces are evidence the server writes and later reads back to decide what it may do: the tenants.audit_exported receipt that authorises a tenant’s deletion (T-118), the tenants.deleted record whose export time bounds what the tenant purge deletes (T-472), tenants.purged, and the GDPR records (gdpr.*). Only the server writes them. The AMQP audit ingestion (axiam_amqp::audit_consumer::process_audit_event), whose messages a tenant’s own producers sign, refuses any action in them; every action constant of a control record must fall in one of them (tests in axiam-amqp and axiam-db pin the ones the purge and the deletion read).
