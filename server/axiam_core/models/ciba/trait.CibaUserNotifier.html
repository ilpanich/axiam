Expand description

The port through which a stored request reaches its user (G-7).

bc-authorize calls it best effort, after the request is stored, and detached from the response: a failed notification never fails the request (the user can still find it on the identity pages), and the response does not wait on it, so its timing says nothing about whether the hint named a real user. T23.7.2 implements it over axiam-email (later push); until a deployment wires one, NoopCibaUserNotifier is in place.
