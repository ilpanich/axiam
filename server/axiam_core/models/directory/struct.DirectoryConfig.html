Expand description

A tenant’s directory configuration, as stored and as read back.

Carries no secret: see the module documentation.

Fields§

§id: Uuid

Row identifier.

§tenant_id: Uuid

The owning tenant. At most one configuration exists per tenant.

§enabled: bool

Whether the directory is used for sign-in and sync.

§kind: DirectoryKind

The kind of directory, which selects defaults.

§url: String

ldaps://host[:port] or ldap://host[:port] together with Self::start_tls. A plaintext URL is refused at configuration time.

§start_tls: bool

Upgrade an ldap:// connection with StartTLS before any bind.

§bind_dn: String

The service account AXIAM binds as to search. It should hold read-only rights: AXIAM never writes to a directory.

§base_dn: String

Where users are searched for.

§user_filter: String

The user-lookup filter template. It contains exactly one {username} placeholder, which the bind path replaces with the RFC 4515-escaped login name; the template itself is never formatted with raw input.

§user_attribute_map: UserAttributeMap

Which attribute feeds which user field.

§group_base_dn: Option<String>

Where groups are searched for (reverse-member lookups, group sync).

§group_filter: Option<String>

Restricts which entries under Self::group_base_dn are groups.

§group_member_attribute: String

memberOf (user-side, AD) or member (group-side, OpenLDAP).

§group_nesting_depth: u8

How many levels of nested groups are followed, 0..=10.

§group_mappings: Vec<GroupMapping>

The group-mapping table (D-30): which directory groups put a user into which AXIAM groups. Empty means no directory group maps to anything, and a sign-in then removes every directory-sourced membership the user held.

§sync_interval_secs: u64

Seconds between incremental sync runs.

§jit_provisioning: bool

Provision an AXIAM user on first successful directory sign-in.

§trust_anchors_pem: Vec<String>

PEM CA certificates that anchor trust in the directory’s server certificate. Empty means the platform roots used by the rest of the workspace’s outbound TLS. An organisation CA’s PEM can be pasted here.

§created_at: DateTime<Utc>

When the row was created.

§updated_at: DateTime<Utc>

When the row was last written.
