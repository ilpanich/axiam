FIDO Alliance Metadata Service (MDS3) domain models (X3, D1/D5/D8).

These types are the parsed, storage-shaped view of a verified MDS3 BLOB — the cryptographic verification and JWT/JSON parsing that produces them live in axiam-pki::mds (PKI owns trust-anchor concerns), but the resulting domain types live here per the repo’s convention that axiam-core holds every model a Repository trait moves in or out of storage.
