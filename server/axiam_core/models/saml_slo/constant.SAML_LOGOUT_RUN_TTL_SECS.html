How long a logout run lives: ten minutes (D-38, D-39).

It is the life of the replay guard on a LogoutRequest ID, so it must exceed the window an IssueInstant is accepted in (five minutes back, the clock-skew allowance forward) — which it does with margin — and it bounds how long a stranded chain (an SP that never answers) holds its rows.
