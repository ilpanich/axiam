Expand description

Everything an administrator supplies when registering or replacing a service provider (create and update both take it; update is a full replacement).

Every field but entity_id, display_name and acs_urls has a default, so a client written against a later revision of this struct keeps working.

Fields§

§enabled: bool

Whether the SP may sign in at all. A disabled SP stays registered but every SSO request for it is refused.

§display_name: String

Human-readable name for the console.

§entity_id: String

The SP’s entityID, unique per tenant. At most MAX_ENTITY_ID_BYTES.

§acs_urls: Vec<AcsEndpoint>

The ACS allow-list. At least one, at most one default.

§slo_url: Option<String>

Single-logout endpoint, if the SP supports it.

§slo_binding: Option<SamlBinding>

The binding slo_url accepts. Set together with slo_url.

§name_id_format: NameIdFormat

NameID policy. Default: persistent, pairwise.

§sign_responses: bool

Sign the <samlp:Response> envelope as well as the assertion (which is signed always). Default true: it costs nothing and many SPs require it.

§encrypt_assertions: bool

Encrypt assertions to the SP’s encryption certificate (D-2). Off by default; requires Self::sp_encryption_cert_pem.

§sp_signing_cert_pem: Option<String>

PEM certificate the SP signs its AuthnRequests with.

§sp_encryption_cert_pem: Option<String>

PEM certificate assertions are encrypted to. Required when encrypt_assertions is set.

§want_authn_requests_signed: bool

Refuse an AuthnRequest that is not signed by sp_signing_cert_pem. Requires that certificate.

§allow_idp_initiated: bool

Whether IdP-initiated SSO is allowed for this SP (D-3). A per-SP opt-in, off by default: an unsolicited assertion has no InResponseTo to bind it to a request the SP made.

§attribute_mappings: Vec<AttributeMapping>

Attribute mapping table, at most MAX_ATTRIBUTE_MAPPINGS entries.

§allowed_groups: Vec<Uuid>

Groups whose members may sign in to this SP. Empty means every active user of the tenant may. Evaluated by the SSO endpoint (T23.2.3).
