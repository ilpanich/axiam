Struct Late 

Source 
pub struct Late<T: ?Sized>(/* private fields */);
Expand description

A sink bound after the objects that hold it exist.

The session repository is built first and cloned into a dozen services; the emitter that implements the sink needs the repositories and the outbox, which come later. The repository is given a Late handle at construction and the composition root binds the real sink once it has one. Until then the handle is inactive and does nothing.
