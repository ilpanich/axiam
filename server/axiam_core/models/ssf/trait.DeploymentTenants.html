Expand description

The datastore’s answer to “how many tenants does this deployment hold” for D-55, and a generation that changes whenever this process creates or deletes a tenant or an organization.

The count is the number of standard tenants across every organization, or the number of organizations if that is larger. An organization’s own scope tenant is not counted beside its standard tenants: the principals in it already reach every tenant of their organization, so a shared issuer gives them nothing they lack; a second organization always counts, since nothing ties its administrators to the first’s.
