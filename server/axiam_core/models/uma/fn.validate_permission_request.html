pub fn validate_permission_request(
    requested: &[RequestedPermission],
    declared: &dyn Fn(Uuid) -> Vec<String>,
) -> Result<(), PermissionRequestError>
Expand description

Validate a permission request against each resource’s declared scope set.

declared answers “which scope names does this resource expose” — the Scope rows for that resource. A resource absent from declared has declared nothing, so every scope asked of it is undeclared; that is the same answer as an unregistered resource, deliberately, so a probe cannot distinguish “no such resource” from “no such scope”.
