Expand description

Storage for network segments: nodes of the reserved /network subtree of the resource tree, with the sidecar row that holds the kind, the VLAN, the Filter-Id envelope and the placement rank. See crate::models::network.

Every method is tenant-scoped: a segment of another tenant is not found, exactly as one that does not exist. Every write is conditional on the version the writer read.

The repository decides only what the data decides: a path outside /network, a kind that disagrees with its branch, a VLAN or a name outside its bounds, a VLAN or rank already taken at the site. Who may write is the authorization function’s (design note §5.2), and every write method of this trait and of ReplyProfileRepository takes the crate::models::network::NetworkWriteClearance that function issues for exactly that write: one issued for another tenant, actor or target is AuthorizationDenied and nothing is written.

fn create( &self, input: NewNetworkSegment, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<NetworkSegment>> + Send

Create a segment at input.path, making the /network, branch and site nodes on first use, in one transaction.

  • Validation for a path outside /network/{zones|quarantine}/<site>/<segment>, a kind that disagrees with the branch, or a field outside its bounds.
  • AlreadyExists when the site already has that name, VLAN or rank.

fn list_site( &self, tenant_id: Uuid, site_key: &str, ) -> impl Future<Output = AxiamResult<Vec<NetworkSegment>>> + Send

Every segment of one site, in both branches (access and quarantine), ordered by kind, then rank, then name: the decision path’s read (design note §4.3). Tenant-scoped like every read here. A row that does not read back is left out (logged), which makes it no candidate: fail closed.

Source

fn update( &self, tenant_id: Uuid, id: Uuid, update: NetworkSegmentUpdate, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<NetworkSegment>> + Send

Rewrite a segment’s envelope.

  • NotFound when it does not exist in this tenant.
  • Conflict when expected_version is stale, or when the new filter_ids would leave the segment’s stored profile outside its envelope, or when the clearance is frozen and the write would change vlan_id, rank or enabled of a segment that has a profile now (R110W6-03).
  • Validation / AlreadyExists as for Self::create.
Source

fn delete( &self, tenant_id: Uuid, id: Uuid, expected_version: u64, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<()>> + Send

Remove a segment and its profile and its resource node, in one transaction. NotFound when it does not exist in this tenant, Conflict on a stale expected_version, when the node has children, or when the clearance is frozen and the segment has a profile now (the decision of 2026-10-16).
