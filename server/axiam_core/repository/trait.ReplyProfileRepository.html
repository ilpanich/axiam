Expand description

Storage for the reply profile of a segment (at most one per segment).

A read returns the effective profile: Session-Timeout clamped to the tenant’s current cap (crate::models::network::ReplyProfile). A write is conditional on the profile’s own version and the owning segment’s, and is validated against the envelope of the very segment row it is written under (design note §3.5, the T-416 lesson).

fn create( &self, tenant_id: Uuid, segment_id: Uuid, input: NewReplyProfile, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<ReplyProfile>> + Send

Create the segment’s profile.

  • NotFound when the segment does not exist in this tenant.
  • Validation for a value outside the dictionary, above the tenant cap, or a filter_id outside the segment’s envelope (§5.2 H3).
  • Conflict when expected_segment_version is stale.
  • AlreadyExists when the segment already has a profile.

fn get_by_segment( &self, tenant_id: Uuid, segment_id: Uuid, ) -> impl Future<Output = AxiamResult<ReplyProfile>> + Send

The segment’s effective profile. NotFound when the segment has none in this tenant.

Source

fn list_page( &self, tenant_id: Uuid, pagination: Pagination, ) -> impl Future<Output = AxiamResult<PaginatedResult<ReplyProfile>>> + Send

One page of the tenant’s effective profiles, ordered by owning segment id, optionally narrowed by Pagination::search (matched against the profile’s filter_id and its segment id). Each carries the tenant’s current cap as Self::get_by_segment does.

Source

fn list_stored( &self, tenant_id: Uuid, segment_ids: &[Uuid], ) -> impl Future<Output = AxiamResult<Vec<StoredReplyProfile>>> + Send

The stored profiles of segment_ids in this tenant, as stored, for the decision path to re-validate (design note §3.4). A segment without a profile is absent from the result; so is a row that does not read back at all (logged). One query whatever the number of ids.

Source

fn replace( &self, tenant_id: Uuid, segment_id: Uuid, input: ReplyProfileReplace, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<ReplyProfile>> + Send

Replace the segment’s profile. Errors as for Self::create, with NotFound for a segment without a profile and Conflict also for a stale profile version.

Source

fn delete( &self, tenant_id: Uuid, segment_id: Uuid, expected_version: u64, clearance: &NetworkWriteClearance, ) -> impl Future<Output = AxiamResult<()>> + Send

Delete the segment’s profile (no profile means no candidate, which only narrows). NotFound when it has none, Conflict on a stale version.
