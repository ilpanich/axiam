Module attestation_metadata_source

Adapter implementing axiam_core::repository::AttestationMetadataSource over any MdsRepository (X3 wave 2, W2-D4).

This is the “implemented over the repositories” half of W2-D4: it exists so axiam-auth can depend on the small, data-only axiam_core::repository::AttestationMetadataSource trait instead of a hard axiam-pki/axiam-db dependency, while the real lookup still goes through the same mds_entry table MdsRepository reads.
