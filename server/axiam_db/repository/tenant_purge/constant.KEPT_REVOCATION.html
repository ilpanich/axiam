The condition a row the purge keeps satisfies: revoked, and expired for less than eight days (REVOCATION_GRACE_SECS).

Not “unexpired” (#608). An issuing CA’s list keeps an expired entry until it has appeared on a list issued after the expiry — RFC 5280 §3.3 requires that — which is up to one nextUpdate interval past notAfter, at most seven days (axiam_pki::crl::MAX_CRL_NEXT_UPDATE_SECS). A row the purge deleted inside that window would leave the list mid-way through a refresh epoch, which changes the list without moving its thisUpdate and so breaks the CRL number every replica derives from them. The eighth day is margin for the datastore’s clock against the replicas’.

Public, with PAST_REVOCATION_GRACE, for the same test (#621); the text is SurrealQL for this crate’s own queries, not an API.
