pub async fn resolve_nested<S: GroupParents>(

) -> Result<ResolvedGroups, ResolveError>
Expand description

Walk the nesting above user_dn through source.

max_depth is the tenant’s group_nesting_depth; cap is MAX_GROUPS_PER_USER (a parameter so the tests can state the boundary without a thousand fixtures).

§Errors

ResolveError::CapExceeded when more than cap distinct groups turn up, and whatever source returns.
