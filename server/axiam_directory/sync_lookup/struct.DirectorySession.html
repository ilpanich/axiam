Struct DirectorySession

pub struct DirectorySession { /* private fields */ }
Expand description

One tenant’s directory, ready to be asked: the stored configuration, the decrypted bind secret (held only until the session is dropped) and the shared bounded client. Built by crate::RepositoryDirectoryAuthenticator::open_sync.

pub fn new( config: DirectoryConfig, target: DirectoryTarget, secret: Zeroizing<String>, client: Arc<DirectoryClient>, ) -> Self

A session over parts the caller has assembled. The composition root uses crate::RepositoryDirectoryAuthenticator::open_sync, which reads the stored configuration and decrypts the secret itself; this exists for callers that already hold both (the client’s own tests).

pub async fn lookup_by_external_id( &self, external_id: &str, ) -> Result<EntryLookup, DirectoryAuthError>

The entry whose identifier is external_id, under base_dn.

§Errors

[DirectoryAuthError::Misconfigured] when the identifier cannot be put in a filter or the directory refuses the search; [DirectoryAuthError::Unavailable] for every transport failure, timeout and busy answer. No error is “not found”: only a completed search that matched nothing is.

Entries changed at or after watermark, at most max_entries of them.

pub async fn read_root_dse(&self) -> Result<RootDse, DirectoryAuthError>

The rootDSE’s dsServiceName and highestCommittedUSN.

Values that are missing, or malformed (a USN that is not a number), are None: the caller falls back to a full run rather than trusting them.
