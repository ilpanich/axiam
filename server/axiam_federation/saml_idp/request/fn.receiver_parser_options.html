The libxml options every document AXIAM receives is parsed with — an AuthnRequest or logout message here, imported SP metadata, a SAMLResponse at the ACS, IdP metadata: no recovery (XML_PARSE_RECOVER off: a document that is not well-formed is refused, not repaired), no network access (XML_PARSE_NONET), no entity substitution and no DTD loading, defaulting or validation (XML_PARSE_NOENT, DTDLOAD, DTDATTR, DTDVALID all off), and UTF-8 whatever the document declares (#605): XML_PARSE_IGNORE_ENC makes libxml skip the declaration, and its own detection reads any text that passed refuse_other_encodings — valid UTF-8, no NUL, no second byte-order mark, beginning with < — as UTF-8. That function has already refused any other declaration, so this changes no document that reaches the parser; it removes the parser’s freedom to read one differently.

encoding stays None. libxml-rs 0.3.3’s parse_string_with_options turns Some(name) into a CString that is dropped inside the match that takes its pointer, so libxml2 read the encoding name from freed memory: a use-after-free (found under valgrind on 2026-10-13). Whatever the allocator had put there named the encoding the document was decoded with — usually none, and the parse failed; sometimes a 7-bit national variant of ASCII, and # in the XML-DSig namespace URI read as another character. Every receiver parse set it from W2.1 (#605), the IdP receiver’s since T23.2.3.

no_def_dtd stays off. libxml-rs 0.3 maps it to the value 4 for both parsers, which is HTML_PARSE_NODEFDTD for the HTML parser but XML_PARSE_DTDLOAD — load the external DTD subset — for the XML parser. Until 2026-10-13 it was set here, asking libxml for the opposite of what the comment said; refuse_markup_declarations refusing every <!DOCTYPE on the bytes, and no_net, kept that from being reachable — as does, once xmlsec is initialised, the process-wide external-entity loader xmlsec installs, which refuses every input but the document itself. Public so the receiver_parser_options integration test can parse with it in a process where xmlsec never runs.
