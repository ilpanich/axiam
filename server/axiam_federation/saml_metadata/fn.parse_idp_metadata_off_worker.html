parse_idp_metadata on the blocking pool, under gate when one is given (R101W2-01; the wait for a permit is bounded, #654): the signature check canonicalizes and hashes up to MAX_METADATA_SIZE bytes, which must not hold an async worker. A sign-in’s cache miss and the uncached administrative fetch both go through here.
