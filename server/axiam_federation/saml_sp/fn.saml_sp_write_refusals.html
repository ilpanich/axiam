Expand description

The write-time refusals of D-42 that need no database, each naming its rule — beyond saml_sp_violations, which the caller runs first:

  • encrypt_assertions: true — assertion encryption is not implemented (D-2); an SP asking for it would be refused at every sign-on, so it is refused here, where the administrator can read why;
  • an sp_signing_cert_pem the SSO endpoint cannot use (sp_signing_certificate_refusal).

The other two — an allowed_groups entry outside the tenant and a changed entity_id — need the datastore and the stored row, and are the route’s.
