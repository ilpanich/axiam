pub fn bound_idp_hint(raw: Option<&str>) -> Option<&str>
Expand description

G-B — the one rule an axiam_idp_hint passes before anything reads it, on either carrier: trimmed, non-blank, at most MAX_HINT_LEN bytes and free of U+FFFD; None otherwise — dropped, never truncated, never an error.

Trimming is str::trim, which removes leading and trailing Unicode whitespace — CR, LF and TAB included — so corp-okta%0A and %09corp-okta name corp-okta (F4-W3-07). Interior control characters, NUL and zero-width characters are not folded; such a hint matches no slug and no UUID and is ignored. Nothing the hint contains reaches a URL either way: only a matched provider’s id does.

The query string reaches this through AuthnRequestParams::parse; the PAR endpoint applies it at push time (F4-W3-09), so a pushed hint is stored already bounded and an over-long one is stored as no hint — answered, when the browser arrives, exactly as the same value on the query string is.
