Expand description

Verify a signed authentication request against the keys a client registered, and return its parameters.

Pure — no clock, no datastore, no network — so every rule is testable against vectors. The caller must record the returned jti; that is the single-use half, and it is not optional.

acceptable_audiences are the issuer identifiers this request may name: the deployment’s and, for a tenant-path request, the tenant’s.
