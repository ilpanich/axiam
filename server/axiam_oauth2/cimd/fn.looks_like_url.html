pub fn looks_like_url(client_id: &str) -> bool
Expand description

Whether a client_id is shaped like an absolute URL at all.

The whole of I1’s cost. This runs on every authorization, PAR and token request in the deployment, so it is a find over at most a handful of bytes and it answers false for every client_id AXIAM has ever issued (oa_ followed by hex). Only when it answers true does anything read a setting, and only then can a tenant’s policy be consulted at all.

Deliberately looser than validate_client_id_url: this is the question “is this worth looking at”, not “is this acceptable”. A URL-shaped client_id that fails the real rules below is still an unknown client.
