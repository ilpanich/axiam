Read the Authorization header value.

None means “this request is not attempting Basic authentication” — no header, or a header naming another scheme (Bearer, DPoP). That is not an error: the token endpoint accepts four other client-authentication methods, three of which put nothing in this header and one of which (private_key_jwt) puts nothing there either.

Some(Err(_)) means “this request is attempting Basic authentication and got it wrong”, which the REST layer answers with a challenge. The distinction matters: collapsing it to Option would make a corrupt Basic header silently equivalent to sending none, and a client whose secret contained a stray byte would see invalid_client with no WWW-Authenticate telling it which scheme failed.
