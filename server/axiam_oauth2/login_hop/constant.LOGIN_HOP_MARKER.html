The query parameter that marks an authorization request as the return leg of a login hop.

axiam_-prefixed so it cannot collide with an OAuth2 or OpenID Connect parameter now or later: the registries do not issue names in a vendor namespace, and a relying party that sends this one is sending a parameter AXIAM defines.
