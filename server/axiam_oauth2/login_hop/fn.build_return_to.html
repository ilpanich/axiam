pub fn build_return_to(query: &str) -> Option<String>
Expand description

Build the return_to for an authorization request whose raw query string is query.

The result carries LOGIN_HOP_MARKER, which is what makes the hop terminate (module docs). It is validated before it is returned, so a caller cannot emit a Location this module would refuse to accept back — the two directions are the same predicate by construction rather than by review.

None when the query is empty or the result would not validate. A caller that gets None must not redirect: there is nothing safe to come back to.
