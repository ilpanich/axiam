pub fn validate_return_to(candidate: &str) -> Result<(), ReturnToError>
Expand description

Is this a return_to the server built and will honour?

See the module docs for the shape and for why it is checked more than once. The check is total and syntactic: it reads the candidate and nothing else, so it gives the same answer on the way out (when the server builds the value) as on the way back (when a browser presents one), which is the whole property “validated on both sides” is worth having.

§Errors

ReturnToError, naming which member of the open-redirect family the candidate belongs to.
