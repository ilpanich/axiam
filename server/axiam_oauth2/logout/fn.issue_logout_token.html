Issue a signed back-channel logout token for one client.

Deliberately not given a nonce parameter. Back-Channel Logout 1.0 §2.4 forbids the claim, and its presence is the documented way an attacker replays an ID token as a logout token. Making it un-passable is stronger than remembering not to pass it.
