The single answer given for a request_uri that is unknown, expired or already consumed.

A constant because two places need to agree on it: ParService::consume produces it, and the authorization endpoint recognises it to tell a login-hop return leg whose 60-second window closed (W3, plan §4.0 and F10) apart from a client that sent nonsense. See is_request_uri_gone.
