Verify a client_assertion against the keys a client registered.

acceptable_audiences is the set of values RFC 7523 §3 permits in aud: AXIAM’s issuer and its token-endpoint URL. Both are accepted because the specifications disagree about which one a client should use — OIDC Core §9 says the token endpoint URL, RFC 7523 says an identifier of the authorization server — and refusing a client for following the other specification would be an interop failure with no security content.

Returns the jti for the caller to record. A caller that drops it has not implemented replay protection, which is why the return type carries it rather than the function answering Ok(()).
