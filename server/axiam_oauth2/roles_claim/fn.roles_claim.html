The claim for a token whose granted scopes are scopes.

Ok(None) — the claim is absent — whenever roles is not granted; no read is made. Otherwise the subject’s global role names, read now.

§Errors

server_error when the role source cannot be read: a token that says “no roles” because the read failed would be a false statement in a signed credential.
