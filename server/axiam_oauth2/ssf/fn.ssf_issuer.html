pub fn ssf_issuer(config: &AuthConfig, tenant_id: Uuid) -> String
Expand description

The iss of a tenant’s SETs and of its transmitter metadata: the tenant’s path issuer when the deployment serves them (T21.6), the deployment’s root issuer otherwise. Never the per-request issuer: a SET is not minted inside the request that caused it.
