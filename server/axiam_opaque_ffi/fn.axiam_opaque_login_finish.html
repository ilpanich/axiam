Expand description

Complete a login, consuming state. Returns the hex KE3.

A NULL return is the whole of the client’s authentication check, and it covers both halves of the mutual authentication: the envelope only opens under the right password, and KE2’s MAC only verifies if the server actually holds the record. Per CONTRACT §23.4 rule 7 the caller MUST NOT send anything to login/finish after a NULL here.

out_session_key and out_export_key may be NULL; when non-NULL they receive strings the caller must release.
