pub async fn guard_host(
    host: &str,
    port: u16,
    policy: &AddressPolicy,
    resolver: &dyn Resolver,
) -> Result<GuardedTarget, GuardError>
Expand description

Resolve host once and judge every address under policy. Pure policy plus resolution: no protocol traffic, no socket opened. An IP-literal host (either family, bracketed or not) is used as written and never handed to the resolver.

§Errors

A GuardError: the host is empty, the name does not resolve, or any address it resolves to is refused.
