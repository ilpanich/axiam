Expand description

The longest common name AXIAM issues, in characters (Unicode scalar values, str::chars().count()), not bytes.

RFC 5280 Appendix A defines ub-common-name INTEGER ::= 64 and types the attribute DirectoryString (SIZE (1..ub-common-name)); for UTF8String the size constraint counts characters. Counting bytes would refuse a 30-character name in a non-Latin script that RFC 5280 admits, and counting anything but characters would let a verifier that enforces the bound refuse a certificate AXIAM signed. (A 64-character name can be up to 256 octets of UTF-8; that is what the standard says.)
