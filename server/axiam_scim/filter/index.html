SCIM filter query-parameter parsing — subset only (RFC 7644 §3.4.2.2).

B4’s scope is explicit: userName eq, externalId eq, and paging. No and/or, no co/sw/pr/comparison operators, no attribute-path filters (emails[type eq "work"]), no parentheses. Anything outside <attr> eq "<value>" is rejected with the RFC’s own invalidFilter scimType (§3.12) rather than silently ignored or partially honored — a caller that thinks it filtered and didn’t would see the wrong page of results, which is worse than an explicit 400.
