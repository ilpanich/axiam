SCIM /Groups resource (RFC 7643 §4.2, RFC 7644 §3.2-3.6).

Maps onto the EXISTING GroupRepository (B4) — no parallel storage; membership is the same member_of graph edge add_member/remove_member/get_members already maintain for the admin UI.

§Webhooks — intentionally none here

B4 says “emit the SAME webhooks … as native user/group CRUD — find where native CRUD emits them and reuse that path.” That path is axiam_api_rest::handlers::users for users (user.created/updated/ deleted, reused in users.rs) — but axiam_api_rest::handlers::groups emits no webhooks at all today (verified: zero emit_webhook call sites in that file). Reusing “that path” for groups therefore means reusing its absence, not inventing a group.created event native group CRUD has never emitted. Audit logging is unaffected either way — it comes from the global AuditMiddleware wrap in axiam-server, not from per-handler calls, so /scim/v2/Groups/* is audited exactly like /api/v1/groups/* regardless.
