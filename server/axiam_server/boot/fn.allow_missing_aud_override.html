AXIAM__AUTH__ALLOW_MISSING_AUD_AS_USER, read by hand in main (the spelling operators already use).

The same variable is first read by the layered config loader (load_config), which binds it to AuthConfig::allow_missing_aud_as_user like every other AXIAM__* boolean. The loader accepts only 1, true, on, yes, 0, false, off and no (case-insensitive, untrimmed); any other value — an empty Compose ${VAR:-}, a padded value, a typo — fails the load and the server does not start. This function never sees such a value.

It runs after a successful load and fails closed (S-9): only true, 1 or yes enable the switch. Of the values the loader accepts, the one whose outcome it changes is on: the loader reads it as true, and this override turns it back off.
