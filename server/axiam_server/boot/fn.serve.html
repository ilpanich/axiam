Compose and run the server until the REST listener stops.

Everything main does after secrets are resolved and the datastore is migrated: the minimal profile’s boot guards (when amqp.enabled is false), the broker connection (when it is true), every repository and service, the dispatcher and its consumers, the gRPC listener, the cleanup scheduler and the REST listener.
