Expand description

One pass of the rate_limit_bucket job (#638): delete the buckets whose last write is older than RATE_LIMIT_BUCKET_RETENTION at now, in batches; returns how many were removed.

Safe for any number of replicas sweeping at once: each delete re-checks updated_at on the row it removes, so a row is removed once, and a row a limiter has just written is kept. A public free function, for the reason run_erasure_pipeline is.
