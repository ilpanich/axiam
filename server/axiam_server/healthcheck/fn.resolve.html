Expand description

Resolve the probe from the environment.

var reads an environment variable; a variable that is set but empty is treated as unset, because that is what a Compose file writes when an interpolated variable is missing.

  • AXIAM_HEALTHCHECK_URL still wins outright, unchanged.
  • Otherwise the scheme follows the listener: https when the server terminates TLS itself, http when it does not.
  • AXIAM_HEALTHCHECK_CA_FILE names the trust anchors.
  • With no CA file and an https probe of a TLS-terminating server, the anchors are the server’s own AXIAM__SERVER__TLS__CERT_PATH chain: a process verifying the certificate it is itself serving adds no trust it does not already have.
