The revocation-feed prune (T-39/T-143, P23W4-06). The one sweep in the loop that a process switch (auth.revocation_feed_enabled) turns on: the loop records it only when the feed is on, so it is registered only then. A deployment without the feed has no such job, and “not in the list” is how /health/jobs says so.
