pub fn lift_verified_client_certificate(conn: &dyn Any, ext: &mut Extensions)
Expand description

The REST listener’s on_connect hook: lift the client certificate rustls verified during the handshake into the connection’s extensions, as the axiam_api_rest::VerifiedClientCert cert-auth handlers and the token endpoint read through HttpRequest::conn_data.

Only a rustls connection with a peer certificate inserts anything; on a plaintext or server-auth-only connection there is no peer certificate and the extensions are left empty. A function rather than a closure in boot so the route-level tls_client_auth tests install exactly this hook (#610).
