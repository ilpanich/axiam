1//! The organization a **system-partition** request row concerns (SA-02, N1).
2//!
3//! The request audit middleware (`axiam_audit::AuditMiddleware`) writes a row
4//! with a nil tenant for every request it cannot attribute to a tenant: no
5//! verifiable access token, no handler-proven [`axiam_audit::AuditAttribution`].
6//! That partition is deployment-wide, and `GET /api/v1/audit-logs/system`
7//! returns an organization only the rows whose recorded organization is its
8//! own. This module is where a request row's organization is decided.
9//!
10//! [`system_audit_organization`] runs inside the audit middleware (the
11//! composition root wraps it there). After the request has been served, and
12//! only for a request the middleware will record in the system partition, it
13//! starts the lookup of the organization **on a task of its own** and lets the
14//! response go (review SR4-3): the audit worker waits for the answer, through
15//! an [`axiam_audit::PendingAuditOrganization`], before it writes the row. No
16//! response waits on the datastore, so a response's latency says nothing about
17//! whether the id its path names exists, whatever the cache below holds. The
18//! organization is resolved from something the server has verified, never
19//! from a value the client merely sent:
20//!
21//! 1. a [`VerifiedAuditTenant`] an extractor inserted after verifying a
22//!    credential that names the tenant — a SCIM provisioning token — gives that
23//!    tenant's organization;
24//! 2. otherwise a path `/api/v1/organizations/{org_id}/…` naming an
25//!    organization that exists gives that organization;
26//! 3. otherwise a path `/saml/v2/{tenant_id}/…` or `/t/{tenant_id}/…` naming a
27//!    live tenant gives its organization.
28//!
29//! Anything else records no organization, and the row is then returned by the
30//! system endpoint to nobody: a request that names no organization in its path
31//! (`/oauth2/token?tenant_id=…`, `/api/v1/users` without a token), or one that
32//! names an organization or tenant that does not exist. A datastore failure
33//! during the lookup counts as unresolved: the row is still written, without
34//! an organization. A path segment says which organization a request was
35//! addressed to, not who sent it; that is exactly what the row records (the
36//! traffic aimed at that organization's routes), and it can only ever be shown
37//! to that organization.
38//!
39//! # What the lookup costs (review QR2-8 / SR2-4)
40//!
41//! The resolver runs for every request the middleware writes to the system
42//! partition — every token-less request among them, a cheap `401` included —
43//! and outside every scope-level rate limiter. A path naming an organization or
44//! tenant would therefore cost one datastore point read per request, and a
45//! client looping an invented id could turn each `401` into one.
46//! [`SystemAuditOrgCache`] bounds that: an id that resolved is remembered for
47//! [`RESOLVED_TTL`], an id the datastore says does not exist for the shorter
48//! [`UNRESOLVED_TTL`], so a repeated id costs one read per TTL, not per
49//! request. A datastore failure is not remembered. What it cannot bound is a
50//! client sending a *different* invented id every time: each still costs one
51//! indexed record-id read, limited by the deployment's edge and
52//! unauthenticated rate limits and, in how many run at once, by the bound
53//! below. Do not add a lookup here that is dearer than that.
54//!
55//! # How many lookups run at once (review SR15-1)
56//!
57//! Since SR4-3 nothing makes the client wait for its lookup, so the cache alone
58//! would leave a client sending a fresh invented id per request free to pile
59//! up detached reads, each outliving the audit worker's wait for it. The
60//! datastore reads are therefore bounded process-wide: a lookup that misses
61//! the caches takes one of [`MAX_CONCURRENT_LOOKUPS`] permits of a semaphore
62//! held beside the cache (`try_acquire_owned`, which never waits) immediately
63//! before its read, and keeps it until the read has finished. A lookup the
64//! caches answer — this module's own, or [`crate::tenant_org_cache`] — reads
65//! nothing and takes no permit (review QR16-2), so a known organization's rows
66//! keep recording it however many invented ids hold the permits. A lookup that
67//! must read while every permit is taken reads nothing and answers no
68//! organization: its row is written without one — returned by the system
69//! endpoint to nobody, the same fail-safe answer as an id that names nothing.
70//! Either way its response was served exactly as any other.
71//!
72//! The cache is an optimisation of the lookup's cost, not of any response's
73//! latency (review SR4-3): the lookup, cached or not, runs on its own task
74//! after the response has gone, so the two TTLs differing — a known id served
75//! from memory where an unknown one is read again — cannot be timed by the
76//! client. The response path does the same work for every id: it reads the
77//! path and spawns the task. Whether a permit is free is decided inside the
78//! task, after the caches, so it cannot change the response either.

98/// A tenant an extractor has **verified** a request concerns, for a request
99/// that carries no access token: the SCIM provisioning token's tenant, once
100/// the token resolved.
101///
102/// Inserted into the request's extensions; read by [`system_audit_organization`]
103/// to record the tenant's organization on the system-partition row. It does
104/// not move the row into the tenant's own log.
105#[derive(Debug, Clone, Copy, PartialEq, Eq)]
106pub struct VerifiedAuditTenant(pub Uuid);
107
108/// Record, for a request the audit middleware writes to the system partition,
109/// the organization it concerns, when that can be resolved with certainty (see
110/// the module documentation). Wrapped inside the audit middleware with
111/// `actix_web::middleware::from_fn(system_audit_organization::<C, _>)`.
112pub async fn system_audit_organization<C, B>(
113    req: ServiceRequest,
114    next: Next<B>,
115) -> Result<ServiceResponse<B>, actix_web::Error>
116where
117    C: Connection + Clone + 'static,
118    B: MessageBody + 'static,
119{
120    let res = next.call(req).await?;
121    // SR4-3: what to look up is read here, synchronously; the lookup itself
122    // runs on a task of its own, and the response leaves without it.
123    // QR16-2: the response path does the same for every id — it inserts the
124    // pending answer and spawns — whether or not the task will need a
125    // datastore read. The SR15-1 permit is taken inside the task, only for
126    // that read (see `bounded_read`).
127    if let Some(lookup) = Lookup::<C>::of(res.request()) {
128        let (answer, pending) = PendingAuditOrganization::channel();
129        res.request().extensions_mut().insert(pending);
130        actix_web::rt::spawn(async move {
131            let organization = lookup.run().await;
132            // The worker may have stopped waiting; the answer is then unread.
133            let _ = answer.send(organization);
134        });
135    }
136    Ok(res)
137}

139/// What a system-partition request row's organization is to be resolved
140/// from, read off the served request; resolved by [`Lookup::run`], off the
141/// response path.
142struct Lookup<C: Connection + Clone + 'static> {
143    state: web::Data<AppState<C>>,
144    target: Target,
145}
146
147enum Target {
148    /// A tenant an extractor verified: its organization.
149    VerifiedTenant(Uuid),
150    /// What the path names.
151    Path(PathScope),
152}
153
154impl<C: Connection + Clone + 'static> Lookup<C> {
155    /// `None` for a request the audit middleware attributes to a tenant, one
156    /// whose organization a handler already named, and one that names nothing
157    /// to resolve.
158    fn of(req: &HttpRequest) -> Option<Self> {
159        let verified = {
160            let ext = req.extensions();
161            // A verified token, or a handler's attribution, puts the row in a
162            // tenant's log: nothing to resolve. An organization already named
163            // by a handler stands.
164            if ext.contains::<Arc<CachedUserIdentity>>()
165                || ext.contains::<AuditAttribution>()
166                || ext.contains::<AuditOrganization>()
167            {
168                return None;
169            }
170            ext.get::<VerifiedAuditTenant>().copied()
171        };
172        let target = match verified {
173            Some(VerifiedAuditTenant(tenant_id)) => Target::VerifiedTenant(tenant_id),
174            None => Target::Path(path_scope(req.path())?),
175        };
176        let state = req.app_data::<web::Data<AppState<C>>>()?.clone();
177        Some(Self { state, target })
178    }
179
180    /// The organization, or `None` when it cannot be resolved with certainty.
181    async fn run(self) -> Option<Uuid> {
182        let state = self.state.get_ref();
183        match self.target {
184            Target::VerifiedTenant(tenant_id) => organization_of_tenant(state, tenant_id).await,
185            Target::Path(scope) => organization_of_path(state, scope).await,
186        }
187    }
188}

197/// The organization an organization or tenant id in the path names, served
198/// from [`SystemAuditOrgCache`] when remembered.
199async fn organization_of_path<C: Connection + Clone>(
200    state: &AppState<C>,
201    scope: PathScope,
202) -> Option<Uuid> {
203    let cache = &state.system_audit_org_cache;
204    if let Some(remembered) = cache.get(scope) {
205        return remembered;
206    }
207    let tenant_cached = match scope {
208        PathScope::Tenant(tenant_id) => state.tenant_org_cache.get(tenant_id),
209        PathScope::Organization(_) => None,
210    };
211    let looked_up = match (scope, tenant_cached) {
212        // Answered from memory: no read, no permit (QR16-2).
213        (PathScope::Tenant(_), Some(org_id)) => Ok(org_id),
214        (PathScope::Organization(org_id), _) => {
215            // No permit free: unresolved for this row, and not remembered.
216            bounded_read(cache, state.org_repo.get_by_id(org_id))
217                .await?
218                .map(|o| o.id)
219        }
220        (PathScope::Tenant(tenant_id), None) => {
221            bounded_read(cache, state.tenant_repo.get_by_id(tenant_id))
222                .await?
223                .map(|t| {
224                    state.tenant_org_cache.insert(tenant_id, t.organization_id);
225                    t.organization_id
226                })
227        }
228    };
229    match looked_up {
230        Ok(org_id) => {
231            state.system_audit_org_cache.insert(scope, Some(org_id));
232            Some(org_id)
233        }
234        // The datastore answered that the id names nothing: remembered, briefly.
235        Err(AxiamError::NotFound { .. }) => {
236            state.system_audit_org_cache.insert(scope, None);
237            None
238        }
239        // A datastore failure: unresolved for this row, and not remembered.
240        Err(_) => None,
241    }
242}

244/// What a request path names, read from the path itself.
245///
246/// Not from the router's match: a request refused before its resource is
247/// matched — the scope's authorization middleware answers `401` to a missing
248/// token first — has no path parameters, and it is exactly the request this
249/// module is for.
250#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
251enum PathScope {
252    Organization(Uuid),
253    Tenant(Uuid),
254}
255
256fn path_scope(path: &str) -> Option<PathScope> {
257    let mut segments = path.split('/').skip(1);
258    let uuid = |s: Option<&str>| s.and_then(|s| Uuid::parse_str(s).ok());
259    match (segments.next()?, segments.next()) {
260        ("api", Some("v1")) if segments.next() == Some("organizations") => {
261            uuid(segments.next()).map(PathScope::Organization)
262        }
263        ("saml", Some("v2")) => uuid(segments.next()).map(PathScope::Tenant),
264        ("t", tenant) => uuid(tenant).map(PathScope::Tenant),
265        _ => None,
266    }
267}

269/// The organization of a live tenant: the server's own record of it, served
270/// from [`crate::tenant_org_cache`] when warm.
271async fn organization_of_tenant<C: Connection + Clone>(
272    state: &AppState<C>,
273    tenant_id: Uuid,
274) -> Option<Uuid> {
275    if let Some(org_id) = state.tenant_org_cache.get(tenant_id) {
276        return Some(org_id);
277    }
278    let tenant = bounded_read(
279        &state.system_audit_org_cache,
280        state.tenant_repo.get_by_id(tenant_id),
281    )
282    .await?
283    .ok()?;
284    state
285        .tenant_org_cache
286        .insert(tenant_id, tenant.organization_id);
287    Some(tenant.organization_id)
288}

290/// Run one datastore `read` of the lookup under a [`MAX_CONCURRENT_LOOKUPS`]
291/// permit (review SR15-1), taken only now — after the caches missed, so a
292/// lookup answered from memory never takes one (review QR16-2) — and held
293/// until the read has finished, answered or not. `None` when every permit is
294/// taken: the read does not start, and the caller records no organization.
295/// Taking the permit never waits.
296async fn bounded_read<F: std::future::Future>(
297    cache: &SystemAuditOrgCache,
298    read: F,
299) -> Option<F::Output> {
300    let permit = cache.try_lookup_permit()?;
301    #[cfg(test)]
302    tests::lookup_gate().await;
303    let answer = read.await;
304    drop(permit);
305    Some(answer)
306}

308/// How long an organization or tenant the path names, once found, is served
309/// from [`SystemAuditOrgCache`] before it is read again.
310///
311/// A tenant's organization never changes; an organization deleted within this
312/// window keeps being recorded on the rows aimed at its routes, which only
313/// that (deleted) organization could ever read.
314pub const RESOLVED_TTL: Duration = Duration::from_secs(60);
315
316/// How long a path id that named **no** organization or tenant is remembered
317/// as unresolved (QR2-8 / SR2-4).
318///
319/// Short on purpose: the cost of a stale miss is that a row aimed at an
320/// organization or tenant created within this window records no organization
321/// — written, but returned to nobody — and that should stay a matter of
322/// seconds.
323pub const UNRESOLVED_TTL: Duration = Duration::from_secs(10);
324
325/// Upper bound on each of the two maps (resolved, unresolved).
326///
327/// Separate maps, so invented ids — which only ever land in the unresolved
328/// one — cannot crowd real organizations out of the resolved one. At the cap a
329/// map stops accepting new entries until an expiry sweep frees room, which
330/// degrades to the uncached behaviour (one read per request) rather than to
331/// unbounded growth or to dropping an organization the datastore does know.
332///
333/// The sweep is a full scan under the map's lock, so a full map is swept at
334/// most once per half of its TTL (review QR3-4): a client looping invented ids
335/// fast enough to keep the map full of live entries would otherwise trigger a
336/// scan that frees nothing on every insert. Between sweeps an insert into a
337/// full map is simply dropped; an entry that expired meanwhile is still removed
338/// by the lookup that finds it.
339const MAX_ENTRIES: usize = 4_096;
340
341/// How many organization lookups may be in flight at once, process-wide
342/// (review SR15-1).
343///
344/// Each lookup is a detached task, and since SR4-3 nothing makes the client
345/// wait for it; a client sending a fresh invented id per request would
346/// otherwise pile datastore reads up with nothing but the edge rate limit to
347/// stop it. A permit is held only for the read itself (review QR16-2): a lookup
348/// answered from a cache takes none, and one that must read while every permit
349/// is taken reads nothing, and its row records no organization.
350pub const MAX_CONCURRENT_LOOKUPS: usize = 128;
351
352#[derive(Debug, Clone, Copy)]
353struct Entry {
354    organization_id: Option<Uuid>,
355    inserted_at: Instant,
356}
357
358/// One of the two bounded maps.
359#[derive(Debug, Default)]
360struct Bucket {
361    entries: HashMap<PathScope, Entry>,
362    /// When `entries` was last swept for expired entries (QR3-4).
363    last_sweep: Option<Instant>,
364    /// Expiry sweeps run over `entries`; tests read it to bound the work.
365    #[cfg(test)]
366    sweeps: usize,
367}
368
369/// What a path id resolved to, remembered for [`RESOLVED_TTL`] when it named
370/// something and for [`UNRESOLVED_TTL`] when the datastore said it does not
371/// exist. A datastore failure is never remembered.
372#[derive(Debug)]
373pub struct SystemAuditOrgCache {
374    resolved_ttl: Duration,
375    unresolved_ttl: Duration,
376    resolved: Mutex<Bucket>,
377    unresolved: Mutex<Bucket>,
378    /// The permits a lookup holds while its datastore read runs
379    /// ([`MAX_CONCURRENT_LOOKUPS`]).
380    lookups: Arc<Semaphore>,
381}
382
383impl Default for SystemAuditOrgCache {
384    fn default() -> Self {
385        Self::new(RESOLVED_TTL, UNRESOLVED_TTL)
386    }
387}
388
389impl SystemAuditOrgCache {
390    /// Build a cache with explicit TTLs (tests pin short ones).
391    pub fn new(resolved_ttl: Duration, unresolved_ttl: Duration) -> Self {
392        Self {
393            resolved_ttl,
394            unresolved_ttl,
395            resolved: Mutex::new(Bucket::default()),
396            unresolved: Mutex::new(Bucket::default()),
397            lookups: Arc::new(Semaphore::new(MAX_CONCURRENT_LOOKUPS)),
398        }
399    }
400
401    /// A permit for one lookup's datastore read, or `None` when
402    /// [`MAX_CONCURRENT_LOOKUPS`] are already in flight. Never waits.
403    fn try_lookup_permit(&self) -> Option<OwnedSemaphorePermit> {
404        Arc::clone(&self.lookups).try_acquire_owned().ok()
405    }
406
407    /// `Some(answer)` when `scope` is remembered and not expired — `answer`
408    /// itself is `None` for a remembered miss — or `None` when it must be read.
409    fn get(&self, scope: PathScope) -> Option<Option<Uuid>> {
410        for (map, ttl) in [
411            (&self.resolved, self.resolved_ttl),
412            (&self.unresolved, self.unresolved_ttl),
413        ] {
414            let mut guard = lock(map);
415            if let Some(entry) = guard.entries.get(&scope).copied() {
416                if entry.inserted_at.elapsed() < ttl {
417                    return Some(entry.organization_id);
418                }
419                guard.entries.remove(&scope);
420            }
421        }
422        None
423    }
424
425    fn insert(&self, scope: PathScope, organization_id: Option<Uuid>) {
426        let (map, ttl) = if organization_id.is_some() {
427            (&self.resolved, self.resolved_ttl)
428        } else {
429            (&self.unresolved, self.unresolved_ttl)
430        };
431        let mut guard = lock(map);
432        if guard.entries.len() >= MAX_ENTRIES && !guard.entries.contains_key(&scope) {
433            let sweep_due = guard.last_sweep.is_none_or(|at| at.elapsed() >= ttl / 2);
434            if !sweep_due {
435                return;
436            }
437            guard.entries.retain(|_, e| e.inserted_at.elapsed() < ttl);
438            guard.last_sweep = Some(Instant::now());
439            #[cfg(test)]
440            {
441                guard.sweeps += 1;
442            }
443            if guard.entries.len() >= MAX_ENTRIES {
444                return;
445            }
446        }
447        guard.entries.insert(
448            scope,
449            Entry {
450                organization_id,
451                inserted_at: Instant::now(),
452            },
453        );
454    }
455}

457/// A poisoned lock means another thread panicked holding a map of ids; there
458/// is no invariant to protect, and recovering beats panicking on every request.
459fn lock(map: &Mutex<Bucket>) -> MutexGuard<'_, Bucket> {
460    map.lock().unwrap_or_else(|p| p.into_inner())
461}

573    /// SR4-3: the organization of a system-partition row is resolved off the
574    /// response path. A token-less request to an organization's routes whose

660    /// The system-partition rows written so far, waiting until there are
661    /// `count` of them.
662    async fn system_rows(
663        audit: &axiam_db::SurrealAuditLogRepository<Db>,
664        count: usize,
665    ) -> Vec<axiam_core::models::audit::AuditLogEntry> {
666        use axiam_core::repository::{AuditLogFilter, AuditLogRepository, Pagination};
667        let deadline = Instant::now() + Duration::from_secs(10);
668        loop {
669            let page = audit
670                .list(
671                    Uuid::nil(),
672                    AuditLogFilter::default(),
673                    Pagination::default(),
674                )
675                .await
676                .unwrap();
677            if page.items.len() >= count {
678                return page.items;
679            }
680            assert!(
681                Instant::now() < deadline,
682                "only {} of {count} system-partition rows were written",
683                page.items.len()
684            );
685            tokio::time::sleep(Duration::from_millis(20)).await;
686        }
687    }

702    /// SR15-1: the detached lookups are bounded. With every one of the
703    /// [`MAX_CONCURRENT_LOOKUPS`] permits taken, a token-less request naming an
704    /// organization that exists but is not cached starts no lookup — no
705    /// datastore read — and its row is still written, recording no
706    /// organization (visible to nobody).
707    ///
708    /// QR16-2: the permit bounds datastore reads only. A request naming an
709    /// organization already in the cache needs no read, so with every permit
710    /// taken its row still records that organization.
711    #[actix_rt::test]
712    async fn with_every_lookup_permit_taken_no_lookup_starts_and_the_row_records_no_organization() {
713        use axiam_db::SurrealAuditLogRepository;
714
715        let (db, state) = state().await;
716        let org_id = organization(&state, "busy").await;
717        let cached_org_id = organization(&state, "cached").await;
718        state
719            .system_audit_org_cache
720            .insert(PathScope::Organization(cached_org_id), Some(cached_org_id));
721        let audit = SurrealAuditLogRepository::new(db.clone());
722        let app = system_audit_app!(state, audit);
723
724        let held: Vec<_> = (0..MAX_CONCURRENT_LOOKUPS)
725            .map(|_| {
726                state
727                    .system_audit_org_cache
728                    .try_lookup_permit()
729                    .expect("a free permit")
730            })
731            .collect();
732        assert!(state.system_audit_org_cache.try_lookup_permit().is_none());
733        LOOKUPS_STARTED.with(|n| n.set(0));
734
735        // QR16-2: the cached organization is recorded without a permit.
736        let req = actix_web::test::TestRequest::get()
737            .uri(&format!("/api/v1/organizations/{cached_org_id}/settings"))
738            .to_request();
739        let res = actix_web::test::call_service(&app, req).await;
740        assert_eq!(res.status(), 401);
741        let rows = system_rows(&audit, 1).await;
742        let cached_row_id = rows[0].id;
743        assert_eq!(
744            rows[0].organization_id,
745            Some(cached_org_id),
746            "a cached organization's row recorded no organization with every \
747             permit taken (QR16-2)"
748        );
749
750        let req = actix_web::test::TestRequest::get()
751            .uri(&format!("/api/v1/organizations/{org_id}/settings"))
752            .to_request();
753        let res = actix_web::test::call_service(&app, req).await;
754        assert_eq!(res.status(), 401);
755
756        let rows = system_rows(&audit, 2).await;
757        let row = rows
758            .iter()
759            .find(|r| r.id != cached_row_id)
760            .expect("the uncached organization's row");
761        assert_eq!(
762            LOOKUPS_STARTED.with(|n| n.get()),
763            0,
764            "a datastore read started with every permit taken (SR15-1)"
765        );
766        assert_eq!(
767            row.organization_id, None,
768            "the row recorded an organization looked up with every permit taken (SR15-1)"
769        );
770        drop(held);
771    }

773    /// SR15-1, the control: with a permit free, the lookup runs and holds its
774    /// permit until its read has finished; the row records the organization,
775    /// and the permit is returned.
776    #[actix_rt::test]
777    async fn a_lookup_holds_its_permit_until_its_read_finishes() {
778        use axiam_db::SurrealAuditLogRepository;
779
780        let (db, state) = state().await;
781        let org_id = organization(&state, "free").await;
782        let audit = SurrealAuditLogRepository::new(db.clone());
783        let app = system_audit_app!(state, audit);
784        let permits = || state.system_audit_org_cache.lookups.available_permits();
785
786        let gate = Arc::new(tokio::sync::Semaphore::new(0));
787        LOOKUP_GATE.with(|g| *g.borrow_mut() = Some(Arc::clone(&gate)));
788        LOOKUPS_STARTED.with(|n| n.set(0));
789        let req = actix_web::test::TestRequest::get()
790            .uri(&format!("/api/v1/organizations/{org_id}/settings"))
791            .to_request();
792        let res = actix_web::test::call_service(&app, req).await;
793        assert_eq!(res.status(), 401);
794        // QR16-2: the permit is taken inside the spawned task, just before its
795        // read, so wait for the task to reach the gated read.
796        let deadline = Instant::now() + Duration::from_secs(5);
797        while LOOKUPS_STARTED.with(|n| n.get()) == 0 {
798            assert!(Instant::now() < deadline, "the lookup's read never started");
799            tokio::time::sleep(Duration::from_millis(10)).await;
800        }
801        assert_eq!(
802            permits(),
803            MAX_CONCURRENT_LOOKUPS - 1,
804            "the lookup in flight holds no permit"
805        );
806
807        gate.add_permits(1);
808        LOOKUP_GATE.with(|g| *g.borrow_mut() = None);
809        let rows = system_rows(&audit, 1).await;
810        assert_eq!(rows[0].organization_id, Some(org_id));
811        let deadline = Instant::now() + Duration::from_secs(5);
812        while permits() != MAX_CONCURRENT_LOOKUPS {
813            assert!(
814                Instant::now() < deadline,
815                "the finished lookup kept its permit"
816            );
817            tokio::time::sleep(Duration::from_millis(10)).await;
818        }
819    }

829    /// QR3-4: with the map full of live entries, a stream of new invented ids
830    /// must not sweep the whole map under the global lock on every insert. A
831    /// sweep that freed nothing is not repeated until half the TTL has passed,
832    /// and the cap still holds.
833    #[test]
834    fn a_full_map_of_live_entries_is_not_swept_on_every_insert() {
835        let cache = SystemAuditOrgCache::new(Duration::from_secs(600), Duration::from_secs(600));
836        fill_unresolved(&cache);
837
838        for _ in 0..1_000 {
839            cache.insert(PathScope::Organization(Uuid::new_v4()), None);
840        }
841
842        let guard = lock(&cache.unresolved);
843        assert!(
844            guard.sweeps <= 1,
845            "1000 inserts into a full map of live entries ran {} full sweeps",
846            guard.sweeps
847        );
848        assert_eq!(guard.entries.len(), MAX_ENTRIES, "the cap no longer holds");
849    }

851    /// QR3-4, the other half: once half the TTL has passed, a full map is
852    /// swept again, so expired entries still make room for new ones.
853    #[test]
854    fn a_full_map_is_swept_again_once_half_the_ttl_has_passed() {
855        let ttl = Duration::from_millis(200);
856        let cache = SystemAuditOrgCache::new(ttl, ttl);
857        fill_unresolved(&cache);
858        // A sweep while every entry is live frees nothing; the id is dropped.
859        let early = PathScope::Organization(Uuid::new_v4());
860        cache.insert(early, None);
861        assert_eq!(cache.get(early), None);
862
863        std::thread::sleep(ttl + Duration::from_millis(20));
864        let late = PathScope::Organization(Uuid::new_v4());
865        cache.insert(late, None);
866
867        assert_eq!(
868            cache.get(late),
869            Some(None),
870            "an insert after the entries expired found no room"
871        );
872        let guard = lock(&cache.unresolved);
873        assert_eq!(guard.sweeps, 2);
874        assert_eq!(guard.entries.len(), 1);
875    }
