1//! The CIBA approval API — the user's half of a backchannel authentication
2//! request (G-7, T23.7.2, D-68).
3//!
4//! `POST /oauth2/bc-authorize` (see [`super::ciba`]) stores a request for a user
5//! the client named; the user is told (a mail with a link, T23.7.2) and decides
6//! here, in the console's end-user area, **after a full sign-in**. Four routes,
7//! the device grant's user routes' shape (`/api/v1/device/verify` and
8//! `/decide`) with the same two properties of that placement:
9//!
10//! * `AuthzMiddleware` — the caller is an authenticated human with a session.
11//!   Approval records *that session* as the evidence behind the minted tokens
12//!   (`sid`, `auth_time`, `amr`, `acr`; D-67), so a caller without one is
13//!   refused, whatever token it holds — and so is a token AXIAM minted for an
14//!   OAuth2 client, which names a session too (W5 F4 review, T-447): only a
15//!   console sign-in's token decides.
16//! * `CsrfMiddleware` — another origin cannot silently POST an approval on a
17//!   victim's session; the `binding_message` is what lets the *user* tell a
18//!   request they started from one an attacker did.
19//!
20//! | Route | Does |
21//! |---|---|
22//! | `GET /api/v1/ciba/requests?status=pending` | the signed-in user's own pending requests, each as the page below shows it |
23//! | `GET /api/v1/ciba/requests/{request_id}` | what the page shows, and the `version` it must send back |
24//! | `POST …/approve` | approve, conditional on that `version` |
25//! | `POST …/deny` | refuse, conditional on that `version` |
26//!
27//! # One answer for every reason (D-68)
28//!
29//! An unknown id, a request for **another user**, an expired one, one already
30//! decided, and one decided by someone else since the page read it are all
31//! `404 not_found`. The page must not become an oracle for which request ids
32//! exist or whose they are — the id is a handle, not a secret (D-68), so what
33//! protects a request is that only its own user, signed in, can see it.
34//!
35//! # The pending list (D-74, #566)
36//!
37//! The approval mail goes only to an address something vouches for (D-74), so an
38//! account without one — every federated account that never verified an address
39//! (T-160) — would never learn a record id. `GET /api/v1/ciba/requests` lists the
40//! caller's **own** pending, unexpired requests so the console can show them (a
41//! badge on the user menu) and open the page above by the `request_id` each
42//! carries. It is the same surface under the same rules: a console sign-in only,
43//! a bucket of its own in `ciba_approval_per_min`, and no oracle — the list holds
44//! only the caller's rows, so another user's, a decided and an expired request
45//! are simply absent. `status=pending` is the one filter; any other value is a
46//! `400`, and an absent one means the same. The `auth_req_id` is not stored in
47//! readable form and never leaves the token endpoint.
48//!
49//! # Step-up
50//!
51//! A request may ask for an authentication class (`acr_values`) the session
52//! has not achieved. `GET` says so up front (`step_up_required`), and `approve`
53//! answers `403 step_up_required` naming the class if the page asked anyway. The
54//! page then sends the user through the **existing login hop**
55//! (`/login?return_to=…&reauth=1&acr=…`), which ends the weak session, demands
56//! the factor, and comes back to this page — no marker is consumed by the way
57//! back: the request is validated afresh by the next `GET`, and `approve` is
58//! conditional on the version that read returned (T-404's lesson).
59//!
60//! # What the audit says
61//!
62//! `ciba.approved` and `ciba.denied` record the user, the session that decided,
63//! the request id, the client and the delivery mode — and, for an approval, the
64//! `acr` achieved. **Never the
65//! `binding_message`**: a client chooses it, and a call-centre agent's text
66//! ("confirm the transfer to J. Doe") can be personal data that has no business
67//! in an append-only log. The reader who needs it has the request row for as
68//! long as the row lives.

90/// What the approval page shows. Never the `auth_req_id`, a token, or the
91/// client's notification endpoint.
92#[derive(Debug, Serialize, utoipa::ToSchema)]
93pub struct CibaApprovalPage {
94    /// The request's record id (the one in the URL).
95    pub request_id: Uuid,
96    /// Send this back with the decision: approval and refusal are conditional on
97    /// it (D-68), so a request changed since the page read it is not decided.
98    pub version: u64,
99    /// The client that asked, by `client_id`.
100    pub client_id: String,
101    /// The client's display name (its `client_id` if the client was deleted).
102    pub client_name: String,
103    /// The scopes requested, `openid` included.
104    pub scopes: Vec<String>,
105    /// The client's `binding_message`, to compare with what the client's own
106    /// device shows. Render it as **text**.
107    pub binding_message: Option<String>,
108    /// The authentication classes the request asked for that AXIAM implements
109    /// (`urn:axiam:acr:1fa`, `urn:axiam:acr:mfa`). Empty when it asked for none.
110    pub requested_acr: Vec<String>,
111    /// Set when this session has not achieved a requested class: the class to
112    /// step up to before approving. `None` when approval can go ahead.
113    pub step_up_required: Option<String>,
114    /// When the request expires.
115    pub expires_at: DateTime<Utc>,
116}

166/// The authentication behind the caller's session, or `None` for a caller with
167/// no session row (a machine token, a session ended since the token was
168/// validated) **or whose token AXIAM minted for an OAuth2 client**.
169///
170/// The last is the W5 F4 review's (T-447): an access token from the code,
171/// refresh or CIBA grant names the user and a live session, and the user
172/// extractor admits it like a console sign-in's. Approving is the person's act
173/// on this page (contract §33: "that page is the console's job and is not SDK
174/// surface"); a relying party holding one of its user's tokens — a CIBA client
175/// that redeemed an earlier request among them — must not be able to approve
176/// in the user's name. A console sign-in's token carries no `client_id`.
177async fn session_evidence<C: Connection + Clone>(
178    state: &AppState<C>,
179    user: &AuthenticatedUser,
180) -> Result<Option<(DateTime<Utc>, Vec<Amr>)>, ()> {
181    if user.minted_for_client() {
182        return Ok(None);
183    }
184    match state
185        .session_repo
186        .get_by_id(user.principal_tenant_id, user.session_id)
187        .await
188    {
189        Ok(session) if session.user_id == user.user_id => {
190            Ok(Some((session.authenticated_at, session.amr)))
191        }
192        Ok(_) => Ok(None),
193        Err(axiam_core::error::AxiamError::NotFound { .. }) => Ok(None),
194        Err(e) => {
195            tracing::error!(error = %e, "the CIBA approval could not read the caller's session");
196            Err(())
197        }
198    }
199}

201/// Read a pending CIBA sign-in request addressed to the signed-in user.
202#[utoipa::path(
203    get,
204    operation_id = "ciba_approval_get",
205    path = "/api/v1/ciba/requests/{request_id}",
206    tag = "ciba",
207    params(("request_id" = Uuid, Path, description = "The request's record id, from the notification link")),
208    responses(
209        (status = 200, description = "The pending request", body = CibaApprovalPage),
210        (status = 401, description = "Not authenticated"),
211        (status = 403, description = "The token is not a console sign-in's: no session row behind it, \
212                                      or AXIAM minted it for an OAuth2 client"),
213        (status = 404, description = "Unknown, another user's, expired or already decided — one answer"),
214    ),
215    security(("session" = [])),
216)]
217pub async fn get_request<C: Connection + Clone>(
218    user: AuthenticatedUser,
219    path: web::Path<Uuid>,
220    state: web::Data<AppState<C>>,
221) -> HttpResponse {
222    let request_id = path.into_inner();
223    let tenant_id = user.principal_tenant_id;
224    let Ok(evidence) = session_evidence(&state, &user).await else {
225        return server_error();
226    };
227    let Some((_, amr)) = evidence else {
228        return session_required();
229    };
230    let view = match state
231        .oauth2
232        .ciba_service
233        .lookup_for_approval(tenant_id, request_id, user.user_id)
234        .await
235    {
236        Ok(Some(view)) => view,
237        Ok(None) => return not_found(),
238        Err(e) => {
239            tracing::error!(error = %e, "the CIBA approval lookup failed");
240            return server_error();
241        }
242    };
243    HttpResponse::Ok()
244        .append_header(("Cache-Control", "no-store"))
245        .json(approval_page(&state, tenant_id, view, &amr).await)
246}

263/// List the signed-in user's own pending CIBA sign-in requests.
264///
265/// For the account the approval mail never reaches (D-74): the console shows
266/// these and opens the page by `request_id`. Console sign-in only.
267#[utoipa::path(
268    get,
269    operation_id = "ciba_approval_list",
270    path = "/api/v1/ciba/requests",
271    tag = "ciba",
272    params(CibaListQuery),
273    responses(
274        (status = 200, description = "The caller's pending, unexpired requests (possibly none)", body = CibaPendingList),
275        (status = 400, description = "`status` is something other than `pending`"),
276        (status = 401, description = "Not authenticated"),
277        (status = 403, description = "The token is not a console sign-in's: no session row behind it, \
278                                      or AXIAM minted it for an OAuth2 client"),
279        (status = 429, description = "The `ciba_approval_per_min` allowance of this route is spent"),
280    ),
281    security(("session" = [])),
282)]
283pub async fn list_requests<C: Connection + Clone>(
284    user: AuthenticatedUser,
285    query: web::Query<CibaListQuery>,
286    state: web::Data<AppState<C>>,
287) -> HttpResponse {
288    let tenant_id = user.principal_tenant_id;
289    let Ok(evidence) = session_evidence(&state, &user).await else {
290        return server_error();
291    };
292    let Some((_, amr)) = evidence else {
293        return session_required();
294    };
295    if query.status.as_deref().is_some_and(|s| s != "pending") {
296        return HttpResponse::BadRequest().json(serde_json::json!({
297            "error": "validation_error",
298            "message": "Only status=pending is supported.",
299        }));
300    }
301    let views = match state
302        .oauth2
303        .ciba_service
304        .list_pending_for_approval(tenant_id, user.user_id)
305        .await
306    {
307        Ok(views) => views,
308        Err(e) => {
309            tracing::error!(error = %e, "the CIBA pending-request list failed");
310            return server_error();
311        }
312    };
313    let mut requests = Vec::with_capacity(views.len());
314    for view in views {
315        requests.push(approval_page(&state, tenant_id, view, &amr).await);
316    }
317    HttpResponse::Ok()
318        .append_header(("Cache-Control", "no-store"))
319        .json(CibaPendingList { requests })
320}

322/// What the page shows for `view`, given the authentication behind the
323/// caller's session (`amr`): shared by the single page and the list, so the
324/// two cannot disagree about a request.
325async fn approval_page<C: Connection + Clone>(
326    state: &AppState<C>,
327    tenant_id: Uuid,
328    view: CibaApprovalView,
329    amr: &[Amr],
330) -> CibaApprovalPage {
331    let client_name = state
332        .oauth2_client_repo
333        .get_by_client_id(tenant_id, &view.client_id)
334        .await
335        .map_or_else(|_| view.client_id.clone(), |client| client.name);
336    let requested_acr = view
337        .acr_values
338        .iter()
339        .filter_map(|v| axiam_oauth2::acr::Acr::from_wire(v))
340        .map(|acr| acr.as_str().to_owned())
341        .collect();
342    CibaApprovalPage {
343        request_id: view.request_id,
344        version: view.version,
345        client_id: view.client_id,
346        client_name,
347        scopes: view.scopes,
348        binding_message: view.binding_message,
349        requested_acr,
350        step_up_required: step_up_required(&view.acr_values, amr)
351            .map(|acr| acr.as_str().to_owned()),
352        expires_at: view.expires_at,
353    }
354}

356/// Approve a pending CIBA sign-in request, conditional on the version read.
357#[utoipa::path(
358    post,
359    operation_id = "ciba_approval_approve",
360    path = "/api/v1/ciba/requests/{request_id}/approve",
361    tag = "ciba",
362    params(("request_id" = Uuid, Path, description = "The request's record id")),
363    request_body = CibaDecisionBody,
364    responses(
365        (status = 200, description = "Approved", body = CibaDecisionResponse),
366        (status = 401, description = "Not authenticated"),
367        (status = 403, description = "The request asked for an authentication class this session has not \
368                                      achieved (`step_up_required`, body below); or the token is not a \
369                                      console sign-in's (`authorization_denied`)", body = CibaStepUpRequired),
370        (status = 404, description = "Unknown, another user's, expired, already decided, or changed since read"),
371    ),
372    security(("session" = [])),
373)]
374pub async fn approve<C: Connection + Clone>(
375    http: HttpRequest,
376    user: AuthenticatedUser,
377    path: web::Path<Uuid>,
378    body: web::Json<CibaDecisionBody>,
379    state: web::Data<AppState<C>>,
380) -> HttpResponse {
381    let request_id = path.into_inner();
382    let tenant_id = user.principal_tenant_id;
383    let Ok(evidence) = session_evidence(&state, &user).await else {
384        return server_error();
385    };
386    let Some((auth_time, amr)) = evidence else {
387        return session_required();
388    };
389    let outcome = state
390        .oauth2
391        .ciba_service
392        .approve(
393            tenant_id,
394            request_id,
395            body.version,
396            CibaApproval {
397                user_id: user.user_id,
398                session_id: user.session_id,
399                auth_time,
400                amr,
401            },
402        )
403        .await;
404    match outcome {
405        Ok(CibaDecisionOutcome::Recorded(request)) => {
406            audit_decision(&state, &http, &user, &request, CIBA_APPROVED_AUDIT_ACTION).await;
407            decided("approved")
408        }
409        Ok(CibaDecisionOutcome::NotDecidable) => not_found(),
410        Ok(CibaDecisionOutcome::StepUpRequired { required }) => HttpResponse::Forbidden()
411            .append_header(("Cache-Control", "no-store"))
412            .json(CibaStepUpRequired {
413                error: "step_up_required",
414                message: "This request needs a stronger sign-in than your current session.",
415                required_acr: required.as_str().to_owned(),
416            }),
417        Err(e) => {
418            tracing::error!(error = %e, "a CIBA approval failed");
419            server_error()
420        }
421    }
422}

424/// Refuse a pending CIBA sign-in request, conditional on the version read.
425#[utoipa::path(
426    post,
427    operation_id = "ciba_approval_deny",
428    path = "/api/v1/ciba/requests/{request_id}/deny",
429    tag = "ciba",
430    params(("request_id" = Uuid, Path, description = "The request's record id")),
431    request_body = CibaDecisionBody,
432    responses(
433        (status = 200, description = "Refused", body = CibaDecisionResponse),
434        (status = 401, description = "Not authenticated"),
435        (status = 403, description = "The token is not a console sign-in's: no session row behind it, \
436                                      or AXIAM minted it for an OAuth2 client"),
437        (status = 404, description = "Unknown, another user's, expired, already decided, or changed since read"),
438    ),
439    security(("session" = [])),
440)]
441pub async fn deny<C: Connection + Clone>(
442    http: HttpRequest,
443    user: AuthenticatedUser,
444    path: web::Path<Uuid>,
445    body: web::Json<CibaDecisionBody>,
446    state: web::Data<AppState<C>>,
447) -> HttpResponse {
448    let request_id = path.into_inner();
449    let tenant_id = user.principal_tenant_id;
450    let Ok(evidence) = session_evidence(&state, &user).await else {
451        return server_error();
452    };
453    if evidence.is_none() {
454        return session_required();
455    }
456    match state
457        .oauth2
458        .ciba_service
459        .deny(tenant_id, request_id, body.version, user.user_id)
460        .await
461    {
462        Ok(CibaDecisionOutcome::Recorded(request)) => {
463            audit_decision(&state, &http, &user, &request, CIBA_DENIED_AUDIT_ACTION).await;
464            decided("denied")
465        }
466        // `deny` never asks for a step-up: refusing needs no stronger sign-in.
467        Ok(CibaDecisionOutcome::NotDecidable | CibaDecisionOutcome::StepUpRequired { .. }) => {
468            not_found()
469        }
470        Err(e) => {
471            tracing::error!(error = %e, "a CIBA refusal failed");
472            server_error()
473        }
474    }
475}

483/// The audit row of a recorded decision. Awaited, not detached: the decision
484/// is already durable, and a deployment that cannot write its audit log should
485/// say so in its own log rather than lose the row silently — but the user's
486/// answer is not undone by it.
487async fn audit_decision<C: Connection + Clone>(
488    state: &AppState<C>,
489    http: &HttpRequest,
490    user: &AuthenticatedUser,
491    request: &CibaRequest,
492    action: &str,
493) {
494    // The session that decided (W5 F4 review, T-435): the request row that
495    // also holds it for an approval is swept ten minutes after it expires, and
496    // a refusal records no session on the row at all.
497    let mut metadata = serde_json::json!({
498        "client_id": request.client_id,
499        "delivery_mode": request.delivery_mode.as_str(),
500        "session_id": user.session_id.to_string(),
501    });
502    if let Some(approval) = &request.approval {
503        metadata["acr"] = serde_json::Value::String(approval.acr.clone());
504    }
505    let entry = CreateAuditLogEntry {
506        tenant_id: request.tenant_id,
507        actor_id: user.user_id,
508        actor_type: ActorType::User,
509        action: action.into(),
510        resource_id: Some(request.id),
511        outcome: AuditOutcome::Success,
512        ip_address: client_ip(http),
513        metadata: Some(metadata),
514    };
515    if let Err(e) = state.audit_repo.append(entry).await {
516        tracing::error!(error = %e, action, "failed to write a CIBA decision audit row");
517    }
