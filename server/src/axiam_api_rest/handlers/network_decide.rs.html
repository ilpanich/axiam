1//! `POST /api/v1/network/decide` — the RADIUS placement decision (RADIUS Live profile,
2//! W6.4; `claude_dev/radius-reply-profile-design.md` §4.3, §6.3, §7, §8; threat
3//! T-468).
4//!
5//! FreeRADIUS's `rlm_rest`, in `post-auth` after EAP-TLS succeeded, posts the
6//! presented certificate (or its fingerprint) and the **site key from its own
7//! client configuration**; AXIAM answers `{ "allow": false }` with **no
8//! reason**, or `{ "allow": true, "reply": … }` with the attributes of the
9//! segment the device is placed on, rendered from its typed reply profile.
10//!
11//! # The caller (T-468)
12//!
13//! An authenticated oracle on "is this certificate good here", so its caller is
14//! held to more than an ordinary machine route's:
15//!
16//! * a **service account** (`aud = axiam:m2m`, `sub_kind = service_account`);
17//!   a user's token, an OAuth2 client's and a user token narrowed to the machine
18//!   audience are `401`;
19//! * its token **bound to its own certificate**: `cnf.x5t#S256` present (a
20//!   plain bearer token, or one bound only by DPoP, is `401`), presented over a
21//!   connection whose TLS-verified client certificate is that one (the
22//!   extractor's sender-constraint check), and that certificate resolves —
23//!   through [`DeviceAuthService::authenticate_der`](axiam_pki::DeviceAuthService::authenticate_der),
24//!   now, so a revoked caller certificate stops at the next request — to **this**
25//!   service account in this tenant, which is `Active`;
26//! * holding `network:decide` on every site node the decision reads (§4.2: "a
27//!   site"), so a FreeRADIUS credential for HQ answers nothing about a branch
28//!   office: `403`, audited;
29//! * metered per **caller** (`network_decide_per_min`, D-6), not per address.
30//!
31//! The `network` permission family stays human-only
32//! ([`HUMAN_ONLY_FAMILIES`](crate::permissions::HUMAN_ONLY_FAMILIES)); this one
33//! route is the named exception,
34//! [`CERTIFICATE_BOUND_MACHINE_ROUTES`](crate::permissions::CERTIFICATE_BOUND_MACHINE_ROUTES).
35//!
36//! # The decision (§4.3), at one cost (T-457)
37//!
38//! Every request that gets past the caller's checks runs the same steps, in the
39//! same order, whatever the certificate turns out to be:
40//!
41//! 1. the certificate row by fingerprint (global), then `authenticate_der` —
42//!    over the caller's own certificate, as a decoy whose result is discarded,
43//!    when no row of this tenant resolved (#706); **another tenant's
44//!    certificate is refused** (§7), with the reject every other failure gets;
45//! 2. the subject's account (the device's service account, or — when no
46//!    certificate of this tenant resolved — the caller's own, as a decoy of the
47//!    same shape) — `Active` or no placement;
48//! 3. the site's segments, their stored profiles and the tenant's cap, each one
49//!    query; every profile is re-validated and rendered (§3.4), and a profile
50//!    that no longer validates makes its segment no candidate and is audited once
51//!    per window;
52//! 4. **one** `check_access_batch` of `network:join` over every enabled segment of
53//!    the site, for the subject (the decoy included), through the decision cache,
54//!    deny-override in force — which is what makes quarantine by deny work (§4.4);
55//! 5. the lowest-ranked `access` candidate, else a `quarantine` one, else none;
56//! 6. one audit row (T-463, §8), and the answer.
57//!
58//! "No candidate", "another tenant's certificate", "an unknown certificate or
59//! fingerprint", "an inactive account" and a placement therefore cost the same
60//! reads, one full verification and the same batch; only the answer differs.
61//! What remains is recorded for the threat model (T-457), not hidden:
62//! `authenticate_der`'s own early refusals for a row of **this** tenant (a
63//! revoked, expired or server certificate stops before the chain is verified),
64//! the engine's answer for a subject with no role assignment, and the **global
65//! fingerprint read** of step 1: a hit deserialises the row of another tenant's
66//! certificate and a miss is `NotFound`, so a caller can tell, by one indexed
67//! read against a verification, whether a certificate with that fingerprint
68//! exists in any tenant (T-457, residual (f); Informational, not closed).
69//!
70//! # What is never on the wire, and never in the row
71//!
72//! The deny carries no reason. The audit row carries the internal reason, the
73//! site, the certificate's SHA-256 fingerprint, and — for a certificate of this
74//! tenant — its id and the service account it is bound to; **never** the
75//! certificate's subject or alternative names, and the request accepts no
76//! `Calling-Station-Id` or `User-Name` (an unknown key is a `400`), so none can
77//! reach the trail (§8, T-464). A certificate of another tenant is recorded by
78//! its fingerprint alone: the caller's tenant learns nothing about the other's.

219/// The body's site key, the presented certificate, and its fingerprint.
220fn parse_body(body: NetworkDecisionRequest) -> Result<(String, Presented, String), AxiamApiError> {
221    if !is_valid_identifier(&body.site) {
222        return Err(invalid("site is not a valid site key"));
223    }
224    match (body.certificate, body.fingerprint) {
225        (Some(b64), None) => {
226            let der = base64::engine::general_purpose::STANDARD
227                .decode(b64.trim())
228                .map_err(|_| invalid("certificate is not standard base64"))?;
229            if der.is_empty() {
230                return Err(invalid("certificate is empty"));
231            }
232            let fingerprint = hex::encode(Sha256::digest(&der));
233            Ok((body.site, Presented::Certificate(der), fingerprint))
234        }
235        (None, Some(fp)) => {
236            let fp = fp.trim().to_ascii_lowercase();
237            if fp.len() != 64 || !fp.bytes().all(|b| b.is_ascii_hexdigit()) {
238                return Err(invalid(
239                    "fingerprint must be the SHA-256 of the certificate's DER, 64 hex digits",
240                ));
241            }
242            Ok((body.site, Presented::Fingerprint, fp))
243        }
244        _ => Err(invalid(
245            "exactly one of certificate and fingerprint is required",
246        )),
247    }
248}

260/// A service-account caller whose token is bound to a certificate this
261/// connection presented — the synchronous half of T-468's caller binding, run as
262/// an extractor so that it answers before the body is read: a plain bearer
263/// token is `401` whatever it posts.
264///
265/// The asynchronous half — that the certificate is still the caller's own and
266/// valid, and the account active — is [`certificate_bound_caller`], the
267/// handler's first step.
268pub struct CertificateBoundServiceAccount {
269    /// The authenticated machine token.
270    pub account: AuthenticatedServiceAccount,
271    /// The service account's id (the token's `sub`).
272    pub subject: Uuid,
273    /// The TLS-verified certificate the token is bound to, DER.
274    pub der: Vec<u8>,
275}
276
277impl FromRequest for CertificateBoundServiceAccount {
278    type Error = AxiamApiError;
279    type Future = std::pin::Pin<Box<dyn std::future::Future<Output = Result<Self, Self::Error>>>>;
280
281    fn from_request(req: &HttpRequest, payload: &mut actix_web::dev::Payload) -> Self::Future {
282        let account = AuthenticatedServiceAccount::from_request(req, payload);
283        let req = req.clone();
284        Box::pin(async move { Self::admit(&req, account.await?) })
285    }
286}
287
288impl CertificateBoundServiceAccount {
289    /// What follows the machine-token extraction, every refusal of it leaving
290    /// the D-12 verdict (#787).
291    fn admit(
292        req: &HttpRequest,
293        account: AuthenticatedServiceAccount,
294    ) -> Result<Self, AxiamApiError> {
295        Self::bind(req, account)
296            .map_err(|refusal| crate::extractors::auth::mark_refused(req, refusal))
297    }
298
299    fn bind(
300        req: &HttpRequest,
301        account: AuthenticatedServiceAccount,
302    ) -> Result<Self, AxiamApiError> {
303        let claims = &account.claims.0;
304        if claims.sub_kind != SubjectKind::ServiceAccount {
305            return Err(unauthenticated(
306                "the network decision route is a service account's; this machine token \
307                     is not one",
308            ));
309        }
310        let subject =
311            Uuid::parse_str(&account.subject).map_err(|_| unauthenticated("invalid sub claim"))?;
312        // A bearer token, or one bound only by DPoP, is not what T-468
313        // asks for: the binding must be to the caller's own certificate.
314        let Some(bound_to) = claims
315            .cnf
316            .as_ref()
317            .and_then(|cnf| cnf.certificate_thumbprint())
318        else {
319            return Err(unauthenticated(CERTIFICATE_BOUND_REFUSAL));
320        };
321        // The extractor has already refused a bound token whose certificate
322        // is not on this connection (`enforce_sender_constraint`); this
323        // restates it here, where the rest of the rule needs the
324        // certificate itself.
325        let Some(verified) = req.conn_data::<VerifiedClientCert>() else {
326            return Err(unauthenticated(CERTIFICATE_BOUND_REFUSAL));
327        };
328        verified
329            .check_usable_for_device_auth()
330            .map_err(AxiamApiError::from)?;
331        if axiam_oauth2::mtls::thumbprint_s256(&verified.der) != bound_to {
332            return Err(unauthenticated(CERTIFICATE_BOUND_REFUSAL));
333        }
334        let der = verified.der.clone();
335        Ok(Self {
336            account,
337            subject,
338            der,
339        })
340    }
341}

343/// The asynchronous half of the caller binding: the certificate the token is
344/// bound to is the caller's own **now** — revoked, expired, rebound to another
345/// account or another tenant's, it stops here at the next request rather than
346/// when the token expires — and the account is `Active`.
347async fn certificate_bound_caller<C: Connection + Clone>(
348    caller: &CertificateBoundServiceAccount,
349    state: &AppState<C>,
350) -> Result<Uuid, AxiamApiError> {
351    let tenant_id = caller.account.tenant_id;
352    let identity = state
353        .pki
354        .device_auth_service
355        .authenticate_der(&caller.der)
356        .await
357        .map_err(|_| unauthenticated(CERTIFICATE_BOUND_REFUSAL))?;
358    if identity.service_account_id != caller.subject || identity.tenant_id != tenant_id {
359        return Err(unauthenticated(CERTIFICATE_BOUND_REFUSAL));
360    }
361    let account = state
362        .service_account_repo
363        .get_by_id(tenant_id, caller.subject)
364        .await
365        .map_err(|_| unauthenticated("the calling service account is not active"))?;
366    if account.status != UserStatus::Active {
367        return Err(unauthenticated("the calling service account is not active"));
368    }
369    Ok(caller.subject)
370}

372/// Spend one decision of the caller's bucket (D-6): the shared counter when it
373/// is on, the in-process keyed limiter when it is off.
374fn admit<C: Connection + Clone>(state: &AppState<C>, tenant_id: Uuid, caller: Uuid) -> bool {
375    let per_min = state.rate_limit_cfg.network_decide_per_min;
376    if state.shared_rate_limit.is_enabled() {
377        state
378            .shared_rate_limit
379            .check_at(&bucket_key(tenant_id, caller), Utc::now(), per_min)
380    } else {
381        state.network_decide.admit(tenant_id, caller, per_min)
382    }
383}

401/// What the presented certificate resolved to.
402enum Resolved {
403    /// A certificate of the caller's tenant, bound to `service_account_id`.
404    Device {
405        service_account_id: Uuid,
406        certificate_id: Uuid,
407    },
408    /// Refused, with the internal reason. `certificate_id` is set only for a
409    /// certificate of the caller's tenant.
410    Refused {
411        reason: &'static str,
412        certificate_id: Option<Uuid>,
413    },
414}
415
416/// The one certificate a decision verifies.
417#[derive(Debug, PartialEq, Eq)]
418enum VerificationTarget<'a> {
419    /// A certificate of the caller's tenant: the DER presented, or — for the
420    /// fingerprint form — the row's own.
421    Presented(std::borrow::Cow<'a, [u8]>),
422    /// No row of the caller's tenant — unknown anywhere, or another tenant's:
423    /// the caller's own certificate, verified as a decoy and the result
424    /// discarded, so the refusal pays the full verification a certificate of
425    /// this tenant pays (T-457, #706).
426    Decoy(&'a [u8]),
427    /// A row of the caller's tenant whose stored PEM does not parse.
428    Nothing,
429}
430
431/// Which certificate `resolve_certificate` verifies. Every path but a stored
432/// PEM that does not parse verifies exactly one, and which one depends on the
433/// caller's own tenant alone: whether a fingerprint is registered in another
434/// tenant, and in what state, never decides whether a verification runs.
435fn verification_target<'a>(
436    presented: &'a Presented,
437    row: Option<&Certificate>,
438    tenant_id: Uuid,
439    caller_der: &'a [u8],
440) -> VerificationTarget<'a> {
441    match (presented, row.filter(|r| r.tenant_id == tenant_id)) {
442        (_, None) => VerificationTarget::Decoy(caller_der),
443        (Presented::Certificate(der), Some(_)) => VerificationTarget::Presented(der.into()),
444        (Presented::Fingerprint, Some(row)) => match pem_to_der(&row.public_cert_pem) {
445            Some(der) => VerificationTarget::Presented(der.into()),
446            None => VerificationTarget::Nothing,
447        },
448    }
449}

451/// Resolve the presented certificate through `authenticate_der`, refusing one
452/// of another tenant (§7). The row is read first, by fingerprint, for two
453/// reasons: the fingerprint form has no DER without it, and a refusal of this
454/// tenant's certificate can then be named from the row (revoked, expired)
455/// rather than from the wording of an error message. When no row of this
456/// tenant resolves, the caller's own certificate is verified instead and the
457/// result discarded ([`VerificationTarget::Decoy`]).
458async fn resolve_certificate<C: Connection + Clone>(
459    state: &AppState<C>,
460    tenant_id: Uuid,
461    presented: &Presented,
462    fingerprint: &str,
463    caller_der: &[u8],
464) -> Result<Resolved, AxiamApiError> {
465    let row: Option<Certificate> = match state
466        .pki
467        .cert_repo
468        .get_by_fingerprint_global(fingerprint)
469        .await
470    {
471        Ok(row) => Some(row),
472        Err(AxiamError::NotFound { .. }) => None,
473        Err(e) => return Err(e.into()),
474    };
475    let device_auth = &state.pki.device_auth_service;
476    let authenticated = match verification_target(presented, row.as_ref(), tenant_id, caller_der) {
477        VerificationTarget::Presented(der) => match device_auth.authenticate_der(&der).await {
478            Ok(identity) => Some(identity),
479            Err(AxiamError::Certificate(_) | AxiamError::NotFound { .. }) => None,
480            Err(e) => return Err(e.into()),
481        },
482        VerificationTarget::Decoy(der) => {
483            // Discarded whole, an error included: the decoy never changes the
484            // answer, the row or the status (the precedent is
485            // `equalising_dummy_verify`).
486            let _ = device_auth.authenticate_der(der).await;
487            None
488        }
489        VerificationTarget::Nothing => None,
490    };
491
492    let Some(row) = row.filter(|r| r.tenant_id == tenant_id) else {
493        // Unknown anywhere, or another tenant's: one reason, so the caller's
494        // tenant does not learn that the certificate exists elsewhere.
495        return Ok(Resolved::Refused {
496            reason: "certificate:not_in_tenant",
497            certificate_id: None,
498        });
499    };
500    match authenticated {
501        Some(identity) if identity.tenant_id == tenant_id && identity.certificate_id == row.id => {
502            Ok(Resolved::Device {
503                service_account_id: identity.service_account_id,
504                certificate_id: row.id,
505            })
506        }
507        _ => {
508            let now = Utc::now();
509            let reason = if row.status == CertificateStatus::Revoked {
510                "certificate:revoked"
511            } else if row.status != CertificateStatus::Active
512                || now < row.not_before
513                || now > row.not_after
514            {
515                "certificate:expired"
516            } else {
517                // Unbound, not a client certificate type, or its chain does
518                // not reach a trusted anchor.
519                "certificate:refused"
520            };
521            Ok(Resolved::Refused {
522                reason,
523                certificate_id: Some(row.id),
524            })
525        }
526    }
527}

529fn pem_to_der(pem: &str) -> Option<Vec<u8>> {

540    let (tenant_id, action) = (entry.tenant_id, entry.action.clone());

543            target: "axiam::network_decide",
544            %tenant_id,
545            action,
546            %error,
547            "a network decision audit row could not be written"
548        );
549    }

552/// One `reply_profile.invalid` row per profile per window (§3.4).
553async fn audit_defect<C: Connection + Clone>(
554    state: &AppState<C>,
555    http_req: &HttpRequest,
556    tenant_id: Uuid,
557    caller: Uuid,
558    segment: &NetworkSegment,
559    version: u64,
560    dictionary: &str,
561    defect: &ProfileDefect,
562) {
563    if !state
564        .network_decide
565        .first_in_window(tenant_id, segment.id, version, defect.rule)
566    {
567        return;
568    }
569    append(
570        state,
571        CreateAuditLogEntry {
572            tenant_id,
573            actor_id: caller,
574            actor_type: ActorType::ServiceAccount,
575            action: AUDIT_PROFILE_INVALID.to_owned(),
576            resource_id: Some(segment.id),
577            outcome: AuditOutcome::Failure,
578            ip_address: client_ip(http_req),
579            metadata: Some(json!({
580                "segment_id": segment.id,
581                "path": segment.path(),
582                "profile_version": version,
583                "dictionary": dictionary,
584                "rule": defect.rule,
585                "reason": defect.reason,
586                "window_secs": crate::network_decide_guard::INVALID_PROFILE_AUDIT_WINDOW.as_secs(),
587            })),
588        },
589    )
590    .await;
591}

593// ---------------------------------------------------------------------------
594// The route
595// ---------------------------------------------------------------------------
596
597/// `POST /api/v1/network/decide`
598///
599/// The RADIUS placement decision FreeRADIUS asks for once per EAP-TLS
600/// authentication (RADIUS Live profile). Not SDK surface: its caller is FreeRADIUS's
601/// service account, over mTLS with a token bound to its own certificate.
602#[utoipa::path(
603    post,
604    operation_id = "network_decide",
605    path = "/api/v1/network/decide",
606    tag = "network",
607    request_body = NetworkDecisionRequest,
608    responses(
609        (status = 200, description = "The decision. `{\"allow\": false}` carries no reason, \
610                                      whatever it was; `{\"allow\": true, \"reply\": …}` carries \
611                                      the placed segment's tunnel attributes and its reply \
612                                      profile's, `Session-Timeout` clamped to the tenant's cap. \
613                                      `Tunnel-Type` and `Tunnel-Medium-Type` carry tag 0 on the \
614                                      wire; `Tunnel-Private-Group-Id` carries no tag octet",
615         body = NetworkDecisionResponse),
616        (status = 400, description = "The body: an unknown key (named), a site key outside the \
617                                      pattern, not exactly one of `certificate` and \
618                                      `fingerprint`, or one that does not decode"),
619        (status = 401, description = "Not a service account, or its token is not bound \
620                                      (`cnf.x5t#S256`) to the certificate this mTLS connection \
621                                      presented, or that certificate is no longer the caller's \
622                                      own and valid, or the account is not active"),
623        (status = 403, description = "The caller lacks `network:decide` on the site"),
624        (status = 429, description = "The caller's `network_decide_per_min` allowance is spent"),
625    ),
626    security(("service_account" = []))
627)]
628pub async fn decide<C: Connection + Clone>(
629    http_req: HttpRequest,
630    caller: CertificateBoundServiceAccount,
631    authz: AuthzData,
632    state: web::Data<AppState<C>>,
633    body: web::Json<NetworkDecisionRequest>,
634) -> Result<HttpResponse, AxiamApiError> {
635    // The bucket is the caller's own (D-6), spent as soon as the token is known
636    // to be its — signed by AXIAM, and bound to the certificate whose key this
637    // connection proved — and before anything is read for it.
638    let tenant_id = caller.account.tenant_id;
639    if !admit(&state, tenant_id, caller.subject) {
640        return Ok(too_many_requests());
641    }
642    let caller_id = certificate_bound_caller(&caller, &state).await?;
643    let (site, presented, fingerprint) = parse_body(body.into_inner())?;
644    let authz = authz.get_ref().as_ref();
645
646    // The site: every segment of it, both branches, one query.
647    let segments = SurrealNetworkSegmentRepository::new(state.db.clone())
648        .list_site(tenant_id, &site)
649        .await?;
650
651    // The caller holds `network:decide` on every site node the decision reads
652    // (a site with no segment yet: on its `zones` node).
653    let mut site_nodes: BTreeSet<Uuid> = segments
654        .iter()
655        .map(|s| site_node_id(tenant_id, s.kind, &site))
656        .collect();
657    if site_nodes.is_empty() {
658        site_nodes.insert(site_node_id(tenant_id, NetworkSegmentKind::Access, &site));
659    }
660    let site_nodes: Vec<Uuid> = site_nodes.into_iter().collect();
661    let decide_checks: Vec<AccessRequest> = site_nodes
662        .iter()
663        .map(|node| AccessRequest {
664            tenant_id,
665            subject_scope: SubjectScope::Tenant,
666            subject_id: caller_id,
667            action: NETWORK_DECIDE.to_owned(),
668            resource_id: *node,
669            scope: None,
670        })
671        .collect();
672    let answers = authz.check_access_batch(&decide_checks).await?;
673    if let Some((node, decision)) = site_nodes
674        .iter()
675        .zip(&answers)
676        .find(|(_, d)| !matches!(d, AccessDecision::Allow))
677    {
678        let reason = match decision {
679            AccessDecision::Deny(r) | AccessDecision::DeniedByRule(r) => r.clone(),
680            AccessDecision::Allow => String::new(),
681        };
682        append(
683            &state,
684            CreateAuditLogEntry {
685                tenant_id,
686                actor_id: caller_id,
687                actor_type: ActorType::ServiceAccount,
688                action: AUDIT_DECISION_REFUSED.to_owned(),
689                resource_id: Some(*node),
690                outcome: AuditOutcome::Denied,
691                ip_address: client_ip(&http_req),
692                metadata: Some(json!({
693                    "site": site,
694                    "rule": "4.2:decide",
695                    "missing_permission": NETWORK_DECIDE,
696                    "node": node,
697                    "reason": reason,
698                    "status": 403,
699                })),
700            },
701        )
702        .await;
703        return Err(AxiamApiError(AxiamError::AuthorizationDenied {
704            reason,
705            action: Some(NETWORK_DECIDE.to_owned()),
706            resource_id: Some(node.to_string()),
707        }));
708    }
709
710    // 1. The certificate, then 2. the subject's account. When no certificate
711    // of this tenant resolved, the caller's own account stands in as the
712    // subject: an account that exists and holds role assignments, so the reads
713    // and the batch below cost what a real device's do. Its answers are
714    // discarded.
715    let resolved =
716        resolve_certificate(&state, tenant_id, &presented, &fingerprint, &caller.der).await?;
717    let (subject, device) = match &resolved {
718        Resolved::Device {
719            service_account_id, ..
720        } => (*service_account_id, true),
721        Resolved::Refused { .. } => (caller_id, false),
722    };
723    let account_active = match state
724        .service_account_repo
725        .get_by_id(tenant_id, subject)
726        .await
727    {
728        Ok(account) => account.status == UserStatus::Active,
729        Err(AxiamError::NotFound { .. }) => false,
730        Err(e) => return Err(e.into()),
731    };
732
733    // 3. The profiles and the cap, each one query, every profile re-validated.
734    let segment_ids: Vec<Uuid> = segments.iter().map(|s| s.id).collect();
735    let stored = SurrealReplyProfileRepository::new(state.db.clone())
736        .list_stored(tenant_id, &segment_ids)
737        .await?;
738    let cap = SurrealNetworkPolicyRepository::new(state.db.clone())
739        .get(tenant_id)
740        .await?
741        .session_timeout_max_secs;
742    let mut rendered: Vec<Option<(RenderedReply, Value)>> = Vec::with_capacity(segments.len());
743    for segment in &segments {
744        let Some(profile) = stored.iter().find(|p| p.segment_id == segment.id) else {
745            // No profile: no candidate, which only narrows (§5.2).
746            rendered.push(None);
747            continue;
748        };
749        match profile.revalidate(segment, cap) {
750            Ok((effective, reply)) => rendered.push(Some((
751                reply,
752                json!({
753                    "profile_version": profile.version,
754                    "session_timeout_secs": effective.session_timeout_secs,
755                    "session_timeout_clamped": effective.session_timeout_clamped,
756                }),
757            ))),
758            Err(defect) => {
759                audit_defect(
760                    &state,
761                    &http_req,
762                    tenant_id,
763                    caller_id,
764                    segment,
765                    profile.version,
766                    &profile.dictionary,
767                    &defect,
768                )
769                .await;
770                rendered.push(None);
771            }
772        }
773    }
774
775    // 4. One batch of `network:join`, over every enabled segment of the site,
776    // through the decision cache, deny-override in force.
777    let enabled: Vec<usize> = (0..segments.len())
778        .filter(|i| segments[*i].enabled)
779        .collect();
780    let join_checks: Vec<AccessRequest> = enabled
781        .iter()
782        .map(|i| AccessRequest {
783            tenant_id,
784            subject_scope: SubjectScope::Tenant,
785            subject_id: subject,
786            action: NETWORK_JOIN.to_owned(),
787            resource_id: segments[*i].id,
788            scope: None,
789        })
790        .collect();
791    let join_answers = authz.check_access_batch(&join_checks).await?;
792    let mut joinable = vec![false; segments.len()];
793    for (i, answer) in enabled.iter().zip(&join_answers) {
794        joinable[*i] = matches!(answer, AccessDecision::Allow);
795    }
796    let usable: Vec<bool> = rendered.iter().map(Option::is_some).collect();
797
798    // 5. The placement — counted only for a device of this tenant whose
799    // account may act.
800    let placed = select_placement(&segments, &joinable, &usable);
801    let placement = placed
802        .filter(|_| device && account_active)
803        .and_then(|i| rendered[i].take().map(|r| (i, r)));
804
805    // 6. One row, and the answer.
806    let mut metadata = json!({
807        "site": site,
808        "presented": presented.as_str(),
809        "certificate_fingerprint": fingerprint,
810        "method": "eap_tls",
811        "transport": "rlm_rest",
812        "candidates": segments.len(),
813    });
814    if let Resolved::Device {
815        service_account_id,
816        certificate_id,
817    } = &resolved
818    {
819        metadata["subject_id"] = json!(service_account_id);
820        metadata["certificate_id"] = json!(certificate_id);
821    }
822    if let Resolved::Refused {
823        certificate_id: Some(id),
824        ..
825    } = &resolved
826    {
827        metadata["certificate_id"] = json!(id);
828    }
829    let response = match placement {
830        Some((i, (reply, values))) => {
831            let segment = &segments[i];
832            metadata["reason"] = json!(match segment.kind {
833                NetworkSegmentKind::Access => "placement:access",
834                NetworkSegmentKind::Quarantine => "placement:quarantine",
835            });
836            metadata["segment_id"] = json!(segment.id);
837            metadata["segment_kind"] = json!(segment.kind.as_str());
838            metadata["vlan_id"] = json!(segment.vlan_id);
839            if let Value::Object(extra) = values {
840                for (k, v) in extra {
841                    metadata[k] = v;
842                }
843            }
844            append(
845                &state,
846                CreateAuditLogEntry {
847                    tenant_id,
848                    actor_id: caller_id,
849                    actor_type: ActorType::ServiceAccount,
850                    action: AUDIT_DECISION_ALLOWED.to_owned(),
851                    resource_id: Some(segment.id),
852                    outcome: AuditOutcome::Success,
853                    ip_address: client_ip(&http_req),
854                    metadata: Some(metadata),
855                },
856            )
857            .await;
858            NetworkDecisionResponse {
859                allow: true,
860                reply: Some(reply),
861            }
862        }
863        None => {
864            let reason = match &resolved {
865                Resolved::Refused { reason, .. } => *reason,
866                Resolved::Device { .. } if !account_active => "account:inactive",
867                Resolved::Device { .. } => "placement:no_candidate",
868            };
869            metadata["reason"] = json!(reason);
870            append(
871                &state,
872                CreateAuditLogEntry {
873                    tenant_id,
874                    actor_id: caller_id,
875                    actor_type: ActorType::ServiceAccount,
876                    action: AUDIT_DECISION_DENIED.to_owned(),
877                    resource_id: None,
878                    outcome: AuditOutcome::Denied,
879                    ip_address: client_ip(&http_req),
880                    metadata: Some(metadata),
881                },
882            )
883            .await;
884            NetworkDecisionResponse {
885                allow: false,
886                reply: None,
887            }
888        }
889    };
890    Ok(HttpResponse::Ok().json(response))
891}

898    const CALLER: &[u8] = b"the caller's own certificate";

903    fn row(tenant_id: Uuid, pem: &str) -> Certificate {
904        Certificate {
905            id: Uuid::new_v4(),
906            tenant_id,
907            issuer_ca_id: Uuid::new_v4(),
908            subject: "device-001".into(),
909            public_cert_pem: pem.into(),
910            fingerprint: "00".repeat(32),
911            cert_type: CertificateType::Device,
912            key_algorithm: KeyAlgorithm::Ed25519,
913            not_before: Utc::now(),
914            not_after: Utc::now(),
915            status: CertificateStatus::Active,
916            metadata: Value::Null,
917            user_id: None,
918            created_at: Utc::now(),
919        }
920    }
921
922    /// The structural half of T-457 for the verification (#706): every path
923    /// verifies exactly one certificate, and every refusal before a row of this
924    /// tenant — an unknown certificate or fingerprint, another tenant's —
925    /// verifies the caller's own, whatever the other tenant holds.
926    #[test]
927    fn every_path_verifies_one_certificate_and_every_refusal_the_callers() {
928        let tenant = Uuid::new_v4();
929        let mine = row(tenant, ROW_PEM);
930        let theirs = row(Uuid::new_v4(), ROW_PEM);
931        let unparsable = row(tenant, "not a PEM");
932        let by_der = Presented::Certificate(PRESENTED.to_vec());
933        let by_fingerprint = Presented::Fingerprint;
934        let cases: [(&str, &Presented, Option<&Certificate>, VerificationTarget); 7] = [
935            (
936                "unknown certificate",
937                &by_der,
938                None,
939                VerificationTarget::Decoy(CALLER),
940            ),
941            (
942                "another tenant's certificate",
943                &by_der,
944                Some(&theirs),
945                VerificationTarget::Decoy(CALLER),
946            ),
947            (
948                "this tenant's certificate",
949                &by_der,
950                Some(&mine),
951                VerificationTarget::Presented(PRESENTED.into()),
952            ),
953            (
954                "unknown fingerprint",
955                &by_fingerprint,
956                None,
957                VerificationTarget::Decoy(CALLER),
958            ),
959            (
960                "another tenant's fingerprint",
961                &by_fingerprint,
962                Some(&theirs),
963                VerificationTarget::Decoy(CALLER),
964            ),
965            (
966                "this tenant's fingerprint",
967                &by_fingerprint,
968                Some(&mine),
969                VerificationTarget::Presented(vec![1, 2, 3].into()),
970            ),
971            (
972                "this tenant's row, PEM unparsable",
973                &by_fingerprint,
974                Some(&unparsable),
975                VerificationTarget::Nothing,
976            ),
977        ];
978        for (name, presented, row, expected) in cases {

984        }
