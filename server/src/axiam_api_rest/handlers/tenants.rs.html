1//! Tenant management endpoints (nested under organizations).
2//!
3//! # Deleting a tenant destroys its audit trail (T-118)
4//!
5//! Tenant data is tenant-scoped all the way down, and `audit_log` is no
6//! exception: the rows that record what happened inside a tenant carry that
7//! tenant's id and go when it goes. That is the evidence disappearing at
8//! exactly the moment it matters, and until beta03 the threat model resolved
9//! it by telling operators to "export to a WORM sink first" — a rule nothing
10//! checked.
11//!
12//! It is now checked. [`export_audit`] streams a tenant's complete audit trail
13//! and records that it did so *in that tenant's own audit log*; [`delete`]
14//! refuses with `409` unless such a record exists and is less than
15//! [`AUDIT_EXPORT_MAX_AGE_HOURS`] hours old. The window is deliberately short
16//! and deliberately not configurable: the point is that the export is
17//! contemporaneous with the deletion, not that one was taken at some time in
18//! the tenant's history.
19//!
20//! ## What this does and does not prove
21//!
22//! It proves that a named principal asked this server for the whole trail, and
23//! that the server produced it, minutes before the deletion. It does **not**
24//! prove the bytes were kept — an operator can stream the export to
25//! `/dev/null`. Nothing in-product can prove custody of a file it handed to
26//! someone else; what changes is that destroying a tenant's audit trail is now
27//! a deliberate two-step act by an identified principal, recorded twice (the
28//! export receipt, and the deletion record written to the *system* audit log,
29//! which survives the tenant).
30//!
31//! ## GDPR Art. 17
32//!
33//! The gate delays an erasure by the length of one export, and does not block
34//! it: there is no `?force` and no configuration that turns the requirement
35//! off, because the export is the thing that makes erasure safe rather than an
36//! obstacle to it. Art. 17(3)(b)/(e) already permit retention where processing
37//! is necessary for legal obligations or the defence of legal claims, which is
38//! what an exported audit trail is for; and the export contains no more
39//! personal data than the tenant already held. A deployment whose lawful basis
40//! does not permit keeping the export simply deletes the file — the receipt
41//! records that an export happened, never its contents.
42

66// T-118: the audit-export gate on tenant deletion
67// ---------------------------------------------------------------------------
68
69/// Audit action recorded by [`export_audit`], and the one [`delete`] looks for.
70///
71/// Namespaced under `tenants.` like the rest of the management surface. It is
72/// written with `outcome = Success` only after the whole trail has been
73/// streamed, so a half-finished download leaves no receipt behind.
74pub const AUDIT_EXPORT_ACTION: &str = "tenants.audit_exported";
75
76/// Audit action recorded — in the **system** log, not the tenant's — when a
77/// tenant is deleted. The tenant's own entries are gone by then; this is what
78/// is left to say the deletion happened, who did it, and which export receipt
79/// authorised it.
80pub const TENANT_DELETED_ACTION: &str = "tenants.deleted";
81
82/// How recent the export receipt must be for [`delete`] to accept it.
83///
84/// Six hours: long enough that an operator can export, verify the file landed
85/// in their archive, and get an approval before deleting; short enough that
86/// the export is unmistakably *about this deletion* rather than a routine dump
87/// from last quarter. Not configurable — a deployment that could set this to a
88/// year would have the rule without the property the rule exists for.
89pub const AUDIT_EXPORT_MAX_AGE_HOURS: i64 = 6;
90
91/// Rows fetched from the datastore per round trip while streaming an export.
92///
93/// The export is streamed rather than assembled because a tenant's audit trail
94/// has no upper bound — the retention sweep (T-119) bounds its *age*, not its
95/// size — and materialising one in the response buffer would make a large
96/// tenant's export an out-of-memory condition on the server.
97const AUDIT_EXPORT_PAGE_SIZE: u64 = 500;
98
99/// One step of the export stream.
100enum ExportPhase {
101    /// Still draining `audit_log`, `offset` rows in.
102    Rows {
103        offset: u64,
104        count: u64,
105        hasher: Sha256,
106    },
107    /// Rows exhausted: write the receipt and emit the trailing manifest line.
108    Manifest { count: u64, digest: String },
109    /// Nothing further to emit.
110    Done,
111}
112
113/// The most recent successful export receipt for `tenant_id`, if one falls
114/// inside the freshness window.
115///
116/// Reads the tenant's own audit log — the receipt is an ordinary append-only
117/// entry, so this needs no new table, no new retention rule and no second
118/// source of truth that could disagree with the trail it is about.
119async fn recent_export_receipt<C: Connection + Clone>(
120    state: &AppState<C>,
121    tenant_id: Uuid,
122    now: DateTime<Utc>,
123) -> Result<Option<(Uuid, DateTime<Utc>)>, AxiamError> {
124    let cutoff = now - chrono::Duration::hours(AUDIT_EXPORT_MAX_AGE_HOURS);
125    let page = state
126        .audit_repo
127        .list(
128            tenant_id,
129            AuditLogFilter {
130                action: Some(AUDIT_EXPORT_ACTION.to_string()),
131                outcome: Some(AuditOutcome::Success),
132                from: Some(cutoff),
133                ..Default::default()
134            },
135            Pagination {
136                offset: 0,
137                // `list` orders by timestamp DESC, so one row is the newest.
138                limit: 1,
139                search: None,
140            },
141        )
142        .await?;
143    Ok(page
144        .items
145        .into_iter()
146        .next()
147        .map(|entry| (entry.id, entry.timestamp)))
148}

183pub async fn create<C: Connection + Clone>(
184    user: AuthenticatedUser,
185    authz: AuthzData,
186    state: web::Data<AppState<C>>,
187    path: web::Path<OrgPath>,
188    body: web::Json<CreateTenantRequest>,
189) -> Result<HttpResponse, AxiamApiError> {
190    RequirePermission::new("tenants:create", Uuid::nil())
191        .check(&user, authz.get_ref().as_ref())
192        .await?;
193
194    // Authorization: only allow creating tenants under the caller's own org.
195    if path.org_id != user.org_id {
196        return Err(AxiamApiError(
197            axiam_core::error::AxiamError::AuthorizationDenied {
198                reason: "cannot access a different organization".into(),
199                action: None,
200                resource_id: None,
201            },
202        ));
203    }
204
205    let req = body.into_inner();
206
207    // The organization scope is created with its organization, never through
208    // this endpoint. Refusing the reserved slug here turns what would be an
209    // opaque unique-index violation into a message that says which name is
210    // taken and why.
211    if req.slug == axiam_core::models::tenant::ORGANIZATION_TENANT_SLUG {
212        return Err(AxiamApiError(AxiamError::Validation {
213            message: format!(
214                "`{}` is reserved for the organization's own scope, which is created \
215                 with the organization; choose another slug",
216                axiam_core::models::tenant::ORGANIZATION_TENANT_SLUG
217            ),
218        }));
219    }
220
221    let input = CreateTenant {
222        organization_id: path.org_id,
223        name: req.name,
224        slug: req.slug,
225        // Always an ordinary tenant: `CreateTenant::kind` is
226        // `skip_deserializing`, so a caller cannot ask for anything else, and
227        // saying so explicitly here keeps that visible at the one call site
228        // that matters.
229        kind: TenantKind::Standard,
230        metadata: req.metadata,
231    };
232    let tenant = state.tenant_repo.create(input).await?;
233
234    // Auto-seed permissions for the new tenant so RBAC works immediately.
235    seed_permissions(&state.db.current(), tenant.id, PERMISSION_REGISTRY)
236        .await
237        .map_err(|e| {
238            tracing::error!(
239                "Failed to seed permissions for new tenant {}: {}",
240                tenant.id,
241                e
242            );
243            AxiamApiError(AxiamError::Internal(
244                "Failed to seed permissions for tenant".into(),
245            ))
246        })?;
247
248    // …and its roles. Seeding permissions alone left the tenant holding a set
249    // of actions with nothing to attach them to: no roles, no grants, no
250    // assignments. The authorization engine filters every lookup by tenant, so
251    // the first question anyone asked about the new tenant — including the
252    // person who had just created it — resolved to `no roles assigned` and was
253    // denied. A tenant nobody can administer is not a tenant.
254    //
255    // Not best-effort, unlike the permission seed's sibling failure paths
256    // elsewhere: a tenant with permissions and no roles is exactly the
257    // unreachable state this repairs, so failing here has to be visible rather
258    // than leaving one behind for someone to find later.
259    seed_default_roles(&state.db.current(), tenant.id, PERMISSION_REGISTRY)
260        .await
261        .map_err(|e| {
262            tracing::error!(
263                tenant_id = %tenant.id,
264                error = %e,
265                "Failed to seed default roles for new tenant"
266            );
267            AxiamApiError(AxiamError::Internal(
268                "Failed to seed default roles for tenant".into(),
269            ))
270        })?;
271
272    // Nothing is assigned to anyone here, deliberately. Organization-level
273    // principals already reach this tenant — their global grants live in the
274    // organization tenant and carry across by the rule in
275    // `AuthorizationEngine::evaluate` — so fanning assignments out at creation
276    // time would write rows that grant nothing new, would miss every
277    // organization-level principal created afterwards, and would have to be
278    // undone in every tenant to revoke. See
279    // `claude_dev/organization-scope-design.md`.
280
281    Ok(HttpResponse::Created().json(tenant))
282}

442pub async fn delete<C: Connection + Clone>(
443    user: AuthenticatedUser,
444    authz: AuthzData,
445    state: web::Data<AppState<C>>,
446    path: web::Path<TenantPath>,
447) -> Result<HttpResponse, AxiamApiError> {
448    RequirePermission::new("tenants:delete", Uuid::nil())
449        .check(&user, authz.get_ref().as_ref())
450        .await?;
451
452    // Authorization: reject cross-org probing before touching the DB.
453    if path.org_id != user.org_id {
454        return Err(AxiamApiError(
455            axiam_core::error::AxiamError::AuthorizationDenied {
456                reason: "cannot access a different organization".into(),
457                action: None,
458                resource_id: None,
459            },
460        ));
461    }
462
463    let existing = state.tenant_repo.get_by_id(path.tenant_id).await?;
464    if existing.organization_id != path.org_id {
465        return Err(AxiamError::NotFound {
466            entity: "Tenant".into(),
467            id: path.tenant_id.to_string(),
468        }
469        .into());
470    }
471
472    // T-118: refuse unless the trail about to be destroyed was exported
473    // recently. Checked BEFORE the delete, so a refusal leaves the tenant
474    // exactly as it was.
475    let now = Utc::now();
476    let Some((receipt_id, exported_at)) =
477        recent_export_receipt(state.get_ref(), path.tenant_id, now).await?
478    else {
479        return Err(AxiamError::Conflict {
480            reason: format!(
481                "deleting this tenant destroys its audit trail. Export it first with \
482                 POST /api/v1/organizations/{}/tenants/{}/audit-export, then retry \
483                 within {AUDIT_EXPORT_MAX_AGE_HOURS} hours.",
484                path.org_id, path.tenant_id
485            ),
486        }
487        .into());
488    };
489
490    state.tenant_repo.delete(path.tenant_id).await?;
491
492    // The tenant's own audit entries — including the export receipt just
493    // checked — went with it, so this record goes to the SYSTEM log (nil
494    // tenant), which is the only part of the trail that outlives the tenant.
495    // Written through the dead-lettering sink for the same reason the erasure
496    // records are: this is the last chance to record it, and a transient
497    // datastore failure must not be how it gets lost.
498    write_erasure_audit_with_dlq(
499        &state.audit_repo,
500        CreateAuditLogEntry {
501            tenant_id: Uuid::nil(),
502            actor_id: user.user_id,
503            actor_type: ActorType::User,
504            action: TENANT_DELETED_ACTION.to_string(),
505            resource_id: Some(path.tenant_id),
506            outcome: AuditOutcome::Success,
507            ip_address: None,
508            metadata: Some(serde_json::json!({
509                "organization_id": path.org_id,
510                "tenant_slug": existing.slug,
511                "audit_export_receipt_id": receipt_id,
512                "audit_exported_at": exported_at,
513            })),
514        },
515    )
516    .await;
517
518    Ok(HttpResponse::NoContent().finish())
519}

521/// `POST /api/v1/organizations/{org_id}/tenants/{tenant_id}/audit-export`
522///
523/// Streams the tenant's complete audit trail as newline-delimited JSON, one
524/// [`axiam_core::models::audit::AuditLogEntry`] per line, newest first, and
525/// records the export in that tenant's audit log — which is what
526/// [`delete`] then requires (T-118).
527///
528/// The last line is not an entry but a manifest object carrying
529/// `record_count`, the SHA-256 `digest` over the entry lines that precede it,
530/// and `receipt_id` — the id of the audit entry this export wrote. An archive
531/// can therefore be tied back to the receipt that authorised the deletion, and
532/// re-hashing the file proves it is the export the receipt describes.
533///
534/// `POST` rather than `GET`: it is not safe and not idempotent — every call
535/// appends a receipt.
536#[utoipa::path(
537    post,
538    path = "/api/v1/organizations/{org_id}/tenants/{tenant_id}/audit-export",
539    tag = "tenants",
540    params(
541        ("org_id" = Uuid, Path, description = "Organization ID"),
542        ("tenant_id" = Uuid, Path, description = "Tenant ID"),
543    ),
544    responses(
545        (status = 200, description = "Newline-delimited audit entries, then a \
546             manifest line", content_type = "application/x-ndjson"),
547        (status = 404, description = "Tenant not found"),
548    ),
549    security(("bearer" = []))
550)]
551pub async fn export_audit<C: Connection + Clone>(
552    user: AuthenticatedUser,
553    authz: AuthzData,
554    state: web::Data<AppState<C>>,
555    path: web::Path<TenantPath>,
556) -> Result<HttpResponse, AxiamApiError> {
557    RequirePermission::new("tenants:export_audit", Uuid::nil())
558        .check(&user, authz.get_ref().as_ref())
559        .await?;
560
561    // Authorization: reject cross-org probing before touching the DB.
562    if path.org_id != user.org_id {
563        return Err(AxiamApiError(AxiamError::AuthorizationDenied {
564            reason: "cannot access a different organization".into(),
565            action: None,
566            resource_id: None,
567        }));
568    }
569
570    let existing = state.tenant_repo.get_by_id(path.tenant_id).await?;
571    if existing.organization_id != path.org_id {
572        return Err(AxiamError::NotFound {
573            entity: "Tenant".into(),
574            id: path.tenant_id.to_string(),
575        }
576        .into());
577    }
578
579    let tenant_id = path.tenant_id;
580    let actor_id = user.user_id;
581    let audit_repo = state.audit_repo.clone();
582    // Fix the upper bound of the export at the moment it starts. Without it,
583    // rows appended while the stream is draining would shift the offsets of
584    // every page after them and the export would skip entries.
585    let started_at = Utc::now();
586
587    let stream = futures::stream::unfold(
588        ExportPhase::Rows {
589            offset: 0,
590            count: 0,
591            hasher: Sha256::new(),
592        },
593        move |phase| {
594            let audit_repo = audit_repo.clone();
595            async move {
596                match phase {
597                    ExportPhase::Rows {
598                        offset,
599                        count,
600                        mut hasher,
601                    } => {
602                        let page = audit_repo
603                            .list(
604                                tenant_id,
605                                AuditLogFilter {
606                                    to: Some(started_at),
607                                    ..Default::default()
608                                },
609                                Pagination {
610                                    offset,
611                                    limit: AUDIT_EXPORT_PAGE_SIZE,
612                                    search: None,
613                                },
614                            )
615                            .await;
616                        let page = match page {
617                            Ok(page) => page,
618                            Err(e) => {
619                                tracing::error!(
620                                    error = %e,
621                                    %tenant_id,
622                                    "tenants: audit export failed mid-stream"
623                                );
624                                // Ending the body with an error truncates the
625                                // transfer, so the caller sees a failure rather
626                                // than a short file that looks complete. No
627                                // receipt is written, so `delete` still refuses.
628                                return Some((
629                                    Err(actix_web::error::ErrorInternalServerError(
630                                        "audit export failed",
631                                    )),
632                                    ExportPhase::Done,
633                                ));
634                            }
635                        };
636
637                        if page.items.is_empty() {
638                            let digest = hex::encode(hasher.finalize());
639                            return Some((
640                                Ok(web::Bytes::new()),
641                                ExportPhase::Manifest { count, digest },
642                            ));
643                        }
644
645                        let fetched = page.items.len() as u64;
646                        let mut chunk = String::new();
647                        for entry in &page.items {
648                            match serde_json::to_string(entry) {
649                                Ok(line) => {
650                                    chunk.push_str(&line);
651                                    chunk.push('\n');
652                                }
653                                Err(e) => {
654                                    tracing::error!(
655                                        error = %e,
656                                        %tenant_id,
657                                        "tenants: audit entry could not be serialized"
658                                    );
659                                    return Some((
660                                        Err(actix_web::error::ErrorInternalServerError(
661                                            "audit export failed",
662                                        )),
663                                        ExportPhase::Done,
664                                    ));
665                                }
666                            }
667                        }
668                        hasher.update(chunk.as_bytes());
669                        Some((
670                            Ok(web::Bytes::from(chunk)),
671                            ExportPhase::Rows {
672                                offset: offset + fetched,
673                                count: count + fetched,
674                                hasher,
675                            },
676                        ))
677                    }
678
679                    ExportPhase::Manifest { count, digest } => {
680                        // The receipt is written HERE — after the last row has
681                        // been handed to the client — so that an export which
682                        // dies half way leaves nothing behind that would let a
683                        // tenant be deleted.
684                        let receipt = audit_repo
685                            .append(CreateAuditLogEntry {
686                                tenant_id,
687                                actor_id,
688                                actor_type: ActorType::User,
689                                action: AUDIT_EXPORT_ACTION.to_string(),
690                                resource_id: Some(tenant_id),
691                                outcome: AuditOutcome::Success,
692                                ip_address: None,
693                                metadata: Some(serde_json::json!({
694                                    "record_count": count,
695                                    "digest": format!("sha256:{digest}"),
696                                    "exported_through": started_at,
697                                })),
698                            })
699                            .await;
700                        let receipt = match receipt {
701                            Ok(entry) => entry,
702                            Err(e) => {
703                                tracing::error!(
704                                    error = %e,
705                                    %tenant_id,
706                                    "tenants: audit export receipt could not be written"
707                                );
708                                // Without a receipt the export did not happen as
709                                // far as `delete` is concerned, so the caller
710                                // must be told rather than handed a manifest
711                                // that claims otherwise.
712                                return Some((
713                                    Err(actix_web::error::ErrorInternalServerError(
714                                        "audit export receipt could not be written",
715                                    )),
716                                    ExportPhase::Done,
717                                ));
718                            }
719                        };
720
721                        let manifest = serde_json::json!({
722                            "axiam_export": "tenant_audit",
723                            "tenant_id": tenant_id,
724                            "exported_by": actor_id,
725                            "exported_through": started_at,
726                            "record_count": count,
727                            "digest": format!("sha256:{digest}"),
728                            "receipt_id": receipt.id,
729                            "receipt_valid_for_hours": AUDIT_EXPORT_MAX_AGE_HOURS,
730                        });
731                        Some((
732                            Ok(web::Bytes::from(format!("{manifest}\n"))),
733                            ExportPhase::Done,
734                        ))
735                    }
736
737                    ExportPhase::Done => None,
738                }
739            }
740        },
741    );
742
743    let filename = format!(
744        "axiam-audit-{tenant_id}-{}.ndjson",
745        started_at.format("%Y%m%dT%H%M%SZ")
746    );
747    Ok(HttpResponse::Ok()
748        .content_type("application/x-ndjson")
749        .insert_header((
750            header::CONTENT_DISPOSITION,
751            format!("attachment; filename=\"{filename}\""),
752        ))
753        .streaming(Box::pin(stream)))
754}
