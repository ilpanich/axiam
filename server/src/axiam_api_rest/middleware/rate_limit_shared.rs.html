1//! Shared (cross-replica) rate-limit pre-check middleware
2//! (SECHRD-03 / D-01a, D-01b, D-01d).
3//!
4//! [`RateLimitShared`] consults the process-wide write-behind
5//! [`SharedRateLimitCounter`] (`axiam-db::rate_limit_counter`) BEFORE the
6//! existing per-replica in-memory `Governor`/`GovernorLayer`
7//! (`server.rs::build_governor`, kept byte-for-byte unchanged as the
8//! fail-open fallback). This closes the multi-replica HPA gap where
9//! per-replica in-memory buckets otherwise multiply the effective rate
10//! limit by the replica count.
11//!
12//! # No synchronous datastore write on the request path (H2 fix)
13//!
14//! This middleware used to `await` ONE SurrealDB `UPSERT`
15//! (`SurrealRateLimitBucketRepository::increment`) per request, before the
16//! handler ran. That single write capped every wrapped endpoint at **16–21
17//! ops/s at any concurrency from 1 to 40 VUs** (p50 ≈ 55–65 ms at 1 VU,
18//! ≈ 1 s at 20 VUs) while structurally identical unwrapped endpoints ran at
19//! 68–4 248 ops/s — the datastore attributed ~39–46 ms of each request to
20//! that one RPC, and the same UPSERT issued directly ran in 6–9 ms and
21//! scaled fine, so the ordering (not the datastore) was the ceiling. Full
22//! measurements: `claude_dev/postseed-transient-investigation.md` §2, §3, §7.
23//!
24//! The counting mechanism — and ONLY the counting mechanism — changed: the
25//! key derivation (`{endpoint}:{key_part}`, the D8 `client_id` modes, the
26//! body peek/restore), the 429 response shape and every fail-open branch
27//! behave exactly as before. [`SharedRateLimitCounter::check`] is fully
28//! synchronous (one sharded-map increment, no datastore round trip, no task
29//! spawn) and a single background flusher coalesces the accumulated
30//! increments into one datastore write per bucket per
31//! `AXIAM__RATE_LIMIT__SHARED_SYNC_MS`. Cross-replica enforcement is
32//! therefore *eventual*, with the overshoot bound stated precisely in the
33//! [`axiam_db::rate_limit_counter`] module docs; the in-memory governor still
34//! makes a full per-replica decision on the very same endpoints.
35//!
36//! **Fail-open (D-01b, T-24-42 accepted risk):** when no client-IP key can be
37//! derived, no [`AppState`] (hence no counter) is registered, or the shared
38//! layer is disabled via `AXIAM__RATE_LIMIT__SHARED=off`, this middleware
39//! forwards the request unchanged so the existing in-memory governor makes
40//! the decision instead. Store outages are now surfaced by the counter's
41//! flusher (a `warn` alarm that never includes the raw key — T-24-43) while
42//! decisions keep being served from local counts. A counter-store outage must
43//! never hard-block auth traffic — this is the ONE deliberate fail-open
44//! exception; every other control fails closed.
45//!
46//! **CRITICAL (RESEARCH Pitfall 1):** `governor::StateStore::measure_and_replace`
47//! is a *synchronous* trait method. This middleware is deliberately NOT a
48//! `StateStore` implementation and never calls `block_on`/`futures::executor::
49//! block_on` — it is a separate Actix `Transform`/`Service` (mirroring
50//! [`crate::middleware::authz::AuthzMiddleware`]'s scaffold). It stays async
51//! only because the D8 body peek (`req.extract::<web::Bytes>()`) is async;
52//! the rate-limit decision itself no longer awaits anything.
53

73/// Fixed-window duration (seconds) for the shared bucket. A simple
74/// fixed-window counter is acceptable here (unlike the in-memory GCRA
75/// governor) because this layer only needs to be *approximately* right —
76/// it fails open by design (RESEARCH.md "Don't Hand-Roll").
77const WINDOW_SECS: i64 = 60;
78
79/// Reads the SAME `AXIAM__RATE_LIMIT__TRUSTED_HOPS` env var
80/// `server.rs::build_governor` uses, so the shared-store bucket key and the
81/// in-memory governor's key are derived from the identical client IP
82/// (D-01d parity — a rotating XFF must not yield a fresh bucket in either
83/// layer).
84fn trusted_hops() -> usize {
85    std::env::var("AXIAM__RATE_LIMIT__TRUSTED_HOPS")
86        .ok()
87        .and_then(|v| v.parse().ok())
88        .unwrap_or(0)
89}
90
91/// Truncates `now` down to the start of the current fixed
92/// [`WINDOW_SECS`]-second window.
93///
94/// The request path no longer calls this — it hands the raw `now` to
95/// [`axiam_db::SharedRateLimitCounter::check_at`], which derives the window
96/// itself so it can also see the *offset* into it (run-5 J1, the
97/// sliding-window bound). Kept, and asserted by a test, because
98/// [`WINDOW_SECS`] must keep agreeing with the counter's configured window:
99/// the two are one contract split across two crates.
100#[cfg_attr(not(test), allow(dead_code))]
101fn window_start(now: DateTime<Utc>) -> DateTime<Utc> {
102    let epoch = now.timestamp();
103    let start_epoch = epoch - epoch.rem_euclid(WINDOW_SECS);
104    DateTime::<Utc>::from_timestamp(start_epoch, 0).unwrap_or(now)
105}
106
107/// Builds the same-shaped 429 response the in-memory governor returns
108/// (`extractors::rate_limit::XForwardedForKeyExtractor::exceed_rate_limit_response`),
109/// so clients see one consistent rate-limit contract regardless of which
110/// layer rejected the request.
111fn too_many_requests_response() -> HttpResponse {
112    HttpResponse::TooManyRequests()
113        .content_type(ContentType::json())
114        .insert_header((RETRY_AFTER, WINDOW_SECS.to_string()))
115        .body(r#"{"error":"rate_limit_exceeded"}"#)
116}

122/// Shared SurrealDB-backed rate-limit pre-check middleware.
123///
124/// Generic over the SurrealDB connection type `C` so it can be wired
125/// against both the production `DbClient` and the in-memory `Mem` engine
126/// used in tests. `endpoint` MUST be unique per rate-limited resource so
127/// the shared bucket key (`"{endpoint}:{ip}"`) preserves per-endpoint
128/// granularity — never collapse distinct endpoints into one global bucket.
129///
130/// Wire this BEFORE (i.e. `.wrap()` AFTER, since the last `.wrap()` call is
131/// the outermost layer and therefore executes first) `build_governor(...)`
132/// on the same resource, e.g.:
133///
134/// ```ignore
135/// web::resource("/login")
136///     .wrap(build_governor(rate_limit_cfg.login_per_min))
137///     .wrap(RateLimitShared::<C>::new("login", rate_limit_cfg.login_per_min))
138///     .route(web::post().to(handlers::auth::login::<C>))
139/// ```
140pub struct RateLimitShared<C: Connection + Clone> {
141    endpoint: &'static str,
142    limit: u32,
143    /// D8: bucket-key derivation mode. Always [`RateLimitKeyMode::Ip`] for
144    /// instances built via [`RateLimitShared::new`] — only
145    /// [`RateLimitShared::new_client_identity_aware`] ever sets this to
146    /// something else.
147    key_mode: RateLimitKeyMode,
148    /// D8: whether this resource has a form-encoded OAuth2 `client_id` to
149    /// peek at (`/oauth2/token`, `/oauth2/revoke`, `/oauth2/introspect`
150    /// ONLY — see [`RateLimitShared::new_client_identity_aware`]). `false`
151    /// for every other resource (including `/auth/login`), which never
152    /// touches the request body and always keys per-IP.
153    client_identity_aware: bool,
154    /// Whether a person spends this bucket at human speed — the
155    /// browser-endpoint preset ([`RateLimitShared::browser_preset`]) — so a
156    /// key the counter has not seen gets its whole budget
157    /// ([`axiam_db::SharedRateLimitCounter::check_at_human`]).
158    human: bool,
159    _marker: PhantomData<C>,
160}
161
162impl<C: Connection + Clone> RateLimitShared<C> {
163    /// Plain IP-keyed constructor — unchanged since before D8. Use this for
164    /// every endpoint EXCEPT `/oauth2/token`, `/oauth2/revoke`, and
165    /// `/oauth2/introspect`. In particular, `/auth/login` MUST keep using
166    /// this constructor: it authenticates a user via username/password, so
167    /// there is no OAuth2 `client_id` in the request to key on, and this
168    /// type never reads `AXIAM__RATE_LIMIT__KEY` for it.
169    pub fn new(endpoint: &'static str, limit: u32) -> Self {
170        Self {
171            endpoint,
172            limit,
173            key_mode: RateLimitKeyMode::Ip,
174            client_identity_aware: false,
175            human: false,
176            _marker: PhantomData,
177        }
178    }
179
180    /// The **browser-endpoint preset**: `end_session_per_min` per IP, for a
181    /// route a person reaches by navigation — `/oauth2/authorize`, the
182    /// end-session routes and the SAML IdP's browser routes — under a bucket of
183    /// its own.
184    ///
185    /// Unlike [`Self::new`] with the same number, a key the counter has not
186    /// seen gets the whole preset whenever in the minute it arrives: the
187    /// counter's cold-entry seed, which pro-rates a newly seen key at limits of
188    /// 20 and up, is for machine traffic, and at 30 it left a person first seen
189    /// late in a minute about three authorizations. The preset owns that
190    /// property, so a route cannot take the number without it.
191    pub fn browser_preset(endpoint: &'static str, rate_limit_cfg: &RateLimitConfig) -> Self {
192        Self {
193            human: true,
194            ..Self::new(endpoint, rate_limit_cfg.end_session_per_min)
195        }
196    }
197
198    /// D8 constructor for the three endpoints where an OAuth2 client
199    /// authenticates itself and names itself by a form-encoded `client_id`
200    /// (`client_secret_post`, RFC 6749 §2.3.1) or by an `Authorization: Basic`
201    /// header (`client_secret_basic`, T23.1.5): `/oauth2/token`,
202    /// `/oauth2/revoke`, `/oauth2/introspect`.
203    ///
204    /// When `key_mode` is [`RateLimitKeyMode::ClientId`] or
205    /// [`RateLimitKeyMode::IpClientId`], this middleware peeks (and
206    /// restores) the request body to read `client_id`, and stashes it into
207    /// the request extensions (as [`RateLimitClientId`]) so the downstream
208    /// in-memory `Governor`'s `ClientAwareKeyExtractor` on the SAME
209    /// resource can reuse it without a second body read. When `key_mode` is
210    /// [`RateLimitKeyMode::Ip`] this is exactly as if `new()` had been
211    /// called — the body is never touched.
212    ///
213    /// **Do not use this constructor for `/auth/login` or any other
214    /// endpoint without a client identity** — see
215    /// [`crate::config::rate_limit::RateLimitKeyMode`] docs.
216    pub fn new_client_identity_aware(
217        endpoint: &'static str,
218        limit: u32,
219        key_mode: RateLimitKeyMode,
220    ) -> Self {
221        Self {
222            endpoint,
223            limit,
224            key_mode,
225            client_identity_aware: true,
226            human: false,
227            _marker: PhantomData,
228        }
229    }
230}

274pub struct RateLimitSharedService<S, C: Connection + Clone> {
275    inner: Rc<S>,
276    endpoint: &'static str,
277    limit: u32,
278    key_mode: RateLimitKeyMode,
279    client_identity_aware: bool,
280    human: bool,
281    _marker: PhantomData<C>,
282}
283
284impl<S, B, C> Service<ServiceRequest> for RateLimitSharedService<S, C>
285where
286    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error> + 'static,
287    B: 'static,
288    C: Connection + Clone + 'static,
289{
290    type Response = ServiceResponse<EitherBody<B>>;
291    type Error = Error;
292    type Future = std::pin::Pin<Box<dyn Future<Output = Result<Self::Response, Self::Error>>>>;
293
294    fn poll_ready(
295        &self,
296        cx: &mut std::task::Context<'_>,
297    ) -> std::task::Poll<Result<(), Self::Error>> {
298        self.inner.poll_ready(cx)
299    }
300
301    fn call(&self, mut req: ServiceRequest) -> Self::Future {
302        let endpoint = self.endpoint;
303        let limit = self.limit;
304        let key_mode = self.key_mode;
305        let client_identity_aware = self.client_identity_aware;
306        let human = self.human;
307        let inner = Rc::clone(&self.inner);
308
309        // Reuse the EXACT fixed IP-key extraction logic (D-01d) so the
310        // shared bucket key and the in-memory governor's key agree.
311        let extractor = XForwardedForKeyExtractor::with_trusted_hops(trusted_hops());
312        let ip = extractor.extract(&req).ok();
313
314        // The process-wide write-behind counter is read from
315        // `web::Data<AppState<C>>` (QUAL-01 — was a standalone
316        // `web::Data<Surreal<C>>` registration used to build a repository per
317        // request). Its absence is treated exactly like the old missing-DB-
318        // handle case below — fail open to the in-memory governor.
319        //
320        // This is a cheap `Arc` clone of the ONE counter registered in
321        // `main.rs`, never a new counter: a per-request (or per-worker)
322        // instance would fragment the local count.
323        let counter = req
324            .app_data::<web::Data<AppState<C>>>()
325            .map(|d| d.shared_rate_limit.clone());
326
327        Box::pin(async move {
328            // D8: for the client-identity-aware endpoints only
329            // (`/oauth2/token`, `/oauth2/revoke`, `/oauth2/introspect` —
330            // never `/auth/login`), peek the form-encoded body for
331            // `client_id` and restore the payload so the handler's
332            // `web::Form<..>` extractor still sees the full body
333            // untouched. This ALSO stashes the result into request
334            // extensions for the downstream in-memory `Governor`'s
335            // `ClientAwareKeyExtractor` to reuse (see
336            // `extractors::rate_limit::RateLimitClientId`).
337            //
338            // Skipped entirely in `ip` mode (the default) — no body read,
339            // byte-for-byte the pre-D8 code path.
340            let client_id = if client_identity_aware {
341                let client_id = if key_mode != RateLimitKeyMode::Ip {
342                    let bytes = req.extract::<web::Bytes>().await.unwrap_or_default();
343                    // T23.1.5: the form's `client_id`, else the one an
344                    // `Authorization: Basic` header names — a
345                    // `client_secret_basic` client sends it there alone.
346                    let authorization = req
347                        .headers()
348                        .get(actix_web::http::header::AUTHORIZATION)
349                        .and_then(|v| v.to_str().ok());
350                    let client_id = extract_client_id(&bytes, authorization);
351                    // Restore the body EXACTLY as read so the handler's
352                    // `web::Form<..>` extraction downstream is unaffected —
353                    // this middleware must be transparent to the request.
354                    req.set_payload(Payload::from(bytes));
355                    client_id
356                } else {
357                    None
358                };
359                req.extensions_mut()
360                    .insert(RateLimitClientId(client_id.clone()));
361                client_id
362            } else {
363                None
364            };
365
366            // The bucket-key "identity" part: IP alone (`ip` mode, or
367            // fail-safe fallback when no client_id was found), the
368            // client_id alone, or the `(ip, client_id)` pair. Mirrors
369            // `extractors::rate_limit::ClientAwareKeyExtractor` exactly so
370            // this shared-store pre-check and the in-memory governor never
371            // disagree about which bucket a request belongs to.
372            let key_part = match (key_mode, &client_id) {
373                (RateLimitKeyMode::Ip, _) | (_, None) => ip.map(|ip| ip.to_string()),
374                (RateLimitKeyMode::ClientId, Some(cid)) => Some(format!("client:{cid}")),
375                (RateLimitKeyMode::IpClientId, Some(cid)) => {
376                    ip.map(|ip| format!("{ip}:client:{cid}"))
377                }
378            };
379
380            let now = Utc::now();
381            // Carried past the decision so a downstream rejection can be
382            // refunded against the SAME key and window (run-5 J1).
383            let charged = match (key_part, counter) {
384                (Some(key_part), Some(counter)) => {
385                    // Same bucket key as before — `{endpoint}:{key_part}` —
386                    // so an in-flight upgrade keeps counting against the same
387                    // `rate_limit_bucket` records.
388                    let key = format!("{endpoint}:{key_part}");
389                    // Fully synchronous: no datastore round trip on the
390                    // request path (H2 fix). Store outages are reported by
391                    // the counter's background flusher, which keeps serving
392                    // decisions from local counts (fail open, D-01b).
393                    //
394                    // `check_at` (not `check`) so the counter sees where
395                    // inside the window the request landed and can apply the
396                    // sliding-window bound that closes the run-5 J1
397                    // over-admission (`axiam_db::rate_limit_counter::WindowMode`).
398                    //
399                    // The browser-endpoint preset skips the counter's
400                    // cold-entry seed: its buckets are a person's.
401                    let allow = if human {
402                        counter.check_at_human(&key, now, limit)
403                    } else {
404                        counter.check_at(&key, now, limit)
405                    };
406                    Some((counter, key, allow))
407                }
408                // No key part (IP unavailable) or no counter registered —
409                // fail open; the in-memory governor still makes the real
410                // decision. (A counter built with
411                // `AXIAM__RATE_LIMIT__SHARED=off` also always allows, from
412                // inside `check_at`.)
413                _ => None,
414            };
415
416            let allow = charged.as_ref().is_none_or(|(_, _, allow)| *allow);
417
418            if allow {
419                let res = inner.call(req).await?;
420                // Run-5 J1: the in-memory governor sits INSIDE this
421                // middleware and may reject with 429 a request this layer
422                // already charged. Charging capacity to a request that was
423                // never served is what starved the gRPC families down to
424                // 1/33 of their ceiling; refund it so the cross-replica
425                // counter tracks *served* traffic. See
426                // `SharedRateLimitCounter::refund`.
427                if res.status() == StatusCode::TOO_MANY_REQUESTS
428                    && let Some((counter, key, true)) = &charged
429                {
430                    counter.refund(key, now);
431                }
432                Ok(res.map_into_left_body())
433            } else {
434                let res = req.into_response(too_many_requests_response());
435                Ok(res.map_into_right_body())
436            }
437        })
438    }
439}

441#[cfg(test)]
442mod window_contract_tests {
443    use super::*;
444
445    /// [`WINDOW_SECS`] and the shared counter's configured window are one
446    /// contract split across two crates: this middleware hands
447    /// `SharedRateLimitCounter::check_at` a raw `now` and lets the counter
448    /// derive the window, so if the two ever disagreed the `Retry-After` this
449    /// middleware advertises would be a lie about a window nobody uses.
450    #[test]
451    fn window_secs_matches_the_shared_counters_window() {
452        let counter_window = axiam_db::SharedRateLimitConfig::default().window;
453        assert_eq!(
454            counter_window.as_secs() as i64,
455            WINDOW_SECS,
456            "REST WINDOW_SECS must equal the shared counter's window"
457        );
458    }
459
460    /// The local truncation helper must agree with the counter's, so a
461    /// `Retry-After` computed here points at the same boundary the counter
462    /// will roll over on.
463    #[test]
464    fn window_start_truncates_to_the_window_boundary() {
465        let now = DateTime::<Utc>::from_timestamp(1_800_000_045, 0).expect("valid epoch");
466        let start = window_start(now);
467
468        assert_eq!(start.timestamp() % WINDOW_SECS, 0, "aligned to the window");
469        assert!(start <= now && now.timestamp() - start.timestamp() < WINDOW_SECS);
470    }
471
472    /// The browser-endpoint preset takes its number from
473    /// `end_session_per_min` and is the one constructor that marks its bucket
474    /// human-facing; `new` with the same number keeps the machine shape.
475    #[test]
476    fn the_browser_preset_is_human_facing_and_new_is_not() {
477        let cfg = RateLimitConfig {
478            end_session_per_min: 30,
479            ..RateLimitConfig::default()
480        };
481        let preset = RateLimitShared::<surrealdb::engine::local::Db>::browser_preset(
482            "oauth2_authorize",
483            &cfg,
484        );
485        assert_eq!(preset.limit, 30);
486        assert!(preset.human);
487        assert!(!preset.client_identity_aware);
488        assert!(preset.clone().human, "a clone keeps the flag");
489
490        let plain = RateLimitShared::<surrealdb::engine::local::Db>::new("revoke", 30);
491        assert!(!plain.human);
492    }
