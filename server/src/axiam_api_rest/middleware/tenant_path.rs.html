1//! The `/t/{tenant_id}` scope: per-tenant path issuers (T21.6).
2//!
3//! RFC 8414 §2 forbids a query component in an issuer identifier, so AXIAM's
4//! `{root}` plus `?tenant_id=` cannot be published as the issuer of one tenant.
5//! An MCP server naming AXIAM in its RFC 9728 `authorization_servers` therefore
6//! had no way to point a client at anything but the deployment's default
7//! tenant. `{root}/t/{tenant_id}` is an issuer a client can turn into a
8//! discovery URL by the RFC 8414 §3 rule with no query at all.
9//!
10//! The whole feature is opt-in
11//! (`AXIAM__AUTH__TENANT_ISSUER_PATHS`, [`AuthConfig::tenant_issuer_paths`]).
12//! With it unset this scope is not mounted, so nothing in this module runs.
13//!
14//! # What the middleware does, and why it is a middleware at all
15//!
16//! Every OAuth2 handler already resolves its tenant from a `tenant_id` query
17//! parameter — the token, revocation, introspection, device-authorization, PAR
18//! and end-session endpoints all require one, and `/oauth2/authorize` needs one
19//! for any request without a principal. So the tenant path does not need new
20//! handlers; it needs the tenant the *path* named to arrive where the handlers
21//! already look. This middleware rewrites the request's query string to carry
22//! it, and the eleven handlers underneath are the same functions serving
23//! `/oauth2/…`, byte for byte.
24//!
25//! It also records a [`TenantPathBinding`] in the request's extensions. Two
26//! things read it:
27//!
28//! * the four places that **stamp** an `iss` — the access token, the ID token,
29//!   the logout token and the RFC 9207 authorization-response parameter — so
30//!   that all four say `{root}/t/{tenant_id}`, which is what the discovery
31//!   document the client read says and what OIDC Core §2 requires them to
32//!   match;
33//! * [`AuthenticatedUser`](crate::extractors::AuthenticatedUser), which refuses
34//!   a principal whose tenant is not the tenant the path named.
35//!
36//! # The two refusals, and why both are fail-closed
37//!
38//! **A tenant segment that is not a UUID** is `invalid_request`, decided from
39//! the path alone with no repository read. Nothing is normalised and nothing is
40//! looked up, so `/t/../oauth2/token` and `/t/%2e%2e/oauth2/token` are refused
41//! for the same reason a typo is: they are not a UUID.
42//!
43//! **A `tenant_id` query parameter on a tenant path** is `invalid_request`,
44//! whether or not it agrees with the path. Two tenant selectors on one request
45//! is exactly the shape a confused-deputy bug takes — one component reads the
46//! path, another reads the query, and they answer differently — and the cheapest
47//! way to have no such bug is to have no such request. A client that followed
48//! the tenant discovery document never sends one: every endpoint URL in it is
49//! bare, which is the point of the path form.
50//!
51//! Note what is deliberately *not* checked here: whether the tenant exists.
52//! Discovery is public and unauthenticated, and a `404` for an unknown tenant
53//! id would make this scope a tenant-enumeration oracle. An unknown tenant gets
54//! exactly what `?tenant_id=<unknown>` gets today — whatever the handler
55//! underneath answers, which for every credential-taking endpoint is
56//! `invalid_client`.

72/// The tenant a request arrived under, and the issuer it therefore mints with.
73///
74/// Present in a request's extensions exactly when that request came through the
75/// `/t/{tenant_id}` scope. Absent on every other request, which is every
76/// request on a deployment with `AXIAM__AUTH__TENANT_ISSUER_PATHS` unset.
77///
78/// The [`AuthConfig`] is a whole clone rather than just the issuer string so
79/// that a handler can pass `&AuthConfig` to the token-minting functions
80/// unchanged — none of them learns that tenant paths exist, which is what keeps
81/// the four `iss` stamping sites from drifting apart.
82#[derive(Debug, Clone)]
83pub struct TenantPathBinding {
84    /// The tenant named by the path segment, already parsed.
85    pub tenant_id: Uuid,
86    /// The deployment's config with
87    /// [`request_issuer`](AuthConfig::request_issuer) set to
88    /// `{root}/t/{tenant_id}`.
89    ///
90    /// `Arc` because several extractors and handlers read it on one request and
91    /// none of them mutates it.
92    pub auth_config: Arc<AuthConfig>,
93}
94
95impl TenantPathBinding {
96    /// The tenant issuer this request mints under.
97    #[must_use]
98    pub fn issuer(&self) -> &str {
99        self.auth_config.effective_issuer()
100    }
101}
102
103/// The tenant binding of a request, if it arrived on a tenant path.
104#[must_use]
105pub fn binding_of(req: &HttpRequest) -> Option<TenantPathBinding> {
106    req.extensions().get::<TenantPathBinding>().cloned()
107}
108
109/// The config a request mints its tokens under.
110///
111/// `Borrowed(deployment)` — and therefore exactly today's behaviour, with no
112/// allocation — for every request that did not arrive on a tenant path.
113#[must_use]
114pub fn minting_config<'a>(req: &HttpRequest, deployment: &'a AuthConfig) -> Cow<'a, AuthConfig> {
115    match binding_of(req) {
116        None => Cow::Borrowed(deployment),
117        Some(binding) => Cow::Owned((*binding.auth_config).clone()),
118    }
119}

147/// The RFC 6749 §5.2-shaped refusal this middleware answers with.
148///
149/// JSON rather than actix's `text/plain` default, because every endpoint under
150/// this scope answers errors as a JSON object and a refusal that arrives before
151/// the handler must not be the one exception a client cannot parse.
152fn invalid_request(description: &str) -> HttpResponse {
153    HttpResponse::BadRequest().json(OAuth2ErrorResponse {
154        error: "invalid_request".into(),
155        error_description: description.to_owned(),
156    })
157}

159/// `path?query` with `tenant_id` appended, as a `Uri` (T21.6).
160///
161/// Only the query is rewritten. The path is left exactly as actix matched it,
162/// because the scope's inner routing reads the already-captured match info
163/// rather than this string — rewriting the path here would change what the
164/// handlers see (`req.path()` feeds the DPoP `htu`, RFC 9449 §4.3) without
165/// changing what was routed, which is the definition of a confusing bug.
166fn uri_with_tenant(uri: &Uri, tenant_id: Uuid) -> Option<Uri> {
167    let path = uri.path();
168    let query = uri.query().unwrap_or_default();
169    let rewritten = if query.is_empty() {
170        format!("{path}?tenant_id={tenant_id}")
171    } else {
172        format!("{path}?{query}&tenant_id={tenant_id}")
173    };
174    let mut parts = uri.clone().into_parts();
175    parts.path_and_query = Some(PathAndQuery::try_from(rewritten).ok()?);
176    Uri::from_parts(parts).ok()
177}

179impl<S, B> Service<ServiceRequest> for TenantPathScopeService<S>
180where
181    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error> + 'static,
182    B: 'static,
183{
184    type Response = ServiceResponse<EitherBody<B>>;
185    type Error = Error;
186    type Future = Pin<Box<dyn Future<Output = Result<Self::Response, Self::Error>>>>;
187
188    fn poll_ready(
189        &self,
190        cx: &mut std::task::Context<'_>,
191    ) -> std::task::Poll<Result<(), Self::Error>> {
192        self.inner.poll_ready(cx)
193    }
194
195    fn call(&self, mut req: ServiceRequest) -> Self::Future {
196        let refuse = |req: ServiceRequest, response: HttpResponse| {
197            let (http_req, _payload) = req.into_parts();
198            let res = ServiceResponse::new(http_req, response).map_into_right_body();
199            Box::pin(async move { Ok(res) })
200                as Pin<Box<dyn Future<Output = Result<Self::Response, Self::Error>>>>
201        };
202
203        // 1. The tenant segment, parsed. Never looked up: see the module docs
204        //    on why an unknown tenant is not this middleware's business.
205        let Some(tenant_id) = req
206            .match_info()
207            .get("tenant_id")
208            .and_then(|raw| Uuid::parse_str(raw).ok())
209        else {
210            return refuse(
211                req,
212                invalid_request("the tenant segment of the path is not a UUID"),
213            );
214        };
215
216        // 2. Two tenant selectors on one request is refused outright, agreeing
217        //    or not. See the module docs.
218        if req
219            .query_string()
220            .split('&')
221            .any(|pair| pair == "tenant_id" || pair.starts_with("tenant_id="))
222        {
223            return refuse(
224                req,
225                invalid_request(
226                    "tenant_id must not be sent as a query parameter on a \
227                     per-tenant issuer path; the tenant is the path segment",
228                ),
229            );
230        }
231
232        // 3. The tenant issuer. `None` means this deployment does not serve
233        //    tenant paths at all — unreachable, because the scope carrying this
234        //    middleware is mounted only when it does, and answered rather than
235        //    unwrapped so that a future caller cannot make it reachable
236        //    silently.
237        let Some(config) = req
238            .app_data::<actix_web::web::Data<AuthConfig>>()
239            .and_then(|deployment| deployment.for_tenant_path(tenant_id))
240        else {
241            return refuse(req, HttpResponse::NotFound().finish());
242        };
243
244        req.extensions_mut().insert(TenantPathBinding {
245            tenant_id,
246            auth_config: Arc::new(config),
247        });
248
249        // 4. Hand the tenant to the handlers where they already look for it.
250        let Some(rewritten) = uri_with_tenant(req.uri(), tenant_id) else {
251            return refuse(
252                req,
253                invalid_request("the request URI could not be scoped to its tenant"),
254            );
255        };
256        req.head_mut().uri = rewritten;
257
258        let fut = self.inner.call(req);
259        Box::pin(async move { Ok(fut.await?.map_into_left_body()) })
260    }
261}

263#[cfg(test)]
264mod tests {
265    use super::uri_with_tenant;
266    use actix_web::http::uri::Uri;
267    use uuid::Uuid;
268
269    const TENANT: &str = "11111111-2222-3333-4444-555555555555";
270
271    #[test]
272    fn a_bare_path_gains_the_tenant_as_its_only_parameter() {
273        let uri: Uri = "/t/x/oauth2/token".parse().unwrap();
274        let out = uri_with_tenant(&uri, Uuid::parse_str(TENANT).unwrap()).unwrap();
275        assert_eq!(out.path(), "/t/x/oauth2/token");
276        assert_eq!(out.query(), Some(format!("tenant_id={TENANT}").as_str()));
277    }
278
279    #[test]
280    fn an_existing_query_is_preserved_and_the_tenant_appended() {
281        let uri: Uri = "/t/x/oauth2/authorize?client_id=oa_1&state=abc"
282            .parse()
283            .unwrap();
284        let out = uri_with_tenant(&uri, Uuid::parse_str(TENANT).unwrap()).unwrap();
285        assert_eq!(
286            out.query(),
287            Some(format!("client_id=oa_1&state=abc&tenant_id={TENANT}").as_str())
288        );
289    }
290
291    /// The path is what `req.path()` reports and therefore what the DPoP `htu`
292    /// is built from (RFC 9449 §4.3). Rewriting it here would make a proof
293    /// signed for the URL the client called fail against the URL the server
294    /// thinks it served.
295    #[test]
296    fn the_path_is_never_rewritten() {
297        let uri: Uri = "/t/x/oauth2/par?a=1".parse().unwrap();
298        let out = uri_with_tenant(&uri, Uuid::parse_str(TENANT).unwrap()).unwrap();
299        assert_eq!(out.path(), uri.path());
300    }
301}
