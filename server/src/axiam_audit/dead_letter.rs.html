1//! The audit dead-letter file: where an audit row goes when the datastore did
2//! not take it (T19.27, T-108).
3//!
4//! One file, named by `AXIAM__GDPR_AUDIT_DLQ_FILE`, append-only, one
5//! [`DeadLetterRecord`] as JSON per line:
6//! `{"occurred_at": …, "reason": …, "entry": {…}}`. The `entry` is the
7//! replayable [`CreateAuditLogEntry`]: an operator (or a later replay job)
8//! reads each line back with [`decode_line`] and appends the entry once the
9//! datastore is healthy. The GDPR records' dead letter
10//! (`write_audit_with_dead_letter`) and the request-audit worker's both write
11//! it, through [`encode_line`], so the two cannot drift apart.
12//!
13//! # When, and why (#595)
14//!
15//! A bare entry has no timestamp, and the replay creates the row at replay
16//! time, so the trail lost when the event happened and its order against the
17//! rows written normally. The envelope carries both:
18//!
19//! - `occurred_at` is when the event happened, captured where the entry is
20//!   produced and carried with it, never when a writer flushes it. For a
21//!   request-audit row it is the moment the response finished and the audit
22//!   entry was built (the middleware, before the row is queued); for a GDPR
23//!   record it is the moment the record was handed to
24//!   `write_audit_with_dead_letter`, which is right after the action it
25//!   records and before the datastore write that was then refused.
26//! - `reason` is a [`DeadLetterReason`]: a closed set of short names, never an
27//!   error's text (which can carry a query, an identifier, or a secret).
28//!
29//! [`decode_line`] reads the earlier, bare form too, with neither field.
30//!
31//! Two ways in:
32//!
33//! - [`append_blocking`] and [`append_off_thread`] write the line, and sync it
34//!   to the device, before they return. For a caller that wants the guarantee:
35//!   the cleanup sweep's erasure record and the GDPR request records. The
36//!   first blocks its thread on file I/O; a request handler uses the second,
37//!   which runs the same write on the runtime's blocking pool (#594).
38//! - [`DeadLetterWriter`] queues the row and returns at once; a writer task owns
39//!   the file. For a caller that must not wait on file I/O — the request-audit
40//!   middleware, whose only reason to dead-letter is that the system is under
41//!   pressure. The task syncs the file's data after each batch it writes.
42//!
43//! # Durability and mode (#594)
44//!
45//! Each line is one `write_all` of the line and its newline, so two records
46//! never share a line. A write that has returned has also been through
47//! `sync_data`: a host crash does not take it back. (The file's directory entry
48//! is not synced separately, so a crash right after the file was first created
49//! can still lose the file itself.) Both openers create the file with mode
50//! `0600` on Unix rather than the process umask's, and tighten an existing
51//! file that is readable by group or others to `0600` when they open it (a
52//! failure to do so is logged, not fatal: the record is still written). The
53//! lines carry user and tenant identifiers and, for a request row, a client
54//! address.
55//!
56//! # The budget (R1W2-02)
57//!
58//! The file is bounded by [`MAX_BYTES_ENV`] ([`DEFAULT_MAX_BYTES`], 192 MiB, by
59//! default). Request-audit rows may fill the first nine tenths of it
60//! ([`request_row_limit`]); past that they are refused, counted as not
61//! recoverable, and the writer reports itself [full](DeadLetterWriter::is_full).
62//! The last tenth is a reserve only [`append_blocking`] — the GDPR records —
63//! writes into, so an erasure record is not refused because a flood of request
64//! rows got there first. Unbounded, the file filled the disk the datastore needs
65//! (Compose) or crossed its volume's `sizeLimit`, which Kubernetes enforces by
66//! evicting the pod and deleting the volume with the file in it.
67//!
68//! A request row's attacker-chosen fields — the path in `action`, the
69//! client-supplied address in `ip_address` — are cut to [`MAX_ACTION_BYTES`]
70//! and [`MAX_ADDRESS_BYTES`] in every line ([`encode_line`]), so a line is
71//! about a kilobyte at most whatever the request carried. The budget counts
72//! the bytes of the line as written, envelope included (about 100 more than
73//! the bare entry).

98/// The budget when [`MAX_BYTES_ENV`] is unset: 192 MiB, below the shipped
99/// Kubernetes volume's 256 MiB `sizeLimit`.

102/// The smallest budget [`MAX_BYTES_ENV`] may set: 1 MiB, a thousand request
103/// rows or so. Below it the file is full before it is useful.
104pub const MIN_MAX_BYTES: u64 = 1024 * 1024;

106/// The longest `action` a line carries, in bytes. A request row's action is
107/// `"{method} {path}"`, and the path is the client's to choose.
108pub const MAX_ACTION_BYTES: usize = 512;
109
110/// The longest `ip_address` a line carries, in bytes: an IPv6 literal with a
111/// zone and a port fits. The value is the client's `Forwarded` /
112/// `X-Forwarded-For` header where a proxy is trusted, and unvalidated.
113pub const MAX_ADDRESS_BYTES: usize = 64;

115/// What replaces the cut end of a field that was longer than its bound.
116const TRUNCATED: &str = "...[truncated]";

118/// Rows the writer task may hold before [`DeadLetterWriter::submit`] refuses
119/// one. Bounded so a slow volume cannot grow memory without limit while the
120/// datastore is also down; a row refused here is counted as unrecoverable.
121const QUEUE_CAPACITY: usize = 1024;
122
123/// Rows written per file write, so a burst costs one syscall rather than one
124/// per row.
125const BATCH: usize = 64;

127/// The budget [`MAX_BYTES_ENV`] sets: [`DEFAULT_MAX_BYTES`] when it is unset or
128/// empty, an error naming the variable when it is not a whole number of bytes
129/// of at least [`MIN_MAX_BYTES`].
130pub fn max_bytes_from_env() -> Result<u64, String> {
131    match std::env::var(MAX_BYTES_ENV) {
132        Ok(v) if !v.trim().is_empty() => parse_max_bytes(&v),
133        _ => Ok(DEFAULT_MAX_BYTES),
134    }
135}
136
137fn parse_max_bytes(value: &str) -> Result<u64, String> {
138    match value.trim().parse::<u64>() {
139        Ok(n) if n >= MIN_MAX_BYTES => Ok(n),
140        Ok(n) => Err(format!(
141            "{MAX_BYTES_ENV}={n} is below the minimum of {MIN_MAX_BYTES} bytes"
142        )),
143        Err(_) => Err(format!(
144            "{MAX_BYTES_ENV}={value:?} is not a whole number of bytes"
145        )),
146    }
147}

149/// How much of a `max_bytes` budget request-audit rows may fill: nine tenths.
150/// The rest is the GDPR records' reserve.
151pub fn request_row_limit(max_bytes: u64) -> u64 {
152    max_bytes - max_bytes / 10
153}
154
155/// `value`, cut to at most `max` bytes (on a character boundary) with a marker
156/// when it was longer.
157fn bounded(value: &str, max: usize) -> Cow<'_, str> {
158    if value.len() <= max {
159        return Cow::Borrowed(value);
160    }
161    let mut end = max.saturating_sub(TRUNCATED.len());
162    while !value.is_char_boundary(end) {
163        end -= 1;
164    }
165    Cow::Owned(format!("{}{TRUNCATED}", &value[..end]))
166}

168/// `entry` with its client-sized fields cut to [`MAX_ACTION_BYTES`] and
169/// [`MAX_ADDRESS_BYTES`]. The audit middleware applies it to the row it
170/// records, so the datastore row and the dead-letter line agree.
171pub fn bound_fields(entry: &mut CreateAuditLogEntry) {
172    if let Cow::Owned(action) = bounded(&entry.action, MAX_ACTION_BYTES) {
173        entry.action = action;
174    }
175    if let Some(ip) = &entry.ip_address
176        && let Cow::Owned(cut) = bounded(ip, MAX_ADDRESS_BYTES)
177    {
178        entry.ip_address = Some(cut);
179    }
180}

182/// Why a row was dead-lettered: a closed set, written to the line as a short
183/// snake_case name. Never an error's text, which can carry a query, an
184/// identifier or a secret, and is unbounded.
185#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
186#[serde(rename_all = "snake_case")]
187pub enum DeadLetterReason {
188    /// The request-audit channel was full when the request finished.
189    ChannelFull,
190    /// The request-audit channel was closed (the worker is gone).
191    ChannelClosed,
192    /// The datastore refused the append.
193    DatastoreError,
194}
195
196impl DeadLetterReason {
197    /// The name the line carries.
198    pub fn as_str(self) -> &'static str {
199        match self {
200            Self::ChannelFull => "channel_full",
201            Self::ChannelClosed => "channel_closed",
202            Self::DatastoreError => "datastore_error",
203        }
204    }
205}

207impl std::fmt::Display for DeadLetterReason {
208    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
209        f.write_str(self.as_str())
210    }
211}

248/// A line as it is read: the envelope, or the bare entry earlier versions
249/// wrote. The envelope is tried first; it needs an `entry` key, which a bare
250/// entry does not have.
251#[derive(Deserialize)]
252#[serde(untagged)]
253enum LineIn {
254    Enveloped {
255        occurred_at: DateTime<Utc>,
256        #[serde(default)]
257        reason: Option<String>,
258        entry: CreateAuditLogEntry,
259    },
260    Bare(CreateAuditLogEntry),
261}

263/// A dead-letter line read back by [`decode_line`].
264#[derive(Debug, Clone)]
265pub struct DeadLetterLine {
266    /// When the event happened; `None` for a bare line from an earlier version.
267    pub occurred_at: Option<DateTime<Utc>>,
268    /// Why it was dead-lettered, as the line spells it (a later version may add
269    /// names); `None` for a bare line.
270    pub reason: Option<String>,
271    /// The row to replay.
272    pub entry: CreateAuditLogEntry,
273}

275/// One dead-letter line, without its newline. The client-sized fields are
276/// bounded (see [`bound_fields`]) whoever built the entry.
277pub fn encode_line(record: &DeadLetterRecord) -> serde_json::Result<String> {
278    let entry = &record.entry;
279    let oversized = entry.action.len() > MAX_ACTION_BYTES
280        || entry
281            .ip_address
282            .as_ref()
283            .is_some_and(|ip| ip.len() > MAX_ADDRESS_BYTES);
284    let entry = if oversized {
285        let mut cut = entry.clone();
286        bound_fields(&mut cut);
287        Cow::Owned(cut)
288    } else {
289        Cow::Borrowed(entry)
290    };
291    serde_json::to_string(&LineOut {
292        occurred_at: record.occurred_at,
293        reason: record.reason,
294        entry: &entry,
295    })
296}

298/// Read one line (without its newline): the envelope [`encode_line`] writes, or
299/// the bare [`CreateAuditLogEntry`] that versions before #595 wrote, which has
300/// neither `occurred_at` nor `reason`.
301pub fn decode_line(line: &str) -> serde_json::Result<DeadLetterLine> {
302    Ok(match serde_json::from_str::<LineIn>(line)? {
303        LineIn::Enveloped {
304            occurred_at,
305            reason,
306            entry,
307        } => DeadLetterLine {
308            occurred_at: Some(occurred_at),
309            reason,
310            entry,
311        },
312        LineIn::Bare(entry) => DeadLetterLine {
313            occurred_at: None,
314            reason: None,
315            entry,
316        },
317    })
318}

320/// The mode a dead-letter file is created with, and tightened to: owner only.
321#[cfg(unix)]
322const FILE_MODE: u32 = 0o600;
323
324/// The options both openers use: create, append, and owner-only on Unix.
325fn open_options() -> std::fs::OpenOptions {
326    let mut options = std::fs::OpenOptions::new();
327    options.create(true).append(true);
328    #[cfg(unix)]
329    {
330        use std::os::unix::fs::OpenOptionsExt as _;
331        options.mode(FILE_MODE);
332    }
333    options
334}
335
336/// Whether `meta` says the file is readable or writable by group or others.
337/// `mode(0o600)` applies only when the file is created, so a file an earlier
338/// version (or an operator) made under a 0644 umask is found this way.
339#[cfg(unix)]
340fn is_exposed(meta: &std::fs::Metadata) -> bool {
341    use std::os::unix::fs::PermissionsExt as _;
342    meta.permissions().mode() & 0o077 != 0
343}
344
345/// The permissions an exposed file is tightened to.
346#[cfg(unix)]
347fn owner_only() -> std::fs::Permissions {
348    use std::os::unix::fs::PermissionsExt as _;
349    std::fs::Permissions::from_mode(FILE_MODE)
350}
351
352#[cfg(unix)]
353fn tighten_failed(path: &Path, error: &std::io::Error) {
354    tracing::warn!(
355        error = %error,
356        path = %path.display(),
357        "audit dead-letter file is readable by group or others and could not be \
358         restricted to its owner"
359    );
360}

362/// The dead-letter file a GDPR record goes to, and its budget, as the
363/// environment names them: read once, when this is built, so one record is
364/// judged against one path and one budget. A deployment without
365/// [`DEAD_LETTER_FILE_ENV`] has none.
366#[derive(Debug, Clone, PartialEq, Eq)]
367pub struct DeadLetterTarget {
368    /// The file.
369    pub path: PathBuf,
370    /// The whole of the budget, the GDPR records' reserve included.
371    pub max_bytes: u64,
372}
373
374impl DeadLetterTarget {
375    /// The target [`DEAD_LETTER_FILE_ENV`] and [`MAX_BYTES_ENV`] name, or
376    /// `None` when the file is unset or empty. An invalid budget falls back to
377    /// [`DEFAULT_MAX_BYTES`]: the boot refuses one ([`DeadLetterWriter::from_env`]),
378    /// so a running server has none, and a record is not dropped over it.
379    pub fn from_env() -> Option<Self> {
380        let path = std::env::var_os(DEAD_LETTER_FILE_ENV).filter(|p| !p.is_empty())?;
381        Some(Self {
382            path: PathBuf::from(path),
383            max_bytes: max_bytes_from_env().unwrap_or(DEFAULT_MAX_BYTES),
384        })
385    }
386}

388/// [`append_blocking`] on the runtime's blocking pool, for a caller on an async
389/// task (a request handler): the file I/O, including the sync, does not hold the
390/// worker. Returns when the line is written and synced.
391///
392/// The write runs to completion even if the caller is dropped meanwhile, and a
393/// task that panicked or was cancelled is reported as an I/O error, the same as
394/// a write that failed. Needs a Tokio runtime.
395pub async fn append_off_thread(
396    target: DeadLetterTarget,
397    record: DeadLetterRecord,
398) -> std::io::Result<()> {
399    tokio::task::spawn_blocking(move || append_blocking(&target.path, &record, target.max_bytes))
400        .await
401        .map_err(|e| std::io::Error::other(format!("dead-letter write task failed: {e}")))?
402}
403
404/// Append `record` to the file at `path` and return when it has been written and
405/// synced (`sync_data`).
406///
407/// Opens with `append(true)`: an existing file is never truncated or rewritten.
408/// A new file is created `0600`, and an existing one that group or others can
409/// read is tightened to it (see the module docs). Blocks on file I/O, so not
410/// for the request path: use [`append_off_thread`] there, or
411/// [`DeadLetterWriter`] for a row that does not need the guarantee.
412///
413/// For the GDPR records: it may write into the reserve above the request rows'
414/// share, up to the whole of `max_bytes`, and refuses a line that would cross
415/// it (an error of kind `StorageFull`); the line counted is the envelope's, as
416/// written. The check reads the file's size before
417/// the write, so a batch the writer task appends at the same moment can take
418/// the file past `max_bytes` by that batch.
419pub fn append_blocking(
420    path: &Path,
421    record: &DeadLetterRecord,
422    max_bytes: u64,
423) -> std::io::Result<()> {
424    let mut line = encode_line(record).map_err(std::io::Error::other)?;
425    line.push('\n');
426    let mut file = open_options().open(path)?;
427    let meta = file.metadata()?;
428    #[cfg(unix)]
429    if is_exposed(&meta)
430        && let Err(e) = file.set_permissions(owner_only())
431    {
432        tighten_failed(path, &e);
433    }
434    let size = meta.len();
435    if size + line.len() as u64 > max_bytes {
436        return Err(std::io::Error::new(
437            std::io::ErrorKind::StorageFull,
438            format!(
439                "the audit dead-letter file holds {size} bytes and its budget is {max_bytes} \
440                 ({MAX_BYTES_ENV}); replay and move it"
441            ),
442        ));
443    }
444    // One call, so the newline cannot be separated from its line.
445    file.write_all(line.as_bytes())?;
446    file.sync_data()
447}

449/// What [`DeadLetterWriter::submit`] did with a row.
450#[derive(Debug, Clone, Copy, PartialEq, Eq)]
451pub enum Submitted {
452    /// Queued for the writer task. It is in the file once the task has run; a
453    /// write that then fails is counted in [`DeadLetterWriter::lost`].
454    Queued,
455    /// No file is configured; the row is not kept anywhere.
456    NotConfigured,
457    /// The writer's queue is full (or its task is gone); the row is not kept.
458    Overflow,
459    /// The file has reached the request rows' share of its budget; the row is
460    /// not kept.
461    Full,
462}

464enum Msg {
465    Entry(DeadLetterRecord),
466    Flush(oneshot::Sender<()>),
467}

469#[derive(Default)]
470struct Counts {
471    written: AtomicU64,
472    lost: AtomicU64,
473    /// Of `lost`, the rows refused because the file was full.
474    refused_full: AtomicU64,
475    /// Whether the file has reached the request rows' share of its budget.
476    full: AtomicBool,
477}
478
479struct Inner {
480    tx: mpsc::Sender<Msg>,
481    counts: Arc<Counts>,
482}

484/// A non-blocking front for the dead-letter file.
485///
486/// [`Self::submit`] never waits: it puts the row on a bounded queue read by one
487/// task, which batches the rows and appends them. Cloning shares the queue.
488/// `disabled()` is the writer of a deployment that configured no file.
489#[derive(Clone, Default)]
490pub struct DeadLetterWriter {
491    inner: Option<Arc<Inner>>,
492}
493
494impl DeadLetterWriter {
495    /// A writer that keeps nothing: every [`Self::submit`] is `NotConfigured`.
496    pub fn disabled() -> Self {
497        Self::default()
498    }
499
500    /// The writer [`DEAD_LETTER_FILE_ENV`] names, bounded by [`MAX_BYTES_ENV`],
501    /// or a disabled one when the file is unset or empty. An invalid budget is
502    /// an error, so a typo fails the boot rather than unbounding the file.
503    /// Spawns the writer task, so call it inside a runtime.
504    pub fn from_env() -> Result<Self, String> {
505        let max_bytes = max_bytes_from_env()?;
506        Ok(match std::env::var_os(DEAD_LETTER_FILE_ENV) {
507            Some(path) if !path.is_empty() => {
508                Self::spawn_with_budget(PathBuf::from(path), max_bytes)
509            }
510            _ => Self::disabled(),
511        })
512    }
513
514    /// Write to `path`, creating it when absent and appending when present,
515    /// within [`DEFAULT_MAX_BYTES`]. Spawns the writer task, so call it inside a
516    /// runtime.
517    pub fn spawn(path: impl Into<PathBuf>) -> Self {
518        Self::spawn_with_budget(path, DEFAULT_MAX_BYTES)
519    }
520
521    /// As [`Self::spawn`], within `max_bytes`: request rows fill at most
522    /// [`request_row_limit`] of it.
523    pub fn spawn_with_budget(path: impl Into<PathBuf>, max_bytes: u64) -> Self {
524        let path = path.into();
525        let (tx, rx) = mpsc::channel(QUEUE_CAPACITY);
526        let counts = Arc::new(Counts::default());
527        let limit = request_row_limit(max_bytes);
528        // A file left full by an earlier run is reported full from the start,
529        // not from the first row it refuses.
530        if std::fs::metadata(&path).is_ok_and(|m| m.len() >= limit) {
531            counts.full.store(true, Ordering::Relaxed);
532        }
533        tokio::spawn(write_task(path, limit, rx, Arc::clone(&counts)));
534        Self {
535            inner: Some(Arc::new(Inner { tx, counts })),
536        }
537    }
538
539    /// Whether a file is configured.
540    pub fn is_configured(&self) -> bool {
541        self.inner.is_some()
542    }
543
544    /// Queue `record` for the file. Never blocks and never does I/O.
545    pub fn submit(&self, record: DeadLetterRecord) -> Submitted {
546        let Some(inner) = &self.inner else {
547            return Submitted::NotConfigured;
548        };
549        // The file does not shrink while the server runs (it is moved only with
550        // the server stopped), so once full it stays full.
551        if inner.counts.full.load(Ordering::Relaxed) {
552            inner.counts.lost.fetch_add(1, Ordering::Relaxed);
553            inner.counts.refused_full.fetch_add(1, Ordering::Relaxed);
554            return Submitted::Full;
555        }
556        match inner.tx.try_send(Msg::Entry(record)) {
557            Ok(()) => Submitted::Queued,
558            Err(_) => {
559                inner.counts.lost.fetch_add(1, Ordering::Relaxed);
560                Submitted::Overflow
561            }
562        }
563    }
564
565    /// Rows this writer has appended to the file since start.
566    pub fn written(&self) -> u64 {
567        self.inner
568            .as_ref()
569            .map_or(0, |i| i.counts.written.load(Ordering::Relaxed))
570    }
571
572    /// Rows this writer was given and could not keep since start: refused for
573    /// want of queue room or because the file was full, or queued and then not
574    /// written (the file could not be opened or written).
575    pub fn lost(&self) -> u64 {
576        self.inner
577            .as_ref()
578            .map_or(0, |i| i.counts.lost.load(Ordering::Relaxed))
579    }
580
581    /// Of [`Self::lost`], the rows refused because the file had reached the
582    /// request rows' share of its budget.
583    pub fn refused_full(&self) -> u64 {
584        self.inner
585            .as_ref()
586            .map_or(0, |i| i.counts.refused_full.load(Ordering::Relaxed))
587    }
588
589    /// Whether the file has reached the request rows' share of its budget, so
590    /// every further request row is refused until it is replayed and moved.
591    pub fn is_full(&self) -> bool {
592        self.inner
593            .as_ref()
594            .is_some_and(|i| i.counts.full.load(Ordering::Relaxed))
595    }
596
597    /// Wait, at most `within`, until every row submitted before this call has
598    /// been through the writer. `true` when there is nothing to wait for.
599    pub async fn flush(&self, within: Duration) -> bool {
600        let Some(inner) = &self.inner else {
601            return true;
602        };
603        let (done, reached) = oneshot::channel();
604        let wait = async {
605            inner.tx.send(Msg::Flush(done)).await.ok()?;
606            reached.await.ok()
607        };
608        matches!(tokio::time::timeout(within, wait).await, Ok(Some(())))
609    }
610}
611
612async fn write_task(path: PathBuf, limit: u64, mut rx: mpsc::Receiver<Msg>, counts: Arc<Counts>) {
613    let mut file: Option<tokio::fs::File> = None;
614    // Logged on the way into failure, not per batch: a volume that is gone
615    // would otherwise add a line per burst to a log that is already busy.
616    let mut failing = false;
617    while let Some(first) = rx.recv().await {
618        let mut lines: Vec<String> = Vec::new();
619        let mut flushes = Vec::new();
620        let mut next = Some(first);
621        while let Some(msg) = next.take() {
622            match msg {
623                Msg::Entry(record) => match encode_line(&record) {
624                    Ok(mut line) => {
625                        line.push('\n');
626                        lines.push(line);
627                    }
628                    Err(e) => {
629                        counts.lost.fetch_add(1, Ordering::Relaxed);
630                        tracing::error!(error = %e, "audit dead-letter record could not be encoded");
631                    }
632                },
633                Msg::Flush(done) => flushes.push(done),
634            }
635            if lines.len() < BATCH {
636                next = rx.try_recv().ok();
637            }
638        }
639        if !lines.is_empty() {
640            match append(&path, &mut file, limit, &lines).await {
641                Ok(appended) => {
642                    counts
643                        .written
644                        .fetch_add(appended.written, Ordering::Relaxed);
645                    failing = false;
646                    if appended.refused > 0 {
647                        counts.lost.fetch_add(appended.refused, Ordering::Relaxed);
648                        counts
649                            .refused_full
650                            .fetch_add(appended.refused, Ordering::Relaxed);
651                        if !counts.full.swap(true, Ordering::Relaxed) {
652                            tracing::error!(
653                                path = %path.display(),
654                                env_var = MAX_BYTES_ENV,
655                                limit_bytes = limit,
656                                "audit dead-letter file is full — request-audit rows are now \
657                                 refused (counted as not_recoverable on /health/jobs); the GDPR \
658                                 records keep a reserve above this. Replay the file, then move \
659                                 it with the server stopped"
660                            );
661                        }
662                    }
663                }
664                Err(e) => {
665                    // A handle that failed may be a dead one; reopen next time.
666                    file = None;
667                    counts.lost.fetch_add(lines.len() as u64, Ordering::Relaxed);
668                    if !failing {
669                        failing = true;
670                        tracing::error!(
671                            error = %e,
672                            path = %path.display(),
673                            env_var = DEAD_LETTER_FILE_ENV,
674                            "audit dead-letter file cannot be written — rows that were headed \
675                             for it are lost (counted as not_recoverable on /health/jobs)"
676                        );
677                    }
678                }
679            }
680        }
681        for done in flushes {
682            let _ = done.send(());
683        }
684    }
685}

687/// What one batch did.
688struct Appended {
689    written: u64,
690    /// Lines that would have taken the file past the request rows' limit.
691    refused: u64,
692}
693
694/// Append, in order, each of the `lines` that still fits under `limit`; refuse
695/// the others. The file's size is read before each batch, so the GDPR records'
696/// own writes (through [`append_blocking`]) count against the limit too.
697async fn append(
698    path: &Path,
699    file: &mut Option<tokio::fs::File>,
700    limit: u64,
701    lines: &[String],
702) -> std::io::Result<Appended> {
703    if file.is_none() {
704        let opened = tokio::fs::OpenOptions::from(open_options())
705            .open(path)
706            .await?;
707        #[cfg(unix)]
708        if is_exposed(&opened.metadata().await?)
709            && let Err(e) = opened.set_permissions(owner_only()).await
710        {
711            tighten_failed(path, &e);
712        }
713        *file = Some(opened);
714    }
715    let f = file.as_mut().expect("opened above");
716    let mut size = f.metadata().await?.len();
717    let mut bytes = String::new();
718    let mut written = 0;
719    for line in lines {
720        let len = line.len() as u64;
721        if size + len > limit {
722            continue;
723        }
724        size += len;
725        bytes.push_str(line);
726        written += 1;
727    }
728    if written > 0 {
729        f.write_all(bytes.as_bytes()).await?;
730        f.flush().await?;
731        // The batch is on the device before it is counted as written.
732        f.sync_data().await?;
733    }
734    Ok(Appended {
735        written,
736        refused: lines.len() as u64 - written,
737    })
738}
