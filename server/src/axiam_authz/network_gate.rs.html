1//! The authorization function of the network write surface (RADIUS Live profile, W6.2;
2//! `claude_dev/radius-reply-profile-design.md` §5.1–§5.3).
3//!
4//! # What it decides
5//!
6//! One function, [`authorize_network_write`], answers for every write that can
7//! create or change **who may be placed on a network segment, and what being
8//! placed there gives**:
9//!
10//! * a reply-profile write, against H1–H6 of §5.2, after refusing an
11//!   administrative `Service-Type` outright (§3.3; a `400`, #700);
12//! * a segment write (`network:segments_write` at the parent or the node; a
13//!   replace that changes `vlan_id`, `rank` or `enabled` of a segment that has
14//!   a profile, or a delete of such a segment, also needs `network:grant`
15//!   there, and on a quarantine segment at its quarantine site — H2 and H5
16//!   applied to the envelope, correction R110W6-03 of the note and the
17//!   decision of 2026-10-16: every write that moves or removes placed devices
18//!   needs the placing right);
19//! * a role assignment, unassignment, permission grant or revoke, role update
20//!   or delete that touches a **network-sensitive** role, against the §5.3
21//!   table and the three write-time rules of §4.2, and against H6 where the
22//!   write would widen the writer's **own** placement (a join it receives, a
23//!   deny it sheds; correction R110W6-01 of the note);
24//! * a certificate **bind** to a service account, against §5.3's binding rows
25//!   and H6 (correction R101W6-03 of the note);
26//! * a write of the tenant's network policy, the `Session-Timeout` cap that H3
27//!   reads as the envelope (`network:segments_write` at `/network`; see
28//!   [`NetworkWrite::PolicyWrite`] for why a raise asks no more than a lowering);
29//! * a write of the generic surfaces that could reach into the reserved
30//!   namespace: a permission whose action is in `network:` (create, rename,
31//!   delete), and a resource of a reserved `network_*` type, or under one, or
32//!   re-parented into or out of the subtree (§4.1).
33//!
34//! Every "holds" is a [`WriteTimeAccess::check_at_write_time`] — the engine's
35//! own evaluation, uncached, deny-override in full force, with the **writer's**
36//! subject scope, so an organization-level writer carries only its global
37//! grants (§2). A deny at the node or an ancestor is "does not hold".
38//!
39//! # What it returns
40//!
41//! A [`GateClearance`] or a [`GateRefusal`]. A refusal carries the HTTP class
42//! (`403` for a permission the writer lacks, `400` for a write no permission
43//! makes legal), the **internal** rule that refused (`H2`, `4.2:rule-2`, …), the
44//! permission and node a `403` names, and the before and after values the audit
45//! row records (§5.4). The caller writes that row; the function does no I/O
46//! besides its reads.
47//!
48//! A clearance for a segment or profile write carries the
49//! [`NetworkWriteClearance`] the repositories demand, so those writes cannot
50//! reach the datastore without this function at all (a compile error, not a
51//! review finding). The other writes go through repository methods older than
52//! this module and shared with the seeder; `network_gate_enumeration_test` in
53//! `axiam-api-rest` pins every call site of them to a function that calls this
54//! one first, or to a named exemption with its reason.
55//!
56//! # The one exemption from "you delegate only what you hold"
57//!
58//! [`EXEMPTION_ORGANIZATION_BOOTSTRAP`]: an **organization-level** writer may
59//! assign a tenant's **own seeded `super-admin`** role, tenant-wide, to a user
60//! of that tenant, although it does not itself hold the role's `network:`
61//! permissions. Since #702 the organization scope's super-admin holds none, so
62//! without this nobody could give a new tenant its first administrator — the
63//! documented bootstrap (`docs/admin/organization-scope.md`), and the intent of
64//! the review that asked for #702 ("each tenant's own super-admin keeps the
65//! bootstrap", R110W6-05, T-483). The bound, all of it checked here:
66//!
67//! * the writer's [`SubjectScope`] is `Organization` (the REST extractor
68//!   already confines the target tenant to that organization);
69//! * the role is the one the seeder makes: named
70//!   [`SEEDED_SUPER_ADMIN_ROLE`], global, and carrying no `network:` grant but
71//!   allows of [`SEEDED_SUPER_ADMIN_NETWORK_ACTIONS`] — a shape only the
72//!   seeder can produce, since §4.2 rule 1 refuses a `network:` grant to any
73//!   global role through the API;
74//! * the grantee is a user, the assignment names no resource, and the grantee
75//!   is not the writer (H6's reading: no self-configuration);
76//! * nothing else widens: a custom role carrying `network:` grants, a
77//!   `network:` permission grant, a resource-scoped assignment and every other
78//!   write stay under the §5.3 bound, and the organization scope's own role
79//!   still holds no `network:` permission. The cleared write is
80//!   network-sensitive and leaves its success row, which names the exemption.
81//!
82//! # What it is not
83//!
84//! It is a **namespace-limited** delegation bound. Outside `network:`,
85//! `roles:assign` stays unbounded and so does `certificates:bind` for an
86//! account that holds no `network:join` (the note's residual 7). "Holds" is a
87//! write-time condition: a profile or an assignment does not lapse when its
88//! writer later loses the permission (residual 1).
89//!
90//! The route-level permission (`roles:assign`, `permissions:grant`,
91//! `certificates:bind`, …) is the caller's to check first; this function adds
92//! to it and never replaces it.

165/// The authorization check the function asks, at write time.
166///
167/// The engine's evaluation, **uncached** (see
168/// [`AuthorizationEngine::check_access_uncached`]). Implemented here for the
169/// engine; the REST layer implements it for its type-erased checker, whose
170/// test doubles answer from a fixed rule.
171pub trait WriteTimeAccess: Send + Sync {
172    /// Evaluate `request` as it stands now, deny-override in force.
173    fn check_at_write_time(
174        &self,
175        request: &AccessRequest,
176    ) -> impl Future<Output = AxiamResult<AccessDecision>> + Send;
177}

417    }

460/// One write the function decides. Each variant is one route's write.
461#[derive(Debug, Clone, Copy)]
462pub enum NetworkWrite<'a> {
463    /// Create or replace a segment's reply profile (H1–H6).
464    ProfileWrite {
465        /// The owning segment.
466        segment_id: Uuid,
467        /// The profile as it would be stored.
468        input: &'a ReplyProfileInput,
469    },
470    /// Delete a segment's reply profile: H1, and — because it removes every
471    /// device placed on the segment (no profile, no candidate) — `network:grant`
472    /// at the segment (`H2:placement`), on a quarantine segment at
473    /// `/network/quarantine/<site>` too (`H5:placement`), then H6 (the decision
474    /// of 2026-10-16).
475    ProfileDelete {
476        /// The owning segment.
477        segment_id: Uuid,
478    },
479    /// Create a segment (`network:segments_write` at its parent).
480    SegmentCreate {
481        /// The segment as it would be created.
482        input: &'a NewNetworkSegment,
483    },
484    /// Rewrite a segment's envelope (`network:segments_write` at the node).
485    ///
486    /// A change of `vlan_id`, `rank` or `enabled` on a segment that has a
487    /// reply profile re-places every device that may join it, so it also
488    /// needs `network:grant` at the segment (`H2:placement`) and, on a
489    /// quarantine segment, at `/network/quarantine/<site>` (`H5:placement`).
490    /// `filter_ids` alone needs `network:segments_write` only. A replace
491    /// cleared without the grant carries a
492    /// [frozen](NetworkWriteClearance::freeze_profiled_placement) token, so the
493    /// write re-checks the profile inside its own transaction (R110W6-03).
494    SegmentUpdate {
495        /// The segment.
496        segment_id: Uuid,
497        /// The new envelope.
498        update: &'a NetworkSegmentUpdate,
499    },
500    /// Delete a segment (`network:segments_write` at the node).
501    ///
502    /// A segment that has a reply profile takes its placed devices with it, so
503    /// its delete also needs `network:grant` at the segment (`H2:placement`),
504    /// on a quarantine segment at `/network/quarantine/<site>` too
505    /// (`H5:placement`), then H6 (the decision of 2026-10-16). A delete cleared
506    /// without the grant (no profile on the gate's read) carries a
507    /// [frozen](NetworkWriteClearance::freeze_profiled_placement) token, so the
508    /// write re-checks the profile inside its own transaction.
509    SegmentDelete {
510        /// The segment.
511        segment_id: Uuid,
512    },
513    /// Assign a role (§5.3 rows 1, 2 and 4; §4.2 rules 2 and 3).
514    RoleAssign {
515        /// The role.
516        role_id: Uuid,
517        /// Who receives it.
518        grantee: Grantee,
519        /// The node it is assigned at; `None` is tenant-wide.
520        resource_id: Option<Uuid>,
521        /// The assignment's `inherit` flag, as it will be stored.
522        inherit: bool,
523    },
524    /// Unassign a role (§5.3 row 3).
525    RoleUnassign {
526        /// The role.
527        role_id: Uuid,
528        /// Who loses it.
529        grantee: Grantee,
530        /// The node of the assignment removed; `None` is the tenant-wide one.
531        resource_id: Option<Uuid>,
532    },
533    /// Update a role (§4.2 rule 1 on `is_global`).
534    RoleUpdate {
535        /// The role.
536        role_id: Uuid,
537        /// The requested `is_global`, when the update names one.
538        is_global: Option<bool>,
539    },
540    /// Delete a role (§5.3 row 6).
541    RoleDelete {
542        /// The role.
543        role_id: Uuid,
544    },
545    /// Grant a permission to a role (§5.3 row 5; §4.2 rules 1–3).
546    PermissionGrant {
547        /// The role.
548        role_id: Uuid,
549        /// The permission.
550        permission_id: Uuid,
551        /// Allow or deny.
552        effect: PermissionEffect,
553        /// The grant's scope constraints.
554        scope_ids: &'a [Uuid],

811/// Decide one network-relevant write, at write time (design note §5.1).
812///
813/// See the module documentation for what each [`NetworkWrite`] is checked
814/// against. A write that touches nothing in the `network:` namespace is
815/// cleared with [`GateClearance::is_network_sensitive`] `false` and costs the
816/// reads needed to know that (the role's grants, the permission's action, the
817/// resource's type).
818///
819/// # Errors
820///
821/// Only what the reads return: `NotFound` for a segment that is not the
822/// tenant's, and datastore failures. A role or permission that is not the
823/// tenant's is cleared, not refused: the write cannot confer anything, and the
824/// repository answers it as it did before this function existed. A refusal is
825/// not an error.
826pub async fn authorize_network_write<A, S>(
827    access: &A,
828    store: &S,
829    writer: GateWriter,
830    write: NetworkWrite<'_>,
831) -> AxiamResult<GateVerdict>
832where
833    A: WriteTimeAccess + ?Sized,
834    S: NetworkGateStore + ?Sized,
835{
836    let gate = Gate {
837        access,
838        store,
839        writer,
840    };
841    // R110W6-04: a role write is decided on the role's grants, holders and
842    // scope, read below; the write claims the epochs read here, first, so that
843    // anything that changed one of those since makes it `409` instead of
844    // landing on a state the decision never saw (the notes in
845    // `axiam-db`'s `repository/role.rs`).
846    let claimed_role = match write {
847        NetworkWrite::RoleAssign { role_id, .. }
848        | NetworkWrite::RoleUnassign { role_id, .. }
849        | NetworkWrite::RoleDelete { role_id }
850        | NetworkWrite::RoleUpdate {
851            role_id,
852            is_global: Some(_),
853        }
854        | NetworkWrite::PermissionGrant { role_id, .. }
855        | NetworkWrite::PermissionRevoke { role_id, .. } => Some(role_id),
856        _ => None,
857    };
858    let epochs = match claimed_role {
859        Some(role_id) => store.role_epochs(writer.tenant_id, role_id).await?,
860        None => None,
861    };
862    let verdict = decide(&gate, write).await?;
863    Ok(verdict.map(|mut clearance| {
864        // A grant or revoke outside `network:` depends on nothing of the role
865        // (the function cleared it on the permission alone), so it claims
866        // nothing and two of them never collide.
867        let grant_or_revoke = matches!(
868            write,
869            NetworkWrite::PermissionGrant { .. } | NetworkWrite::PermissionRevoke { .. }
870        );
871        if let (Some(role_id), Some(epochs)) = (claimed_role, epochs)
872            && (!grant_or_revoke || clearance.network_sensitive)
873        {
874            clearance.role_claim = Some(RoleClaim {
875                role_id,
876                epochs,
877                revoked_effect: clearance.revoked_effect,
878            });
879        }
880        clearance
881    }))
882}

884/// The dispatch of [`authorize_network_write`].
885async fn decide<A, S>(gate: &Gate<'_, A, S>, write: NetworkWrite<'_>) -> AxiamResult<GateVerdict>
886where
887    A: WriteTimeAccess + ?Sized,
888    S: NetworkGateStore + ?Sized,
889{
890    match write {
891        NetworkWrite::ProfileWrite { segment_id, input } => {
892            gate.profile_write(segment_id, input).await
893        }
894        NetworkWrite::ProfileDelete { segment_id } => gate.profile_delete(segment_id).await,
895        NetworkWrite::SegmentCreate { input } => gate.segment_create(input).await,
896        NetworkWrite::SegmentUpdate { segment_id, update } => {
897            gate.segment_update(segment_id, update).await
898        }
899        NetworkWrite::SegmentDelete { segment_id } => gate.segment_delete(segment_id).await,
900        NetworkWrite::RoleAssign {
901            role_id,
902            grantee,
903            resource_id,
904            inherit,
905        } => {
906            gate.role_assign(role_id, grantee, resource_id, inherit)
907                .await
908        }
909        NetworkWrite::RoleUnassign {
910            role_id,
911            grantee,
912            resource_id,
913        } => gate.role_unassign(role_id, grantee, resource_id).await,
914        NetworkWrite::RoleUpdate { role_id, is_global } => {

916        }
917        NetworkWrite::RoleDelete { role_id } => gate.role_delete(role_id).await,
918        NetworkWrite::PermissionGrant {
919            role_id,
920            permission_id,
921            effect,
922            scope_ids,
923        } => {

926        }
927        NetworkWrite::PermissionRevoke {
928            role_id,
929            permission_id,
930        } => gate.permission_revoke(role_id, permission_id).await,
931        NetworkWrite::PermissionCreate { action } => gate.permission_create(action),
932        NetworkWrite::PermissionUpdate {
933            permission_id,
934            action,
935        } => gate.permission_update(permission_id, action).await,
936        NetworkWrite::PermissionDelete { permission_id } => {

938        }
939        NetworkWrite::PolicyWrite {

962    }
963}

970#[derive(Debug, Default)]
971struct NetworkGrants {
972    /// Any `network:` grant at all: the role is network-sensitive (§4.2).
973    any: bool,
974    /// Any `network:` grant with effect deny.
975    any_deny: bool,
976    /// An allow of `network:join`.
977    join_allow: bool,
978    /// A deny of `network:join` (quarantine).
979    join_deny: bool,
980    /// Allows of a meta permission or of the administrative class: what an
981    /// assigner must hold to confer.
982    delegated: BTreeSet<String>,
983}

985impl NetworkGrants {
986    fn of(grants: &[PermissionGrant]) -> Self {
987        let mut out = Self::default();
988        for g in grants {
989            let action = g.permission.action.as_str();
990            if !is_network_action(action) {
991                continue;
992            }
993            out.any = true;
994            let deny = g.effect == PermissionEffect::Deny;
995            out.any_deny |= deny;
996            if action == NETWORK_JOIN {
997                if deny {
998                    out.join_deny = true;
999                } else {
1000                    out.join_allow = true;
1001                }
1002            } else if !deny
1003                && (NETWORK_META_ACTIONS.contains(&action)
1004                    || NETWORK_ADMIN_CLASS_ACTIONS.contains(&action))
1005            {
1006                out.delegated.insert(action.to_owned());
1007            }
1008        }
1009        out
1010    }
1011}

1308
1309    async fn profile_write(
1310        &self,
1311        segment_id: Uuid,
1312        input: &ReplyProfileInput,
1313    ) -> AxiamResult<GateVerdict> {
1314        let seg = self.store.segment(self.tenant(), segment_id).await?;
1315        let stored = self.store.profile(self.tenant(), segment_id).await?;
1316        let with_values = |mut r: GateRefusal| {
1317            r.before = describe_stored_profile(stored.as_ref());
1318            r.before.extend(describe_segment(&seg));
1319            r.after = describe_profile(input);
1320            r
1321        };
1322        let audit = AUDIT_PROFILE_WRITE_REFUSED;
1323
1324        // Design note §3.3: under option B the administrative class is
1325        // disabled, so a profile that names it is legal for nobody — a `400`,
1326        // decided before any permission is read. Asking for H4's permissions
1327        // first answered a `403` naming `network:grant_admin`, which no
1328        // grant can confer (R110W6-02, #700).
1329        if input.service_type.is_some_and(|s| s.is_admin_class()) {
1330            return Ok(Err(with_values(refuse(
1331                RefusalStatus::Invalid,
1332                "3.3:admin-class",
1333                audit,
1334                "the administrative Service-Type values are disabled",
1335            ))));
1336        }
1337
1338        // H1: the profile's own permission. H2: writing it is a grant.
1339        for (rule, action) in [("H1", NETWORK_PROFILES_WRITE), ("H2", NETWORK_GRANT)] {
1340            if let Some(r) = self.require_all(&[action], seg.id, rule, audit).await? {
1341                return Ok(Err(with_values(r)));
1342            }
1343        }
1344
1345        // H3: inside the envelope. The VLAN is derived from the segment and
1346        // cannot be named; the filter id must be one the segment declares and
1347        // the timeout within the tenant's cap.
1348        if let Some(filter_id) = input.filter_id.as_deref()
1349            && !seg.filter_ids.iter().any(|f| f == filter_id)
1350        {
1351            return Ok(Err(with_values(refuse(
1352                RefusalStatus::Forbidden,
1353                "H3:envelope:filter_id",
1354                audit,
1355                "filter_id is not one of the segment's declared filter_ids",
1356            ))));
1357        }
1358        let cap = self.store.session_timeout_cap(self.tenant()).await?;
1359        if input.session_timeout_secs > cap {
1360            return Ok(Err(with_values(refuse(
1361                RefusalStatus::Forbidden,
1362                "H3:envelope:session_timeout",
1363                audit,
1364                format!("session_timeout_secs is above the tenant's cap of {cap}"),
1365            ))));
1366        }
1367
1368        // H4: conferring administrative login needs holding it, and the right
1369        // to confer it. Unreachable under option B, where the class is refused
1370        // above (and by the repository); kept so that option A, which lifts
1371        // that refusal, inherits the rule.
1372        if input.service_type.is_some_and(|s| s.is_admin_class())
1373            && let Some(r) = self
1374                .require_all(&[NETWORK_GRANT_ADMIN, NETWORK_ADMIN], seg.id, "H4", audit)
1375                .await?
1376        {
1377            return Ok(Err(with_values(r)));
1378        }
1379
1380        // H5: the quarantine profile reaches every quarantined device of the
1381        // site; shaping it is a grant to all of them. (A profile write cannot
1382        // change the segment's kind: the input has no such field.)
1383        if seg.kind == NetworkSegmentKind::Quarantine {
1384            let site = site_node_id(self.tenant(), NetworkSegmentKind::Quarantine, &seg.site_key);
1385            if let Some(r) = self
1386                .require_all(&[NETWORK_GRANT], site, "H5", audit)
1387                .await?
1388            {
1389                return Ok(Err(with_values(r)));
1390            }
1391        }
1392
1393        // H6: a subject that may join the segment does not shape what joining
1394        // gives, whatever it holds.
1395        if self.holds(NETWORK_JOIN, seg.id).await? {
1396            return Ok(Err(with_values(refuse(
1397                RefusalStatus::Forbidden,
1398                "H6",
1399                audit,
1400                "a subject that may be placed on this segment cannot write its profile",
1401            ))));
1402        }
1403
1404        Ok(Ok(self.clearance(NetworkWriteTarget::ProfileWrite {
1405            segment_id,
1406        })))
1407    }

1409    async fn profile_delete(&self, segment_id: Uuid) -> AxiamResult<GateVerdict> {
1410        let seg = self.store.segment(self.tenant(), segment_id).await?;
1411        let audit = AUDIT_PROFILE_WRITE_REFUSED;
1412        let refused = |mut r: GateRefusal, stored: Option<&ReplyProfile>| {
1413            r.before = describe_stored_profile(stored);
1414            r.before.extend(describe_segment(&seg));
1415            r.after = vec![("profile", "deleted".to_owned())];
1416            r
1417        };
1418        if let Some(r) = self
1419            .require_all(&[NETWORK_PROFILES_WRITE], seg.id, "H1", audit)
1420            .await?
1421        {
1422            let stored = self.store.profile(self.tenant(), segment_id).await?;
1423            return Ok(Err(refused(r, stored.as_ref())));
1424        }
1425        // The decision of 2026-10-16: no profile means no candidate, so the
1426        // delete removes every device placed on the segment — a placement
1427        // write, which asks the placing right as the profile write does (H2,
1428        // and H5 on a quarantine segment). The segment's kind does not change,
1429        // so nothing here depends on a read a concurrent write could falsify.
1430        if let Some(r) = self.placement_rights(&seg, audit).await? {
1431            let stored = self.store.profile(self.tenant(), segment_id).await?;
1432            return Ok(Err(refused(r, stored.as_ref())));
1433        }
1434        if self.holds(NETWORK_JOIN, seg.id).await? {
1435            let stored = self.store.profile(self.tenant(), segment_id).await?;
1436            return Ok(Err(refused(
1437                refuse(
1438                    RefusalStatus::Forbidden,
1439                    "H6",
1440                    audit,
1441                    "a subject that may be placed on this segment cannot delete its profile",
1442                ),
1443                stored.as_ref(),
1444            )));
1445        }
1446        Ok(Ok(self.clearance(NetworkWriteTarget::ProfileDelete {
1447            segment_id,
1448        })))
1449    }

1452    /// `network:grant` at the segment (`H2:placement`) and, on a quarantine
1453    /// segment, on `/network/quarantine/<site>` (`H5:placement`). Asked of
1454    /// every write that moves or removes the devices placed on a profiled
1455    /// segment (R110W6-03; the decision of 2026-10-16).
1456    async fn placement_rights(
1457        &self,
1458        seg: &NetworkSegment,
1459        audit: &'static str,
1460    ) -> AxiamResult<Option<GateRefusal>> {
1461        if let Some(r) = self
1462            .require_all(&[NETWORK_GRANT], seg.id, "H2:placement", audit)
1463            .await?
1464        {
1465            return Ok(Some(r));
1466        }
1467        if seg.kind == NetworkSegmentKind::Quarantine {
1468            let site = site_node_id(self.tenant(), NetworkSegmentKind::Quarantine, &seg.site_key);
1469            return self
1470                .require_all(&[NETWORK_GRANT], site, "H5:placement", audit)
1471                .await;
1472        }
1473        Ok(None)
1474    }

1478    async fn segment_create(&self, input: &NewNetworkSegment) -> AxiamResult<GateVerdict> {
1479        let audit = AUDIT_SEGMENT_WRITE_REFUSED;
1480        let after = || {
1481            vec![
1482                ("path", input.path.clone()),
1483                ("kind", input.kind.as_str().to_owned()),
1484                ("vlan_id", input.vlan_id.to_string()),
1485                ("filter_ids", input.filter_ids.join(",")),
1486                (
1487                    "rank",
1488                    input
1489                        .rank
1490                        .map_or_else(|| "none".to_owned(), |r| r.to_string()),
1491                ),
1492                ("enabled", input.enabled.to_string()),
1493            ]
1494        };
1495        let path = match NetworkSegmentPath::parse(&input.path) {
1496            Ok(p) => p,
1497            Err(e) => {
1498                let mut r = refuse(
1499                    RefusalStatus::Invalid,
1500                    "4.1:reserved-subtree",
1501                    audit,
1502                    e.to_string(),
1503                );
1504                r.after = after();
1505                return Ok(Err(r));
1506            }
1507        };
1508        // The parent is the site; one that does not exist yet is created by
1509        // this write under its own parent, so the check climbs to the nearest
1510        // node that exists (and to `/network` itself, which answers only to
1511        // tenant-wide grants until the first segment makes it).
1512        let site = site_node_id(self.tenant(), path.kind, &path.site_key);
1513        let branch = branch_node_id(self.tenant(), path.kind);
1514        let mut parent = self.root();
1515        for node in [site, branch] {
1516            if self.store.resource(self.tenant(), node).await?.is_some() {
1517                parent = node;
1518                break;
1519            }
1520        }
1521        if let Some(mut r) = self
1522            .require_all(
1523                &[NETWORK_SEGMENTS_WRITE],
1524                parent,
1525                "4.2:segments_write",
1526                audit,
1527            )
1528            .await?
1529        {
1530            r.before = vec![("segment", "none".to_owned())];
1531            r.after = after();
1532            return Ok(Err(r));
1533        }
1534        Ok(Ok(self.clearance(NetworkWriteTarget::SegmentCreate {
1535            path: input.path.clone(),
1536        })))
1537    }

1539    async fn segment_update(
1540        &self,
1541        segment_id: Uuid,
1542        update: &NetworkSegmentUpdate,
1543    ) -> AxiamResult<GateVerdict> {
1544        let seg = self.store.segment(self.tenant(), segment_id).await?;
1545        let audit = AUDIT_SEGMENT_WRITE_REFUSED;
1546        let with_values = |mut r: GateRefusal| {
1547            r.before = describe_segment(&seg);
1548            r.after = vec![
1549                ("vlan_id", update.vlan_id.to_string()),
1550                ("filter_ids", update.filter_ids.join(",")),
1551                (
1552                    "rank",
1553                    update
1554                        .rank
1555                        .map_or_else(|| "none".to_owned(), |r| r.to_string()),
1556                ),
1557                ("enabled", update.enabled.to_string()),
1558                ("expected_version", update.expected_version.to_string()),
1559            ];
1560            r
1561        };
1562        if let Some(r) = self
1563            .require_all(
1564                &[NETWORK_SEGMENTS_WRITE],
1565                seg.id,
1566                "4.2:segments_write",
1567                audit,
1568            )
1569            .await?
1570        {
1571            return Ok(Err(with_values(r)));
1572        }
1573        // R110W6-03: on a segment that has a profile, `vlan_id`, `rank` and
1574        // `enabled` decide where every device that may join it lands — a new
1575        // VLAN for all of them, another winner among the site's access
1576        // candidates, a candidate more or less. Changing them is a placement
1577        // write, so it asks what a profile write asks for the same reason: H2
1578        // at the segment, and H5 on a quarantine segment, which every
1579        // quarantined device of the site reaches. `filter_ids` is not one of
1580        // them: it bounds what a profile may name, and removing the name the
1581        // profile uses is the repository's `409` (§5.2).
1582        let moves_placement = update.vlan_id != seg.vlan_id
1583            || update.rank != seg.rank
1584            || update.enabled != seg.enabled;
1585        let profiled =
1586            moves_placement && self.store.profile(self.tenant(), seg.id).await?.is_some();
1587        if profiled && let Some(r) = self.placement_rights(&seg, audit).await? {
1588            return Ok(Err(with_values(r)));
1589        }
1590        // H6's reasoning applies to the envelope as much as to the profile: the
1591        // VLAN is what joining the segment gives.
1592        if self.holds(NETWORK_JOIN, seg.id).await? {
1593            return Ok(Err(with_values(refuse(
1594                RefusalStatus::Forbidden,
1595                "H6",
1596                audit,
1597                "a subject that may be placed on this segment cannot rewrite its envelope",
1598            ))));
1599        }
1600        let cleared = self.clearance(NetworkWriteTarget::SegmentUpdate { segment_id });
1601        if profiled {
1602            return Ok(Ok(cleared));
1603        }
1604        // Cleared without asking `network:grant`, on this read: no placement
1605        // change, or no profile. The write's transaction re-checks both against
1606        // the row it replaces, so a profile created in between is a `409`
1607        // (the stale read it is), never a placement moved without the grant.
1608        Ok(Ok(cleared.freeze_profiled_placement()))
1609    }

1659    }

1687    // -- role assignment (§5.3, §4.2) --------------------------------------
1688
1689    async fn role_assign(
1690        &self,
1691        role_id: Uuid,
1692        grantee: Grantee,
1693        resource_id: Option<Uuid>,
1694        inherit: bool,
1695    ) -> AxiamResult<GateVerdict> {
1696        let Some(role) = self.found(self.store.role(self.tenant(), role_id).await)? else {
1697            return Ok(Ok(GateClearance::plain(false)));
1698        };
1699        let role_grants = self.store.role_grants(self.tenant(), role_id).await?;
1700        let grants = NetworkGrants::of(&role_grants);
1701        if !grants.any {
1702            return Ok(Ok(GateClearance::plain(false)));
1703        }
1704        let audit = AUDIT_ROLE_ASSIGN_REFUSED;
1705        let node = self.assignment_node(&role, resource_id);
1706        let held = match grantee {
1707            Grantee::Group(id) => self.store.group_assignments(self.tenant(), id).await?,
1708            Grantee::User(id) | Grantee::ServiceAccount(id) => {
1709                self.store.subject_assignments(self.tenant(), id).await?
1710            }
1711        };
1712        let (kind, who) = grantee.describe();
1713        let with_values = |mut r: GateRefusal| {
1714            r.before = describe_assignments(role_id, &held);
1715            r.after = vec![
1716                ("role_id", role_id.to_string()),
1717                ("role", role.name.clone()),
1718                (kind, who.clone()),
1719                ("node", node.to_string()),
1720                ("inherit", inherit.to_string()),
1721            ];
1722            r
1723        };
1724
1725        // Rule 2: never through a group. Membership is written by
1726        // `groups:add_member`, SCIM and directory sync, and each would become a
1727        // network grant.
1728        if matches!(grantee, Grantee::Group(_)) {
1729            return Ok(Err(with_values(refuse(
1730                RefusalStatus::Invalid,
1731                "4.2:rule-2",
1732                audit,
1733                "a role carrying a network: permission is never assigned to a group",
1734            ))));
1735        }
1736        // Rule 3: a network deny with `inherit: false` is a quarantine that
1737        // silently reaches nothing below its node.
1738        if grants.any_deny && !inherit {
1739            return Ok(Err(with_values(refuse(
1740                RefusalStatus::Invalid,
1741                "4.2:rule-3",
1742                audit,
1743                "a role carrying a network: deny cannot be assigned with inherit: false",
1744            ))));
1745        }
1746        // H6: a subject does not confer network:join on itself, whatever it
1747        // holds. Taking on a deny narrows and stays allowed; a meta permission
1748        // conferred is one §5.3 below already demands the writer hold at N.
1749        if grants.join_allow && self.edge_reaches_writer(grantee).await? {
1750            return Ok(Err(with_values(refuse(
1751                RefusalStatus::Forbidden,
1752                "H6",
1753                audit,
1754                "a subject cannot assign itself a role carrying network:join",
1755            ))));
1756        }
1757
1758        // The organization bootstrap (module documentation): the one write
1759        // cleared without the writer holding what the role confers.
1760        if self.is_organization_bootstrap(&role, &role_grants, grantee, resource_id) {
1761            return Ok(Ok(
1762                GateClearance::plain(true).exempt(EXEMPTION_ORGANIZATION_BOOTSTRAP)
1763            ));
1764        }

1767        // permission conferred needs holding it at N.
1768        let mut needed: Vec<&str> = Vec::new();
1769        if grants.join_allow || grants.join_deny {
1770            needed.push(NETWORK_GRANT);
1771        }

1774                needed.push(a.as_str());
1775            }
1776        }
1777        if let Some(r) = self.require_all(&needed, node, "5.3:assign", audit).await? {
1778            return Ok(Err(with_values(r)));
1779        }
1780        Ok(Ok(GateClearance::plain(true)))

1912    async fn permission_grant(
1913        &self,
1914        role_id: Uuid,
1915        permission_id: Uuid,
1916        effect: PermissionEffect,
1917        scope_ids: &[Uuid],
1918    ) -> AxiamResult<GateVerdict> {
1919        let Some(permission) =
1920            self.found(self.store.permission(self.tenant(), permission_id).await)?
1921        else {
1922            return Ok(Ok(GateClearance::plain(false)));
1923        };
1924        if !is_network_action(&permission.action) {
1925            return Ok(Ok(GateClearance::plain(false)));
1926        }
1927        let Some(role) = self.found(self.store.role(self.tenant(), role_id).await)? else {
1928            return Ok(Ok(GateClearance::plain(false)));
1929        };
1930        let current = self.store.role_grants(self.tenant(), role_id).await?;
1931        let audit = AUDIT_ROLE_GRANT_REFUSED;
1932        let action = permission.action.as_str();
1933        let effect_name = match effect {
1934            PermissionEffect::Allow => "allow",
1935            PermissionEffect::Deny => "deny",
1936        };
1937        let with_values = |mut r: GateRefusal| {
1938            r.before = vec![
1939                ("role_id", role_id.to_string()),
1940                ("role", role.name.clone()),
1941                (
1942                    "grant",
1943                    current
1944                        .iter()
1945                        .find(|g| g.permission.id == permission_id)
1946                        .map_or_else(
1947                            || "none".to_owned(),
1948                            |g| match g.effect {
1949                                PermissionEffect::Allow => "allow".to_owned(),
1950                                PermissionEffect::Deny => "deny".to_owned(),
1951                            },
1952                        ),
1953                ),
1954            ];
1955            r.after = vec![
1956                ("permission", action.to_owned()),
1957                ("effect", effect_name.to_owned()),
1958                ("scope_ids", scope_ids.len().to_string()),
1959            ];
1960            r
1961        };
1962        let invalid = |rule: &'static str, msg: &str| {
1963            Ok(Err(with_values(refuse(
1964                RefusalStatus::Invalid,
1965                rule,
1966                audit,
1967                msg,
1968            ))))
1969        };
1970
1971        if effect == PermissionEffect::Allow && NETWORK_ADMIN_CLASS_ACTIONS.contains(&action) {
1972            return invalid(
1973                "4.2:not-grantable",
1974                "network:admin and network:grant_admin are not grantable under option B",
1975            );
1976        }
1977        if !scope_ids.is_empty() {
1978            // A scoped network grant matches only scoped checks, and the
1979            // placement check is unscoped: a scoped deny would be a quarantine
1980            // that reaches nothing.
1981            return invalid(
1982                "4.2:scoped-grant",
1983                "a network: permission is granted without scopes",
1984            );
1985        }
1986        if role.is_global {
1987            return invalid(
1988                "4.2:rule-1",
1989                "a network: permission cannot be granted to a global role",
1990            );
1991        }
1992        let holders = self.store.role_holders(self.tenant(), role_id).await?;
1993        if !holders.groups.is_empty() {
1994            return invalid(
1995                "4.2:rule-2",
1996                "a network: permission cannot be granted to a role a group holds",
1997            );
1998        }
1999        if effect == PermissionEffect::Deny && holders.all().any(|h| !h.inherit) {
2000            return invalid(
2001                "4.2:rule-3",
2002                "a network: deny cannot be granted to a role assigned with inherit: false",
2003            );
2004        }
2005        // H6: a join allow on a role the writer holds is a join the writer
2006        // confers on itself, whatever it holds.
2007        if effect == PermissionEffect::Allow
2008            && action == NETWORK_JOIN
2009            && self.writer_holds_role(role_id).await?
2010        {
2011            return Ok(Err(with_values(refuse(
2012                RefusalStatus::Forbidden,
2013                "H6",
2014                audit,
2015                "a subject cannot grant network:join to a role it holds",
2016            ))));
2017        }
2018
2019        // It changes every existing assignment of the role at once.
2020        let mut needed = vec![NETWORK_GRANT];
2021        if effect == PermissionEffect::Allow
2022            && NETWORK_META_ACTIONS.contains(&action)
2023            && action != NETWORK_GRANT
2024        {
2025            needed.push(action);
2026        }
2027        if let Some(r) = self
2028            .require_all(&needed, self.root(), "5.3:permission", audit)
2029            .await?
2030        {
2031            return Ok(Err(with_values(r)));
2032        }
2033        Ok(Ok(GateClearance::plain(true)))
2034    }

2036    async fn permission_revoke(
2037        &self,
2038        role_id: Uuid,
2039        permission_id: Uuid,
2040    ) -> AxiamResult<GateVerdict> {
2041        let Some(permission) =
2042            self.found(self.store.permission(self.tenant(), permission_id).await)?
2043        else {
2044            return Ok(Ok(GateClearance::plain(false)));
2045        };
2046        if !is_network_action(&permission.action) {
2047            return Ok(Ok(GateClearance::plain(false)));
2048        }
2049        let current = self
2050            .store
2051            .role_grants(self.tenant(), role_id)
2052            .await?
2053            .into_iter()
2054            .find(|g| g.permission.id == permission_id)
2055            .map(|g| g.effect);

2057            r.before = vec![
2058                ("role_id", role_id.to_string()),
2059                ("permission", permission.action.clone()),
2060                (
2061                    "grant",
2062                    match current {
2063                        None => "none",
2064                        Some(PermissionEffect::Allow) => "allow",
2065                        Some(PermissionEffect::Deny) => "deny",
2066                    }
2067                    .to_owned(),
2068                ),
2069            ];
2070            r.after = vec![("grant", "revoked".to_owned())];
2071            r
2072        };
2073        // H6: revoking a network deny from a role the writer holds sheds the
2074        // writer's own deny (a quarantine released by the quarantined).
2075        if current == Some(PermissionEffect::Deny) && self.writer_holds_role(role_id).await? {
2076            return Ok(Err(with_values(refuse(
2077                RefusalStatus::Forbidden,
2078                "H6",
2079                AUDIT_ROLE_GRANT_REFUSED,
2080                "a subject cannot revoke a network deny from a role it holds",
2081            ))));
2082        }
2083        if let Some(r) = self
2084            .require_all(
2085                &[NETWORK_GRANT],
2086                self.root(),
2087                "5.3:permission",
2088                AUDIT_ROLE_GRANT_REFUSED,
2089            )
2090            .await?
2091        {
2092            return Ok(Err(with_values(r)));
2093        }
2094        // The delete is conditional on the grant read here (R110W6-04): a deny
2095        // written since would otherwise be deleted by a revoke H6 never saw.
2096        Ok(Ok(GateClearance::plain(true).revoking(current)))
2097    }

2165    async fn certificate_bind(
2166        &self,
2167        certificate_id: Uuid,
2168        service_account_id: Uuid,
2169    ) -> AxiamResult<GateVerdict> {
2170        let audit = AUDIT_BINDING_REFUSED;
2171        let before = self.store.bound_service_account(certificate_id).await?;
2172        let with_values = |mut r: GateRefusal| {
2173            r.before = vec![
2174                ("certificate_id", certificate_id.to_string()),
2175                (
2176                    "service_account_id",
2177                    before.map_or_else(|| "unbound".to_owned(), |s| s.to_string()),
2178                ),
2179            ];
2180            r.after = vec![("service_account_id", service_account_id.to_string())];
2181            r
2182        };
2183
2184        // H6: a subject does not bind a certificate to itself, nor (the same
2185        // thing) through a certificate bound to the account being written: a
2186        // certificate-authenticated caller *is* that account.
2187        if self.writer.subject_id == service_account_id {
2188            return Ok(Err(with_values(refuse(
2189                RefusalStatus::Forbidden,
2190                "H6",
2191                audit,
2192                "a service account cannot bind a certificate to itself",
2193            ))));
2194        }
2195
2196        // Placement is the pair (the account's joins, the binding). Every node
2197        // at which the account holds an effective `network:join` allow needs
2198        // the binder to hold `network:grant` there.
2199        let assignments = self
2200            .store
2201            .subject_assignments(self.tenant(), service_account_id)
2202            .await?;
2203        let mut nodes: BTreeSet<Uuid> = BTreeSet::new();
2204        let mut seen_roles: BTreeSet<Uuid> = BTreeSet::new();
2205        let mut join_roles: BTreeSet<Uuid> = BTreeSet::new();
2206        for a in assignments
2207            .iter()
2208            .filter(|a| a.reaches_tenant(self.tenant()))
2209        {
2210            if seen_roles.insert(a.role.id) {
2211                let grants =
2212                    NetworkGrants::of(&self.store.role_grants(self.tenant(), a.role.id).await?);
2213                if grants.join_allow {
2214                    join_roles.insert(a.role.id);
2215                }
2216            }
2217            if join_roles.contains(&a.role.id) {
2218                nodes.insert(self.assignment_node(&a.role, a.resource_id));
2219            }
2220        }
2221        for node in nodes {
2222            // Read with the engine's own evaluation: an allow a deny already
2223            // beats at the node is not one the binder must hold. Sound because
2224            // a network deny is never assigned with `inherit: false` (§4.2
2225            // rule 3), so a deny that beats the allow at its node beats it at
2226            // every node below.
2227            if !self
2228                .subject_holds(service_account_id, SubjectScope::Tenant, NETWORK_JOIN, node)
2229                .await?
2230            {
2231                continue;
2232            }
2233            if let Some(r) = self
2234                .require_all(&[NETWORK_GRANT], node, "5.3:bind", audit)
2235                .await?
2236            {
2237                return Ok(Err(with_values(r)));
2238            }
2239        }
2240        Ok(Ok(GateClearance::plain(true)))
2241    }
