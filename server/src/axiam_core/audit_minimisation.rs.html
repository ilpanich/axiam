1//! Deployment-wide minimisation of what reaches the append-only audit log
2//! (T-110).
3//!
4//! # The problem this answers
5//!
6//! The audit log is append-only by design, which is in direct tension with the
7//! Art. 17 erasure path AXIAM also offers: personal data written into it cannot
8//! later be removed, only aged out. T-119 bounded the *retention* side — a
9//! default 730-day sweep, the table's only deletion path. The collection side
10//! was never configurable at all, so a deployment whose lawful basis does not
11//! support holding a full client IP address for two years had nothing to turn
12//! off.
13//!
14//! # What it does, and what it deliberately does not
15//!
16//! With minimisation on, two fields are reduced **before** the write, because
17//! after it there is no second chance by construction:
18//!
19//! - `ip_address` is truncated to its `/24` (IPv4) or `/48` (IPv6) prefix. That
20//!   keeps the network an action came from — enough to see a pattern, to
21//!   correlate a burst, to answer "was this the office" — and drops the part
22//!   that identifies a subscriber line or a device.
23//! - a `user_agent` member of `metadata`, where a producer sets one, is reduced
24//!   to a coarse family. A full user-agent string is a fingerprint; the family
25//!   is the part an investigation actually reads.
26//!
27//! **It does not strip the structured metadata domain producers write**, and
28//! that limit is the design rather than an omission.
29//! `oauth2.refresh_token_replayed` names the client, its profile and the
30//! disposition (T-254); a sensitive-scope release names the claim by name
31//! (T-241); a JIT provision names the provider and the external subject
32//! (T-161). Those are accountability evidence that other threats' mitigations
33//! depend on. Dropping them would weaken three controls to narrow one, and
34//! none of them is request metadata: the request-audit middleware collects
35//! `http_status` and `authenticated` and nothing else, which is pinned by its
36//! own test rather than left to habit.
37//!
38//! # Why deployment-wide and not per tenant
39//!
40//! Audit is an accountability control the deployment relies on, **including
41//! against a tenant administrator**. A per-tenant switch would let a tenant
42//! weaken the evidence that would be used to investigate that tenant. It is
43//! the same argument that makes `sensitive_scopes_enabled` disable-only for a
44//! tenant under T-241, applied to a control where the tenant is a possible
45//! subject rather than a possible victim.
46//!
47//! Off by default, because turning it on reduces forensic precision and that
48//! is a lawful-basis judgement a deployment must make deliberately rather than
49//! inherit.

55/// Whether a deployment minimises what it collects into the audit log.
56///
57/// Built once at the composition root from `AXIAM__AUDIT__MINIMISE` and held
58/// by the repository, so every producer passes through it — there are eighteen
59/// of them, and only the repository is common to all.
60#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
61pub struct AuditMinimisation {
62    enabled: bool,
63}
64
65impl AuditMinimisation {
66    /// `enabled = false` is today's behaviour and the default.
67    #[must_use]
68    pub const fn new(enabled: bool) -> Self {
69        Self { enabled }
70    }
71
72    /// Whether minimisation is in force. Logged at startup either way.
73    #[must_use]
74    pub const fn is_enabled(self) -> bool {
75        self.enabled
76    }
77
78    /// Reduce an entry in place. A no-op when minimisation is off, which is
79    /// what makes an unconfigured deployment byte-identical.
80    pub fn apply(self, entry: &mut CreateAuditLogEntry) {
81        if !self.enabled {
82            return;
83        }
84        entry.ip_address = entry.ip_address.as_deref().and_then(truncate_ip);
85        if let Some(serde_json::Value::Object(map)) = entry.metadata.as_mut()
86            && let Some(agent) = map.get("user_agent").and_then(serde_json::Value::as_str)
87        {
88            let family = user_agent_family(agent).to_owned();
89            map.insert("user_agent".into(), serde_json::Value::String(family));
90        }
91    }
92}

94/// Truncate an address to its `/24` (IPv4) or `/48` (IPv6) prefix.
95///
96/// Returns `None` for anything that does not parse as an address, and that is
97/// the load-bearing case: a value which cannot be parsed cannot be shown to
98/// have been minimised, and passing it through would be a silent hole in the
99/// control. Dropping it costs one field on a row whose `action`, `actor_id`
100/// and `outcome` are unaffected.
101///
102/// `realip_remote_addr` can hand back a `host:port` string, so a single
103/// trailing `:port` on an IPv4 address is stripped first. An IPv6 address is
104/// only accepted in its bracketed form when a port is present, because
105/// `::1:8080` is a valid address in its own right and guessing would corrupt
106/// it.
107#[must_use]
108pub fn truncate_ip(raw: &str) -> Option<String> {
109    let trimmed = raw.trim();
110    let candidate = if let Some(rest) = trimmed.strip_prefix('[') {
111        // `[2001:db8::1]:8080` or `[2001:db8::1]`
112        rest.split(']').next()?
113    } else if trimmed.matches(':').count() == 1 {
114        // Exactly one colon can only be `v4:port` — an IPv6 address always has
115        // at least two.
116        trimmed.split(':').next()?
117    } else {
118        trimmed
119    };
120
121    match candidate.parse::<IpAddr>().ok()? {
122        IpAddr::V4(v4) => {
123            let [a, b, c, _] = v4.octets();
124            Some(format!("{a}.{b}.{c}.0/24"))
125        }
126        IpAddr::V6(v6) => {
127            // A v4-mapped address is a v4 address wearing a hat; minimise it
128            // as what it is, or the same client reaches the log at two
129            // different granularities depending on the socket family.
130            if let Some(v4) = v6.to_ipv4_mapped() {
131                let [a, b, c, _] = v4.octets();
132                return Some(format!("{a}.{b}.{c}.0/24"));
133            }
134            let s = v6.segments();
135            Some(format!("{:x}:{:x}:{:x}::/48", s[0], s[1], s[2]))
136        }
137    }
138}

140/// A coarse family for a user-agent string.
141///
142/// Total, dependency-free, and deliberately crude. A user-agent parsing
143/// library exists to recover precision, which is the precise thing being
144/// removed here — using one would be working against the control.
145///
146/// Order matters: every mainstream browser claims to be several others, so the
147/// most specific claim is checked first.
148#[must_use]
149pub fn user_agent_family(raw: &str) -> &'static str {
150    let ua = raw.to_ascii_lowercase();
151    for (needle, family) in [
152        ("edg/", "Edge"),
153        ("opr/", "Opera"),
154        ("firefox/", "Firefox"),
155        ("chrome/", "Chrome"),
156        ("safari/", "Safari"),
157        ("curl/", "curl"),
158        ("wget/", "Wget"),
159        ("python-requests", "python-requests"),
160        ("okhttp", "OkHttp"),
161        ("go-http-client", "Go"),
162        ("postmanruntime", "Postman"),
163        ("axiam", "AXIAM SDK"),
164    ] {
165        if ua.contains(needle) {
166            return family;
167        }
168    }
169    "other"
170}

172#[cfg(test)]
173mod tests {
174    use super::*;
175    use crate::models::audit::{ActorType, AuditOutcome};
176    use uuid::Uuid;

178    fn entry(ip: Option<&str>, metadata: Option<serde_json::Value>) -> CreateAuditLogEntry {
179        CreateAuditLogEntry {
180            tenant_id: Uuid::new_v4(),
181            actor_id: Uuid::new_v4(),
182            actor_type: ActorType::User,
183            action: "POST /api/v1/users".into(),
184            resource_id: None,
185            outcome: AuditOutcome::Success,
186            ip_address: ip.map(str::to_owned),
187            metadata,
188        }
189    }
190
191    #[test]
192    fn ipv4_keeps_the_network_and_drops_the_host() {
193        assert_eq!(
194            truncate_ip("203.0.113.42").as_deref(),
195            Some("203.0.113.0/24")
196        );
197        assert_eq!(truncate_ip("  10.1.2.3  ").as_deref(), Some("10.1.2.0/24"));
198    }
199
200    /// `realip_remote_addr` hands back a `host:port` string on some
201    /// configurations, and a value that failed to parse would be dropped
202    /// rather than minimised — which is correct but loses a field nobody
203    /// needed to lose.
204    #[test]
205    fn a_port_suffix_does_not_defeat_it() {
206        assert_eq!(
207            truncate_ip("203.0.113.42:54321").as_deref(),
208            Some("203.0.113.0/24")
209        );
210        assert_eq!(
211            truncate_ip("[2001:db8:1234:5678::1]:443").as_deref(),
212            Some("2001:db8:1234::/48")
213        );
214        assert_eq!(
215            truncate_ip("[2001:db8:1234:5678::1]").as_deref(),
216            Some("2001:db8:1234::/48")
217        );
218    }
219
220    #[test]
221    fn ipv6_keeps_the_first_three_groups() {
222        assert_eq!(
223            truncate_ip("2001:db8:abcd:0012::1").as_deref(),
224            Some("2001:db8:abcd::/48")
225        );
226        // An unbracketed v6 with two or more colons is taken whole — `::1` has
227        // no port and guessing one would corrupt it.
228        assert_eq!(truncate_ip("::1").as_deref(), Some("0:0:0::/48"));
229    }
230
231    /// A v4-mapped v6 address is a v4 address. Minimising it as a v6 one would
232    /// give the same client two different granularities depending on the
233    /// socket family the listener happened to accept it on.
234    #[test]
235    fn a_v4_mapped_address_is_minimised_as_v4() {
236        assert_eq!(
237            truncate_ip("::ffff:203.0.113.42").as_deref(),
238            Some("203.0.113.0/24")
239        );
240    }
241
242    /// The one that must fail closed: a value that cannot be parsed cannot be
243    /// shown to have been minimised, so it is dropped rather than written
244    /// through.
245    #[test]
246    fn an_unparseable_address_is_dropped_rather_than_passed_through() {
247        for bad in ["not-an-ip", "", "   ", "203.0.113", "gibberish:1:2:3"] {
248            assert_eq!(truncate_ip(bad), None, "{bad:?} must not pass through");
249        }
250    }
251
252    #[test]
253    fn user_agent_families_prefer_the_most_specific_claim() {
254        // Edge and Opera both claim Chrome and Safari; Chrome claims Safari.
255        assert_eq!(
256            user_agent_family(
257                "Mozilla/5.0 (Windows NT 10.0) AppleWebKit/537.36 Chrome/120 Safari/537.36 Edg/120"
258            ),
259            "Edge"
260        );
261        assert_eq!(
262            user_agent_family("Mozilla/5.0 AppleWebKit/537.36 Chrome/120 Safari/537.36"),
263            "Chrome"
264        );
265        assert_eq!(user_agent_family("curl/8.5.0"), "curl");
266        assert_eq!(user_agent_family("something nobody has seen"), "other");
267    }
268
269    #[test]
270    fn minimisation_on_truncates_both_fields() {
271        let mut e = entry(
272            Some("203.0.113.42"),
273            Some(serde_json::json!({
274                "http_status": 200,
275                "user_agent": "Mozilla/5.0 (X11; Linux) Firefox/128.0",
276            })),
277        );
278        AuditMinimisation::new(true).apply(&mut e);
279        assert_eq!(e.ip_address.as_deref(), Some("203.0.113.0/24"));
280        assert_eq!(e.metadata.as_ref().unwrap()["user_agent"], "Firefox");
281        // And leaves the structured accountability metadata exactly alone.
282        assert_eq!(e.metadata.as_ref().unwrap()["http_status"], 200);
283    }

285    /// **I4 twin.** Off is the default, and off must be indistinguishable from
286    /// the code that existed before this module.
287    #[test]
288    fn minimisation_off_changes_nothing() {
289        let original = entry(
290            Some("203.0.113.42"),
291            Some(serde_json::json!({ "user_agent": "curl/8.5.0" })),
292        );
293        let mut e = original.clone();
294        AuditMinimisation::default().apply(&mut e);
295        assert_eq!(e.ip_address, original.ip_address);
296        assert_eq!(e.metadata, original.metadata);
297        assert!(!AuditMinimisation::default().is_enabled());
298    }

318            "minimisation must not strip a producer's structured metadata"
319        );
320    }
