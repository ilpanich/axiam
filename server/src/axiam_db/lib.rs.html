1//! AXIAM Database — SurrealDB connection management and repository
2//! implementations.
3//!
4//! This crate provides:
5//! - Connection management ([`DbManager`], [`DbConfig`], [`DbPool`])
6//! - [`DbHandle`] — the LIVE pooled-connection reference repositories bind to,
7//!   so a reconnect-loop handle swap is observed on the next query rather than
8//!   leaving them pinned to an evicted connection
9//! - Schema initialization and migrations ([`run_migrations`])
10//! - Repository implementations for `axiam-core` traits
11//! - Error types ([`DbError`])
12//! - The process-wide write-behind shared rate-limit counter
13//!   ([`SharedRateLimitCounter`]), used by BOTH the REST and gRPC
14//!   shared-store rate-limit layers
15
