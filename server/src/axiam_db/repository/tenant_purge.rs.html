1//! The tenant purge (#523, P23W2-04, D-4).
2//!
3//! Deleting a tenant tombstones it ([`super::SurrealTenantRepository`]'s
4//! `delete`): the row stays, with `deleted_at` set, so the tenant leaves every
5//! read path at once while its data is still there. The cleanup job's
6//! `tenant_purge` sweep then removes the data — every row of every
7//! tenant-scoped table — and the tenant row last.
8//!
9//! # The order
10//!
11//! [`TENANT_PURGE_ORDER`] follows the order the GDPR user erasure uses
12//! (`axiam_server::cleanup`'s purge pipeline, steps (a) to (f)), widened from
13//! one account to every account and every configuration of the tenant:
14//!
15//! 1. [`PurgeStage::Grants`] — sessions, refresh tokens and every other grant or
16//!    in-flight credential, so nothing issued to the tenant can be redeemed
17//!    while the rest goes (erasure step (a)). The request that tombstoned the
18//!    tenant already revoked its sessions and refresh tokens; this removes the
19//!    rows.
20//! 2. [`PurgeStage::IdentityLinks`] — federation links (step (b)).
21//! 3. [`PurgeStage::Credentials`] — passkeys, OPAQUE records, password history
22//!    (step (b2)).
23//! 4. [`PurgeStage::Authorization`] — groups, roles, permissions, scopes,
24//!    resources and service accounts; their graph edges go with the records
25//!    (step (b3)).
26//! 5. [`PurgeStage::AuditTrail`] — the tenant's own audit entries **the
27//!    export covered**, and the signatures over nothing but those entries (step
28//!    (d); see "The audit trail" below). The `tenant.deleted` record is written
29//!    to the system log (the nil tenant) and is never touched here.
30//! 6. [`PurgeStage::Records`] — consents, deletion requests, export jobs and
31//!    erasure proofs (steps (f) and (g)).
32//! 7. [`PurgeStage::Accounts`] — the user rows themselves (step (e); an erasure
33//!    anonymizes one account in place, a tenant purge removes them all).
34//! 8. [`PurgeStage::Configuration`] — everything the tenant configured,
35//!    including the encrypted credentials it held for systems outside AXIAM.
36//!
37//! Every step is one idempotent `DELETE … WHERE <tenant>`, so a purge that
38//! fails part-way stops there, leaves the tenant tombstoned, and is resumed by
39//! the next sweep; the tenant row goes only after every step succeeded.
40//!
41//! # The audit trail: only what the export holds (R1W1-04, #602, D-5)
42//!
43//! The deletion is refused until the tenant's audit trail has been exported
44//! (T-118), and the receipt it accepts may be up to six hours old. The export
45//! covers the rows written up to the moment it started — its receipt's
46//! `exported_through`, which the deletion copies into its `tenants.deleted`
47//! system-log record as `audit_exported_through` — and nothing written after
48//! it: the receipt itself, what the tenant did in the hours before the
49//! deletion, and what the deletion and the time until the purge produced (its
50//! revocations, refused sign-ins, refused client calls).
51//!
52//! So the purge deletes the tenant's `audit_log` rows with `timestamp` **at or
53//! before** that export time and no others: the operator holds a copy of every
54//! row it destroys. A later row stays under the tenant id, which no tenant row
55//! names any more, as the rows of an orphaned tenant id do
56//! ([`PurgeScope::Orphan`]); the audit retention sweep (T-119) deletes it once
57//! it is older than the deployment's retention window, as it does every audit
58//! row, whatever tenant it names. Nothing is copied to the system log. An
59//! `audit_signature` row goes when **none** of its `entry_ids` is still in the
60//! log — every entry it signs went with the purge; one that also signs a kept
61//! entry stays, and the retention sweep removes it by its `signed_at`.
62//!
63//! The export time is read from the newest `tenants.deleted` record naming the
64//! tenant (`resource_id`). A record written before this rule existed carries
65//! only the receipt id, and the time is then read from that receipt's own
66//! `exported_through`, which every receipt has carried. Either way it is
67//! **clamped to the receipt's own `timestamp`** (R101W3-03, #637): the receipt
68//! is written after the export drains, so an honest export time is earlier than
69//! the receipt, and the row's `timestamp` is the datastore's while
70//! `exported_through` is whatever its writer said. A receipt claiming to cover
71//! rows after itself bounds the purge at itself, never later (the deletion
72//! refuses such a receipt since #637, and no AMQP producer can write one —
73//! `tenants.*` is reserved, [`axiam_core::models::audit::RESERVED_ACTION_NAMESPACES`]).
74//! An honest receipt is after the bound, so the purge never deletes it. When no
75//! time can be read — no deletion record (its write was dead-lettered, or the
76//! purge ran before it landed), a record without one, or a record whose
77//! receipt is not in the tenant's log — the purge deletes **no** audit row
78//! and no signature of the tenant: it keeps everything, as for an orphan, and
79//! leaves it to the retention sweep. `tenants.purged` records the export time
80//! used (or `null`) and how many audit rows were deleted and kept
81//! ([`TenantPurgeReport`]).
82//!
83//! The audit log is append-only (`super::audit`): the purge's audit stage is a
84//! documented exception, and it deletes only what an export holds or what
85//! signs nothing still in the log; it updates no audit row.
86//!
87//! # Revocation evidence outlives the tenant (R1W1-01)
88//!
89//! Two tables are not emptied: `certificate` and `ca_certificate` keep every
90//! **revoked** row that is unexpired or expired less than eight days ago
91//! ([`Retain::RevokedUntilExpiry`]; the grace is the longest time a list keeps
92//! an expired entry, #608). An issuing CA's
93//! revocation list (`axiam_pki::crl`, T-102) is read from those rows, across
94//! tenants, by issuer; deleting them took a revoked leaf off its organization
95//! CA's list and made it valid again to every relying party outside AXIAM. The
96//! deletion revoked every certificate and signing CA of the tenant already
97//! (the handler, and again the tombstone transaction), and the step revokes
98//! anything still unrevoked first, so after the purge each of the tenant's
99//! unexpired certificates is a revoked row its issuer's list names — and that
100//! every authentication path refuses, since each reads the row's status.
101//!
102//! What is kept is what the list needs and no more: the step clears a
103//! certificate's free-form `metadata` and a CA's sealed private key. The rows
104//! name a tenant id with no tenant row, which is what the orphan scan looks
105//! for; it ignores a kept row until eight days after it expires, and then the
106//! orphan purge removes it — the cleanup job deletes the evidence once no list
107//! names it and no relying party can need it.
108//!
109//! # Completeness is pinned
110//!
111//! `schema::tests::every_tenant_scoped_table_is_purged` scans every migration
112//! for a table with a `tenant_id` field (or the `scope`/`scope_id` pair) and
113//! fails when one is missing here — a table added later without a purge step
114//! fails the build's tests rather than surviving its tenant.

194/// Which of a table's rows the purge keeps.
195#[derive(Debug, Clone, Copy, PartialEq, Eq)]
196pub enum Retain {
197    /// None: every row of the tenant goes.
198    Nothing,
199    /// A revoked certificate whose `not_after` is still ahead, or passed less
200    /// than eight days ago — the evidence its issuer's revocation list is read
201    /// from (R1W1-01, #608; see the module documentation). Every other row goes; an unrevoked, unexpired row is
202    /// revoked first, and a kept row has `strip` applied (an `UPDATE … SET`
203    /// clause clearing what the list does not need).
204    RevokedUntilExpiry {
205        /// The `SET` clause applied to a kept row.
206        strip: &'static str,
207    },
208    /// `audit_log`: a row written after the export the deletion required
209    /// (R1W1-04; see the module documentation). Rows with a `timestamp` at or
210    /// before the export time go; the purge skips the step, keeping every row,
211    /// when it knows no export time.
212    AfterExport,
213    /// `audit_signature`: a signature over at least one entry still in
214    /// `audit_log` once [`Retain::AfterExport`] has run. A signature whose every
215    /// entry is gone goes.
216    CoveringKeptEntries,
217}

219/// How many days after its `notAfter` a revoked certificate's row is kept: the
220/// longest an issuer's list can keep an expired entry (one `nextUpdate`
221/// interval, at most seven days, #608) and a day's margin for the datastore's
222/// clock. One spelling, a macro, because it feeds [`REVOCATION_GRACE_SECS`] and
223/// the two `concat!`ed SurrealQL conditions [`KEPT_REVOCATION`] and
224/// [`PAST_REVOCATION_GRACE`], so the number and the queries cannot drift apart.
225/// The `axiam-server` test `kept_revocation_covers_the_longest_crl_interval`
226/// ties it to `axiam_pki::crl::MAX_CRL_NEXT_UPDATE_SECS` (#621).
227macro_rules! revocation_grace_days {
228    () => {
229        8
230    };
231}
232
233/// [`KEPT_REVOCATION`]'s grace in seconds: eight days past `notAfter`.
234///
235/// Public so a test in a crate that sees both this one and `axiam-pki` can
236/// check it against the longest list interval instead of repeating the number
237/// (#621).
238pub const REVOCATION_GRACE_SECS: u64 = revocation_grace_days!() * 86_400;
239
240/// The condition a row the purge keeps satisfies: revoked, and expired for
241/// less than eight days ([`REVOCATION_GRACE_SECS`]).
242///
243/// Not "unexpired" (#608). An issuing CA's list keeps an expired entry until it
244/// has appeared on a list issued after the expiry — RFC 5280 §3.3 requires
245/// that — which is up to one `nextUpdate` interval past `notAfter`, at most
246/// seven days (`axiam_pki::crl::MAX_CRL_NEXT_UPDATE_SECS`). A row the purge
247/// deleted inside that window would leave the list mid-way through a refresh
248/// epoch, which changes the list without moving its `thisUpdate` and so breaks
249/// the CRL number every replica derives from them. The eighth day is margin
250/// for the datastore's clock against the replicas'.
251///
252/// Public, with [`PAST_REVOCATION_GRACE`], for the same test (#621); the text
253/// is SurrealQL for this crate's own queries, not an API.
254pub const KEPT_REVOCATION: &str = concat!(
255    "status = 'Revoked' AND not_after > time::now() - ",
256    revocation_grace_days!(),
257    "d"
258);
259
260/// A certificate row no revocation list names any more and no relying party
261/// can need: `notAfter` passed more than [`KEPT_REVOCATION`]'s grace ago,
262/// whatever its status (W1.4, #618). What the cleanup job's certificate
263/// retention sweep deletes in a live tenant — and what the tenant purge's
264/// orphan scan has always waited for, now for every certificate rather than
265/// only for the kept ones of a deleted tenant. The grace is spelled once, in
266/// `revocation_grace_days!`, so the two cannot drift apart.
267pub const PAST_REVOCATION_GRACE: &str =
268    concat!("not_after <= time::now() - ", revocation_grace_days!(), "d");

270/// One table of the purge.
271#[derive(Debug, Clone, Copy)]
272pub struct PurgeStep {
273    /// The table.
274    pub table: &'static str,
275    /// How its rows name their tenant.
276    pub key: TenantKey,
277    /// Where in the erasure order it is purged.
278    pub stage: PurgeStage,
279    /// Which rows outlive the purge.
280    pub retain: Retain,
281}
282
283impl PurgeStep {
284    const fn by_tenant(table: &'static str, stage: PurgeStage) -> Self {
285        Self {
286            table,
287            key: TenantKey::TenantId,
288            stage,
289            retain: Retain::Nothing,
290        }
291    }
292
293    /// An audit table: keyed by `tenant_id`, keeping what no export holds.
294    const fn audit(table: &'static str, retain: Retain) -> Self {
295        Self {
296            table,
297            key: TenantKey::TenantId,
298            stage: AuditTrail,
299            retain,
300        }
301    }
302
303    const fn by_scope(table: &'static str, stage: PurgeStage) -> Self {
304        Self {
305            table,
306            key: TenantKey::Scope,
307            stage,
308            retain: Retain::Nothing,
309        }
310    }
311
312    /// A certificate table: keyed by `tenant_id`, keeping revocation evidence
313    /// until eight days after it expires.
314    const fn keeping_revocations(
315        table: &'static str,
316        strip: &'static str,
317        stage: PurgeStage,
318    ) -> Self {
319        Self {
320            table,
321            key: TenantKey::TenantId,
322            stage,
323            retain: Retain::RevokedUntilExpiry { strip },
324        }
325    }
326
327    /// The statement that removes the tenant's rows (`$id` is the tenant).
328    ///
329    /// The table name and a retaining step's `strip` clause are compile-time
330    /// constants of [`TENANT_PURGE_ORDER`], never input, so formatting them
331    /// into the statement is safe.
332    fn delete_statement(&self) -> String {
333        let table = self.table;
334        match (self.key, self.retain) {
335            (TenantKey::TenantId, Retain::Nothing) => {
336                format!("DELETE {table} WHERE tenant_id = $id")
337            }
338            (TenantKey::TenantId, Retain::RevokedUntilExpiry { strip }) => format!(
339                "UPDATE {table} SET status = 'Revoked', revoked_at = revoked_at ?? time::now() \
340                     WHERE tenant_id = $id AND status != 'Revoked' AND not_after > time::now(); \
341                 UPDATE {table} SET {strip} WHERE tenant_id = $id AND {KEPT_REVOCATION}; \
342                 DELETE {table} WHERE tenant_id = $id AND NOT ({KEPT_REVOCATION});"
343            ),
344            (TenantKey::TenantId, Retain::AfterExport) => {
345                format!("DELETE {table} WHERE tenant_id = $id AND timestamp <= $exported_through")
346            }
347            (TenantKey::TenantId, Retain::CoveringKeptEntries) => format!(
348                "LET $kept = (SELECT VALUE meta::id(id) FROM audit_log WHERE tenant_id = $id); \
349                 DELETE {table} WHERE tenant_id = $id \
350                     AND array::len(array::intersect(entry_ids, $kept)) = 0;"
351            ),
352            (TenantKey::Scope, _) => {
353                format!("DELETE {table} WHERE scope = 'tenant' AND scope_id = $id")
354            }
355        }
356    }
357
358    /// The condition, beyond the tenant, a row must meet to be purged — what
359    /// the orphan scan counts.
360    fn purgeable(&self) -> String {
361        match self.retain {
362            Retain::Nothing => "true".into(),
363            Retain::RevokedUntilExpiry { .. } => format!("NOT ({KEPT_REVOCATION})"),
364            // The audit trail is never read by the orphan scan (see
365            // `orphaned_tenant_ids`); the retention sweep governs what is kept.
366            Retain::AfterExport | Retain::CoveringKeptEntries => "false".into(),
367        }
368    }
369}

465/// Whose rows a purge removes, and whether it may take the audit trail.
466#[derive(Debug, Clone, Copy, PartialEq, Eq)]
467pub(crate) enum PurgeScope {
468    /// A tombstoned tenant: everything, and of its audit trail the rows the
469    /// export the deletion required holds (T-118, R1W1-04) — the rows at or
470    /// before the export time its `tenants.deleted` record names. Later rows,
471    /// or every row when no export time can be read, stay for the retention
472    /// sweep.
473    Tombstoned,
474    /// A tenant id that has rows but no tenant row — left by a deletion made
475    /// before the tombstone existed. Everything **but** the audit trail: no
476    /// export receipt can be checked for it, and an audit entry naming a tenant
477    /// id that never existed (a refused request) is a record the retention
478    /// sweep, not this one, decides about.
479    Orphan,
480}

482/// What a tenant purge did with the tenant's audit trail — what the cleanup
483/// job records in `tenants.purged` (R1W1-04).
484#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
485pub struct TenantPurgeReport {
486    /// The time the export the deletion required covered up to, clamped to
487    /// its receipt's own `timestamp` (R101W3-03); the purge deleted the
488    /// tenant's audit rows at or before it. `None` when no export time could
489    /// be read (an orphan, a deletion record without one, or one whose receipt
490    /// is not in the tenant's log): no audit row was deleted.
491    pub audit_exported_through: Option<DateTime<Utc>>,
492    /// Audit rows of the tenant this purge deleted. A purge resumed after a
493    /// failure counts only what the resuming pass deleted.
494    pub audit_rows_deleted: u64,
495    /// Audit rows of the tenant left for the retention sweep (T-119): those
496    /// written after the export, or all of them when there is no export time.
497    pub audit_rows_kept: u64,
498    /// The id had no tenant row of its own: an orphaned tenant id
499    /// ([`PurgeScope::Orphan`]), purged under the marker row its claim wrote
500    /// (R101W1-09 (a)) — by the replica that claimed it, or, after that
501    /// replica died, by the tombstoned-tenant purge that took the marker over.
502    pub orphan: bool,
503}

505/// Remove `tenant_id`'s rows from every table of [`TENANT_PURGE_ORDER`], in
506/// order, stopping at the first failure (every step is idempotent, so the next
507/// sweep resumes).
508pub(crate) async fn purge_rows<C: Connection>(
509    db: &DbHandle<C>,
510    tenant_id: Uuid,
511    scope: PurgeScope,
512) -> Result<TenantPurgeReport, DbError> {
513    let id = tenant_id.to_string();
514    let exported_through = match scope {
515        PurgeScope::Tombstoned => audit_export_cutoff(db, tenant_id).await?,
516        PurgeScope::Orphan => None,
517    };
518    let mut report = TenantPurgeReport {
519        audit_exported_through: exported_through,
520        orphan: scope == PurgeScope::Orphan,
521        ..TenantPurgeReport::default()
522    };
523    for step in TENANT_PURGE_ORDER {
524        let conn = db.current();
525        let mut query = conn.query(step.delete_statement());
526        if step.stage == AuditTrail {
527            // No export time, no audit deletion: the trail stays whole for the
528            // retention sweep, as an orphan's does.
529            let Some(cutoff) = exported_through else {
530                continue;
531            };
532            if step.retain == Retain::AfterExport {
533                report.audit_rows_deleted = count(
534                    db,
535                    &format!(
536                        "SELECT count() AS total FROM {} WHERE tenant_id = $id \
537                         AND timestamp <= $exported_through GROUP ALL",
538                        step.table
539                    ),
540                    &id,
541                    Some(cutoff),
542                )
543                .await?;
544            }
545            query = query.bind(("exported_through", cutoff));
546        }
547        query
548            .bind(("id", id.clone()))
549            .await?
550            .check()
551            .map_err(|e| DbError::Migration(format!("purging {}: {e}", step.table)))?;
552    }
553    report.audit_rows_kept = count(
554        db,
555        "SELECT count() AS total FROM audit_log WHERE tenant_id = $id GROUP ALL",
556        &id,
557        None,
558    )
559    .await?;
560    Ok(report)
561}

563/// One `count()` over `statement`, with `$id` (and `$exported_through`).
564async fn count<C: Connection>(
565    db: &DbHandle<C>,
566    statement: &str,
567    id: &str,
568    exported_through: Option<DateTime<Utc>>,
569) -> Result<u64, DbError> {
570    let conn = db.current();
571    let mut query = conn.query(statement).bind(("id", id.to_owned()));
572    if let Some(cutoff) = exported_through {
573        query = query.bind(("exported_through", cutoff));
574    }
575    let mut result = query.await?.check()?;
576    let rows: Vec<CountRow> = result.take(0)?;
577    Ok(rows.first().map_or(0, |r| r.total))
578}

580/// The time the export a tombstoned tenant's deletion accepted covered up to,
581/// or `None` when it cannot be read (see the module documentation).
582///
583/// Read from the newest [`TENANT_DELETED_ACTION`] record in the system log
584/// naming the tenant: its [`DELETION_EXPORTED_THROUGH`], or, for a record
585/// written before that key existed, the [`RECEIPT_EXPORTED_THROUGH`] of the
586/// receipt it names ([`DELETION_RECEIPT_ID`]).
587///
588/// **Clamped to the receipt's own `timestamp`** (R101W3-03, #637). The receipt
589/// is written after the export drains, so an honest `exported_through` is
590/// earlier than the row that carries it; the row's `timestamp` is assigned by
591/// the datastore, while `exported_through` is metadata whoever wrote the row
592/// chose. The bound is therefore `min(exported_through, receipt.timestamp)`:
593/// a receipt claiming to cover rows written after it bounds the purge at the
594/// receipt, never later. The receipt is looked up in **this tenant's** log, by
595/// id and action. A record that names no receipt, or one that is not there —
596/// a purge resumed after a clamped pass deleted it, or a record no deletion
597/// wrote — leaves nothing to clamp to, and counts as no time: the purge then
598/// keeps the whole trail. A value that is not an RFC 3339 time counts as
599/// absent too.
600async fn audit_export_cutoff<C: Connection>(
601    db: &DbHandle<C>,
602    tenant_id: Uuid,
603) -> Result<Option<DateTime<Utc>>, DbError> {
604    #[derive(Debug, SurrealValue)]
605    struct MetadataRow {
606        #[surreal(default)]
607        metadata: Option<serde_json::Value>,
608    }
609    #[derive(Debug, SurrealValue)]
610    struct ReceiptRow {
611        #[surreal(default)]
612        metadata: Option<serde_json::Value>,
613        timestamp: DateTime<Utc>,
614    }
615    fn time_at(metadata: Option<&serde_json::Value>, key: &str) -> Option<DateTime<Utc>> {
616        let raw = metadata?.get(key)?.as_str()?;
617        DateTime::parse_from_rfc3339(raw)
618            .ok()
619            .map(|t| t.with_timezone(&Utc))
620    }
621
622    let mut result = db
623        .current()
624        .query(
625            "SELECT metadata, timestamp FROM audit_log \
626             WHERE tenant_id = $system AND action = $action AND resource_id = $id \
627             ORDER BY timestamp DESC LIMIT 1",
628        )
629        .bind(("system", Uuid::nil().to_string()))
630        .bind(("action", TENANT_DELETED_ACTION.to_owned()))
631        .bind(("id", tenant_id.to_string()))
632        .await?
633        .check()?;
634    let rows: Vec<MetadataRow> = result.take(0)?;
635    let Some(deletion) = rows.into_iter().next().and_then(|r| r.metadata) else {
636        return Ok(None);
637    };
638    // The receipt the deletion accepted, in the tenant's own log: the clamp's
639    // source, and the export time of a record that does not carry one.
640    let Some(receipt_id) = deletion.get(DELETION_RECEIPT_ID).and_then(|v| v.as_str()) else {
641        return Ok(None);
642    };
643    let mut result = db
644        .current()
645        .query(
646            "SELECT metadata, timestamp FROM type::record('audit_log', $receipt) \
647             WHERE tenant_id = $id AND action = $action",
648        )
649        .bind(("receipt", receipt_id.to_owned()))
650        .bind(("id", tenant_id.to_string()))
651        .bind(("action", AUDIT_EXPORT_ACTION.to_owned()))
652        .await?
653        .check()?;
654    let rows: Vec<ReceiptRow> = result.take(0)?;
655    let Some(receipt) = rows.into_iter().next() else {
656        return Ok(None);
657    };
658    let claimed = time_at(Some(&deletion), DELETION_EXPORTED_THROUGH)
659        .or_else(|| time_at(receipt.metadata.as_ref(), RECEIPT_EXPORTED_THROUGH));
660    Ok(claimed.map(|through| through.min(receipt.timestamp)))
661}

663/// Whether `tenant_id` still owns a row the orphan scan counts — a row of a
664/// tenant-scoped table but the audit trail, other than revocation evidence the
665/// purge keeps ([`PurgeStep::purgeable`]) — so that the orphan purge records
666/// only a purge that had something to remove (R101W1-09 (a)): a replica whose
667/// scan predates another replica's purge of the same id finds nothing here.
668///
669/// One `LIMIT 1` read per table, stopping at the first row found.
670pub(crate) async fn has_purgeable_rows<C: Connection>(
671    db: &DbHandle<C>,
672    tenant_id: Uuid,
673) -> Result<bool, DbError> {
674    for step in TENANT_PURGE_ORDER {
675        if step.stage == AuditTrail {
676            continue;
677        }
678        let statement = match step.key {
679            TenantKey::TenantId => format!(
680                "SELECT VALUE true FROM {} \
681                 WHERE tenant_id = $id AND ({}) LIMIT 1",
682                step.table,
683                step.purgeable()
684            ),
685            TenantKey::Scope => format!(
686                "SELECT VALUE true FROM {} \
687                 WHERE scope = 'tenant' AND scope_id = $id LIMIT 1",
688                step.table
689            ),
690        };
691        let mut result = db
692            .current()
693            .query(statement)
694            .bind(("id", tenant_id.to_string()))
695            .await?
696            .check()?;
697        let found: Vec<bool> = result.take(0)?;
698        if !found.is_empty() {
699            return Ok(true);
700        }
701    }
702    Ok(false)
703}

705/// Tenant ids that own rows in a tenant-scoped table (the audit trail aside,
706/// see [`PurgeScope::Orphan`]) but have no tenant row — tombstoned or live.
707///
708/// A row a purge keeps ([`Retain::RevokedUntilExpiry`]) is not counted until
709/// eight days after it expires; then it is, and the orphan purge removes it.
710///
711/// The tables are read **before** the tenant set: a tenant row is written
712/// before any row naming it, so a tenant created while this runs is either
713/// absent from the tables read or present in the set read after them, and is
714/// never mistaken for an orphan. The nil id is the system log's and never an
715/// orphan.
716pub(crate) async fn orphaned_tenant_ids<C: Connection>(
717    db: &DbHandle<C>,
718) -> Result<Vec<Uuid>, DbError> {
719    #[derive(Debug, SurrealValue)]
720    struct ByTenant {
721        #[surreal(default)]
722        tenant_id: Option<String>,
723    }
724    #[derive(Debug, SurrealValue)]
725    struct ByScope {
726        #[surreal(default)]
727        scope_id: Option<String>,
728    }
729    #[derive(Debug, SurrealValue)]
730    struct TenantRow {
731        record_id: String,
732    }
733
734    let mut named: BTreeSet<String> = BTreeSet::new();
735    for step in TENANT_PURGE_ORDER {
736        if step.stage == AuditTrail {
737            continue;
738        }
739        // `GROUP BY` so the datastore returns one row per tenant, not one
740        // per row of the table.
741        match step.key {
742            TenantKey::TenantId => {
743                let mut result = db
744                    .current()
745                    .query(format!(
746                        "SELECT tenant_id FROM {} WHERE {} GROUP BY tenant_id",
747                        step.table,
748                        step.purgeable()
749                    ))
750                    .await?
751                    .check()?;
752                let rows: Vec<ByTenant> = result.take(0)?;
753                named.extend(rows.into_iter().filter_map(|r| r.tenant_id));
754            }
755            TenantKey::Scope => {
756                let mut result = db
757                    .current()
758                    .query(format!(
759                        "SELECT scope_id FROM {} WHERE scope = 'tenant' GROUP BY scope_id",
760                        step.table
761                    ))
762                    .await?
763                    .check()?;
764                let rows: Vec<ByScope> = result.take(0)?;
765                named.extend(rows.into_iter().filter_map(|r| r.scope_id));
766            }
767        }
768    }
769
770    let mut result = db
771        .current()
772        .query("SELECT meta::id(id) AS record_id FROM tenant")
773        .await?
774        .check()?;
775    let tenants: Vec<TenantRow> = result.take(0)?;
776    let known: BTreeSet<String> = tenants.into_iter().map(|t| t.record_id).collect();
777
778    Ok(named
779        .difference(&known)
780        .filter_map(|id| Uuid::parse_str(id).ok())
781        .filter(|id| !id.is_nil())
782        .collect())
783}
