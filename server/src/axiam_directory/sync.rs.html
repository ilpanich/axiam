1//! The directory sync job (G-3, T23.3.5, D-31): keeping AXIAM's directory
2//! accounts in step with the directory they came from, **without ever being
3//! able to grant anything**.
4//!
5//! # What it does, per tenant with an enabled directory
6//!
7//! Two kinds of run, both read-only against the directory:
8//!
9//! * **Full** (the first run, then every [`SyncLimits::full_interval`]): look up
10//!   **every** account carrying a `directory_external_id` by that identifier —
11//!   `entryUUID=<uuid>`, or `objectGUID=<binary-escaped octets>`, under
12//!   `base_dn`, exactly one entry. Found: refresh the account (below). Not
13//!   found: **vanished**. Only a full run concludes "vanished", because only it
14//!   has asked about everyone.
15//! * **Incremental** (every `sync_interval_secs`): one search for entries whose
16//!   change attribute is at or after a stored watermark, acting only on entries
17//!   whose identifier belongs to a marked account. Deletions are invisible to
18//!   it and are left to the full run. On Active Directory the watermark is
19//!   `highestCommittedUSN` read from the rootDSE of the same server; a changed
20//!   `dsServiceName`, or no usable watermark, falls back to a full run.
21//!
22//! # What it may write (D-31)
23//!
24//! * A vanished or directory-disabled account becomes **`Inactive`** — never
25//!   `Deleted` (an anonymised tombstone), never a hard delete. Its sessions and
26//!   OAuth2 refresh tokens are revoked **through the repositories** (so the
27//!   session validation cache and the revocation feed see it), its
28//!   directory-sourced memberships are removed through the D-30 mapper (so the
29//!   decision cache is flushed), and `account_may_act` then refuses it on every
30//!   path — passkeys and the OP cookie included, which closes T-303's residual.
31//!   The row, its marker and its audit trail stay.
32//! * An account that is present and enabled is refreshed: its username, email
33//!   and display name follow the entry (through the same cleaners just-in-time
34//!   provisioning applies; a change that would collide with another account is
35//!   **skipped and audited**, never applied) and its group mapping is applied.
36//! * **Nothing else.** The job never re-enables an account, never creates one
37//!   and never links one by name (D-28): an `Inactive` account whose entry is
38//!   present and enabled is **reported** — once — as needing an administrator.
39//!   It never touches an account without a marker.
40//!
41//! # Why it is safe to be wrong about the directory
42//!
43//! * **Errors change nothing.** A directory that cannot be reached, a refused
44//!   search, a deadline: the run ends before anything is written (the full run
45//!   reads everything first, writes second), and the state records the failure.
46//!   An empty or failed search never reads as "everyone vanished": the question
47//!   that was not answered is an error, not a negative answer.
48//! * **The safety valve.** A full run that would deactivate more than
49//!   [`SyncLimits::valve_percent`] % of the tenant's directory accounts **and**
50//!   at least [`SyncLimits::valve_min_accounts`] of them applies **nothing**,
51//!   audits, and reports failure. An empty search after a misconfiguration or an
52//!   outage must not disable a company.
53//! * **Per-user failures skip that user.** A failed mapping, a failed write:
54//!   that account is left as it was and the next run is a full one.
55//! * **Order of a deactivation** is revoke, remove memberships, then flip the
56//!   status **last** with a compare-and-set: a failure part-way leaves the
57//!   account `Active` and the next run finds it again, so there is no state in
58//!   which an account is `Inactive` yet still holds what the job should have
59//!   taken.
60//!
61//! # Scheduling and bounds
62//!
63//! One tenant at a time, on the server's cleanup scheduler, through the same
64//! bounded pool and deadlines as every other directory use; each run is also
65//! bounded by [`SyncLimits::run_deadline`]. There is **no multi-replica guard**:
66//! two replicas run the same job against the same rows. Every write is
67//! idempotent or a compare-and-set, so the result is the same; the cost is
68//! duplicated directory reads and, for refreshes, duplicated audit rows.
69//!
70//! No audit row, log line or error carries a name, an address, a DN or a
71//! password: accounts are named by id and entries by their immutable identifier.

102/// The bounds and thresholds of the job. [`Default`] is the documented values;
103/// tests shrink them.
104#[derive(Debug, Clone, Copy, PartialEq, Eq)]
105pub struct SyncLimits {
106    /// How long after the last complete full run the next one is due (24 h).
107    pub full_interval: Duration,
108    /// The longest one tenant's run may take, directory I/O and writes
109    /// together. A run that exceeds it is abandoned; the next one is full.
110    pub run_deadline: Duration,
111    /// The most directory accounts one full run handles. A tenant with more is
112    /// refused with an error rather than half-synced.
113    pub max_accounts: usize,
114    /// Accounts read from the store per page.
115    pub page_size: u32,
116    /// The most entries one incremental search reads; more is a prefix, the
117    /// entries read are applied, and the next run is a full one.
118    pub max_changed_entries: usize,
119    /// The safety valve's percentage: a full run that would deactivate **more
120    /// than** this share of the tenant's directory accounts is a candidate.
121    pub valve_percent: usize,
122    /// The safety valve's floor: …and only when it would deactivate **at
123    /// least** this many.
124    pub valve_min_accounts: usize,
125}
126
127impl Default for SyncLimits {
128    fn default() -> Self {
129        Self {
130            full_interval: Duration::from_secs(24 * 60 * 60),
131            run_deadline: Duration::from_secs(15 * 60),
132            max_accounts: 100_000,
133            page_size: 500,
134            max_changed_entries: 10_000,
135            valve_percent: 10,
136            valve_min_accounts: 5,
137        }
138    }
139}

161/// Why a tenant's run did not complete. None of these changed the tenant's
162/// accounts, except where stated.
163#[derive(Debug, thiserror::Error)]
164pub enum SyncError {
165    /// The directory could not be used: unreachable, misconfigured, refusing the
166    /// search or the service bind, or the bind secret unavailable.
167    #[error("the directory could not be used for sync: {0:?}")]
168    Directory(DirectoryAuthError),
169    /// The state row, the account store or the configuration could not be read
170    /// or written.
171    #[error("the sync state or the account store failed: {0}")]
172    Store(String),
173    /// The full run would have deactivated too many accounts and applied
174    /// nothing.
175    #[error(
176        "the safety valve tripped: a full run would deactivate {would_deactivate} of \
177         {directory_accounts} directory accounts; nothing was applied"
178    )]
179    SafetyValve {
180        /// Accounts the run would have deactivated.
181        would_deactivate: usize,
182        /// The tenant's directory accounts.
183        directory_accounts: usize,
184    },
185    /// The tenant has more directory accounts than one run handles.
186    #[error("the tenant has more than {0} directory accounts, more than one run handles")]
187    TooManyAccounts(usize),
188    /// The run exceeded its deadline and was abandoned part-way.
189    #[error("the run exceeded its deadline")]
190    Deadline,
191}
192
193impl SyncError {
194    /// A short fixed tag for job health: what failed, never who.
195    #[must_use]
196    pub const fn tag(&self) -> &'static str {
197        match self {
198            Self::Directory(DirectoryAuthError::Unavailable) => "directory_unavailable",
199            Self::Directory(DirectoryAuthError::Misconfigured) => "directory_misconfigured",
200            Self::Directory(_) => "directory_refused",
201            Self::Store(_) => "store",
202            Self::SafetyValve { .. } => "safety_valve",
203            Self::TooManyAccounts(_) => "too_many_accounts",
204            Self::Deadline => "deadline",
205        }
206    }
207}

209fn store(error: AxiamError) -> SyncError {
210    SyncError::Store(error.to_string())
211}

275pub struct SyncSummary {
276    /// Tenants whose run completed.
277    pub reports: Vec<TenantReport>,

284impl SyncSummary {
285    /// Accounts changed across every completed run.
286    #[must_use]
287    pub fn changed(&self) -> u64 {
288        self.reports.iter().map(|r| r.changed() as u64).sum()
289    }
290
291    /// One line for job health, naming how many tenants failed and with which
292    /// fixed tags — never a tenant's data.
293    #[must_use]
294    pub fn failure_message(&self) -> Option<String> {
295        if self.failures.is_empty() {
296            return None;
297        }
298        let tags: Vec<&str> = self.failures.iter().map(|(_, e)| e.tag()).collect();
299        Some(format!(
300            "directory sync failed for {} of {} tenants ({})",
301            self.failures.len(),
302            self.failures.len() + self.reports.len(),
303            tags.join(", ")
304        ))
305    }

312/// What the directory said about one account.
313#[derive(Debug, Clone, PartialEq, Eq)]
314enum Verdict {
315    /// The full run asked and the search completed with no match.
316    Vanished,
317    /// The entry exists.
318    Present(Box<SyncEntry>),
319}

321/// Why an account is deactivated.
322#[derive(Debug, Clone, Copy, PartialEq, Eq)]
323enum Reason {
324    Vanished,
325    Disabled,
326}
327
328impl Reason {
329    const fn as_str(self) -> &'static str {
330        match self {
331            Self::Vanished => "vanished",
332            Self::Disabled => "disabled",
333        }
334    }
335}

337/// What to do about one account, given its status and the directory's answer.
338#[derive(Debug, Clone, PartialEq, Eq)]
339enum Decision {
340    /// Nothing: a tombstone, or an `Inactive` account the directory agrees is
341    /// gone or disabled.
342    Ignore,
343    /// Set it `Inactive`.
344    Deactivate(Reason),
345    /// It is `Inactive` and its entry is present and enabled: say so, once.
346    Reappeared,
347    /// Keep it in step with its entry.
348    Refresh(Box<SyncEntry>),
349}
350
351/// The whole rule of D-31, with no I/O. Note what is **absent**: no branch
352/// leads to `Active`, to `Deleted`, or to any status but `Inactive`.
353fn decide(status: &UserStatus, verdict: &Verdict) -> Decision {
354    match status {
355        // Tombstones carry no marker and are none of the job's business.
356        UserStatus::Deleted | UserStatus::Anonymized => Decision::Ignore,
357        UserStatus::Inactive => match verdict {
358            Verdict::Present(entry) if !entry.disabled => Decision::Reappeared,
359            _ => Decision::Ignore,
360        },
361        UserStatus::Active | UserStatus::PendingVerification | UserStatus::Locked => {
362            match verdict {
363                Verdict::Vanished => Decision::Deactivate(Reason::Vanished),
364                Verdict::Present(entry) if entry.disabled => Decision::Deactivate(Reason::Disabled),
365                Verdict::Present(entry) => Decision::Refresh(entry.clone()),
366            }
367        }
368    }
369}

371/// Whether a full run that would deactivate `would_deactivate` of `total`
372/// directory accounts must apply nothing (D-31): **more than** `percent` % and
373/// **at least** `min`.
374#[must_use]
375pub fn valve_trips(would_deactivate: usize, total: usize, limits: &SyncLimits) -> bool {
376    would_deactivate >= limits.valve_min_accounts
377        && would_deactivate.saturating_mul(100) > total.saturating_mul(limits.valve_percent)
378}

380/// Which run is due, from the stored state alone.
381fn choose_run(state: &DirectorySyncState, now: DateTime<Utc>, limits: &SyncLimits) -> RunKind {
382    let full_due = match state.last_full_run_at {
383        None => true,
384        Some(last) => {
385            chrono::Duration::from_std(limits.full_interval).map_or(true, |i| now - last >= i)
386        }
387    };
388    if state.full_required || state.watermark.is_none() || full_due {
389        RunKind::Full
390    } else {
391        RunKind::Incremental
392    }
393}

395/// Whether a tenant is due for a run at all: the incremental schedule counts
396/// from the last attempt, successful or not.
397fn is_due(config: &DirectoryConfig, state: &DirectorySyncState, now: DateTime<Utc>) -> bool {
398    match state.last_attempt_at {
399        None => true,
400        Some(last) => {
401            let interval = i64::try_from(config.sync_interval_secs).unwrap_or(i64::MAX);
402            now - last >= chrono::Duration::seconds(interval)
403        }
404    }
405}

407/// The later of two watermarks of the same shape. Generalized times sort
408/// lexicographically; USNs are compared as numbers (their lengths differ).
409fn later_watermark(a: &str, b: &str) -> String {
410    if is_usn(a) && is_usn(b) {
411        let (x, y) = (
412            a.parse::<u128>().unwrap_or(0),
413            b.parse::<u128>().unwrap_or(0),
414        );
415        return if x >= y { a } else { b }.to_string();
416    }
417    if a >= b { a } else { b }.to_string()
418}

520    /// One scheduler pass: every tenant with an **enabled** directory, one at a
521    /// time, each only if it is due. A tenant without a directory, or with it
522    /// disabled, is never listed, so no connection is made for it.
523    ///
524    /// # Errors
525    ///
526    /// [`SyncError::Store`] when the configurations cannot be listed. A tenant's
527    /// own failure is not an error here: it is in [`SyncSummary::failures`], and
528    /// the next tenant still runs.
529    pub async fn run_due(&self) -> Result<SyncSummary, SyncError> {
530        let configs = self.configs.list_enabled().await.map_err(store)?;
531        let mut summary = SyncSummary::default();
532        for config in configs {
533            match self.sync_tenant(&config, Utc::now()).await {
534                Ok(Some(report)) => summary.reports.push(report),
535                Ok(None) => summary.not_due += 1,
536                // Disabled or deleted between listing and opening: the tenant
537                // has no enabled directory any more, which is a skip.
538                Err(SyncError::Directory(DirectoryAuthError::NotConfigured)) => {
539                    summary.not_due += 1;
540                }
541                Err(error) => {
542                    tracing::warn!(
543                        target: "axiam::directory",
544                        tenant_id = %config.tenant_id,
545                        outcome = error.tag(),
546                        "directory sync failed for a tenant; nothing was changed by the failing step"
547                    );
548                    summary.failures.push((config.tenant_id, error));
549                }
550            }
551        }
552        Ok(summary)
553    }
554
555    /// One tenant's pass: `Ok(None)` when it is not yet due.
556    ///
557    /// # Errors
558    ///
559    /// The [`SyncError`] that ended the run.
560    pub async fn sync_tenant(
561        &self,
562        config: &DirectoryConfig,
563        now: DateTime<Utc>,
564    ) -> Result<Option<TenantReport>, SyncError> {
565        let tenant_id = config.tenant_id;
566        let mut state = self
567            .states
568            .get(tenant_id)
569            .await
570            .map_err(store)?
571            .unwrap_or_else(|| DirectorySyncState::new(tenant_id));
572        if !is_due(config, &state, now) {
573            return Ok(None);
574        }
575        let run = choose_run(&state, now, &self.limits);
576        state.last_attempt_at = Some(now);
577
578        let outcome = tokio::time::timeout(
579            self.limits.run_deadline,
580            self.execute(config, &mut state, run, now),
581        )
582        .await;
583        let (result, outcome) = match outcome {
584            Ok(Ok(report)) => (
585                if report.accounts_skipped > 0 {
586                    DirectorySyncResult::Partial
587                } else {
588                    DirectorySyncResult::Ok
589                },
590                Ok(report),
591            ),
592            Ok(Err(error)) => (
593                if matches!(error, SyncError::SafetyValve { .. }) {
594                    DirectorySyncResult::SafetyValve
595                } else {
596                    DirectorySyncResult::Failed
597                },
598                Err(error),
599            ),
600            Err(_) => {
601                // Abandoned part-way: some accounts may have been handled, so
602                // the next run reconciles everything.
603                state.full_required = true;
604                (DirectorySyncResult::Failed, Err(SyncError::Deadline))
605            }
606        };
607        state.last_result = Some(result);
608        if let Err(error) = self.states.save(&state).await {
609            tracing::error!(
610                target: "axiam::directory",
611                %tenant_id,
612                %error,
613                "the directory sync state could not be saved"
614            );
615            if outcome.is_ok() {
616                return Err(store(error));
617            }
618        }
619        outcome.map(Some)
620    }

622    async fn execute(
623        &self,
624        config: &DirectoryConfig,
625        state: &mut DirectorySyncState,
626        run: RunKind,
627        now: DateTime<Utc>,
628    ) -> Result<TenantReport, SyncError> {
629        let session = match self.authenticator.open_sync(config.tenant_id).await {
630            Ok(session) => session,
631            Err(error) => return Err(SyncError::Directory(error)),
632        };
633        match run {
634            RunKind::Full => self.full_run(&session, state, now, false).await,
635            RunKind::Incremental => self.incremental_run(&session, state, now).await,
636        }
637    }

639    // -----------------------------------------------------------------------
640    // Full run
641    // -----------------------------------------------------------------------
642
643    async fn full_run(
644        &self,
645        session: &DirectorySession,
646        state: &mut DirectorySyncState,
647        now: DateTime<Utc>,
648        fell_back: bool,
649    ) -> Result<TenantReport, SyncError> {
650        let config = session.config();
651        let tenant_id = config.tenant_id;
652        let kind = config.kind;
653        let mut report = TenantReport::new(tenant_id, RunKind::Full);
654        report.fell_back_to_full = fell_back;
655
656        // Active Directory's watermark is read **before** anything is looked up:
657        // any change after this point has a higher USN and is seen by the next
658        // incremental run. A failed read is not a failed run; it is "no
659        // watermark". A tenant with no directory accounts has nothing to resume
660        // and the directory is not asked.
661        let root_dse = if kind == DirectoryKind::ActiveDirectory
662            && !self
663                .users
664                .list_directory_accounts(tenant_id, None, 1)
665                .await
666                .map_err(store)?
667                .is_empty()
668        {
669            match session.read_root_dse().await {
670                Ok(dse) => Some(dse),
671                Err(error) => {
672                    tracing::warn!(
673                        target: "axiam::directory",
674                        %tenant_id,
675                        outcome = ?error,
676                        "the rootDSE could not be read; the next incremental run will be a full one"
677                    );
678                    None
679                }
680            }
681        } else {
682            None
683        };
684
685        // Phase 1: read. Nothing is written until everything is known, so an
686        // error anywhere in this phase leaves every account as it was.
687        let plan = self.read_everything(session).await?;
688        report.accounts_examined = plan.items.len();
689
690        // The valve: counted over the decisions, before any is applied.
691        let would_deactivate = plan
692            .items
693            .iter()
694            .filter(|(user, verdict)| {
695                matches!(decide(&user.status, verdict), Decision::Deactivate(_))
696            })
697            .count();
698        if valve_trips(would_deactivate, plan.directory_accounts, &self.limits) {
699            if state.last_result != Some(DirectorySyncResult::SafetyValve) {
700                self.record(
701                    tenant_id,
702                    AUDIT_SYNC_SAFETY_VALVE,
703                    None,
704                    AuditOutcome::Denied,
705                    serde_json::json!({
706                        "run": RunKind::Full.as_str(),
707                        "would_deactivate": would_deactivate,
708                        "directory_accounts": plan.directory_accounts,
709                        "valve_percent": self.limits.valve_percent,
710                        "valve_min_accounts": self.limits.valve_min_accounts,
711                        "applied": "nothing",
712                    }),
713                )
714                .await;
715            }
716            tracing::error!(
717                target: "axiam::directory",
718                %tenant_id,
719                would_deactivate,
720                directory_accounts = plan.directory_accounts,
721                "directory sync safety valve tripped: a full run would deactivate too many \
722                 accounts; nothing was applied"
723            );
724            // The next attempt is a full run again, so the situation is
725            // re-evaluated rather than skipped past by an incremental.
726            state.full_required = true;
727            return Err(SyncError::SafetyValve {
728                would_deactivate,
729                directory_accounts: plan.directory_accounts,
730            });
731        }
732
733        // Phase 2: write. Each account is handled on its own; a failure skips
734        // that account only.
735        let mut reports = Reports {
736            known: state.reported_user_ids.iter().copied().collect(),
737            current: HashSet::new(),
738        };
739        let mut newest_change: Option<String> = None;
740        for (user, verdict) in &plan.items {
741            if let Verdict::Present(entry) = verdict
742                && let Some(change) = &entry.change_value
743            {
744                newest_change = Some(match newest_change {
745                    Some(have) => later_watermark(&have, change),
746                    None => change.clone(),
747                });
748            }
749            self.apply(
750                session,
751                user,
752                verdict,
753                RunKind::Full,
754                &mut reports,
755                &mut report,
756            )
757            .await;
758        }
759        report.accounts_skipped += plan.undecided.len();
760
761        // The next incremental run resumes from here, or — with nothing to
762        // resume from — is a full one.
763        let (watermark, server_identity) = match kind {
764            DirectoryKind::ActiveDirectory => match root_dse {
765                Some(RootDse {
766                    server_identity: Some(identity),
767                    highest_committed_usn: Some(usn),
768                }) => (Some(usn), Some(identity)),
769                _ => (None, None),
770            },
771            DirectoryKind::OpenLdap => (newest_change, None),
772        };
773        state.watermark = watermark;
774        state.server_identity = server_identity;
775        state.full_required = report.accounts_skipped > 0;
776        state.last_full_run_at = Some(now);
777        // Reported accounts the run did not look at (undecided) keep their
778        // entry; every other one is re-derived from what the run saw.
779        for id in &plan.undecided {
780            if reports.known.contains(id) {
781                reports.current.insert(*id);
782            }
783        }
784        state.reported_user_ids = sorted(reports.current);
785
786        self.record(
787            tenant_id,
788            AUDIT_SYNC_RUN,
789            None,
790            if report.accounts_skipped > 0 {
791                AuditOutcome::Failure
792            } else {
793                AuditOutcome::Success
794            },
795            serde_json::json!({
796                "run": RunKind::Full.as_str(),
797                "fell_back_to_full": report.fell_back_to_full,
798                "accounts_examined": report.accounts_examined,
799                "deactivated_vanished": report.deactivated_vanished,
800                "deactivated_disabled": report.deactivated_disabled,
801                "reappeared_reported": report.reappeared_reported,
802                "attributes_updated": report.attributes_updated,
803                "attributes_skipped": report.attributes_skipped,
804                "memberships_changed": report.memberships_changed,
805                "accounts_skipped": report.accounts_skipped,
806            }),
807        )
808        .await;
809        Ok(report)
810    }

812    /// Phase 1 of a full run: page through the tenant's marked accounts and ask
813    /// the directory about each. Any directory failure ends the run.
814    async fn read_everything(&self, session: &DirectorySession) -> Result<Plan, SyncError> {
815        let config = session.config();
816        let tenant_id = config.tenant_id;
817        let id_attribute = &config.user_attribute_map.external_id;
818        let mut plan = Plan {
819            items: Vec::new(),
820            undecided: Vec::new(),
821            directory_accounts: 0,
822        };
823        let mut after: Option<Uuid> = None;
824        loop {
825            let page = self
826                .users
827                .list_directory_accounts(tenant_id, after, self.limits.page_size)
828                .await
829                .map_err(store)?;
830            let Some(last) = page.last() else { break };
831            after = Some(last.id);
832            for user in page {
833                if matches!(user.status, UserStatus::Deleted | UserStatus::Anonymized) {
834                    continue;
835                }
836                plan.directory_accounts += 1;
837                if plan.directory_accounts > self.limits.max_accounts {
838                    return Err(SyncError::TooManyAccounts(self.limits.max_accounts));
839                }
840                let Some(marker) = user.directory_external_id.clone() else {
841                    continue;
842                };
843                // An identifier that cannot be put in a filter is a question
844                // that cannot be asked: the account is skipped, never read as
845                // vanished.
846                if external_id_filter(id_attribute, &marker).is_none() {
847                    plan.undecided.push(user.id);
848                    continue;
849                }
850                match session
851                    .lookup_by_external_id(&marker)
852                    .await
853                    .map_err(SyncError::Directory)?
854                {
855                    EntryLookup::Found(entry) => plan.items.push((user, Verdict::Present(entry))),
856                    EntryLookup::NotFound => plan.items.push((user, Verdict::Vanished)),
857                    EntryLookup::Ambiguous => plan.undecided.push(user.id),
858                }
859            }
860        }
861        Ok(plan)
862    }

867
868    async fn incremental_run(
869        &self,
870        session: &DirectorySession,
871        state: &mut DirectorySyncState,
872        now: DateTime<Utc>,
873    ) -> Result<TenantReport, SyncError> {
874        let config = session.config();
875        let tenant_id = config.tenant_id;
876        let kind = config.kind;
877        let Some(watermark) = state.watermark.clone() else {
878            return self.full_run(session, state, now, true).await;
879        };
880
881        // Active Directory: the watermark counts one server's USNs. Read the
882        // server's identity and its current high-water mark *before* searching;
883        // a different server, or no readable mark, cannot be trusted.
884        let mut next_watermark: Option<String> = None;
885        if kind == DirectoryKind::ActiveDirectory {
886            let dse = match session.read_root_dse().await {
887                Ok(dse) => dse,
888                Err(error) => {
889                    tracing::warn!(
890                        target: "axiam::directory",
891                        %tenant_id,
892                        outcome = ?error,
893                        "the rootDSE could not be read; running a full reconciliation instead"
894                    );
895                    return self.full_run(session, state, now, true).await;
896                }
897            };
898            let same_server =
899                dse.server_identity.is_some() && dse.server_identity == state.server_identity;
900            if !same_server || dse.highest_committed_usn.is_none() {
901                tracing::info!(
902                    target: "axiam::directory",
903                    %tenant_id,
904                    "the directory server changed or gave no watermark; running a full \
905                     reconciliation instead"
906                );
907                return self.full_run(session, state, now, true).await;
908            }
909            next_watermark = dse.highest_committed_usn;
910        }
911
912        let changed = session
913            .search_changed(&watermark, self.limits.max_changed_entries)
914            .await
915            .map_err(SyncError::Directory)?;
916
917        let mut report = TenantReport::new(tenant_id, RunKind::Incremental);
918        report.bound_hit = !changed.complete;
919        let mut reports = Reports {
920            known: state.reported_user_ids.iter().copied().collect(),
921            current: state.reported_user_ids.iter().copied().collect(),
922        };
923        let mut newest = Some(watermark.clone());
924        for entry in changed.entries {
925            // Every entry read — marked or not — advances an OpenLDAP watermark:
926            // each was changed at or after it, and the next search resumes there.
927            if let Some(change) = &entry.change_value {
928                newest = Some(match newest {
929                    Some(have) => later_watermark(&have, change),
930                    None => change.clone(),
931                });
932            }
933            // Only an entry whose identifier belongs to a marked account is
934            // acted on. A directory that changes an entry no account owns
935            // creates nothing: the job never provisions and never links.
936            let user = match self
937                .users
938                .get_by_directory_external_id(tenant_id, &entry.identity.external_id)
939                .await
940            {
941                Ok(Some(user)) => user,
942                Ok(None) => continue,
943                Err(error) => {
944                    tracing::warn!(
945                        target: "axiam::directory",
946                        %tenant_id,
947                        %error,
948                        "an account could not be looked up by its directory identifier"
949                    );
950                    report.accounts_skipped += 1;
951                    continue;
952                }
953            };
954            report.accounts_examined += 1;
955            let verdict = Verdict::Present(Box::new(entry));
956            self.apply(
957                session,
958                &user,
959                &verdict,
960                RunKind::Incremental,
961                &mut reports,
962                &mut report,
963            )
964            .await;
965        }
966
967        // The watermark moves only when everything it covers was handled: a
968        // bound hit or a skipped account leaves it and makes the next run full.
969        let clean = changed.complete && report.accounts_skipped == 0;
970        if clean {
971            state.watermark = match kind {
972                DirectoryKind::ActiveDirectory => next_watermark.or(Some(watermark)),
973                DirectoryKind::OpenLdap => newest,
974            };
975        }
976        state.full_required = !clean;
977        state.reported_user_ids = sorted(reports.current);
978        Ok(report)
979    }

981    // -----------------------------------------------------------------------
982    // Applying one decision
983    // -----------------------------------------------------------------------
984
985    /// Decide for one account and carry it out. Never returns an error: a
986    /// failure skips the account (counted) and the run goes on.
987    async fn apply(
988        &self,
989        session: &DirectorySession,
990        user: &User,
991        verdict: &Verdict,
992        run: RunKind,
993        reports: &mut Reports,
994        report: &mut TenantReport,
995    ) {
996        let tenant_id = session.config().tenant_id;
997        match decide(&user.status, verdict) {
998            Decision::Ignore => {
999                // Disabled or gone *and* already inactive: nothing is waiting
1000                // for an administrator, so nothing stays reported.
1001                if run == RunKind::Incremental {
1002                    reports.current.remove(&user.id);
1003                }
1004            }
1005            Decision::Reappeared => {
1006                reports.current.insert(user.id);
1007                if !reports.known.contains(&user.id) {
1008                    reports.known.insert(user.id);
1009                    report.reappeared_reported += 1;
1010                    self.record(
1011                        tenant_id,
1012                        AUDIT_ACCOUNT_REAPPEARED,
1013                        Some(user.id),
1014                        AuditOutcome::Denied,
1015                        serde_json::json!({
1016                            "run": run.as_str(),
1017                            "reason": "the directory entry is present and enabled while the \
1018                                       account is inactive; sync never re-enables",
1019                            "action": "administrator action required",
1020                            "directory_external_id": user.directory_external_id,
1021                        }),
1022                    )
1023                    .await;
1024                }
1025            }
1026            Decision::Deactivate(reason) => {
1027                reports.current.remove(&user.id);
1028                match self.deactivate(session, user, reason, run).await {
1029                    Ok(true) => match reason {
1030                        Reason::Vanished => report.deactivated_vanished += 1,
1031                        Reason::Disabled => report.deactivated_disabled += 1,
1032                    },
1033                    Ok(false) => {}
1034                    Err(()) => report.accounts_skipped += 1,
1035                }
1036            }
1037            Decision::Refresh(entry) => {
1038                reports.current.remove(&user.id);
1039                if self
1040                    .refresh(session, user, &entry, run, report)
1041                    .await
1042                    .is_err()
1043                {
1044                    report.accounts_skipped += 1;
1045                }
1046            }
1047        }
1048    }

1050    /// Revoke, remove memberships, flip the status last. `Ok(true)` when this
1051    /// call made the account `Inactive`; `Ok(false)` when another did; `Err`
1052    /// when a step failed and the account was left `Active` for the next run.
1053    async fn deactivate(
1054        &self,
1055        session: &DirectorySession,
1056        user: &User,
1057        reason: Reason,
1058        run: RunKind,
1059    ) -> Result<bool, ()> {
1060        let tenant_id = session.config().tenant_id;
1061        let failed = |stage: &'static str, error: String| async move {
1062            tracing::error!(
1063                target: "axiam::directory",
1064                %tenant_id,
1065                user_id = %user.id,
1066                stage,
1067                %error,
1068                "deactivating a directory account failed; it is left as it was and the next \
1069                 run retries"
1070            );
1071            self.record(
1072                tenant_id,
1073                AUDIT_ACCOUNT_DEACTIVATED,
1074                Some(user.id),
1075                AuditOutcome::Failure,
1076                serde_json::json!({
1077                    "run": run.as_str(),
1078                    "reason": reason.as_str(),
1079                    "stage": stage,
1080                    "directory_external_id": user.directory_external_id,
1081                }),
1082            )
1083            .await;
1084        };
1085
1086        // Through the repositories, so the session validation cache and the
1087        // revocation feed see it (as linking does, D-28).
1088        if let Err(error) = self
1089            .sessions
1090            .invalidate_user_sessions(tenant_id, user.id)
1091            .await
1092        {
1093            failed("sessions", error.to_string()).await;
1094            return Err(());
1095        }
1096        if let Err(error) = self
1097            .refresh_tokens
1098            .revoke_all_for_user(tenant_id, user.id)
1099            .await
1100        {
1101            failed("refresh_tokens", error.to_string()).await;
1102            return Err(());
1103        }
1104        // The D-30 mapper, so the decision cache is flushed and manual
1105        // memberships are never touched.
1106        let removed = match self
1107            .mapper
1108            .remove_directory_memberships(tenant_id, user.id)
1109            .await
1110        {
1111            Ok(outcome) => outcome.removed.len(),
1112            Err(error) => {
1113                failed("memberships", format!("{error:?}")).await;
1114                return Err(());
1115            }
1116        };
1117        // Last, and as one compare-and-set: from here `account_may_act` refuses
1118        // the account everywhere.
1119        match self
1120            .users
1121            .deactivate_directory_account(tenant_id, user.id)
1122            .await
1123        {
1124            Ok(Some(_)) => {
1125                if let Some(sink) = &self.ssf_sink {
1126                    sink.account_disabled(tenant_id, user).await;
1127                }
1128                self.record(
1129                    tenant_id,
1130                    AUDIT_ACCOUNT_DEACTIVATED,
1131                    Some(user.id),
1132                    AuditOutcome::Success,
1133                    serde_json::json!({
1134                        "run": run.as_str(),
1135                        "reason": reason.as_str(),
1136                        "sessions_and_refresh_tokens_revoked": true,
1137                        "directory_memberships_removed": removed,
1138                        "directory_external_id": user.directory_external_id,
1139                    }),
1140                )
1141                .await;
1142                Ok(true)
1143            }
1144            Ok(None) => Ok(false),
1145            Err(error) => {
1146                failed("status", error.to_string()).await;
1147                Err(())
1148            }
1149        }
1150    }

1152    /// Keep a present, enabled account in step with its entry: group mapping
1153    /// first (a failure there skips the user, changing nothing), then the
1154    /// attributes.
1155    async fn refresh(
1156        &self,
1157        session: &DirectorySession,
1158        user: &User,
1159        entry: &SyncEntry,
1160        run: RunKind,
1161        report: &mut TenantReport,
1162    ) -> Result<(), ()> {
1163        let tenant_id = session.config().tenant_id;
1164
1165        // The DN is the one the directory returned for this very entry.
1166        match self
1167            .mapper
1168            .apply_for_user(tenant_id, user.id, &entry.identity.dn)
1169            .await
1170        {
1171            Ok(outcome) => {
1172                if outcome.changed() {
1173                    report.memberships_changed += 1;
1174                    self.record(
1175                        tenant_id,
1176                        AUDIT_GROUPS_MAPPED,
1177                        Some(user.id),
1178                        AuditOutcome::Success,
1179                        serde_json::json!({
1180                            "source": "sync",
1181                            "run": run.as_str(),
1182                            "groups_added": outcome.added,
1183                            "groups_removed": outcome.removed,
1184                            "added_count": outcome.added.len(),
1185                            "removed_count": outcome.removed.len(),
1186                            "manual_memberships_left": outcome.left_manual.len(),
1187                            "directory_groups_resolved": outcome.directory_groups_resolved,
1188                            "directory_groups_mapped": outcome.directory_groups_mapped,
1189                        }),
1190                    )
1191                    .await;
1192                }
1193            }
1194            Err(error) => {
1195                tracing::warn!(
1196                    target: "axiam::directory",
1197                    %tenant_id,
1198                    user_id = %user.id,
1199                    outcome = ?error,
1200                    "the group mapping could not be applied; the account is skipped"
1201                );
1202                self.record(
1203                    tenant_id,
1204                    AUDIT_SYNC_USER_SKIPPED,
1205                    Some(user.id),
1206                    AuditOutcome::Failure,
1207                    serde_json::json!({
1208                        "run": run.as_str(),
1209                        "reason": "group_mapping_not_applied",
1210                        "directory_external_id": user.directory_external_id,
1211                    }),
1212                )
1213                .await;
1214                return Err(());
1215            }
1216        }
1217
1218        self.refresh_attributes(tenant_id, user, entry, run, report)
1219            .await
1220    }

1222    /// Update username, email and display name to the entry's, through the
1223    /// cleaners provisioning uses, skipping and auditing any change that would
1224    /// collide with another account.
1225    async fn refresh_attributes(
1226        &self,
1227        tenant_id: Uuid,
1228        user: &User,
1229        entry: &SyncEntry,
1230        run: RunKind,
1231        report: &mut TenantReport,
1232    ) -> Result<(), ()> {
1233        let cleaned = CleanedAttributes::from_identity(&entry.identity);
1234        let mut update = UpdateUser::default();
1235        let mut fields: Vec<&'static str> = Vec::new();
1236
1237        // An attribute the entry lacks, or carries in a form that cannot be
1238        // cleaned, leaves the account's value alone.
1239        for (field, new, current) in [
1240            (
1241                "username",
1242                cleaned.username.as_deref(),
1243                user.username.as_str(),
1244            ),
1245            ("email", cleaned.email.as_deref(), user.email.as_str()),
1246        ] {
1247            let Some(new) = new else { continue };
1248            if new == current {
1249                continue;
1250            }
1251            match self
1252                .users
1253                .find_identity_collision_excluding(tenant_id, &[new.to_string()], user.id)
1254                .await
1255            {
1256                Ok(None) => {
1257                    if field == "username" {
1258                        update.username = Some(new.to_string());
1259                    } else {
1260                        update.email = Some(new.to_string());
1261                    }
1262                    fields.push(field);
1263                }
1264                Ok(Some(collision)) => {
1265                    report.attributes_skipped += 1;
1266                    self.record_skip(tenant_id, user, field, Some(collision), run)
1267                        .await;
1268                }
1269                Err(error) => {
1270                    tracing::warn!(
1271                        target: "axiam::directory",
1272                        %tenant_id,
1273                        user_id = %user.id,
1274                        %error,
1275                        "the collision probe failed; the account's attributes are left alone"
1276                    );
1277                    return Err(());
1278                }
1279            }
1280        }
1281        if let Some(name) = cleaned.display_name.as_deref() {
1282            let current = user
1283                .metadata
1284                .get("oidc")
1285                .and_then(|oidc| oidc.get("name"))
1286                .and_then(serde_json::Value::as_str);
1287            if current != Some(name) {
1288                let mut metadata = if user.metadata.is_object() {
1289                    user.metadata.clone()
1290                } else {
1291                    serde_json::json!({})
1292                };
1293                if !metadata
1294                    .get("oidc")
1295                    .is_some_and(serde_json::Value::is_object)
1296                {
1297                    metadata["oidc"] = serde_json::json!({});
1298                }
1299                metadata["oidc"]["name"] = serde_json::Value::String(name.to_string());
1300                update.metadata = Some(metadata);
1301                fields.push("display_name");
1302            }
1303        }
1304        if fields.is_empty() {
1305            return Ok(());
1306        }
1307        match self.users.update(tenant_id, user.id, update).await {
1308            Ok(_) => {
1309                report.attributes_updated += 1;
1310                self.record(
1311                    tenant_id,
1312                    AUDIT_ACCOUNT_UPDATED,
1313                    Some(user.id),
1314                    AuditOutcome::Success,
1315                    serde_json::json!({
1316                        "run": run.as_str(),
1317                        "fields": fields,
1318                        "directory_external_id": user.directory_external_id,
1319                    }),
1320                )
1321                .await;
1322                Ok(())
1323            }
1324            // Another account took the name between the probe and the write: a
1325            // collision after all.
1326            Err(AxiamError::AlreadyExists { .. }) => {
1327                report.attributes_skipped += 1;
1328                self.record_skip(tenant_id, user, "username_or_email", None, run)
1329                    .await;
1330                Ok(())
1331            }
1332            Err(error) => {
1333                tracing::warn!(
1334                    target: "axiam::directory",
1335                    %tenant_id,
1336                    user_id = %user.id,
1337                    %error,
1338                    "updating a directory account's attributes failed; it is skipped"
1339                );
1340                Err(())
1341            }
1342        }
1343    }
1344
1345    async fn record_skip(
1346        &self,
1347        tenant_id: Uuid,
1348        user: &User,
1349        attribute: &str,
1350        collision: Option<axiam_core::models::user::IdentityCollision>,
1351        run: RunKind,
1352    ) {
1353        self.record(
1354            tenant_id,
1355            AUDIT_SYNC_ATTRIBUTE_SKIPPED,
1356            Some(user.id),
1357            AuditOutcome::Denied,
1358            serde_json::json!({
1359                "run": run.as_str(),
1360                "reason": "collision",
1361                "attribute": attribute,
1362                "existing_user_id": collision.map(|c| c.user_id.to_string()),
1363                "existing_attribute": collision.map(|c| c.attribute.as_str()),
1364                "directory_external_id": user.directory_external_id,
1365            }),
1366        )
1367        .await;
1368    }

1370    /// One audit row, as the system. Never fails the run: the sink logs a row it
1371    /// cannot write.
1372    async fn record(
1373        &self,
1374        tenant_id: Uuid,
1375        action: &str,
1376        resource_id: Option<Uuid>,
1377        outcome: AuditOutcome,
1378        metadata: serde_json::Value,
1379    ) {
1380        self.audit
1381            .record(CreateAuditLogEntry {
1382                tenant_id,
1383                actor_id: Uuid::nil(),
1384                actor_type: ActorType::System,
1385                action: action.to_string(),
1386                resource_id,
1387                outcome,
1388                ip_address: None,
1389                metadata: Some(metadata),
1390            })
1391            .await;
1392    }
