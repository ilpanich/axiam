1//! Receiving an `AuthnRequest` (T23.2.3): decoding, parsing and signature
2//! verification for the SSO endpoint, on both bindings.
3//!
4//! Pure and synchronous, like the rest of this module: no I/O, no lookups. The
5//! SSO endpoint calls these in order — decode, parse, find the SP by the parsed
6//! `Issuer`, verify — and every refusal here happens **before** any service
7//! provider is looked up, any row is written or any person is sent to a
8//! sign-in page.
9//!
10//! # What is refused before XML parsing
11//!
12//! * **Size.** The encoded value is bounded ([`MAX_ENCODED_REQUEST_BYTES`]),
13//!   and so is the document it decodes to ([`MAX_REQUEST_XML_BYTES`]). On the
14//!   HTTP-Redirect binding the document is raw DEFLATE, and inflating stops one
15//!   byte past the bound: a decompression bomb costs at most that much memory,
16//!   however small its compressed form.
17//! * **Any markup declaration.** An `AuthnRequest` has no use for a DTD, so a
18//!   document containing `<!` other than a comment or a CDATA section —
19//!   `<!DOCTYPE`, `<!ENTITY`, `<!ELEMENT`, `<!ATTLIST` — is refused on its
20//!   bytes, before libxml sees it. That is the whole defence against external
21//!   entities and entity expansion ("billion laughs"): there is no entity to
22//!   expand. libxml is then run without recovery and without network access, so
23//!   a malformed document is refused rather than repaired into something the
24//!   signature check and the field reader might read differently.
25//!
26//! # Signatures
27//!
28//! * **HTTP-POST** — an enveloped `ds:Signature`, and only one place may hold it:
29//!   the child of the `AuthnRequest` root, with exactly one reference, naming the
30//!   root's `ID`. Any other `ds:Signature` anywhere refuses the document (the
31//!   placement rule D-23 gave the SP side). The one admitted signature may
32//!   name only `enveloped-signature` and the canonicalizations without comments
33//!   ([`signature_transforms_admitted`], R101W2-01), and is then verified by
34//!   xmlsec against the SP's registered certificate, on its own node, with
35//!   SHA-1 algorithms refused.
36//! * **HTTP-Redirect** — the `Signature` query parameter over the octets SAML
37//!   Bindings §3.4.4.1 names, **exactly as received**:
38//!   `SAMLRequest=…[&RelayState=…]&SigAlg=…`, each value still percent-encoded
39//!   the way the SP encoded it. Re-encoding the decoded values (what
40//!   `samael`'s `UrlVerifier` does) would verify a string the SP never signed.
41//!   Each of the four parameters may appear once; a repeated one is refused,
42//!   since two readers could pick different copies. RSA with SHA-256, -384 or
43//!   -512 only.
44//!
45//! An enveloped signature inside a Redirect-binding document is not a signature
46//! of that binding (§3.4.4.1 says it must be removed); it is refused rather than
47//! ignored, so no document carries a signature nobody checked.
48//!
49//! # Reused by single logout (T23.2.4)
50//!
51//! [`super::logout`] receives `LogoutRequest`s and `LogoutResponse`s with the same
52//! decoding, the same refusals before libxml, the same placement rule —
53//! [`signature_placement`] is a function over **any root element** — and the same
54//! two signature verifiers. [`RedirectQuery`] carries either `SAMLRequest` or
55//! `SAMLResponse` ([`MessageParam`]) and signs over whichever it was, exactly as
56//! received. `verify_signed_xml`, which checks only the first signature, is never
57//! called (D-23, D-38).

108/// Why an `AuthnRequest` was refused before any lookup.
109///
110/// Fixed strings with no value in them, so a refusal can be logged as is. None
111/// of these is delivered to an SP: the request is not yet known to come from
112/// one, so the endpoint answers with an error page that posts nowhere.
113#[derive(Debug, Clone, Copy, PartialEq, Eq, thiserror::Error)]
114pub enum RequestError {
115    /// The message is larger than this endpoint reads.
116    #[error("the SAML request is too large")]
117    TooLarge,
118    /// No `SAMLRequest`, or it is not base64.
119    #[error("the SAML request is missing or not base64")]
120    Encoding,
121    /// The Redirect binding's DEFLATE stream is not valid.
122    #[error("the SAML request does not inflate")]
123    Inflate,
124    /// The document contains a markup declaration (a DTD, an entity).
125    #[error("the SAML request declares a DTD or an entity")]
126    Dtd,
127    /// The document is not well-formed UTF-8 XML.
128    #[error("the SAML request is not well-formed XML")]
129    Malformed,
130    /// The root is not a SAML 2.0 `samlp:AuthnRequest`.
131    #[error("the message is not a SAML 2.0 AuthnRequest")]
132    NotAnAuthnRequest,
133    /// `ID` is missing or not a request id this IdP will echo.
134    #[error("the AuthnRequest ID is missing or invalid")]
135    InvalidId,
136    /// An attribute or child element is missing, repeated or malformed.
137    #[error("the AuthnRequest is malformed")]
138    InvalidField,
139    /// `IssueInstant` is outside the accepted window.
140    #[error("the AuthnRequest IssueInstant is outside the accepted window")]
141    Stale,
142    /// The request names a `Subject`, which this IdP does not honour.
143    #[error("an AuthnRequest naming a Subject is not supported")]
144    SubjectUnsupported,
145    /// A query parameter of the Redirect binding appears more than once.
146    #[error("a SAML query parameter is repeated")]
147    DuplicateParameter,
148    /// A signature sits somewhere a signature may not.
149    #[error("a signature is placed where none may be")]
150    SignaturePlacement,
151    /// The SP requires signed requests and this one is not signed.
152    #[error("the AuthnRequest is not signed")]
153    SignatureMissing,
154    /// The signature algorithm is not one this IdP accepts.
155    #[error("the signature algorithm is not accepted")]
156    SignatureAlgorithm,
157    /// The root is not a SAML 2.0 `samlp:LogoutRequest` or `samlp:LogoutResponse`.
158    #[error("the message is not a SAML 2.0 LogoutRequest or LogoutResponse")]
159    NotALogoutMessage,
160    /// A `LogoutRequest` that names no `NameID`, or more than one.
161    #[error("the LogoutRequest does not name exactly one NameID")]
162    NameIdMissing,
163    /// A `LogoutRequest` naming its principal by `BaseID` or `EncryptedID`,
164    /// neither of which this IdP issues.
165    #[error("a BaseID or EncryptedID is not supported")]
166    NameIdUnsupported,
167    /// More `SessionIndex` elements than one request may carry.
168    #[error("the LogoutRequest carries too many SessionIndex elements")]
169    TooManySessionIndexes,
170    /// The request's `NotOnOrAfter` has passed.
171    #[error("the LogoutRequest has expired")]
172    Expired,
173    /// The message carries no `Destination`.
174    #[error("the message has no Destination")]
175    DestinationMissing,
176    /// The signature does not verify against the SP's certificate.
177    #[error("the AuthnRequest signature does not verify")]
178    SignatureInvalid,
179}

208/// Decode an HTTP-Redirect `SAMLRequest` value (already URL-decoded): base64,
209/// then raw DEFLATE inflated to at most [`MAX_REQUEST_XML_BYTES`].
210///
211/// # Errors
212///
213/// [`RequestError::TooLarge`], [`RequestError::Encoding`],
214/// [`RequestError::Inflate`], [`RequestError::Malformed`] (not UTF-8).
215pub fn decode_redirect(value: &str) -> Result<String, RequestError> {
216    let compressed = decode_base64(value, false)?;
217    let mut inflated = Vec::with_capacity(4096);
218    flate2::read::DeflateDecoder::new(compressed.as_slice())
219        .take(MAX_REQUEST_XML_BYTES as u64 + 1)
220        .read_to_end(&mut inflated)
221        .map_err(|_| RequestError::Inflate)?;
222    if inflated.len() > MAX_REQUEST_XML_BYTES {
223        return Err(RequestError::TooLarge);
224    }
225    String::from_utf8(inflated).map_err(|_| RequestError::Malformed)
226}

228/// Decode an HTTP-POST `SAMLRequest` value: base64 of the document, line breaks
229/// tolerated (some SPs wrap at 76 columns).
230///
231/// # Errors
232///
233/// [`RequestError::TooLarge`], [`RequestError::Encoding`],
234/// [`RequestError::Malformed`] (not UTF-8).
235pub fn decode_post(value: &str) -> Result<String, RequestError> {
236    let bytes = decode_base64(value, true)?;
237    if bytes.len() > MAX_REQUEST_XML_BYTES {
238        return Err(RequestError::TooLarge);
239    }
240    String::from_utf8(bytes).map_err(|_| RequestError::Malformed)
241}
242
243fn decode_base64(value: &str, allow_line_breaks: bool) -> Result<Vec<u8>, RequestError> {
244    if value.len() > MAX_ENCODED_REQUEST_BYTES {
245        return Err(RequestError::TooLarge);
246    }
247    let compact: String = if allow_line_breaks {
248        value
249            .chars()
250            .filter(|c| !matches!(c, '\r' | '\n' | ' ' | '\t'))
251            .collect()
252    } else {
253        value.to_owned()
254    };
255    if compact.is_empty() {
256        return Err(RequestError::Encoding);
257    }
258    STANDARD
259        .decode(compact.as_bytes())
260        .map_err(|_| RequestError::Encoding)
261}

263/// Refuse a document that contains any markup declaration.
264///
265/// `<!--` (a comment) and `<![CDATA[` are the only two constructs beginning
266/// `<!` that may appear in a document without a DTD; anything else beginning
267/// `<!` — `<!DOCTYPE`, `<!ENTITY`, `<!ELEMENT`, `<!ATTLIST`, `<!NOTATION`, in
268/// any case — is a declaration, and an `AuthnRequest` needs none.
269///
270/// # Errors
271///
272/// [`RequestError::Dtd`].
273pub fn refuse_markup_declarations(document: &str) -> Result<(), RequestError> {
274    let mut rest = document;
275    while let Some(at) = rest.find("<!") {
276        let tail = &rest[at..];
277        if !(tail.starts_with("<!--") || tail.starts_with("<![CDATA[")) {
278            return Err(RequestError::Dtd);
279        }
280        rest = &rest[at + 2..];
281    }
282    Ok(())
283}

285/// Refuse a document that is not plainly UTF-8: one containing a NUL (which is
286/// how UTF-16 and UTF-32 spell ASCII, and would hide a `<!DOCTYPE` from
287/// [`refuse_markup_declarations`]), one whose first character after XML
288/// whitespace is not `<`, or one whose XML declaration names another encoding.
289/// AXIAM's own parses force UTF-8 ([`receiver_parser_options`]), and xmlsec's
290/// honours the declaration; refusing every other declaration keeps the two
291/// reading the same characters.
292///
293/// #605 (R1W1-07): the declaration is read only where the parser reads it — at
294/// the start of the document — so the start must be markup. Exactly one
295/// leading byte-order mark is stripped first (R101W2-02: Microsoft Entra ID's
296/// federation metadata begins with one, as .NET's UTF-8 writer emits by
297/// default). In a validated `&str` a leading U+FEFF can only be the UTF-8 BOM
298/// `ef bb bf` — a UTF-16 or UTF-32 BOM is not valid UTF-8, and a NUL is refused
299/// — so the strip changes no encoding. After it the rules apply to the true
300/// start: a second BOM, or any other leading text, is refused, and a
301/// declaration naming another encoding is read and refused.
302///
303/// Returns the accepted document **without** that BOM. Every caller rebinds to
304/// the returned slice before anything else reads the document, so the
305/// byte-level scans, libxml, samael and xmlsec all read the same characters.
306/// The BOM is never part of what a signature covers: canonicalisation works on
307/// the parsed tree, which a BOM never enters.
308///
309/// # Errors
310///
311/// [`RequestError::Malformed`].
312pub fn refuse_other_encodings(document: &str) -> Result<&str, RequestError> {
313    if document.contains('\0') {
314        return Err(RequestError::Malformed);
315    }
316    let document = document.strip_prefix('\u{feff}').unwrap_or(document);
317    // XML's whitespace (`S`): space, tab, CR, LF — and nothing else.
318    let trimmed = document.trim_start_matches([' ', '\t', '\r', '\n']);
319    if !trimmed.starts_with('<') {
320        return Err(RequestError::Malformed);
321    }
322    if let Some(rest) = trimmed.strip_prefix("<?xml") {
323        let declaration = rest.split("?>").next().unwrap_or_default();
324        if let Some(at) = declaration.find("encoding") {
325            let value = declaration[at + "encoding".len()..]
326                .trim_start()
327                .trim_start_matches('=')
328                .trim_start()
329                .trim_start_matches(['"', '\''])
330                .split(['"', '\''])
331                .next()
332                .unwrap_or_default();
333            if !value.eq_ignore_ascii_case("utf-8") {
334                return Err(RequestError::Malformed);
335            }
336        }
337    }
338    Ok(document)
339}

341/// Parse an `AuthnRequest` and check what needs no SP: shape, `Version`, `ID`,
342/// `IssueInstant` against `now`, `Issuer`, and where a signature sits.
343///
344/// # Errors
345///
346/// A [`RequestError`]; nothing about the document is in it.
347pub fn parse_authn_request(
348    document: &str,
349    now: DateTime<Utc>,
350) -> Result<ParsedAuthnRequest, RequestError> {
351    let doc = parse_xml(document)?;
352    let root = doc.get_root_element().ok_or(RequestError::Malformed)?;
353    if !is_element(&root, NS_PROTOCOL, "AuthnRequest") {
354        return Err(RequestError::NotAnAuthnRequest);
355    }
356    if root.get_attribute("Version").as_deref() != Some("2.0") {
357        return Err(RequestError::NotAnAuthnRequest);
358    }
359
360    let id = root.get_attribute("ID").ok_or(RequestError::InvalidId)?;
361    super::check_request_id(&id).map_err(|_| RequestError::InvalidId)?;
362
363    let issue_instant = fresh_issue_instant(&root, now)?;
364
365    let children = root.get_child_elements();
366    let issuer = read_issuer(&children)?;
367    if children
368        .iter()
369        .any(|c| is_element(c, NS_ASSERTION, "Subject"))
370    {
371        return Err(RequestError::SubjectUnsupported);
372    }
373    let policies: Vec<_> = children
374        .iter()
375        .filter(|c| is_element(c, NS_PROTOCOL, "NameIDPolicy"))
376        .collect();
377    let name_id_format = match policies.as_slice() {
378        [] => None,
379        [policy] => policy.get_attribute("Format"),
380        _ => return Err(RequestError::InvalidField),
381    };
382
383    let enveloped_signature = signature_placement(&doc, &root, &id)?;
384
385    Ok(ParsedAuthnRequest {
386        id,
387        issue_instant,
388        destination: root.get_attribute("Destination"),
389        issuer,
390        force_authn: xs_boolean(root.get_attribute("ForceAuthn"))?,
391        is_passive: xs_boolean(root.get_attribute("IsPassive"))?,
392        acs_url: root.get_attribute("AssertionConsumerServiceURL"),
393        acs_index: root
394            .get_attribute("AssertionConsumerServiceIndex")
395            .map(|raw| raw.trim().parse::<u16>())
396            .transpose()
397            .map_err(|_| RequestError::InvalidField)?,
398        protocol_binding: root.get_attribute("ProtocolBinding"),
399        name_id_format,
400        enveloped_signature,
401    })
402}

404/// The libxml options every document AXIAM receives is parsed with — an
405/// `AuthnRequest` or logout message here, imported SP metadata, a `SAMLResponse`
406/// at the ACS, IdP metadata: no recovery (`XML_PARSE_RECOVER` off: a document
407/// that is not well-formed is refused, not repaired), no network access
408/// (`XML_PARSE_NONET`), no entity substitution and no DTD loading, defaulting or
409/// validation (`XML_PARSE_NOENT`, `DTDLOAD`, `DTDATTR`, `DTDVALID` all off), and
410/// UTF-8 whatever the document declares (#605): `XML_PARSE_IGNORE_ENC` makes
411/// libxml skip the declaration, and its own detection reads any text that
412/// passed [`refuse_other_encodings`] — valid UTF-8, no NUL, no second
413/// byte-order mark, beginning with `<` — as UTF-8. That function has already
414/// refused any other declaration, so this changes no document that reaches the
415/// parser; it removes the parser's freedom to read one differently.
416///
417/// `encoding` stays **`None`**. libxml-rs 0.3.3's `parse_string_with_options`
418/// turns `Some(name)` into a `CString` that is dropped inside the `match` that
419/// takes its pointer, so libxml2 read the encoding name from freed memory: a
420/// use-after-free (found under valgrind on 2026-10-13). Whatever the allocator
421/// had put there named the encoding the document was decoded with — usually
422/// none, and the parse failed; sometimes a 7-bit national variant of ASCII,
423/// and `#` in the XML-DSig namespace URI read as another character. Every
424/// receiver parse set it from W2.1 (#605), the IdP receiver's since T23.2.3.
425///
426/// `no_def_dtd` stays **off**. libxml-rs 0.3 maps it to the value 4 for both
427/// parsers, which is `HTML_PARSE_NODEFDTD` for the HTML parser but
428/// `XML_PARSE_DTDLOAD` — *load the external DTD subset* — for the XML parser.
429/// Until 2026-10-13 it was set here, asking libxml for the opposite of what the
430/// comment said; [`refuse_markup_declarations`] refusing every `<!DOCTYPE` on
431/// the bytes, and `no_net`, kept that from being reachable — as does, once
432/// xmlsec is initialised, the process-wide external-entity loader xmlsec
433/// installs, which refuses every input but the document itself. Public so the
434/// `receiver_parser_options` integration test can parse with it in a process
435/// where xmlsec never runs.
436pub fn receiver_parser_options() -> libxml::parser::ParserOptions<'static> {
437    libxml::parser::ParserOptions {
438        recover: false,
439        no_net: true,
440        no_def_dtd: false,
441        ignore_enc: true,
442        encoding: None,
443        ..Default::default()
444    }
445}

447/// Parse a document the way every message this IdP receives is parsed: size
448/// bound, no markup declaration, no other encoding — all on the bytes, before
449/// libxml — then libxml with [`receiver_parser_options`].
450pub(super) fn parse_xml(document: &str) -> Result<libxml::tree::Document, RequestError> {
451    if document.len() > MAX_REQUEST_XML_BYTES {
452        return Err(RequestError::TooLarge);
453    }
454    // R101W2-02: from here on, `document` is the text without its BOM.
455    let document = refuse_other_encodings(document)?;
456    refuse_markup_declarations(document)?;
457
458    libxml::parser::Parser::default()
459        .parse_string_with_options(document.as_bytes(), receiver_parser_options())
460        .map_err(|_| RequestError::Malformed)
461}

463/// `IssueInstant`, required, and inside the accepted window: at most
464/// [`REQUEST_MAX_AGE_SECS`] old and no further ahead than the clock-skew
465/// allowance.
466pub(super) fn fresh_issue_instant(
467    root: &libxml::tree::Node,
468    now: DateTime<Utc>,
469) -> Result<DateTime<Utc>, RequestError> {
470    let issue_instant = root
471        .get_attribute("IssueInstant")
472        .and_then(|raw| DateTime::parse_from_rfc3339(raw.trim()).ok())
473        .map(|t| t.with_timezone(&Utc))
474        .ok_or(RequestError::InvalidField)?;
475    let skew = Duration::seconds(crate::oidc::CLOCK_SKEW_LEEWAY_SECS as i64);
476    if issue_instant > now + skew
477        || issue_instant < now - Duration::seconds(REQUEST_MAX_AGE_SECS) - skew
478    {
479        return Err(RequestError::Stale);
480    }
481    Ok(issue_instant)
482}

484/// The one `saml:Issuer` among `children`: its text, the SP's entity id. Exactly
485/// one, non-empty, and when it carries a `Format` the entity one.
486pub(super) fn read_issuer(children: &[libxml::tree::Node]) -> Result<String, RequestError> {
487    let issuers: Vec<_> = children
488        .iter()
489        .filter(|c| is_element(c, NS_ASSERTION, "Issuer"))
490        .collect();
491    let [issuer] = issuers.as_slice() else {
492        return Err(RequestError::InvalidField);
493    };
494    if issuer
495        .get_attribute("Format")
496        .is_some_and(|f| f != NAME_ID_FORMAT_ENTITY)
497    {
498        return Err(RequestError::InvalidField);
499    }
500    let issuer = issuer.get_content().trim().to_owned();
501    if issuer.is_empty() {
502        return Err(RequestError::InvalidField);
503    }
504    Ok(issuer)
505}

507/// `xs:boolean`, absent meaning `false`.
508fn xs_boolean(raw: Option<String>) -> Result<bool, RequestError> {
509    match raw.as_deref().map(str::trim) {
510        None | Some("false" | "0") => Ok(false),
511        Some("true" | "1") => Ok(true),
512        Some(_) => Err(RequestError::InvalidField),
513    }
514}

516/// Where the document's signatures sit: `Ok(false)` for none, `Ok(true)` for
517/// exactly one enveloped child of the root referencing the root's `ID`, and
518/// [`RequestError::SignaturePlacement`] for anything else — including an
519/// element locally named `Signature` that is not an XML-DSig one, so a
520/// namespace this check misreads refuses the document rather than reading it
521/// as unsigned.
522///
523/// **A function over any root element** (D-38): `root` is whatever the caller
524/// established the document's root to be — an `AuthnRequest` here, a
525/// `LogoutRequest` or `LogoutResponse` in [`super::logout`] — and `root_id` its
526/// `ID`. The rule never looks at the root's name, so it cannot differ between
527/// message kinds.
528pub(crate) fn signature_placement(
529    doc: &libxml::tree::Document,
530    root: &libxml::tree::Node,
531    root_id: &str,
532) -> Result<bool, RequestError> {
533    let mut context = libxml::xpath::Context::new(doc).map_err(|()| RequestError::Malformed)?;
534    let all = every_signature(&mut context)?;
535    if all.is_empty() {
536        return Ok(false);
537    }
538    let at_root: Vec<_> = root
539        .get_child_elements()
540        .into_iter()
541        .filter(|c| is_element(c, NS_DSIG, "Signature"))
542        .collect();
543    let ([signature], 1) = (at_root.as_slice(), all.len()) else {
544        return Err(RequestError::SignaturePlacement);
545    };
546    let references: Vec<_> = signature
547        .get_child_elements()
548        .into_iter()
549        .filter(|c| is_element(c, NS_DSIG, "SignedInfo"))
550        .flat_map(|info| info.get_child_elements())
551        .filter(|c| is_element(c, NS_DSIG, "Reference"))
552        .collect();
553    let expected = format!("#{root_id}");
554    match references.as_slice() {
555        [reference] if reference.get_attribute("URI").as_deref() == Some(expected.as_str()) => {}
556        _ => return Err(RequestError::SignaturePlacement),
557    }
558    // R101W2-01: before xmlsec, which evaluates a reference's transforms
559    // before it checks the signature value.
560    if signature_transforms_admitted(&mut context, signature)
561        .map_err(|()| RequestError::Malformed)?
562    {
563        Ok(true)
564    } else {
565        Err(RequestError::SignaturePlacement)
566    }
567}

569/// Exclusive XML canonicalization 1.0, without comments.
570const C14N_EXCLUSIVE: &str = "http://www.w3.org/2001/10/xml-exc-c14n#";
571/// Canonical XML 1.0, without comments.
572const C14N_10: &str = "http://www.w3.org/TR/2001/REC-xml-c14n-20010315";
573/// Canonical XML 1.1, without comments.
574const C14N_11: &str = "http://www.w3.org/2006/12/xml-c14n11";
575/// The enveloped-signature transform.
576const TRANSFORM_ENVELOPED: &str = "http://www.w3.org/2000/09/xmldsig#enveloped-signature";
577/// The namespace of exclusive canonicalization's `InclusiveNamespaces`.
578const NS_EXC_C14N: &str = C14N_EXCLUSIVE;
579/// The most `Transform`s one `Reference` may name: `enveloped-signature` and a
580/// canonicalization.
581const MAX_REFERENCE_TRANSFORMS: usize = 2;
582
583/// The one attribute named `Algorithm` on `method`, in any namespace — the
584/// value xmlsec's `xmlGetProp` reads. `Ok(None)` when there is not exactly one;
585/// `Err(())` when the XPath evaluation itself fails.
586///
587/// Shared by the transform allow-list ([`signature_transforms_admitted`]) and
588/// the SP's SHA-1 escape-hatch check (#606), so both read an algorithm the
589/// same way.
590pub(crate) fn sole_algorithm(
591    context: &mut libxml::xpath::Context,
592    method: &libxml::tree::Node,
593) -> Result<Option<String>, ()> {
594    let attributes = context.findnodes("@*[local-name()='Algorithm']", Some(method))?;
595    Ok(match attributes.as_slice() {
596        [attribute] => Some(attribute.get_content()),
597        _ => None,
598    })
599}

601/// Whether `signature` names only the transforms and the canonicalization a
602/// SAML signature needs (R101W2-01).
603///
604/// xmlsec admits every transform it registers for a `Reference` — XSLT, XPath,
605/// XPath Filter 2, XPointer as this build links it — and evaluates them, and
606/// the canonicalization, **before** it compares the signature value; samael
607/// restricts neither. So whoever sends a document chooses how much work the
608/// verifier does before it refuses an unsigned one. This allow-list runs on the
609/// libxml tree the caller already holds, before samael, on every path (the SHA-2
610/// default and the SP's SHA-1 escape hatch alike):
611///
612/// * exactly one `SignedInfo` with exactly one `CanonicalizationMethod`, whose
613///   algorithm is exclusive c14n, c14n 1.0 or c14n 1.1 — never a
614///   `#WithComments` variant;
615/// * per `Reference` at most one `Transforms`, holding only `Transform`
616///   elements, at most [`MAX_REFERENCE_TRANSFORMS`] of them, each
617///   `enveloped-signature` or one of those canonicalizations;
618/// * no `Transform` or `CanonicalizationMethod` anywhere else in the signature
619///   (a `Manifest` or `RetrievalMethod` would carry one);
620/// * each method with exactly one attribute named `Algorithm`
621///   ([`sole_algorithm`]), compared exactly, and no element child except one
622///   `ec:InclusiveNamespaces` carrying only `PrefixList`, under exclusive c14n.
623///
624/// Keycloak, samael, Microsoft Entra ID, Okta, Shibboleth and AXIAM's own
625/// signer use `enveloped-signature` with exclusive c14n, so this admits them.
626/// `Err(())` only when an XPath evaluation fails.
627pub(crate) fn signature_transforms_admitted(
628    context: &mut libxml::xpath::Context,
629    signature: &libxml::tree::Node,
630) -> Result<bool, ()> {
631    fn dsig_children(node: &libxml::tree::Node, name: &str) -> Vec<libxml::tree::Node> {
632        node.get_child_elements()
633            .into_iter()
634            .filter(|c| is_element(c, NS_DSIG, name))
635            .collect()
636    }
637    let canonicalization = |uri: &str| [C14N_EXCLUSIVE, C14N_10, C14N_11].contains(&uri);
638
639    let signed_infos = dsig_children(signature, "SignedInfo");
640    let [signed_info] = signed_infos.as_slice() else {
641        return Ok(false);
642    };
643    let methods = dsig_children(signed_info, "CanonicalizationMethod");
644    let [c14n] = methods.as_slice() else {
645        return Ok(false);
646    };
647    if !method_admitted(context, c14n, canonicalization)? {
648        return Ok(false);
649    }
650
651    let mut transforms_seen = 0;
652    for reference in dsig_children(signed_info, "Reference") {
653        let containers = dsig_children(&reference, "Transforms");
654        let transforms = match containers.as_slice() {
655            [] => continue,
656            [transforms] => transforms.get_child_elements(),
657            _ => return Ok(false),
658        };
659        if transforms.len() > MAX_REFERENCE_TRANSFORMS {
660            return Ok(false);
661        }
662        for transform in &transforms {
663            if !is_element(transform, NS_DSIG, "Transform")
664                || !method_admitted(context, transform, |uri| {
665                    uri == TRANSFORM_ENVELOPED || canonicalization(uri)
666                })?
667            {
668                return Ok(false);
669            }
670        }
671        transforms_seen += transforms.len();
672    }
673
674    // Nothing the walk above did not judge: a `Transform` in a `Manifest` or a
675    // `KeyInfo/RetrievalMethod`, or a second canonicalization. Counted by local
676    // name in any namespace, so a `Transforms` or `Transform` the walk skipped
677    // because its namespace did not read as XML-DSig refuses the signature
678    // instead of escaping the count (fail closed).
679    let everywhere = |context: &mut libxml::xpath::Context, name: &str| {
680        context
681            .findnodes(&format!(".//*[local-name()='{name}']"), Some(signature))
682            .map(|nodes| nodes.len())
683    };
684    Ok(everywhere(context, "Transform")? == transforms_seen
685        && everywhere(context, "CanonicalizationMethod")? == 1)
686}

688/// One method element of [`signature_transforms_admitted`]: exactly one
689/// `Algorithm`, admitted by `admitted`, and no element child but exclusive
690/// c14n's `InclusiveNamespaces` with only a `PrefixList`.
691fn method_admitted(
692    context: &mut libxml::xpath::Context,
693    method: &libxml::tree::Node,
694    admitted: impl Fn(&str) -> bool,
695) -> Result<bool, ()> {
696    let Some(algorithm) = sole_algorithm(context, method)? else {
697        return Ok(false);
698    };
699    if !admitted(&algorithm) {
700        return Ok(false);
701    }
702    Ok(match method.get_child_elements().as_slice() {
703        [] => true,
704        [inclusive] if algorithm == C14N_EXCLUSIVE => {
705            // `@PrefixList` in XPath is the attribute in no namespace.
706            is_element(inclusive, NS_EXC_C14N, "InclusiveNamespaces")
707                && inclusive.get_child_elements().is_empty()
708                && context.findnodes("@*", Some(inclusive))?.len() == 1
709                && context.findnodes("@PrefixList", Some(inclusive))?.len() == 1
710        }
711        _ => false,
712    })
713}

715pub(super) fn is_element(node: &libxml::tree::Node, namespace: &str, name: &str) -> bool {
716    node.get_name() == name
717        && node
718            .get_namespace()
719            .is_some_and(|ns| ns.get_href() == namespace)
720}

722/// Every element in the document locally named `Signature`, in any namespace,
723/// each of which must be an XML-DSig `Signature`:
724/// [`RequestError::SignaturePlacement`] otherwise. Searching by local name and
725/// then checking the namespace — rather than searching for the namespace — is
726/// what makes a namespace this reader gets wrong refuse the document instead
727/// of hiding a signature from the checks while xmlsec, on its own parse, still
728/// finds and verifies it.
729fn every_signature(
730    context: &mut libxml::xpath::Context,
731) -> Result<Vec<libxml::tree::Node>, RequestError> {
732    let all = context
733        .findnodes("//*[local-name()='Signature']", None)
734        .map_err(|()| RequestError::Malformed)?;
735    if all.iter().all(|s| is_element(s, NS_DSIG, "Signature")) {
736        Ok(all)
737    } else {
738        Err(RequestError::SignaturePlacement)
739    }
740}

742/// Verify a POST-binding request's enveloped signature against the SP's
743/// registered certificate (DER). Call only after [`parse_authn_request`]
744/// answered `enveloped_signature: true`, which is what established that the one
745/// signature in the document is the root's own.
746///
747/// # Errors
748///
749/// [`RequestError::SignaturePlacement`] — a `ds:Signature` in the document
750/// names a transform or canonicalization outside
751/// [`signature_transforms_admitted`]'s set (R101W2-01): checked here again, on
752/// this very text, before xmlsec runs, so this function never hands xmlsec a
753/// transform whatever its caller checked. [`RequestError::SignatureInvalid`] —
754/// a wrong key, a changed byte, a SHA-1 algorithm, a document that does not
755/// parse, or anything xmlsec refuses.
756///
757/// CPU-bound: the SSO and SLO endpoints call it off the async workers, under
758/// the crypto semaphore.
759pub fn verify_post_signature(document: &str, sp_cert_der: &[u8]) -> Result<(), RequestError> {
760    // R101W2-02: xmlsec reads exactly the text `parse_xml` read — the same
761    // function strips the same one BOM, so the two never see different
762    // characters, whatever string the caller holds.
763    let document = refuse_other_encodings(document).map_err(|_| RequestError::SignatureInvalid)?;
764    // R101W2-01: the transform allow-list, on every signature of the very
765    // text xmlsec is handed. (The placement rule is the parse's: this function
766    // also verifies documents whose signature sits on a child, such as an
767    // issued response's assertion.)
768    let doc = parse_xml(document).map_err(|_| RequestError::SignatureInvalid)?;
769    let mut context = libxml::xpath::Context::new(&doc).map_err(|()| RequestError::Malformed)?;
770    let signatures = every_signature(&mut context)?;
771    // Called only for a document whose parse found its signature: finding none
772    // here means this read and that one disagree, and xmlsec would verify
773    // whatever it finds with nothing checked first. Refused (fail closed).
774    if signatures.is_empty() {
775        return Err(RequestError::SignatureInvalid);
776    }
777    for signature in &signatures {
778        if !signature_transforms_admitted(&mut context, signature)
779            .map_err(|()| RequestError::Malformed)?
780        {
781            return Err(RequestError::SignaturePlacement);
782        }
783    }
784    let cert = CertificateDer::from(sp_cert_der.to_vec());
785    <XmlSec as CryptoProvider>::reduce_xml_to_signed_with_allowed_algorithms(
786        document,
787        &[cert],
788        ReduceMode::PreDigest,
789        Some(&ALLOWED_XML_SIGNATURE_ALGORITHMS),
790    )
791    .map(|_| ())
792    .map_err(|_| RequestError::SignatureInvalid)
793}

795/// Which message parameter an HTTP-Redirect query carries (SAML Bindings
796/// §3.4.4: exactly one of the two).
797#[derive(Debug, Clone, Copy, PartialEq, Eq)]
798pub enum MessageParam {
799    /// `SAMLRequest`.
800    Request,
801    /// `SAMLResponse`.
802    Response,
803}
804
805impl MessageParam {
806    /// The parameter's name, which is also the first octets of what a Redirect
807    /// signature covers.
808    #[must_use]
809    pub const fn name(self) -> &'static str {
810        match self {
811            Self::Request => "SAMLRequest",
812            Self::Response => "SAMLResponse",
813        }
814    }
815}
816
817/// The HTTP-Redirect parameters, **as received** — still percent-encoded.
818#[derive(Debug, Clone, Copy, PartialEq, Eq)]
819pub struct RedirectQuery<'q> {
820    /// Which of `SAMLRequest` and `SAMLResponse` the query carries.
821    pub param: MessageParam,
822    /// The message parameter's value, raw.
823    pub message: &'q str,
824    /// `RelayState`, raw.
825    pub relay_state: Option<&'q str>,
826    /// `SigAlg`, raw.
827    pub sig_alg: Option<&'q str>,
828    /// `Signature`, raw.
829    pub signature: Option<&'q str>,
830}
831
832impl<'q> RedirectQuery<'q> {
833    /// Split a raw query string for the SSO endpoint, which takes a
834    /// `SAMLRequest`. Parameters other than the four are ignored (a
835    /// `SAMLResponse` among them); each of the four may appear at most once, and
836    /// `SAMLRequest` must.
837    ///
838    /// # Errors
839    ///
840    /// [`RequestError::DuplicateParameter`], [`RequestError::Encoding`] (no
841    /// `SAMLRequest`), [`RequestError::TooLarge`].
842    pub fn parse(query: &'q str) -> Result<Self, RequestError> {
843        Self::split(query, false)
844    }
845
846    /// Split a raw query string for the SLO endpoint, which takes **either**
847    /// `SAMLRequest` or `SAMLResponse`, never both: a query naming both is
848    /// ambiguous (two readers could pick different ones) and is refused. Each of
849    /// the parameters may appear at most once.
850    ///
851    /// # Errors
852    ///
853    /// [`RequestError::DuplicateParameter`] (a repeated parameter, or both
854    /// messages), [`RequestError::Encoding`] (neither), [`RequestError::TooLarge`].
855    pub fn parse_logout(query: &'q str) -> Result<Self, RequestError> {
856        Self::split(query, true)
857    }
858
859    fn split(query: &'q str, either: bool) -> Result<Self, RequestError> {
860        if query.len() > MAX_ENCODED_REQUEST_BYTES * 3 {
861            return Err(RequestError::TooLarge);
862        }
863        let (mut request, mut response, mut relay_state, mut sig_alg, mut signature) =
864            (None, None, None, None, None);
865        for pair in query.split('&') {
866            let (name, value) = pair.split_once('=').unwrap_or((pair, ""));
867            let slot = match name {
868                "SAMLRequest" => &mut request,
869                "SAMLResponse" if either => &mut response,
870                "RelayState" => &mut relay_state,
871                "SigAlg" => &mut sig_alg,
872                "Signature" => &mut signature,
873                _ => continue,
874            };
875            if slot.replace(value).is_some() {
876                return Err(RequestError::DuplicateParameter);
877            }
878        }
879        let request = request.filter(|v: &&str| !v.is_empty());
880        let response = response.filter(|v: &&str| !v.is_empty());
881        let (param, message) = match (request, response) {
882            (Some(message), None) => (MessageParam::Request, message),
883            (None, Some(message)) => (MessageParam::Response, message),
884            (Some(_), Some(_)) => return Err(RequestError::DuplicateParameter),
885            (None, None) => return Err(RequestError::Encoding),
886        };
887        Ok(Self {
888            param,
889            message,
890            relay_state,
891            sig_alg,
892            signature,
893        })
894    }
895
896    /// Whether the query carries a signature (or a half of one).
897    #[must_use]
898    pub fn is_signed(&self) -> bool {
899        self.sig_alg.is_some() || self.signature.is_some()
900    }
901
902    /// The message parameter, URL-decoded. A base64 value contains no space, so a
903    /// `+` an SP left unencoded (and form decoding turned into a space) is put
904    /// back.
905    #[must_use]
906    pub fn message(&self) -> String {
907        url_decode(self.message).replace(' ', "+")
908    }
909
910    /// `RelayState`, URL-decoded, as it will be echoed.
911    #[must_use]
912    pub fn relay_state(&self) -> Option<String> {
913        self.relay_state.map(url_decode)
914    }
915
916    /// Verify the query signature against the SP's certificate (DER), over the
917    /// octets SAML Bindings §3.4.4.1 names, exactly as received:
918    /// `SAMLRequest=…` (or `SAMLResponse=…`)`[&RelayState=…]&SigAlg=…`.
919    ///
920    /// # Errors
921    ///
922    /// [`RequestError::SignatureMissing`] (no `SigAlg` or no `Signature`),
923    /// [`RequestError::SignatureAlgorithm`], [`RequestError::SignatureInvalid`].
924    pub fn verify_signature(&self, sp_cert_der: &[u8]) -> Result<(), RequestError> {
925        let (Some(sig_alg_raw), Some(signature_raw)) = (self.sig_alg, self.signature) else {
926            return Err(RequestError::SignatureMissing);
927        };
928        let digest = match url_decode(sig_alg_raw).as_str() {
929            "http://www.w3.org/2001/04/xmldsig-more#rsa-sha256" => {
930                openssl::hash::MessageDigest::sha256()
931            }
932            "http://www.w3.org/2001/04/xmldsig-more#rsa-sha384" => {
933                openssl::hash::MessageDigest::sha384()
934            }
935            "http://www.w3.org/2001/04/xmldsig-more#rsa-sha512" => {
936                openssl::hash::MessageDigest::sha512()
937            }
938            _ => return Err(RequestError::SignatureAlgorithm),
939        };
940        let signature = STANDARD
941            .decode(url_decode(signature_raw).replace(' ', "+").as_bytes())
942            .map_err(|_| RequestError::SignatureInvalid)?;
943
944        let mut signed = format!("{}={}", self.param.name(), self.message);
945        if let Some(relay_state) = self.relay_state {
946            signed.push_str("&RelayState=");
947            signed.push_str(relay_state);
948        }
949        signed.push_str("&SigAlg=");
950        signed.push_str(sig_alg_raw);
951
952        let public_key = openssl::x509::X509::from_der(sp_cert_der)
953            .and_then(|cert| cert.public_key())
954            .map_err(|_| RequestError::SignatureInvalid)?;
955        if public_key.id() != openssl::pkey::Id::RSA {
956            return Err(RequestError::SignatureAlgorithm);
957        }
958        let mut verifier = openssl::sign::Verifier::new(digest, &public_key)
959            .map_err(|_| RequestError::SignatureInvalid)?;
960        verifier
961            .update(signed.as_bytes())
962            .map_err(|_| RequestError::SignatureInvalid)?;
963        match verifier.verify(&signature) {
964            Ok(true) => Ok(()),
965            _ => Err(RequestError::SignatureInvalid),
966        }
967    }
968}

970/// `application/x-www-form-urlencoded` decoding of one value.
971fn url_decode(raw: &str) -> String {
972    url::form_urlencoded::parse(format!("v={raw}").as_bytes())
973        .next()
974        .map(|(_, v)| v.into_owned())
975        .unwrap_or_default()
976}

978/// Whether `requested` — an `AuthnRequest`'s `NameIDPolicy@Format` — can be
979/// honoured by an SP configured for `configured`: absent, `unspecified`, or
