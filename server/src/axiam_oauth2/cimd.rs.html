1//! Client ID Metadata Documents — a `client_id` that is a URL (T21.5).
2//!
3//! Implements `draft-ietf-oauth-client-id-metadata-document`: a client
4//! identifies itself with an `https` URL, and the authorization server fetches
5//! that URL to learn the client's metadata instead of holding a registration
6//! an administrator created. It is how Claude Code, VS Code and the MCP
7//! Inspector can be *the same client* at every AXIAM deployment they ever talk
8//! to, with nothing registered anywhere in advance.
9//!
10//! # The draft revision this implements
11//!
12//! **Not pinned to a numbered revision, deliberately, and this is a departure
13//! from the plan's instruction.** The executing environment's egress proxy
14//! refuses `datatracker.ietf.org` and `ietf.org` (HTTP 403 on CONNECT), so the
15//! revision current on 2026-09-17 could not be read, and a number written from
16//! memory would be a claim this code cannot support. What is implemented is
17//! the draft's stable core — the URL rules, the document shape, and the
18//! metadata members RFC 7591 §2 already defines — cross-checked against
19//! Keycloak's `cimd` feature, whose validation list the plan names as the
20//! reference behaviour. `docs/admin/client-id-metadata-documents.md` says the
21//! same thing in the same words, and T7 or T8, from an environment with
22//! egress, should replace both with the revision and re-read the diff.
23//!
24//! # What this module is, and what it is not
25//!
26//! It is a **pure decision** plus one **cache**. It decides whether a
27//! `client_id` may be resolved at all, fetches the document behind the shared
28//! SSRF guard, decides whether what came back is a client AXIAM will admit,
29//! and produces the `CreateOAuth2Client` that a caller materialises. It holds
30//! no repository, writes nothing, and answers every failure with one enum the
31//! caller turns into today's "unknown client".
32//!
33//! # Why every failure is the same failure
34//!
35//! [`CimdError`] is rich for the logs and invisible on the wire. A caller that
36//! cannot resolve a URL-shaped `client_id` does not materialise a row, so the
37//! ordinary repository lookup runs and answers exactly what it answers today
38//! for a `client_id` nobody registered. That is invariant I1 for the tenant
39//! that has CIMD off, and it is also what stops this mechanism becoming a
40//! probe: a stranger cannot learn from the response whether their document was
41//! unreachable, oversize, malformed, refused by a domain rule or refused by
42//! the SSRF guard.
43//!
44//! # The threat this module exists inside
45//!
46//! An unauthenticated request names a URL and AXIAM fetches it. Every bound
47//! here is therefore a security control rather than a tuning knob, and each is
48//! owned by something that has already been reviewed:
49//!
50//! | Bound | Owned by |
51//! | --- | --- |
52//! | Which hosts may be fetched at all | `CimdPolicy::trusted_client_id_domains`, empty refused at the settings layer |
53//! | Private/loopback addresses, IPv4-mapped IPv6, DNS rebinding | `axiam_pki::ssrf` (SEC-054, SEC-094): resolve, canonicalise, validate, **pin** |
54//! | Redirect following | the same guard: automatic redirects off, every hop re-validated, `MAX_HOPS` |
55//! | Plaintext `http` | the same guard, plus [`CimdPolicy::allow_http`] |
56//! | Response size | `CimdPolicy::max_metadata_bytes`, applied as a **streaming** cap |
57//! | Request time | the guard's per-request client timeout |
58//! | How often a fetch may repeat | `CimdPolicy::min_cache_secs` |
59//! | How long a stranger may pin a client | `CimdPolicy::max_cache_secs` |
60//!
61//! No address classification, no redirect policy and no connection building
62//! happens in this file. It was written once, reviewed once
63//! (`claude_dev/security-review-f4bis-2026-08-15.md` §3), and fixed once; a
64//! second copy here would be a second thing to get SEC-094 wrong in.
65//!
66//! # What a document may not decide
67//!
68//! The same four things a self-registered client may not decide, for the same
69//! reasons, and one more:
70//!
71//! | The document may name | It is decided by |
72//! | --- | --- |
73//! | `redirect_uris` | the document, within `cimd.trusted_redirect_domains` |
74//! | `scope` | the document, within `dcr_allowed_scopes` |
75//! | `grant_types` | the document, within `{authorization_code, refresh_token}` |
76//! | `token_endpoint_auth_method` | the document, within `{none, private_key_jwt}` |
77//! | **audiences** (`allowed_resources`) | **the tenant, always** (D3) |
78//! | **profile** | **forced to `standard`** (I5) |
79//! | **provenance** (`managed_by`) | **forced to `cimd`** (D5) |
80//! | **consent** | **forced on** (D4) |
81//! | **a shared secret** | **cannot exist** — the registration is a public document |

97/// How long past its TTL a cached document may still be served when the
98/// publisher is unreachable (24 hours).
99///
100/// The stale-while-revalidate window `JwksCache` uses (D-03), for the reason
101/// it uses it: a publisher having a bad afternoon should not sign every one of
102/// its users out of every MCP server they are using. It is bounded by the same
103/// argument in the other direction — a document withdrawn for good stops
104/// working within a day of its TTL expiring — and it is a window on a
105/// *successful* previous fetch, so nothing enters the cache through it.
106pub const STALE_WINDOW_SECS: i64 = 24 * 3600;

108/// The `token_endpoint_auth_method` values a metadata document may name.
109///
110/// Two, and the absent third is the point: a client whose registration is a
111/// document anybody can read cannot hold a shared secret, so
112/// `client_secret_post` and `client_secret_basic` are not "unsupported here",

117    [ClientAuthMethod::None, ClientAuthMethod::PrivateKeyJwt];

123/// Why a URL-shaped `client_id` did not become a client.
124///
125/// Every variant produces the same outcome for the caller — no row, therefore
126/// today's unknown-client refusal — and exists so the operator's log says
127/// which rule fired. See this module's header for why the wire cannot tell
128/// them apart.
129#[derive(Debug, Clone, PartialEq, Eq)]
130pub enum CimdError {
131    /// The tenant has `cimd.enabled` false. The first check and the cheapest:
132    /// nothing is parsed, nothing is fetched, nothing is logged at a level an
133    /// unauthenticated caller could make noisy.
134    Disabled,
135    /// The `client_id` is not a URL this server will resolve: wrong scheme, no
136    /// path, a query, a fragment, userinfo, a dot segment, or a spelling that
137    /// is not its own canonical form.
138    UnusableClientId(String),
139    /// The `client_id`'s host is not on `cimd.trusted_client_id_domains`.
140    UntrustedPublisher { host: String },
141    /// The fetch failed, was refused by the SSRF guard, timed out, answered a
142    /// non-success status, or returned more bytes than the cap allows.
143    Fetch(String),
144    /// The response was not JSON, or was not a client metadata document.
145    Malformed(String),
146    /// The document parsed but names a client this tenant will not admit.
147    Refused(String),
148}
149
150impl std::fmt::Display for CimdError {
151    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
152        match self {
153            Self::Disabled => {
154                write!(
155                    f,
156                    "client ID metadata documents are disabled for this tenant"
157                )
158            }
159            Self::UnusableClientId(d) => write!(f, "unusable client_id URL: {d}"),
160            Self::UntrustedPublisher { host } => write!(
161                f,
162                "{host} is not on this tenant's cimd.trusted_client_id_domains"
163            ),
164            Self::Fetch(d) => write!(f, "the metadata document could not be fetched: {d}"),
165            Self::Malformed(d) => write!(f, "the metadata document is not usable: {d}"),
166            Self::Refused(d) => write!(
167                f,
168                "the metadata document names a client this tenant will not admit: {d}"
169            ),
170        }
171    }
172}

180/// Whether a `client_id` is shaped like an absolute URL at all.
181///
182/// **The whole of I1's cost.** This runs on every authorization, PAR and token
183/// request in the deployment, so it is a `find` over at most a handful of
184/// bytes and it answers `false` for every `client_id` AXIAM has ever issued
185/// (`oa_` followed by hex). Only when it answers `true` does anything read a
186/// setting, and only then can a tenant's policy be consulted at all.
187///
188/// Deliberately looser than [`validate_client_id_url`]: this is the question
189/// "is this worth looking at", not "is this acceptable". A URL-shaped
190/// `client_id` that fails the real rules below is still an unknown client.
191pub fn looks_like_url(client_id: &str) -> bool {
192    // A scheme, "://", and something after it. `Url::parse` would also accept
193    // `mailto:` and other schemes that have no authority; those are not
194    // client_id URLs and are not worth a parse.
195    client_id.starts_with("https://") || client_id.starts_with("http://")
196}

198/// Validate a `client_id` as a metadata document URL, against the tenant's
199/// policy.
200///
201/// # The rules, and why each one is here
202///
203/// Keycloak's list, which the plan names as the reference behaviour, plus one
204/// of AXIAM's own:
205///
206/// * **`https` only**, unless the tenant set `cimd.allow_http`. The document
207///   *is* the registration; over plaintext it is rewritable in transit by
208///   anybody on the path, who would then be choosing this client's redirect
209///   URIs.
210/// * **A path is required.** `https://example.com` identifies a *host*, and a
211///   host is not a client: every party who can publish anything under that
212///   origin would otherwise be the same client.
213/// * **No `.` or `..` segments.** Two spellings of one document are two
214///   `client_id`s, two shadow rows, and two consent records for one client.
215/// * **No fragment, no query, no userinfo.** A fragment is not sent to the
216///   server, so it can only ever create a second spelling; a query makes the
217///   identifier's own equality depend on parameter order; userinfo puts a
218///   credential in a public identifier.
219/// * **The `client_id` must be its own canonical form.** AXIAM's own rule, and
220///   the one that makes the four above sufficient rather than merely
221///   necessary: the string is compared for equality against the document's own
222///   `client_id`, used as the key of a cache, and stored as the `client_id` of
223///   a row that a later request must find by exact match. If
224///   `https://Example.com/a` and `https://example.com/a` could both be
225///   presented, the three would not agree. Rejecting the non-canonical
226///   spelling is one comparison and removes the class.
227/// * **The host must be on `cimd.trusted_client_id_domains`.** See
228///   `CimdPolicy`: the fetch is reachable by an unauthenticated caller who
229///   chooses the URL.
230pub fn validate_client_id_url(client_id: &str, policy: &CimdPolicy) -> Result<Url, CimdError> {
231    let refuse = |why: &str| CimdError::UnusableClientId(format!("{client_id:?}: {why}"));
232
233    let url = Url::parse(client_id).map_err(|e| refuse(&e.to_string()))?;
234
235    match url.scheme() {
236        "https" => {}
237        "http" if policy.allow_http => {}
238        "http" => {
239            return Err(refuse(
240                "http is permitted only when the tenant sets cimd.allow_http, which is a \
241                 development posture",
242            ));
243        }
244        other => return Err(refuse(&format!("scheme {other:?} is not https"))),
245    }
246
247    if !url.username().is_empty() || url.password().is_some() {
248        return Err(refuse("a client_id URL must carry no userinfo"));
249    }
250    if url.query().is_some() {
251        return Err(refuse("a client_id URL must carry no query string"));
252    }
253    if url.fragment().is_some() {
254        return Err(refuse("a client_id URL must carry no fragment"));
255    }
256
257    let Some(host) = url.host_str().map(str::to_owned) else {
258        return Err(refuse("a client_id URL must name a host"));
259    };
260
261    let path = url.path();
262    if path.is_empty() || path == "/" {
263        return Err(refuse(
264            "a client_id URL must have a path component: an origin identifies a host, and a \
265             host is not a client",
266        ));
267    }
268    if path.split('/').any(|seg| seg == "." || seg == "..") {
269        return Err(refuse(
270            "a client_id URL must contain no . or .. path segment",
271        ));
272    }
273
274    if url.as_str() != client_id {
275        return Err(refuse(&format!(
276            "is not its own canonical form (it normalises to {:?}); present the canonical \
277             spelling, which is the one the document must also carry",
278            url.as_str()
279        )));
280    }
281
282    if !policy
283        .trusted_client_id_domains
284        .iter()
285        .any(|p| host_glob_matches(p, &host))
286    {
287        return Err(CimdError::UntrustedPublisher { host });
288    }
289
290    Ok(url)
291}

297/// A client metadata document, as fetched.
298///
299/// The members are RFC 7591 §2's, which the draft reuses. Everything AXIAM
300/// cannot act on is dropped by `serde`, exactly as it is for a registration
301/// request: RFC 7591 §2 requires a server to ignore metadata it does not
302/// understand, and `client_uri`, `logo_uri`, `contacts`, `tos_uri` and
303/// `policy_uri` all arrive from real clients.
304///
305/// There is no `software_statement` arm here, and its absence is not an
306/// oversight: a document *is* an assertion about the client, made at a URL the
307/// client controls, so a signed statement inside it would add a second,
308/// unverifiable claim. A document carrying one is admitted and the member
309/// ignored — unlike at the registration endpoint, where accepting one silently
310/// would have meant treating an unverified assertion as verified.
311#[derive(Debug, Clone, Deserialize)]
312pub struct ClientMetadataDocument {
313    /// The draft's one required member: the URL this document was fetched
314    /// from, restated by the document itself.
315    #[serde(default)]
316    pub client_id: Option<String>,
317    /// Shown to the end user on the consent screen D4 forces.
318    #[serde(default)]
319    pub client_name: Option<String>,
320    /// RFC 7591 §2 `redirect_uris`.
321    #[serde(default)]
322    pub redirect_uris: Vec<String>,
323    /// RFC 7591 §2 `grant_types`; absent means `["authorization_code"]`.
324    #[serde(default)]
325    pub grant_types: Option<Vec<String>>,
326    /// RFC 7591 §2 `response_types`; absent means `["code"]`.
327    #[serde(default)]
328    pub response_types: Option<Vec<String>>,
329    /// RFC 7591 §2 `token_endpoint_auth_method`; see
330    /// [`resolve_auth_method`] for why absent means `none` here and
331    /// `client_secret_basic` at the registration endpoint.
332    #[serde(default)]
333    pub token_endpoint_auth_method: Option<String>,
334    /// RFC 7591 §2 `scope`, space-delimited.
335    #[serde(default)]
336    pub scope: Option<String>,
337    /// RFC 7591 §2 `jwks` — an inline JWK Set, for `private_key_jwt`.
338    #[serde(default)]
339    pub jwks: Option<serde_json::Value>,
340    /// RFC 7591 §2 `jwks_uri`.
341    #[serde(default)]
342    pub jwks_uri: Option<String>,
343}
344
345/// Resolve the document's `token_endpoint_auth_method`.
346///
347/// **Absent means `none`**, where `dcr::resolve_auth_method` reads absent as
348/// RFC 7591 §2's `client_secret_basic`. The two defaults differ because the
349/// two situations do: a registration request is a conversation in which the
350/// server can mint a secret and hand it back, and a metadata document is a
351/// public file. There is no secret for a CIMD client to have and no channel to
352/// give it one on, so `client_secret_basic` here would not be a default, it
353/// would be a client that can never authenticate.
354fn resolve_auth_method(raw: Option<&str>) -> Result<ClientAuthMethod, CimdError> {
355    let Some(raw) = raw.map(str::trim).filter(|s| !s.is_empty()) else {
356        return Ok(ClientAuthMethod::None);
357    };
358    ClientAuthMethod::from_wire(raw)
359        .filter(|m| CIMD_AUTH_METHODS.contains(m))
360        .ok_or_else(|| {
361            CimdError::Refused(format!(
362                "token_endpoint_auth_method {raw:?} is not one a metadata document may name \
363                 (allowed: {}); a client whose registration is a public document cannot hold \
364                 a shared secret",
365                CIMD_AUTH_METHODS
366                    .iter()
367                    .map(|m| m.as_str())
368                    .collect::<Vec<_>>()
369                    .join(", ")
370            ))
371        })
372}

382/// Validate a fetched document against the `client_id` it claims to describe
383/// and the tenant's policy, and produce the row it becomes.
384///
385/// Pure: no clock, no database, no network. The caller has already decided
386/// that the tenant permits CIMD at all and that the URL is one this tenant
387/// will fetch.
388///
389/// # Order of refusals
390///
391/// Identity first. `client_id` inside the document must equal the URL it came
392/// from, because every check after that is about *this* client and is
393/// meaningless if the document is describing another one — a document copied
394/// from elsewhere, or served by a host that mirrors other people's files, is
395/// refused before its redirect URIs are ever read.
396pub fn validate(
397    tenant_id: Uuid,
398    client_id: &Url,
399    doc: &ClientMetadataDocument,
400    policy: &OidcPolicy,
401) -> Result<ValidatedCimdClient, CimdError> {
402    let cimd = &policy.cimd;
403    let client_id_str = client_id.as_str();
404
405    // --- identity -----------------------------------------------------------
406    match doc.client_id.as_deref() {
407        Some(stated) if stated == client_id_str => {}
408        Some(stated) => {
409            return Err(CimdError::Refused(format!(
410                "the document states client_id {stated:?} but was fetched from \
411                 {client_id_str:?}; a document describes the URL it lives at and nothing else"
412            )));
413        }
414        None => {
415            return Err(CimdError::Refused(
416                "the document states no client_id; the draft requires it, and without it a \
417                 document cannot be distinguished from one copied from another publisher"
418                    .into(),
419            ));
420        }
421    }
422
423    // --- redirect URIs ------------------------------------------------------
424    if doc.redirect_uris.is_empty() {
425        return Err(CimdError::Refused(
426            "redirect_uris must name at least one URI: every grant a CIMD client may hold is \
427             completed through a browser redirect"
428                .into(),
429        ));
430    }
431    let client_host = client_id.host_str().unwrap_or_default().to_owned();
432    for uri in &doc.redirect_uris {
433        let parsed = Url::parse(uri).map_err(|_| {
434            CimdError::Refused(format!("redirect_uri {uri:?} is not a valid absolute URI"))
435        })?;
436        let host = parsed
437            .host_str()
438            .ok_or_else(|| {
439                CimdError::Refused(format!("redirect_uri {uri:?} has no host component"))
440            })?
441            .to_owned();
442        let loopback = is_loopback_host(&host);
443        match parsed.scheme() {
444            "https" => {}
445            // RFC 8252 §7.3. A loopback callback never leaves the machine the
446            // person is sitting at, which is why every desktop MCP client uses
447            // one and why plaintext on it is not a transport exposure.
448            "http" if loopback => {}
449            other => {
450                return Err(CimdError::Refused(format!(
451                    "redirect_uri {uri:?} uses scheme {other:?}: a CIMD client's callback must \
452                     be https, or http on a loopback host (RFC 8252 section 7.3)"
453                )));
454            }
455        }
456        if parsed.fragment().is_some() {
457            return Err(CimdError::Refused(format!(
458                "redirect_uri {uri:?} carries a fragment, which RFC 6749 section 3.1.2 forbids"
459            )));
460        }
461        if !redirect_host_is_allowed(&cimd.trusted_redirect_domains, &host) {
462            return Err(CimdError::Refused(format!(
463                "the host {host:?} is not one this tenant accepts a CIMD redirect for; an \
464                 administrator sets cimd.trusted_redirect_domains (loopback is always allowed)"
465            )));
466        }
467        // The same-domain rule, which is why the desktop profiles turn it off:
468        // a loopback callback can never share a host with an `https` client_id.
469        if cimd.restrict_same_domain && !host.eq_ignore_ascii_case(&client_host) {
470            return Err(CimdError::Refused(format!(
471                "redirect_uri {uri:?} is on {host:?}, and this tenant requires every redirect \
472                 to be on the client_id's own host ({client_host:?}). A client with a loopback \
473                 callback needs cimd.restrict_same_domain off"
474            )));
475        }
476    }
477
478    // --- grants and response types -----------------------------------------
479    if let Some(types) = &doc.response_types
480        && let Some(bad) = types.iter().find(|t| t.trim() != "code")
481    {
482        return Err(CimdError::Refused(format!(
483            "response_type {bad:?} is not supported; this server issues authorization codes only"
484        )));
485    }
486
487    let grant_types: Vec<String> = match &doc.grant_types {
488        None => vec!["authorization_code".to_owned()],
489        Some(requested) => {
490            for g in requested {
491                if !DCR_GRANT_TYPES.contains(&g.trim()) {
492                    return Err(CimdError::Refused(format!(
493                        "grant_type {g:?} is not one a CIMD client may hold (allowed: {}); both \
494                         absent grants mint a token on the strength of the client's own \
495                         identity, and the identity of a CIMD client is a file a stranger \
496                         publishes",
497                        DCR_GRANT_TYPES.join(", ")
498                    )));
499                }
500            }
501            if !requested.iter().any(|g| g.trim() == "authorization_code") {
502                return Err(CimdError::Refused(
503                    "grant_types must include authorization_code: refresh_token alone would \
504                     describe a client that can refresh a token it cannot obtain"
505                        .into(),
506                ));
507            }
508            requested.iter().map(|g| g.trim().to_owned()).collect()
509        }
510    };
511
512    // --- client authentication ---------------------------------------------
513    let token_endpoint_auth_method =
514        resolve_auth_method(doc.token_endpoint_auth_method.as_deref())?;
515    if cimd.confidential_only && token_endpoint_auth_method.is_public() {
516        return Err(CimdError::Refused(
517            "this tenant admits only confidential CIMD clients (cimd.confidential_only), and \
518             this document names token_endpoint_auth_method: none"
519                .into(),
520        ));
521    }
522    if token_endpoint_auth_method == ClientAuthMethod::PrivateKeyJwt {
523        let sources = usize::from(doc.jwks.is_some()) + usize::from(doc.jwks_uri.is_some());
524        if sources != 1 {
525            return Err(CimdError::Refused(format!(
526                "private_key_jwt requires exactly one of jwks or jwks_uri (RFC 7591 section 2); \
527                 the document names {sources}"
528            )));
529        }
530        if let Some(uri) = doc.jwks_uri.as_deref() {
531            let parsed = Url::parse(uri).map_err(|_| {
532                CimdError::Refused(format!("jwks_uri {uri:?} is not an absolute URL"))
533            })?;
534            if parsed.scheme() != "https" {
535                return Err(CimdError::Refused(format!(
536                    "jwks_uri {uri:?} must be https: AXIAM fetches it to obtain the keys that \
537                     authenticate this client"
538                )));
539            }
540        }
541    } else if doc.jwks.is_some() || doc.jwks_uri.is_some() {
542        // The same consistency rule `fapi::validate_registration` applies to a
543        // public registration: a client that authenticates with nothing does
544        // not also register a key, and a document saying both says two
545        // different things about which credential the token endpoint should
546        // want.
547        return Err(CimdError::Refused(
548            "a document naming token_endpoint_auth_method: none may not also register jwks or \
549             jwks_uri; a public client authenticates with nothing"
550                .into(),

552    }

557    // named for DCR because DCR defined it; what it means is "what an
558    // externally registered client may ask for", and a CIMD client is one.
559    // `validate_dcr_policy` already refuses `address` and `phone` on that

578        .client_name
579        .as_deref()
580        .map(str::trim)
581        .filter(|n| !n.is_empty())
582        .map_or_else(|| client_id_str.to_owned(), str::to_owned);

586            tenant_id,
587            name,

595            // from a stranger's file can never carry a FAPI profile;
596            // `fapi::validate_registration` refuses the combination too, so
597            // this is the first of two gates rather than the only one.
598            profile: ClientProfile::Standard,

600            tls_client_auth_subject_dn: None,
601            tls_client_auth_san_dns: None,
602            tls_client_auth_san_uri: None,
603            self_signed_tls_client_auth_thumbprints: Vec::new(),
604            tls_client_certificate_bound_access_tokens: false,

607            dpop_bound_access_tokens: false,

609            authn_request_params: AuthnRequestParamsMode::Ignore,
610            browser_sso: false,

638/// One cached document.
639#[derive(Debug, Clone)]
640pub struct CachedDocument {
641    /// The document as fetched and parsed.
642    pub document: ClientMetadataDocument,
643    /// When it was last fetched successfully.
644    pub fetched_at: DateTime<Utc>,
645    /// How long it may be served for, already clamped to the tenant's bounds
646    /// and to the deployment constants.
647    pub ttl_secs: u64,
648}

650/// Process-wide client-metadata-document cache, keyed by
651/// `(tenant_id, client_id URL)`.
652///
653/// Modelled on `axiam_federation::jwks_cache::JwksCache` — the same TTL, the
654/// same stale-while-revalidate discipline, the same shared SSRF guard — with
655/// three differences that the threat demands:
656///
657/// 1. **The TTL is not a constant.** It comes from the document's own
658///    `Cache-Control`, clamped to the tenant's `min_cache_secs` and
659///    `max_cache_secs` and then to the deployment's own floor and ceiling. A
660///    publisher may ask to be re-read sooner or trusted longer, within bounds
661///    the publisher does not set.
662/// 2. **The key includes the tenant.** Two tenants that both admit the same
663///    document get their own entries, because they may have different bounds,
664///    different trusted domains and different resource lists, and a cache
665///    shared across them would let one tenant's policy decide another's.
666/// 3. **Nothing negative is cached.** A refusal costs a fetch next time, which
667///    is the right way round: caching a refusal would let one bad minute at a
668///    publisher lock its users out for the length of a TTL they did not
669///    choose.
670/// 4. **Entries nobody can be served are evicted** (T21.8 / MCP-04), on the
671///    insert path, so a cache miss pays for it and a hit does not. An entry
672///    past its TTL *and* past [`STALE_WINDOW_SECS`] cannot be returned by
673///    either branch of [`ClientMetadataCache::get_or_fetch`], so dropping it
674///    changes no answer and keeps the map bounded by what is still live rather
675///    than by every URL a stranger has ever named.
676///
677/// Per process, not per worker: it lives in `AppState` and is cloned (an `Arc`
678/// clone) into every actix worker, exactly as the JWKS cache is.
679#[derive(Clone, Default)]
680pub struct ClientMetadataCache(Arc<RwLock<HashMap<(Uuid, String), CachedDocument>>>);
681
682impl ClientMetadataCache {
683    /// A new, empty cache.
684    pub fn new() -> Self {
685        Self(Arc::new(RwLock::new(HashMap::new())))
686    }

688    /// Return the document for `client_id`, fetching it if the cache has
689    /// nothing fresh.
690    ///
691    /// 1. Cache hit within TTL → return it, no HTTP.
692    /// 2. Miss or expired → fetch through the SSRF guard.
693    ///    * Success → store and return.
694    ///    * Failure with an entry inside [`STALE_WINDOW_SECS`] past its TTL →
695    ///      serve stale with a WARN, exactly as the JWKS cache does.
696    ///    * Failure with nothing usable → the error.
697    pub async fn get_or_fetch(
698        &self,
699        tenant_id: Uuid,
700        client_id: &Url,
701        policy: &CimdPolicy,
702    ) -> Result<ClientMetadataDocument, CimdError> {
703        let key = (tenant_id, client_id.as_str().to_owned());
704        let now = Utc::now();
705
706        {
707            let guard = self.0.read().await;
708            if let Some(entry) = guard.get(&key)
709                && entry.fetched_at + chrono::Duration::seconds(entry.ttl_secs as i64) > now
710            {
711                return Ok(entry.document.clone());
712            }
713        }
714
715        match fetch_document(client_id, policy).await {
716            Ok((document, ttl_secs)) => {
717                let mut guard = self.0.write().await;
718                // T21.8 / MCP-04 — evict what can no longer be served before
719                // inserting. Without this the map grows by one entry per
720                // distinct trusted URL an unauthenticated caller can name and
721                // never shrinks, which is the same finding as the unswept
722                // shadow rows, in RAM: a cache that is never evicted is not a
723                // cache.
724                //
725                // On the insert path only, so a cache hit stays a read lock
726                // and the common request pays nothing. O(n) under the write
727                // lock, and n is bounded by the prune itself — an entry past
728                // its TTL *and* past the stale window can be served to
729                // nobody, by either branch of this function, so dropping it
730                // changes no answer. Not a per-tenant cap: the quota in
731                // `axiam-api-rest`'s `materialise_if_cimd` refuses before the
732                // fetch that would populate this map.
733                guard.retain(|_, entry| {
734                    entry.fetched_at
735                        + chrono::Duration::seconds(entry.ttl_secs as i64)
736                        + chrono::Duration::seconds(STALE_WINDOW_SECS)
737                        > now
738                });
739                guard.insert(
740                    key,
741                    CachedDocument {
742                        document: document.clone(),
743                        fetched_at: now,
744                        ttl_secs,
745                    },
746                );
747                Ok(document)
748            }
749            Err(fetch_err) => {
750                let guard = self.0.read().await;
751                if let Some(entry) = guard.get(&key)
752                    && entry.fetched_at
753                        + chrono::Duration::seconds(entry.ttl_secs as i64)
754                        + chrono::Duration::seconds(STALE_WINDOW_SECS)
755                        > now
756                {
757                    tracing::warn!(
758                        client_id = %client_id,
759                        error = %fetch_err,
760                        "serving a stale client ID metadata document while its publisher is \
761                         unreachable"
762                    );
763                    return Ok(entry.document.clone());
764                }
765                Err(fetch_err)
766            }
767        }
768    }

770    /// Test-only seam: move an entry's `fetched_at` backwards, so a test can
771    /// reach the expiry and stale-window branches without sleeping.
772    ///
773    /// A seam rather than an injected clock because the clock is read in one
774    /// place and the alternative — threading a `now` through every caller —
775    /// would put a test parameter on a security-relevant API.
776    #[doc(hidden)]
777    pub async fn backdate_for_test(&self, tenant_id: Uuid, client_id: &str, by_secs: i64) -> bool {
778        let mut guard = self.0.write().await;
779        match guard.get_mut(&(tenant_id, client_id.to_owned())) {

784            None => false,

806/// Fetch and parse one document. Returns it with the TTL it earned.
807///
808/// Every outbound property is the shared guard's: resolution, IPv4-mapped
809/// canonicalisation, the private-address refusal, the pinning of the validated
810/// address into the connection, the refusal to follow a redirect without
811/// re-running all of it, the hop limit and the request timeout. This function
812/// adds exactly three things on top — a status check, a content-type check and
813/// a streaming byte cap — and each is the caller-side half of a control the
814/// guard cannot make for us.
815async fn fetch_document(
816    client_id: &Url,
817    policy: &CimdPolicy,
818) -> Result<(ClientMetadataDocument, u64), CimdError> {
819    // `allow_private` is the guard's test/development seam and is tied here to
820    // `cimd.allow_http`, because the guard refuses a plaintext scheme on the
821    // same flag that admits a private address. That coupling is stated on
822    // `CimdPolicy::allow_http` and in the operator documentation: a deployment
823    // that allows http has also stopped refusing 169.254.169.254 on the first
824    // hop. Redirect hops are validated strictly regardless.
825    let response =
826        axiam_federation::ssrf::guarded_fetch(client_id.as_str(), policy.allow_http, |c, u| {
827            c.get(u).header(reqwest::header::ACCEPT, "application/json")
828        })
829        .await
830        .map_err(|e| CimdError::Fetch(e.to_string()))?;
831
832    let status = response.status();
833    if !status.is_success() {
834        return Err(CimdError::Fetch(format!("the publisher answered {status}")));
835    }
836
837    // A document served as `text/html` is a login page, an error page or a
838    // single-page application — not a registration. Checked before the body is
839    // read so that an HTML response is refused rather than parsed.
840    let content_type = response
841        .headers()
842        .get(reqwest::header::CONTENT_TYPE)
843        .and_then(|v| v.to_str().ok())
844        .unwrap_or_default()
845        .to_owned();
846    if !is_json_content_type(&content_type) {
847        return Err(CimdError::Malformed(format!(
848            "the publisher served Content-Type {content_type:?}; a client ID metadata document \
849             is application/json"
850        )));
851    }
852
853    let advertised = max_age_secs(
854        response
855            .headers()
856            .get(reqwest::header::CACHE_CONTROL)
857            .and_then(|v| v.to_str().ok()),
858    );
859    let ttl_secs = policy.clamp_cache_secs(advertised);
860
861    // The hard cap, applied while reading rather than after: a chunked
862    // response with no `Content-Length` bypasses the guard's coarse header
863    // check entirely, and buffering it first is precisely the memory
864    // exhaustion this bound exists to prevent.
865    let body =
866        axiam_federation::ssrf::read_capped_body(response, policy.effective_max_metadata_bytes())
867            .await
868            .map_err(|e| CimdError::Fetch(e.to_string()))?;
869
870    let document = serde_json::from_slice::<ClientMetadataDocument>(&body)
871        .map_err(|e| CimdError::Malformed(e.to_string()))?;
872
873    Ok((document, ttl_secs))
874}

876/// Whether a `Content-Type` names JSON.
877///
878/// `application/json`, with or without parameters, and the `+json` structured
879/// suffix (RFC 6839) — a publisher serving
880/// `application/client-metadata+json` is serving JSON and saying what kind.
881/// Anything else is refused.
882fn is_json_content_type(raw: &str) -> bool {
883    let essence = raw
884        .split(';')
885        .next()
886        .unwrap_or_default()
887        .trim()
888        .to_ascii_lowercase();
889    essence == "application/json" || essence.ends_with("+json")
890}

892/// The `max-age` of a `Cache-Control` header, if it names one.
893///
894/// Only `max-age`. `no-store` and `no-cache` are **not** honoured, and that is
895/// deliberate: they would ask AXIAM to re-fetch on every authorization
896/// request, which is the amplification `min_cache_secs` exists to bound. A
897/// publisher that sends them gets the floor, which is also what a publisher
898/// that sends nothing gets.
899fn max_age_secs(header: Option<&str>) -> Option<u64> {
900    let header = header?;
901    header.split(',').find_map(|directive| {
902        let directive = directive.trim();
903        let value = directive
904            .strip_prefix("max-age")
905            .or_else(|| directive.strip_prefix("Max-Age"))?
906            .trim_start()
907            .strip_prefix('=')?
908            .trim()
909            .trim_matches('"');
910        value.parse::<u64>().ok()
911    })
912}

918/// Decide whether a `client_id` is a CIMD client at all, and if so produce the
919/// row it becomes.
920///
921/// The order is the whole of I1 and most of the abuse surface:
922///
923/// 1. **Is it URL-shaped?** A string comparison. Every `client_id` AXIAM has
924///    ever issued stops here, having read no setting and touched no network.
925/// 2. **Is CIMD on for this tenant?** The caller has read the policy by now;
926///    `enabled` false answers [`CimdError::Disabled`] and nothing else runs.
927/// 3. **Is the URL usable, and is its publisher trusted?** Pure, and before
928///    any fetch, so an untrusted host costs a parse rather than a connection.
929/// 4. **Fetch, cached.** Behind the SSRF guard and the cache bounds.
930/// 5. **Does the document describe a client this tenant admits?** Pure.
931pub async fn resolve(
932    cache: &ClientMetadataCache,
933    tenant_id: Uuid,
934    client_id: &str,
935    policy: &OidcPolicy,
936) -> Result<ValidatedCimdClient, CimdError> {
937    if !policy.cimd.enabled {
938        return Err(CimdError::Disabled);
939    }
940    let url = validate_client_id_url(client_id, &policy.cimd)?;
941    let document = cache.get_or_fetch(tenant_id, &url, &policy.cimd).await?;
942    validate(tenant_id, &url, &document, policy)
943}

1442    /// **T21.8 / MCP-04.** An entry nobody can be served is gone after the
1443    /// next insert.
1444    ///
1445    /// Without this the map grows by one entry per distinct trusted URL an
1446    /// unauthenticated caller can name and never shrinks. The eviction runs on
1447    /// the insert path only, which is why another document has to be fetched
1448    /// for a dead entry to disappear — and why a cache *hit* still costs only
1449    /// a read lock.
1450    ///
1451    /// The boundary asserted is TTL **plus** the stale window: inside it the
1452    /// entry is still servable by `get_or_fetch`'s failure branch, so evicting
1453    /// it would change an answer. Past it, no branch can return it.
1454    #[tokio::test]
1455    async fn an_unservable_cache_entry_is_evicted_on_the_next_insert() {
1456        let server = MockServer::start().await;
1457        let tenant = Uuid::new_v4();
1458        let policy = loopback_policy(&server);
1459        let cache = ClientMetadataCache::new();
1460
1461        let url_of = |n: &str| {
1462            let id = format!("{}/{n}.json", server.uri());
1463            (id.clone(), Url::parse(&id).unwrap())
1464        };
1465        let (one_id, one) = url_of("one");
1466        let (two_id, two) = url_of("two");
1467        let (three_id, three) = url_of("three");
1468        let (four_id, four) = url_of("four");
1469
1470        for (doc_path, id) in [
1471            ("/one.json", &one_id),
1472            ("/two.json", &two_id),
1473            ("/three.json", &three_id),
1474            ("/four.json", &four_id),
1475        ] {
1476            serve_at(&server, doc_path, id).await;
1477        }
1478
1479        cache.get_or_fetch(tenant, &one, &policy).await.unwrap();
1480
1481        // A second, unrelated document. The first entry is still live, so both
1482        // are held: the eviction drops what is dead, not what is merely old.
1483        cache.get_or_fetch(tenant, &two, &policy).await.unwrap();
1484        assert_eq!(
1485            cache.len_for_test().await,
1486            2,
1487            "a live entry is not evicted by another document's fetch"
1488        );
1489
1490        // Move the first entry past its TTL but *inside* the stale window. It
1491        // is still servable, so it must survive.
1492        assert!(
1493            cache
1494                .backdate_for_test(tenant, &one_id, 601 + STALE_WINDOW_SECS / 2)
1495                .await
1496        );
1497        cache.get_or_fetch(tenant, &three, &policy).await.unwrap();
1498        assert_eq!(
1499            cache.len_for_test().await,
1500            3,
1501            "an entry inside the stale window can still be served and must not be evicted"
1502        );

1504        // Past the stale window: unservable by either branch, so gone.
1505        assert!(
1506            cache
1507                .backdate_for_test(tenant, &one_id, STALE_WINDOW_SECS)
1508                .await
1509        );

1512            cache.ttl_for_test(tenant, &one_id).await,
1513            None,
1514            "an entry past its TTL and its stale window is evicted on the next insert"

1516        assert_eq!(
1517            cache.len_for_test().await,
1518            3,
1519            "and the map shrank rather than only losing a lookup"
