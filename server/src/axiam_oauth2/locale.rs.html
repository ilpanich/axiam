1//! The presentation parameters of an authentication request (W5, plan §4.6 —
2//! G6/G7), as types rather than as strings.
3//!
4//! `ui_locales` and `display` are the two cosmetic parameters that *do*
5//! something. Neither changes what a token means — a relying party cannot
6//! detect whether either was honoured by inspecting anything it receives —
7//! which is why they are refused on no honest `fapi2` row and why the plan
8//! files them away from the security-bearing five. What they do change is a
9//! page a human is about to type a password into, and that is the whole reason
10//! they are modelled here instead of being forwarded as the strings they
11//! arrived as.
12//!
13//! # Why the raw value never leaves the server
14//!
15//! `ui_locales` is a space-separated list chosen by the relying party. The
16//! obvious implementation forwards it to the sign-in page and lets the page
17//! decide; the page then holds an attacker-chosen string, and every later edit
18//! that renders it — a "language not available" notice, a `lang` attribute, a
19//! debug banner — is a reflected-XSS bug waiting for someone to write it.
20//!
21//! So the match happens here, and what crosses to the SPA is a
22//! [`Locale`] — one of five values this binary knows the names of. Test T6.2
23//! (`ui_locales=<img onerror=…>` appears in no redirect the server builds) is
24//! then true *by construction*: there is no code path along which the raw
25//! value could be written into a URL, because the only thing the builder
26//! accepts is this enum. It is not true because someone remembered to escape
27//! it, and it does not become false when the next person forgets.
28//!
29//! [`Display`] is the same argument with four values instead of five.
30//!
31//! # `claims_locales` is not here, on purpose
32//!
33//! OIDC Core §3.1.2.1 defines `claims_locales` beside `ui_locales`, one letter
34//! of prefix apart, with the same BCP 47 syntax. It selects the language of
35//! **claim values** — a `name` in Japanese, an `address` in French — and AXIAM
36//! has no localised claims at all, so it is accepted and ignored
37//! (`OIDCCClaimsLocales` asks only that it not be an error).
38//!
39//! The thing to guard against is not that ignoring it is wrong; it is that the
40//! two names are adjacent and the values are interchangeable-looking, so a
41//! future edit reaching for "the locale the RP asked for" can reach for the
42//! wrong one and be visibly correct in review. Nothing in this module reads
43//! `claims_locales`, no caller passes it here, and
44//! `crate::login_hop::build_login_redirect_for` has no parameter it could
45//! arrive through. There is a test in `crate::honour`'s wave pinning that
46//! `claims_locales=it` alone leaves the page in the deployment default.
47//!
48//! # The list is short on purpose
49//!
50//! Five languages, each translated completely in the SPA
51//! (`frontend/src/i18n/`). A sixth added here without its bundle would make
52//! `ui_locales=pt` *succeed* and then deliver English, which is worse than
53//! answering "no match" and delivering English for a stated reason:
54//! `scripts/check-locale-bundle-sync.py` fails the build when this enum and
55//! the SPA's catalogue disagree, in either direction.
56

59/// A language the sign-in page is fully translated into.
60///
61/// The variants are the allow-list. There is no constructor from an arbitrary
62/// string that does not go through [`Locale::from_tag`], and nothing outside
63/// this module can add a sixth.
64#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
65pub enum Locale {
66    /// English — the deployment default, and what the absence of any selection
67    /// means everywhere in this feature.
68    English,
69    /// Italian.
70    Italian,
71    /// French.
72    French,
73    /// German.
74    German,
75    /// Spanish.
76    Spanish,
77}
78
79/// Every locale, in the order the documentation and the SPA list them.
80///
81/// Public because the sync gate and the discovery-adjacent documentation both
82/// need to enumerate the list, and a second hand-written copy of it is the
83/// thing this constant exists to prevent.
84pub const ALL_LOCALES: [Locale; 5] = [
85    Locale::English,
86    Locale::Italian,
87    Locale::French,
88    Locale::German,
89    Locale::Spanish,
90];
91
92/// What AXIAM falls back to when nothing else selects a language.
93///
94/// Named rather than spelled `Locale::English` at each call site: "the
95/// deployment default" and "English" are the same value today and are not the
96/// same *idea*, and a deployment that changed one should not silently change
97/// the other.
98pub const DEPLOYMENT_DEFAULT: Locale = Locale::English;
99
100impl Locale {
101    /// The BCP 47 language tag, lower-case, as it appears in a URL and in the
102    /// SPA's catalogue key.
103    pub const fn as_tag(self) -> &'static str {
104        match self {
105            Self::English => "en",
106            Self::Italian => "it",
107            Self::French => "fr",
108            Self::German => "de",
109            Self::Spanish => "es",
110        }
111    }
112
113    /// The language's own name for itself, for an operator-facing list.
114    ///
115    /// Endonyms rather than English names: a language picker that offers
116    /// "German" to somebody who reads only German has picked the wrong
117    /// audience for its own labels.
118    pub const fn endonym(self) -> &'static str {
119        match self {
120            Self::English => "English",
121            Self::Italian => "Italiano",
122            Self::French => "Français",
123            Self::German => "Deutsch",
124            Self::Spanish => "Español",
125        }
126    }
127
128    /// Parse one complete language tag. Case-insensitive; exact otherwise.
129    ///
130    /// BCP 47 tags are case-insensitive (RFC 5646 §2.1.1), so `EN`, `En` and
131    /// `en` are one tag and answering differently would make the match depend
132    /// on a relying party's house style. No truncation happens here — that is
133    /// [`select_ui_locale`]'s job, and keeping the two apart is what lets this
134    /// function also be the parser for a stored tenant default, where
135    /// `fr-CA` in the column should mean "somebody wrote something this
136    /// binary does not ship" rather than "French".
137    pub fn from_tag(raw: &str) -> Option<Self> {
138        let tag = raw.trim();
139        ALL_LOCALES
140            .into_iter()
141            .find(|locale| locale.as_tag().eq_ignore_ascii_case(tag))
142    }
143}
144
145impl fmt::Display for Locale {
146    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
147        f.write_str(self.as_tag())
148    }
149}

151/// The `display` values OIDC Core §3.1.2.1 defines.
152///
153/// A closed set for the same reason [`Locale`] is one: the value reaches a
154/// sign-in page, and the only safe thing to hand a page is a value the page
155/// could have named itself. Anything outside the set is dropped — OIDC Core
156/// makes `display` a hint, and an OP that refused an unknown hint would be
157/// refusing a request it can answer perfectly well.
158#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
159pub enum Display {
160    /// A full page. The default, and what every other value also gets.
161    Page,
162    /// A popup window: the one value that changes the layout.
163    Popup,
164    /// A touch device.
165    Touch,
166    /// A feature phone ("WAP"). Modelled because the specification defines it,
167    /// and mapped to the default layout because AXIAM ships no WML.
168    Wap,
169}
170
171impl Display {
172    /// The wire spelling.
173    pub const fn as_str(self) -> &'static str {
174        match self {
175            Self::Page => "page",
176            Self::Popup => "popup",
177            Self::Touch => "touch",
178            Self::Wap => "wap",
179        }
180    }
181
182    /// Parse a `display` value; `None` for anything outside the four.
183    pub fn from_wire(raw: &str) -> Option<Self> {
184        match raw.trim() {
185            "page" => Some(Self::Page),
186            "popup" => Some(Self::Popup),
187            "touch" => Some(Self::Touch),
188            "wap" => Some(Self::Wap),
189            _ => None,
190        }
191    }
192
193    /// Whether this asks for the compact layout.
194    ///
195    /// The plan's mapping in one place: `popup` is compact, everything else is
196    /// the default. The SPA holds the CSS; this is the decision, so that "the
197    /// allow-list" is one list and not two that could come to disagree.
198    pub const fn is_compact(self) -> bool {
199        matches!(self, Self::Popup)
200    }
201}
202
203impl fmt::Display for Display {
204    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
205        f.write_str(self.as_str())
206    }
207}

209/// Select the sign-in page's language for one authorization request.
210///
211/// `requested` is the raw `ui_locales` value — a space-separated list of BCP 47
212/// tags in the relying party's **preference order** — and `tenant_default` is
213/// the tenant's configured language, if it set one and if it names a locale
214/// this binary ships.
215///
216/// Returns the locale to forward, or `None` when nothing was selected. `None`
217/// and [`DEPLOYMENT_DEFAULT`] mean the same page: the SPA renders English when
218/// it is told nothing, so a request that selects English is a request that
219/// needs no parameter, and one fewer parameter in a URL is one fewer thing to
220/// get wrong. That is also what makes T6.2 checkable by inspection — a value
221/// that matches nothing produces no parameter at all.
222///
223/// # The matching rule
224///
225/// RFC 4647 §3.4 *lookup*, applied per requested tag, and the requested tags
226/// are tried **in the order the relying party wrote them**. So
227/// `ui_locales=zz it fr` selects Italian, not French: the first tag that
228/// matches anything wins, rather than the best match found anywhere in the
229/// list. That mirrors the "most-preferred satisfied, in RP order" rule W4
230/// pinned for `acr_values` ([`crate::acr::report_acr`]) — one preference rule
231/// for the whole authorization request rather than one per parameter.
232///
233/// Within a tag, lookup progressively truncates at `-`: `fr-CA` tries `fr-CA`
234/// then `fr`; `de-AT-1996` tries `de-AT-1996`, `de-AT`, `de`. A trailing
235/// single-character subtag is removed with the one before it, as §3.4 requires,
236/// so a private-use tag cannot truncate to a bare `x`.
237///
238/// The input is bounded to [`crate::authn_params::MAX_HINT_LEN`] bytes by the
239/// parser, so the two nested loops here are bounded by that and need no
240/// separate limit.
241pub fn select_ui_locale(requested: Option<&str>, tenant_default: Option<Locale>) -> Option<Locale> {
242    requested
243        .and_then(lookup)
244        // No tag matched — or none was sent. The tenant's own default is the
245        // next answer, and the deployment default (English, i.e. `None`) is
246        // the last.
247        .or(tenant_default)
248}
249
250/// RFC 4647 §3.4 lookup over the whole requested list. See
251/// [`select_ui_locale`] for the rule this implements.
252fn lookup(requested: &str) -> Option<Locale> {
253    for tag in requested.split_ascii_whitespace() {
254        let mut candidate = tag;
255        loop {
256            if let Some(locale) = Locale::from_tag(candidate) {
257                return Some(locale);
258            }
259            let Some(cut) = candidate.rfind('-') else {
260                break;
261            };
262            candidate = &candidate[..cut];
263            // §3.4 step 3: a truncation that leaves a single-character subtag
264            // at the end must remove that too, so `en-x-private` cannot become
265            // the meaningless `en-x` and then `en` by a different route than
266            // the one the specification describes.
267            if let Some(cut) = candidate.rfind('-')
268                && candidate.len() - cut == 2
269            {
270                candidate = &candidate[..cut];
271            }
272            if candidate.is_empty() {
273                break;
274            }
275        }
276    }
277    None
278}

284    /// **T6.1**, the exact-match half, plus the case-insensitivity BCP 47
285    /// requires.
286    #[test]
287    fn an_exact_tag_selects_its_locale_whatever_its_case() {
288        for (requested, expected) in [
289            ("en", Locale::English),
290            ("it", Locale::Italian),
291            ("fr", Locale::French),
292            ("de", Locale::German),
293            ("es", Locale::Spanish),
294            ("IT", Locale::Italian),
295            ("De", Locale::German),
296        ] {
297            assert_eq!(
298                select_ui_locale(Some(requested), None),
299                Some(expected),
300                "{requested:?} must select {expected:?}"
301            );
302        }
303    }

305    /// **T6.1**, the subtag-fallback half. RFC 4647 lookup truncates at `-`
306    /// until something matches.
307    #[test]
308    fn a_region_or_variant_subtag_falls_back_to_the_language() {
309        for (requested, expected) in [
310            ("fr-CA", Locale::French),
311            ("de-AT-1996", Locale::German),
312            ("es-419", Locale::Spanish),
313            ("it-IT", Locale::Italian),

321        }

324    /// A private-use singleton must not survive truncation on its own.
325    #[test]
326    fn a_trailing_single_character_subtag_is_removed_with_the_one_before_it() {
327        assert_eq!(
328            select_ui_locale(Some("de-x-private"), None),
329            Some(Locale::German)
330        );
331        // `x` alone matches nothing and must not loop forever either.
332        assert_eq!(select_ui_locale(Some("x"), None), None);
333        assert_eq!(select_ui_locale(Some("x-y-z"), None), None);
334        assert_eq!(select_ui_locale(Some("-"), None), None);
335        assert_eq!(select_ui_locale(Some("---"), None), None);
336    }

338    /// **T6.1**, the preference-order half — the rule that mirrors W4's
339    /// `acr_values`: the first *requested* tag that matches wins, not the best
340    /// match found in the list.
341    #[test]
342    fn the_first_requested_tag_that_matches_wins_in_the_rps_order() {
343        assert_eq!(
344            select_ui_locale(Some("zz it fr"), None),
345            Some(Locale::Italian),
346            "the RP put Italian before French"
347        );
348        assert_eq!(
349            select_ui_locale(Some("zz fr it"), None),
350            Some(Locale::French),
351            "…and the other order selects the other language"
352        );
353        // A more specific tag later in the list does not outrank an exact
354        // match earlier in it.
355        assert_eq!(
356            select_ui_locale(Some("de fr-CA"), None),
357            Some(Locale::German)
358        );
359    }

361    /// **T6.1**, the fallback chain: no match → tenant default → deployment
362    /// default (which is `None`, i.e. "forward nothing").
363    #[test]
364    fn nothing_matched_falls_through_to_the_tenant_then_the_deployment_default() {
365        assert_eq!(
366            select_ui_locale(Some("zz qq"), Some(Locale::Italian)),
367            Some(Locale::Italian)
368        );
369        assert_eq!(select_ui_locale(Some("zz qq"), None), None);
370        assert_eq!(
371            select_ui_locale(None, Some(Locale::Spanish)),
372            Some(Locale::Spanish)

375        // A tenant default never overrides a tag that did match.
376        assert_eq!(

378            Some(Locale::French)

405    /// The one shape that *does* contain a valid tag inside something hostile:

416    /// Every tag this type can emit is URL-safe and lower-case, which is what
417    /// lets the redirect builder write it without a second thought — and what
418    /// the sync gate compares against the SPA's catalogue keys.
419    #[test]
420    fn every_tag_is_a_short_lowercase_ascii_identifier() {
421        for locale in ALL_LOCALES {
422            let tag = locale.as_tag();
423            assert!(
424                tag.chars().all(|c| c.is_ascii_lowercase()),
425                "{tag:?} must be lower-case ASCII"
426            );
427            assert_eq!(tag.len(), 2, "{tag:?}");
428            assert_eq!(
429                Locale::from_tag(tag),
430                Some(locale),
431                "{tag:?} must round-trip"
432            );
433            assert!(!locale.endonym().is_empty());
434        }
435        // The list has no duplicates: a repeated tag would make the sync gate
436        // and the SPA's exhaustive record disagree about how many there are.
437        let mut tags: Vec<&str> = ALL_LOCALES.iter().map(|l| l.as_tag()).collect();
438        tags.sort_unstable();
439        let before = tags.len();
440        tags.dedup();
441        assert_eq!(tags.len(), before, "ALL_LOCALES must not repeat a tag");
442    }
