1//! G-A — native sign-in with a provider ID token: the grant (W2.3).
2//!
3//! Design: `claude_dev/social-login-gap-plan-2026-10-30.md` §3.1, D-N1, D-N6.
4//! The rule the whole feature applies:
5//!
6//! > **An ID token is accepted as a sign-in only when it was issued to us.**
7//!
8//! `axiam-federation`'s `native_login` decides *whether* a provider ID token
9//! proves a sign-in and *who* signed in (§3.1 steps 2–7). This module turns
10//! that answer into the client's ordinary sign-in token set (step 8) and owns
11//! the gate in front of it (step 1). The token endpoint dispatches here and
12//! writes the audit record (step 9).
13//!
14//! # The wire
15//!
16//! `POST /oauth2/token` with
17//! `grant_type=`[`PROVIDER_ID_TOKEN_GRANT_TYPE`], `provider` (the federation
18//! provider's UUID or `provider_slug`), `id_token`, `nonce` (the raw nonce the
19//! app generated; the provider's SDK was given its SHA-256 hex, which is what
20//! the token carries — D-N16), optional `scope` and RFC 8707 `resource`, and
21//! the client's usual authentication — a public (mobile) client sends
22//! `client_id` only.
23//!
24//! # Why a vendor URN, and this one
25//!
26//! The grant is AXIAM's own: no IETF or OIDF registry defines "sign in with a
27//! third party's ID token" as a grant, and RFC 8693 is the wrong shape (X4
28//! refuses ID tokens by design; §3.1). RFC 6749 §4.5 extension grants are
29//! named by absolute URI, and the tree already has exactly one vendor grant
30//! URN, `urn:axiam:params:oauth:grant-type:may-impersonate`
31//! (`crate::token_exchange::MAY_IMPERSONATE_GRANT`). This one follows it
32//! segment for segment, so the two read as one family and no new namespace is
33//! opened. Nothing else in the tree, the SDK contract or the discovery
34//! document spells `provider-id-token`.
35//!
36//! # Order, and what each step may write
37//!
38//! 1. **The client** is read and authenticates by its registered method — a
39//!    public client by presenting nothing, a confidential one by its
40//!    credential ([`TokenService::authenticate_provider_id_token_client`]).
41//!    The profile's request-time rules run (`fapi::enforce_token_request`),
42//!    the registration must list the grant (`unauthorized_client`
43//!    otherwise), and the binding the registration asks for (`cnf`: DPoP,
44//!    certificate) is decided — refused, not downgraded, when the request
45//!    cannot satisfy it. The REST layer then applies the
46//!    `oauth2_provider_id_token` bucket. Nothing has been written.
47//! 2. **The request**: `provider`, `id_token` and `nonce` present; `scope`
48//!    within the client's registered set (after the external-client ceiling);
49//!    `resource` one the client may address
50//!    ([`TokenService::prepare_provider_id_token_grant`]). Still nothing
51//!    written, so a malformed request does not spend the token.
52//! 3. **Steps 2–7** run in `axiam-federation` (the provider, the signature,
53//!    the claims, the shape, the replay record, the user). Every refusal is
54//!    one `invalid_grant` on the wire ([`refusal_for`]). The token endpoint
55//!    then fires `login.post_auth` for the resolved user (CONTRACT §22,
56//!    F4-W2-01) — the gate every interactive sign-in passes — and a veto is
57//!    the same `invalid_grant`.
58//! 4. **Consent** (D-N6): a scope that would need a consent ceremony is
59//!    `consent_required` ([`decide_consent`]) — there is nobody to ask on
60//!    this request, so it is answered as `prompt=none` is at `/authorize`.
61//! 5. **Issue** ([`TokenService::issue_provider_id_token_grant`]): a session
62//!    recording the federated authentication, the access token, a refresh
63//!    token when the client holds `refresh_token`, and an ID token carrying
64//!    the request's nonce when `openid` was granted.
65//!
66//! # The session, and what it records
67//!
68//! A federated *browser* sign-in creates a session whose evidence is
69//! `AuthenticationEvidence::upstream(auth_time, now, [fed])`, and a code
70//! issued from it carries that session in `sid` and that evidence onward.
71//! The native sign-in records the same: one session row with the provider's
72//! `auth_time` (clamped to now) and `amr = [fed]`, no browser cookie, and a
73//! console refresh credential nobody is given. The access token names it in
74//! `sid`, so UserInfo and the session-validated API admit the token, ending
75//! the session (logout, password reset, an administrator's revocation) ends
76//! the tokens, and the user's session list shows the device. No claim is new.
77//!
78//! "Ends the tokens" includes the refresh token (D-N39, #839): a single-session
79//! logout (`AuthService::logout`, behind `/auth/logout`, RP-initiated logout
80//! and SAML single logout) revokes every refresh token issued under the
81//! session, and the user-wide revocations revoke all of the user's. The token
82//! endpoint records the client as a participant of the session it creates
83//! ([`NativeSignIn::session_id`]), so back-channel logout reaches a client
84//! that registered a `backchannel_logout_uri`.

126/// The longest `nonce` the grant accepts, in bytes (F4-W2-09).
127///
128/// The nonce is hashed and echoed into the signed AXIAM ID token, so it is
129/// bounded like every other caller-supplied value that reaches a token. A
130/// nonce is a random value: 512 bytes is sixteen times the 32 random bytes a
131/// careful app generates, hex- or base64-encoded with room to spare, and the
132/// same bound `native_login` puts on a listed client ID.
133pub const MAX_NONCE_BYTES: usize = 512;

135/// Whether a client's registration lists this grant.
136pub fn holds_provider_id_token_grant(grant_types: &[String]) -> bool {
137    grant_types
138        .iter()
139        .any(|g| g == PROVIDER_ID_TOKEN_GRANT_TYPE)
140}

142/// The three grant parameters, borrowed from the request, or
143/// `invalid_request` naming the first one that is missing or empty, or a
144/// `nonce` longer than [`MAX_NONCE_BYTES`].
145///
146/// # Errors
147///
148/// `invalid_request` when `provider`, `id_token` or `nonce` is absent or
149/// empty, or `nonce` is too long.
150pub fn native_request(req: &TokenRequest) -> Result<NativeIdTokenRequest<'_>, OAuth2Error> {
151    fn required<'a>(value: Option<&'a String>, name: &str) -> Result<&'a str, OAuth2Error> {
152        value
153            .map(String::as_str)
154            .filter(|v| !v.trim().is_empty())
155            .ok_or_else(|| {
156                OAuth2Error::InvalidRequest(format!(
157                    "{name} is required for the provider-id-token grant"
158                ))
159            })
160    }
161    let request = NativeIdTokenRequest {
162        provider: required(req.provider.as_ref(), "provider")?,
163        id_token: required(req.id_token.as_ref(), "id_token")?,
164        nonce: required(req.nonce.as_ref(), "nonce")?,
165    };
166    if request.nonce.len() > MAX_NONCE_BYTES {
167        return Err(OAuth2Error::InvalidRequest(format!(
168            "nonce must be at most {MAX_NONCE_BYTES} bytes"
169        )));
170    }
171    Ok(request)
172}

174/// The scopes this grant issues: the requested ones, each of which must be
175/// in the client's registered set.
176///
177/// The result is the intersection of the request with the registration, and
178/// a requested scope outside it is **refused** (`invalid_scope`) rather than
179/// dropped — the rule `/oauth2/authorize` applies to the same registration,
180/// so a scope that would be refused there is not quietly narrowed away here.
181/// An absent or empty `scope` is the empty set, as at `/authorize`: no
182/// `openid`, so no ID token. Order is the request's; duplicates collapse.
183///
184/// `registered` is the client's set after the external-client ceiling.
185///
186/// # Errors
187///
188/// `invalid_scope` naming every requested scope the client is not registered
189/// for.
190pub fn requested_scopes(
191    raw: Option<&str>,
192    registered: &[String],
193) -> Result<Vec<String>, OAuth2Error> {
194    let mut scopes: Vec<String> = Vec::new();
195    for scope in raw.unwrap_or("").split_whitespace() {
196        if !scopes.iter().any(|s| s == scope) {
197            scopes.push(scope.to_owned());
198        }
199    }
200    let unregistered: Vec<&str> = scopes
201        .iter()
202        .filter(|s| !registered.contains(s))
203        .map(String::as_str)
204        .collect();
205    if !unregistered.is_empty() {
206        return Err(OAuth2Error::InvalidScope(format!(
207            "unregistered scopes: {}",
208            unregistered.join(", ")
209        )));
210    }
211    Ok(scopes)
212}

214/// What the REST layer resolved about the consent this sign-in's scopes need,
215/// for the user [`NativeSubject`] named.
216///
217/// The same two questions `/oauth2/authorize` asks, resolved by the same
218/// functions over the same records — this crate decides, it does not fetch.
219/// The default is the state of a request from an administrator's client
220/// asking for nothing sensitive.
221#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
222pub struct ConsentState {
223    /// W7: the GDPR-sensitive scopes (`address`, `phone`).
224    pub sensitive: crate::sensitive::Requested,
225    /// W7: the tenant's effective settings have the sensitive scopes off.
226    pub sensitive_switch_off: bool,
227    /// T21.4 / D4: an externally registered client acting as the user.
228    pub external: crate::external_consent::Requested,
229}
230
231/// What [`decide_consent`] and [`refuse_switched_off_sensitive_scopes`] answer
232/// for the GDPR-sensitive scopes the tenant has switched off.
233const SENSITIVE_SWITCHED_OFF: &str = "the address and phone scopes are not enabled for this tenant";
234
235/// F4-W2-05 (D-N14): the tenant's sensitive-scope switch does not depend on
236/// the user, so it is decided with the other request checks, before the
237/// provider token is verified and spent. `switched_off` is true when the
238/// request asks for `address` or `phone` and the tenant's effective settings
239/// have them off.
240///
241/// # Errors
242///
243/// `invalid_scope`, worded as [`decide_consent`] words it.
244pub fn refuse_switched_off_sensitive_scopes(switched_off: bool) -> Result<(), OAuth2Error> {
245    if switched_off {
246        Err(OAuth2Error::InvalidScope(SENSITIVE_SWITCHED_OFF.into()))
247    } else {
248        Ok(())
249    }
250}
251
252/// D-N6: refuse any scope that would need a consent ceremony.
253///
254/// This grant has no interaction to offer — no browser, no consent screen —
255/// so it is decided exactly as an `/authorize` request carrying `prompt=none`
256/// on its first leg: what is consented (or needs no consent, which the
257/// client's registration decides as it does today) proceeds, and what would
258/// need the screen is `consent_required`. There is no implicit-consent switch
259/// for first-party clients; that is a separate decision (D-N6).
260///
261/// # Errors
262///
263/// `invalid_scope` when the sensitive scopes are switched off for the tenant;
264/// `consent_required` when a consent record is missing.
265pub fn decide_consent(state: ConsentState) -> Result<(), OAuth2Error> {
266    use crate::external_consent as external;
267    use crate::sensitive;
268
269    match sensitive::decide(state.sensitive, state.sensitive_switch_off, false, true) {
270        sensitive::Decision::Proceed => {}
271        // Reached only if the switch changed between the early check and
272        // here; the early check is what normally answers it.
273        sensitive::Decision::Refuse(sensitive::Refusal::Disabled) => {
274            return Err(OAuth2Error::InvalidScope(SENSITIVE_SWITCHED_OFF.into()));
275        }
276        // `AskForConsent` cannot come back with `prompt_none`, and `Declined`
277        // cannot without a consent leg; both are answered as what they would
278        // need — a ceremony this grant cannot hold.
279        sensitive::Decision::AskForConsent
280        | sensitive::Decision::Refuse(
281            sensitive::Refusal::ConsentRequired | sensitive::Refusal::Declined,
282        ) => {
283            return Err(OAuth2Error::ConsentRequired(
284                "releasing the requested scopes needs the end user's consent, which this grant \
285                 cannot ask for; obtain it through an authorization request first"
286                    .into(),
287            ));
288        }
289    }
290    match external::decide(state.external, false, true) {
291        external::Decision::Proceed => Ok(()),
292        external::Decision::AskForConsent | external::Decision::Refuse(_) => {
293            Err(OAuth2Error::ConsentRequired(
294                "this client was not registered by an administrator of this tenant, so the end \
295                 user must consent before it may act as them, which this grant cannot ask for; \
296                 obtain it through an authorization request first"
297                    .into(),
298            ))
299        }
300    }
301}

303/// What the wire sees for a refusal of §3.1 steps 2–7.
304///
305/// One `invalid_grant` with [`PUBLIC_REFUSAL_DESCRIPTION`] for every refusal
306/// about the token or the configuration — a wrong token and a wrong
307/// configuration are told apart only in the server log and the audit record
308/// ([`NativeLoginError::reason_code`]) — and one generic `server_error` for a
309/// datastore failure, the replay store's included.
310pub fn refusal_for(e: &NativeLoginError) -> OAuth2Error {
311    match e.refusal() {
312        NativeLoginRefusal::InvalidGrant => {
313            OAuth2Error::InvalidGrant(PUBLIC_REFUSAL_DESCRIPTION.into())
314        }
315        NativeLoginRefusal::ServerError => {
316            OAuth2Error::ServerError(SERVER_REFUSAL_DESCRIPTION.into())
317        }
318    }
319}

388impl<OC, AC, TR, RT, UR, SA, SR, AR> TokenService<OC, AC, TR, RT, UR, SA, SR, AR>
389where
390    OC: OAuth2ClientRepository,
391    SA: ServiceAccountRepository,
392    AC: AuthorizationCodeRepository,
393    TR: TenantRepository,
394    RT: RefreshTokenRepository,
395    UR: UserRepository,
396    SR: SessionRepository,
397    AR: AuditLogRepository,
398{
399    /// Step 1: authenticate the client of a provider-id-token request and
400    /// decide its token binding.
401    ///
402    /// A public client authenticates by presenting nothing and is refused if
403    /// it presents a credential; a confidential one by the method its
404    /// registration names (SEC-093). After authentication, and only then, the
405    /// profile's request-time rules run and the grant must be registered —
406    /// so `unauthorized_client` is learnt only by the credential's holder
407    /// (SEC-086's ordering). The binding is decided last: a client registered
408    /// for DPoP- or certificate-bound tokens whose request carries no proof
409    /// is refused here, before the provider token is looked at.
410    ///
411    /// # Errors
412    ///
413    /// `invalid_request` without a `client_id`; `invalid_client` for an
414    /// unknown client, a failed credential, a tombstoned tenant or an
415    /// unsatisfiable binding; the codes of `fapi::enforce_token_request`;
416    /// `unauthorized_client` for a client not registered for the grant.
417    pub async fn authenticate_provider_id_token_client(
418        &self,
419        tenant_id: Uuid,
420        req: &TokenRequest,
421        ctx: &TokenRequestContext,
422    ) -> Result<ProviderIdTokenClient, OAuth2Error> {
423        let client_id = resolve_client_id(req.client_id.as_deref(), ctx)?;
424        let client_secret = req.client_secret.as_deref();
425        let refused = || OAuth2Error::InvalidClient(CLIENT_AUTH_FAILED.into());
426        let client = match self
427            .client_repo
428            .get_by_client_id(tenant_id, client_id)
429            .await
430        {
431            Ok(client) => client,
432            Err(AxiamError::NotFound { .. }) => {
433                // #679: a refusal costs the verify a wrong secret costs.
434                spend_one_verify(client_secret, ctx);
435                return Err(refused());
436            }
437            // QUAL-03/D-11: a datastore fault is not bad client credentials.
438            Err(other) => return Err(OAuth2Error::ServerError(other.to_string())),
439        };
440        // Defence in depth: the lookup is tenant-scoped in SQL.
441        if client.tenant_id != tenant_id {
442            spend_one_verify(client_secret, ctx);
443            return Err(refused());
444        }
445        // The public arm inside refuses a credential presented by a public
446        // client; a confidential client with none is refused as a wrong one.
447        let tenant = self
448            .authenticate_client_credential(tenant_id, &client, client_secret, ctx)
449            .await?;
450        crate::fapi::enforce_token_request(&client, ctx.evidence())?;
451        if !holds_provider_id_token_grant(&client.grant_types) {
452            return Err(OAuth2Error::UnauthorizedClient(
453                "client is not registered for the provider-id-token grant".into(),
454            ));
455        }
456        let cnf = self.certificate_binding_for(&client, ctx)?;
457        Ok(ProviderIdTokenClient {
458            client,
459            organization_id: tenant.organization_id,
460            cnf,
461        })
462    }
463
464    /// Step 2: the request's own parameters, decided before the provider token
465    /// is verified — so a malformed request does not spend it.
466    ///
467    /// The scopes are checked against the client's registered set after the
468    /// tenant's external-client ceiling (#613), and the RFC 8707 `resource`
469    /// against its `allowed_resources`, exactly as `/oauth2/authorize` checks
470    /// both.
471    ///
472    /// # Errors
473    ///
474    /// `invalid_request` for a missing grant parameter; `invalid_scope`;
475    /// `invalid_target`; `server_error` when an external client's ceiling
476    /// cannot be read.
477    pub async fn prepare_provider_id_token_grant(
478        &self,
479        client: ProviderIdTokenClient,
480        req: &TokenRequest,
481    ) -> Result<ProviderIdTokenGrant, OAuth2Error> {
482        native_request(req)?;
483        let mut client = client;
484        crate::scope_ceiling::apply_to_client(self.scope_policy.as_ref(), &mut client.client)
485            .await?;
486        let scopes = requested_scopes(req.scope.as_deref(), &client.client.scopes)?;
487        let resource = crate::resource::resolve_requested(
488            &client.client.allowed_resources,
489            req.resource.as_deref(),
490        )?;
491        Ok(ProviderIdTokenGrant {
492            client,
493            scopes,
494            resource,
495        })
496    }
497
498    /// Steps 4 and 5 (§3.1 step 8): decide consent, then issue the client's
499    /// ordinary sign-in token set for the user the provider token signed in.
500    ///
501    /// `nonce` is the request's raw nonce, which the AXIAM ID token carries
502    /// back when `openid` was granted. Evidence (`auth_time`, `amr = [fed]`,
503    /// and the class it earns) is recorded on the session and the refresh
504    /// token whatever the client's lane, and released in the ID token only to
505    /// a client on the lane that emits it — the code flow's rule.
506    ///
507    /// # Errors
508    ///
509    /// `invalid_scope` / `consent_required` from [`decide_consent`];
510    /// `invalid_grant` when a reactor vetoes issuance; `server_error` for a
511    /// datastore or signing failure.
512    #[allow(clippy::too_many_arguments)]
513    pub async fn issue_provider_id_token_grant(
514        &self,
515        tenant_id: Uuid,
516        grant: &ProviderIdTokenGrant,
517        subject: &NativeSubject,
518        nonce: &str,
519        consent: ConsentState,
520        origin: SignInOrigin,
521        ctx: &TokenRequestContext,
522    ) -> Result<NativeSignIn, OAuth2Error> {
523        decide_consent(consent)?;
524        if subject.tenant_id != tenant_id {
525            // The federation service resolves users in the requesting tenant
526            // only; a subject from anywhere else is an inconsistency, refused.
527            return Err(OAuth2Error::ServerError(
528                "native sign-in resolved a subject outside the requesting tenant".into(),
529            ));
530        }
531        let client = &grant.client.client;
532        let user_id = subject.user_id;
533
534        // X1 — the `token.pre_issue` hook, before anything is written, so a
535        // veto leaves no session behind.
536        let ext = self
537            .pre_issue_ext_claims(
538                tenant_id,
539                &user_id.to_string(),
540                "user",
541                &client.client_id,
542                &grant.scopes,
543            )
544            .await?;
545
546        // The session the federated browser sign-in would have created, with
547        // the same evidence: the provider's `auth_time` clamped to now (D-10)
548        // and `fed` alone (X7.2).
549        let now = Utc::now();
550        let evidence =
551            AuthenticationEvidence::upstream(subject.upstream_auth_time, now, vec![Amr::Fed]);
552        let session = self
553            .session_repo
554            .create(CreateSession {
555                tenant_id,
556                user_id,
557                // The console refresh credential of this session, which nobody
558                // is given: the client refreshes through its OAuth2 refresh
559                // token, and `/auth/refresh` can never rotate this row.
560                token_hash: hash_refresh_token(&generate_refresh_token()),
561                ip_address: origin.ip_address,
562                user_agent: origin.user_agent,
563                expires_at: now + chrono::Duration::seconds(self.refresh_token_lifetime_secs),
564                authenticated_at: evidence.authenticated_at,
565                amr: evidence.amr.clone(),
566                // No browser, so no `axiam_op_session` cookie to match.
567                browser_token_hash: None,
568                lineage_id: None,
569            })
570            .await
571            .map_err(|e| OAuth2Error::ServerError(e.to_string()))?;
572
573        // W4 — the class this evidence earns, recorded only for a client on
574        // the honour lane, as the authorization code records it.
575        let acr = crate::fapi::honours_authn_params(client)
576            .then(|| crate::acr::acr_for(&evidence.amr).as_str().to_owned());
577
578        let cnf = grant.client.cnf.clone();
579        let token_type = crate::dpop::token_type_for(cnf.as_ref());
580        // #681 — a public DPoP client's refresh token is bound to its key.
581        let refresh_jkt = crate::dpop::refresh_token_binding(client, cnf.as_ref());
582        let audience = grant
583            .resource
584            .as_deref()
585            .unwrap_or(axiam_auth::token::AUD_USER)
586            .to_owned();
587        let minting = self.minting_config(ctx.issuer.as_deref());
588        let access_token = axiam_auth::token::AccessTokenSpec::user(
589            user_id,
590            tenant_id,
591            grant.client.organization_id,
592            Uuid::new_v4().to_string(),
593        )
594        .aud(&audience)
595        .scopes(&grant.scopes)
596        .cnf(cnf)
597        .ext(ext)
598        .client_id(Some(&client.client_id))
599        .session(Some(session.id))
600        .issue(&minting)
601        .map_err(|e| OAuth2Error::ServerError(e.to_string()))?;
602
603        let refresh_token = if client.grant_types.iter().any(|g| g == "refresh_token") {
604            let raw_refresh = generate_refresh_token();
605            self.refresh_token_repo
606                .create(CreateRefreshToken {
607                    tenant_id,
608                    token_hash: hash_refresh_token(&raw_refresh),
609                    client_id: client.client_id.clone(),
610                    user_id: Some(user_id),
611                    scopes: grant.scopes.clone(),
612                    session_id: Some(session.id),
613                    requested_userinfo_claims: Vec::new(),
614                    // RFC 8707 — the target travels with the grant.
615                    resource: grant.resource.clone(),
616                    // D-9 — the authentication this grant descends from, so a
617                    // refreshed ID token reports the original.
618                    auth_time: Some(evidence.authenticated_at),
619                    acr: acr.clone(),
620                    amr: evidence.amr.clone(),
621                    dpop_jkt: refresh_jkt,
622                    expires_at: now + chrono::Duration::seconds(self.refresh_token_lifetime_secs),
623                    lineage_id: None,
624                })
625                .await
626                .map_err(|e| OAuth2Error::ServerError(e.to_string()))?;
627            Some(raw_refresh)
628        } else {
629            None
630        };
631
632        let id_token = if grant.scopes.iter().any(|s| s == "openid") {
633            let user = self
634                .user_repo
635                .get_by_id(tenant_id, user_id)
636                .await
637                .map_err(|e| OAuth2Error::ServerError(e.to_string()))?;
638            let claims_evidence = if crate::fapi::emits_session_evidence(client) {
639                super::evidence_from_snapshot(
640                    Some(evidence.authenticated_at),
641                    acr.as_deref(),
642                    &evidence.amr,
643                )
644            } else {
645                IdTokenEvidence::NONE
646            };
647            Some(
648                issue_id_token(
649                    user_id,
650                    &client.client_id,
651                    Some(nonce),
652                    Some(&user.username),
653                    &grant.scopes,
654                    &minting,
655                    Some(session.id),
656                    &claims_evidence,
657                )
658                .map_err(|e| OAuth2Error::ServerError(e.to_string()))?,
659            )
660        } else {
661            None
662        };
663
664        Ok(NativeSignIn {
665            response: TokenResponse {
666                access_token,
667                token_type,
668                expires_in: self.auth_config.access_token_lifetime_secs,
669                refresh_token,
670                scope: (!grant.scopes.is_empty()).then(|| grant.scopes.join(" ")),
671                id_token,
672            },
673            session_id: session.id,
674        })
675    }
