1//! Certificate revocation lists — one per issuing CA (RFC 5280 §5; #565,
2//! T-102).
3//!
4//! Revoking a certificate sets the status on its row. Until this module that
5//! status reached exactly the places that read the row — device sign-in, and
6//! since the same change OAuth2 `tls_client_auth` — and nowhere else: a
7//! relying party that validates AXIAM-issued certificates itself, a FreeRADIUS
8//! server doing EAP-TLS or a VPN gateway, had no channel through which to learn
9//! of a revocation, although every AXIAM CA carries the `cRLSign` bit.
10//!
11//! # What is published
12//!
13//! A complete, version 2 CRL per issuing CA, DER-encoded, at
14//! `GET /pki/v1/{org_id}/ca/{ca_id}/crl` ([`crl_path`]), unauthenticated:
15//!
16//! - **signed with the CA's own key, fetched from the CA's own custodian** —
17//!   the custodian the CA row names, through the same `load` the leaf path
18//!   uses, so an RSA-4096 CA and an Ed25519 CA sign their lists exactly as they
19//!   sign certificates;
20//! - `thisUpdate` the moment it was signed, `nextUpdate` a configurable
21//!   interval later ([`DEFAULT_CRL_NEXT_UPDATE_SECS`]) and never past the CA's
22//!   own `notAfter`;
23//! - a CRL number and an authority key identifier equal to the CA's subject key
24//!   identifier — the two extensions RFC 5280 §5.2 requires of every CRL;
25//! - an entry for every certificate the CA signed and revoked that has not yet
26//!   expired: its leaves in every tenant, and the subordinate CAs it signed, so
27//!   an organization CA's list names a revoked tenant signing CA. Each entry
28//!   carries the serial read out of the certificate and the date AXIAM recorded
29//!   the revocation. No reason code: AXIAM does not record one, and RFC 5280
30//!   §5.3.1 prefers an absent reason to `unspecified`.
31//!
32//! # Which CAs publish one
33//!
34//! A CA AXIAM can sign with, while it is active and in date. Three kinds
35//! answer `404` instead, the same `404` as a CA that does not exist:
36//!
37//! - **a revoked or expired CA.** AXIAM signs nothing with one; its own status
38//!   is on its parent's list;
39//! - **an imported trust anchor with no key** (`external` custody): it cannot
40//!   sign anything, a list included;
41//! - **a CA whose key Vault's PKI engine holds** (`vault_pki`). Vault signs on
42//!   AXIAM's behalf only certificate requests; it has no operation that signs a
43//!   list AXIAM composed, and AXIAM never holds the key. Vault publishes that
44//!   CA's list itself, and AXIAM revokes each leaf there too
45//!   ([`crate::CertService::revoke`], T-470), so Vault's list names it. Leaves of
46//!   such a CA carry no AXIAM distribution point — Vault issues them with its
47//!   own profile, naming whatever the operator configured on the mount
48//!   (`config/urls`) — so nothing points at a route that cannot answer, and
49//!   relying parties read Vault's list (`/v1/<mount>/issuer/<issuer>/crl/der`).
50//!
51//! # Signing on request, and the cache in front of it
52//!
53//! A list is signed when it is first asked for and kept, per CA, until either
54//! the set of revoked certificates changes or half of its validity has passed;
55//! every request still reads the set, so a revocation is in the next response.
56//! Two things follow. A relying party revalidating with `If-None-Match` gets a
57//! `304` until the list really changes, because an unchanged list is the same
58//! bytes. And a flood of requests costs one database read each and no
59//! signature, which matters on an unauthenticated route whose custodian may be
60//! a Vault round trip away.
61//!
62//! The CRL number is the signing time in milliseconds since the Unix epoch,
63//! and strictly greater than the last number this process issued for the CA.
64//! Monotonic across replicas and restarts for as long as the clocks are, which
65//! is what RFC 5280 §5.2.3 asks of it, without a counter every replica would
66//! have to agree on.
67//!
68//! # The distribution point
69//!
70//! [`CrlDistribution`] is the absolute URL of the route, built from the
71//! deployment's public base URL. `CertService` and `CaService` write it into
72//! every certificate they sign in-process from then on — leaves on both paths,
73//! and subordinate CAs — so a relying party that follows distribution points
74//! finds the list without being told. With no public base URL there is no
75//! absolute URL to write, and the extension is omitted; the composition root
76//! says so at boot.

100/// The media type a DER CRL is served as (RFC 5280 §4.2.1.13).
101pub const CRL_MEDIA_TYPE: &str = "application/pkix-crl";
102
103/// Default interval between a list's `thisUpdate` and its `nextUpdate`: one
104/// day. Env: `AXIAM__PKI__CRL_NEXT_UPDATE_SECS`.
105///
106/// It bounds how long a relying party that caches a list honours a certificate
107/// revoked after the list was fetched, which is the revocation window this
108/// whole module exists to shorten. A day is the common choice for a CA whose
109/// relying parties fetch on schedule; a deployment that needs a shorter window
110/// sets a shorter interval and pays for it in fetches.
111pub const DEFAULT_CRL_NEXT_UPDATE_SECS: u64 = 86_400;
112
113/// Shortest accepted interval: five minutes. Below it a relying party would
114/// spend more time fetching the list than trusting it.
115pub const MIN_CRL_NEXT_UPDATE_SECS: u64 = 300;
116
117/// Longest accepted interval: seven days. Past it the list stops being a
118/// revocation channel anybody should rely on.
119pub const MAX_CRL_NEXT_UPDATE_SECS: u64 = 604_800;
120
121/// The route a CA's list is published at, relative to the deployment's public
122/// base URL.
123pub fn crl_path(organization_id: Uuid, ca_id: Uuid) -> String {
124    format!("/pki/v1/{organization_id}/ca/{ca_id}/crl")
125}
126
127/// Check an operator's `nextUpdate` interval against
128/// [`MIN_CRL_NEXT_UPDATE_SECS`] and [`MAX_CRL_NEXT_UPDATE_SECS`].
129pub fn validate_next_update_secs(secs: u64) -> Result<u64, String> {
130    if (MIN_CRL_NEXT_UPDATE_SECS..=MAX_CRL_NEXT_UPDATE_SECS).contains(&secs) {
131        Ok(secs)
132    } else {
133        Err(format!(
134            "the CRL nextUpdate interval must be between {MIN_CRL_NEXT_UPDATE_SECS} and \
135             {MAX_CRL_NEXT_UPDATE_SECS} seconds, not {secs}"
136        ))
137    }
138}

140/// Where a relying party finds a CA's list: the absolute URL written into the
141/// CRL distribution points extension of every certificate signed after it is
142/// configured.
143#[derive(Debug, Clone, PartialEq, Eq)]
144pub struct CrlDistribution {
145    /// `scheme://host[:port][/path]`, with no trailing slash.
146    base: String,
147}
148
149impl CrlDistribution {
150    /// Validate a public base URL: absolute, `http` or `https`, with a host and
151    /// no query or fragment.
152    ///
153    /// `http` is accepted on purpose. A CRL is signed, so the transport adds no
154    /// integrity, and RFC 5280 §4.2.1.13 expects distribution points that a
155    /// relying party can fetch before it can validate anything — some cannot
156    /// follow an `https` one without the chain they are trying to check.
157    pub fn new(base_url: &str) -> Result<Self, String> {
158        let trimmed = base_url.trim();
159        let parsed = url::Url::parse(trimmed)
160            .map_err(|e| format!("the CRL base URL is not an absolute URL: {e}"))?;
161        if !matches!(parsed.scheme(), "http" | "https") {
162            return Err(format!(
163                "the CRL base URL must be http or https, not {}",
164                parsed.scheme()
165            ));
166        }
167        if parsed.host_str().is_none_or(str::is_empty) {
168            return Err("the CRL base URL has no host".into());
169        }
170        if parsed.query().is_some() || parsed.fragment().is_some() {
171            return Err("the CRL base URL must carry no query or fragment".into());
172        }
173        Ok(Self {
174            base: trimmed.trim_end_matches('/').to_owned(),
175        })
176    }
177
178    /// The distribution point configured explicitly, or else the one derived
179    /// from the deployment's issuer URL — `None` when neither is an absolute
180    /// `http(s)` URL.
181    ///
182    /// An explicit value that does not parse is an error rather than a
183    /// fallback: an operator who set one meant it, and certificates naming the
184    /// issuer instead would point somewhere they did not choose. An issuer that
185    /// is not a URL (the JWT `iss` fallback is often a bare name) yields `None`.
186    pub fn resolve(explicit: Option<&str>, issuer_url: &str) -> Result<Option<Self>, String> {
187        match explicit.map(str::trim).filter(|v| !v.is_empty()) {
188            Some(value) => Self::new(value).map(Some),
189            None => Ok(Self::new(issuer_url).ok()),
190        }
191    }
192
193    /// The absolute URL of a CA's list.
194    pub fn uri_for(&self, organization_id: Uuid, ca_id: Uuid) -> String {
195        format!("{}{}", self.base, crl_path(organization_id, ca_id))
196    }
197
198    /// The extension value for a certificate `issuer` signs.
199    pub(crate) fn point_for(&self, issuer: &CaCertificate) -> CrlDistributionPoint {
200        CrlDistributionPoint {
201            uris: vec![self.uri_for(issuer.organization_id, issuer.id)],
202        }
203    }
204}

206/// A signed list, as the route serves it.
207#[derive(Debug, Clone)]
208pub struct PublishedCrl {
209    /// The DER encoding.
210    pub der: Arc<[u8]>,
211    /// The list's `thisUpdate`.
212    pub this_update: DateTime<Utc>,
213    /// The list's `nextUpdate`.
214    pub next_update: DateTime<Utc>,
215    /// The list's CRL number.
216    pub crl_number: u64,
217    /// A strong entity tag over the DER, quoted.
218    pub etag: String,
219}
220
221impl PublishedCrl {
222    /// Seconds a cache may keep this list: until its `nextUpdate`, never
223    /// negative.
224    pub fn max_age_secs(&self, now: DateTime<Utc>) -> u64 {
225        u64::try_from((self.next_update - now).num_seconds().max(0)).unwrap_or(0)
226    }
227
228    /// Whether an `If-None-Match` header names this list (RFC 9110 §13.1.2):
229    /// `*`, or any listed tag equal to [`Self::etag`], weak or strong.
230    pub fn matches_if_none_match(&self, header: &str) -> bool {
231        let wanted = self.etag.trim_start_matches("W/");
232        header
233            .split(',')
234            .map(str::trim)
235            .any(|candidate| candidate == "*" || candidate.trim_start_matches("W/") == wanted)
236    }
237}

239/// What the cache keeps per CA.
240struct CachedCrl {
241    crl: PublishedCrl,
242    /// Digest of the entries the list was signed over.
243    entries_digest: [u8; 32],
244    /// When the list is re-signed even if nothing was revoked: half-way to its
245    /// `nextUpdate`, so a cached response always has half its life left.
246    refresh_at: DateTime<Utc>,
247}

249/// Signs and caches each issuing CA's certificate revocation list.
250#[derive(Clone)]
251pub struct CrlService<CA, CR> {
252    ca_repo: CA,
253    cert_repo: CR,
254    /// Shared bounding semaphore for CPU-bound crypto (CQ-B02).
255    crypto_semaphore: Arc<Semaphore>,
256    /// Who holds the CA signing keys. See [`crate::ca_key_store`].
257    custodians: Arc<CaKeyCustodians>,
258    next_update: Duration,
259    cache: Arc<Mutex<HashMap<Uuid, CachedCrl>>>,
260}
261
262impl<CA: CaCertificateRepository, CR: CertificateRepository> CrlService<CA, CR> {
263    /// `next_update_secs` is the `thisUpdate` → `nextUpdate` interval; the
264    /// composition root validates it with [`validate_next_update_secs`].
265    pub fn new(
266        ca_repo: CA,
267        cert_repo: CR,
268        crypto_semaphore: Arc<Semaphore>,
269        custodians: Arc<CaKeyCustodians>,
270        next_update_secs: u64,
271    ) -> Self {
272        Self {
273            ca_repo,
274            cert_repo,
275            crypto_semaphore,
276            custodians,
277            next_update: Duration::seconds(i64::try_from(next_update_secs).unwrap_or(i64::MAX)),
278            cache: Arc::default(),
279        }
280    }
281
282    /// The current list of CA `ca_id` of organization `organization_id`.
283    ///
284    /// `NotFound` for a CA that does not exist in that organization **and** for
285    /// one that publishes no list (see the module docs): the route is
286    /// unauthenticated, and which of the two it is — or which custodian holds a
287    /// key — is not an outsider's business. The reason is logged.
288    pub async fn current(&self, organization_id: Uuid, ca_id: Uuid) -> AxiamResult<PublishedCrl> {
289        let not_published = || AxiamError::NotFound {
290            entity: "certificate revocation list".into(),
291            id: ca_id.to_string(),
292        };
293
294        // Organization-scoped, as every CA lookup is (T-98): a CA id under the
295        // wrong organization is not found, not served.
296        let ca = match self.ca_repo.get_by_id(organization_id, ca_id).await {
297            Ok(ca) => ca,
298            Err(AxiamError::NotFound { .. }) => return Err(not_published()),
299            Err(e) => return Err(e),
300        };
301        let now = Utc::now();
302        if let Some(reason) = Self::why_unpublished(&ca, now) {
303            tracing::debug!(%organization_id, %ca_id, reason, "no CRL is published for this CA");
304            return Err(not_published());
305        }
306        let store = self.custodians.store_for(ca.key_custody)?;
307        if store.signs_remotely() {
308            tracing::debug!(
309                %organization_id,
310                %ca_id,
311                "no CRL is published for this CA: its key is held by a custodian that signs \
312                 certificate requests only (vault_pki), and publishes the CA's list itself"
313            );
314            return Err(not_published());
315        }
316
317        // Read on every request, outside the lock: a revocation is in the very
318        // next response, and a slow read does not hold up other CAs' lists.
319        let mut entries = self.cert_repo.list_revoked_by_issuer(ca.id).await?;
320        entries.extend(self.ca_repo.list_revoked_children(ca.id).await?);
321        entries.sort_by(|a, b| a.fingerprint.cmp(&b.fingerprint));
322        let digest = entries_digest(&entries);
323
324        let mut cache = self.cache.lock().await;
325        let last_number = match cache.get(&ca.id) {
326            Some(cached) if cached.entries_digest == digest && now < cached.refresh_at => {
327                return Ok(cached.crl.clone());
328            }
329            Some(cached) => Some(cached.crl.crl_number),
330            None => None,
331        };
332
333        // Whole seconds: a CRL's times are encoded to the second, and the
334        // `Last-Modified` header and the list must say the same thing.
335        let this_update = DateTime::from_timestamp(now.timestamp(), 0).unwrap_or(now);
336        let next_update = (this_update + self.next_update).min(ca.not_after);
337        if next_update <= this_update {
338            tracing::debug!(%organization_id, %ca_id, "no CRL is published: the CA expires now");
339            return Err(not_published());
340        }
341        let crl_number = u64::try_from(now.timestamp_millis())
342            .unwrap_or(0)
343            .max(last_number.map_or(0, |n| n.saturating_add(1)));
344
345        let key_ref = CaService::<CA>::key_ref(&ca);
346        let ca_key_pem = store
347            .load(&key_ref, ca.encrypted_private_key.as_deref())
348            .await?
349            .to_string();
350        let _permit = self
351            .crypto_semaphore
352            .acquire()
353            .await
354            .map_err(|_| AxiamError::Internal("crypto semaphore closed".into()))?;
355        let ca_cert_pem = ca.public_cert_pem.clone();
356        let der = tokio::task::spawn_blocking(move || {
357            sign_crl(
358                &ca_cert_pem,
359                ca_key_pem,
360                &entries,
361                this_update,
362                next_update,
363                crl_number,
364            )
365        })
366        .await
367        .map_err(|e| AxiamError::Internal(format!("spawn_blocking join error: {e}")))??;
368
369        let etag = format!("\"{}\"", hex::encode(&Sha256::digest(&der)[..16]));
370        let crl = PublishedCrl {
371            der: Arc::from(der),
372            this_update,
373            next_update,
374            crl_number,
375            etag,
376        };
377        cache.insert(
378            ca.id,
379            CachedCrl {
380                crl: crl.clone(),
381                entries_digest: digest,
382                refresh_at: this_update + (next_update - this_update) / 2,
383            },
384        );
385        Ok(crl)
386    }

388    /// Why `ca` publishes no list, if it does not — the reasons that need no
389    /// custodian to answer.
390    fn why_unpublished(ca: &CaCertificate, now: DateTime<Utc>) -> Option<&'static str> {
391        if ca.status != CertificateStatus::Active {
392            return Some("the CA is not active; its own status is on its parent's list");
393        }
394        if now < ca.not_before || now >= ca.not_after {
395            return Some("the CA is outside its validity window");
396        }
397        if ca.key_custody == CaKeyCustody::External {
398            return Some("AXIAM holds no key for this CA: it was imported as a trust anchor");
399        }
400        None
401    }
402}

404/// A digest that changes exactly when the list's entries would.
405fn entries_digest(entries: &[RevokedCertificate]) -> [u8; 32] {
406    let mut hasher = Sha256::new();
407    for entry in entries {
408        hasher.update(entry.fingerprint.as_bytes());
409        hasher.update(b":");
410        hasher.update(revocation_time(entry).timestamp().to_be_bytes());
411        hasher.update(b"\n");
412    }
413    hasher.finalize().into()
414}

416/// The date an entry states: when AXIAM recorded the revocation, or — for a
417/// certificate revoked before the date was kept — its own `notBefore`, the
418/// earliest moment anyone could have relied on it.
419fn revocation_time(entry: &RevokedCertificate) -> DateTime<Utc> {
420    entry.revoked_at.unwrap_or(entry.not_before)
421}
422
423fn to_offset(t: DateTime<Utc>) -> AxiamResult<time::OffsetDateTime> {
424    time::OffsetDateTime::from_unix_timestamp(t.timestamp())
425        .map_err(|e| AxiamError::Internal(format!("CRL time out of range: {e}")))
426}

428/// Sign a CRL over `entries` with the CA's key. Pure and blocking — the caller
429/// runs it under the crypto semaphore, off the async runtime.
430///
431/// A revoked certificate whose PEM does not parse fails the whole list rather
432/// than being left off it: a list that silently omits a revocation is worse
433/// than no list, because a relying party trusts what it says.
434pub(crate) fn sign_crl(
435    ca_cert_pem: &str,
436    mut ca_key_pem: String,
437    entries: &[RevokedCertificate],
438    this_update: DateTime<Utc>,
439    next_update: DateTime<Utc>,
440    crl_number: u64,
441) -> AxiamResult<Vec<u8>> {
442    let key_pair = KeyPair::from_pem(&ca_key_pem)
443        .map_err(|e| AxiamError::Certificate(format!("invalid CA private key: {e}")));
444    // Scrubbed as soon as it is parsed, as on the leaf path.
445    ca_key_pem.zeroize();
446    let key_pair = key_pair?;
447
448    // The authority key identifier must equal the CA certificate's subject key
449    // identifier, whatever method produced it — an imported CA's is usually a
450    // SHA-1 of its key, not rcgen's default — so it is read from the
451    // certificate rather than derived again.
452    let (_, ca_block) = x509_parser::pem::parse_x509_pem(ca_cert_pem.as_bytes())
453        .map_err(|e| AxiamError::Certificate(format!("invalid CA certificate PEM: {e}")))?;
454    let (_, ca_x509) = X509Certificate::from_der(&ca_block.contents)
455        .map_err(|e| AxiamError::Certificate(format!("invalid CA certificate: {e}")))?;
456    let key_identifier_method = ca_x509
457        .extensions()
458        .iter()
459        .find_map(|ext| match ext.parsed_extension() {
460            ParsedExtension::SubjectKeyIdentifier(kid) => Some(kid.0.to_vec()),
461            _ => None,
462        })
463        .map_or(KeyIdMethod::Sha256, KeyIdMethod::PreSpecified);
464
465    let issuer = Issuer::from_ca_cert_pem(ca_cert_pem, key_pair)
466        .map_err(|e| AxiamError::Certificate(format!("invalid CA certificate PEM: {e}")))?;
467
468    let revoked_certs = entries
469        .iter()
470        .map(|entry| {
471            let (_, block) = x509_parser::pem::parse_x509_pem(entry.public_cert_pem.as_bytes())
472                .map_err(|e| {
473                    AxiamError::Internal(format!(
474                        "revoked certificate {} is not PEM: {e}",
475                        entry.fingerprint
476                    ))
477                })?;
478            let (_, cert) = X509Certificate::from_der(&block.contents).map_err(|e| {
479                AxiamError::Internal(format!(
480                    "revoked certificate {} does not parse: {e}",
481                    entry.fingerprint
482                ))
483            })?;
484            Ok(RevokedCertParams {
485                serial_number: SerialNumber::from_slice(&cert.serial.to_bytes_be()),
486                revocation_time: to_offset(revocation_time(entry))?,
487                reason_code: None,
488                invalidity_date: None,
489            })
490        })
491        .collect::<AxiamResult<Vec<_>>>()?;
492
493    let params = CertificateRevocationListParams {
494        this_update: to_offset(this_update)?,
495        next_update: to_offset(next_update)?,
496        crl_number: SerialNumber::from(crl_number),
497        // A complete list: every certificate this CA signed, leaves and CAs.
498        issuing_distribution_point: None,
499        revoked_certs,
500        key_identifier_method,
501    };
502    let crl = params
503        .signed_by(&issuer)
504        .map_err(|e| AxiamError::Certificate(format!("CRL signing failed: {e}")))?;
505    Ok(crl.der().to_vec())
506}
